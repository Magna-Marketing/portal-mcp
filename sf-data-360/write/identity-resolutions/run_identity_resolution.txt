Tool: run_identity_resolution_ruleset_now

Description
Trigger an on-demand Identity Resolution run. Async; returns a
`runId` that's poll-able via the IR ruleset's main GET endpoint.

Salesforce API
Connect plane.

Endpoint
POST {instanceUrl}/services/data/v{ver}/ssot/identity-resolutions/:identityResolution/actions/run-now

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
{ "runMode": "Incremental" }

Input (parameters)
identityResolution (string, required) - Developer name or ID of the Identity Resolution Ruleset to run (required)
callingApp (string, required) - Identifier of the application initiating the run (required). Use 'Flow' when triggered
from a Salesforce Flow, or your app/integration name for auditability
callingAppInfo (string, required) - Additional metadata about the caller (required). Typically a version number, flow ID, or
reference context (e.g., '10')

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api` (or `cdp_identityresolution_api` for runtime).

Idempotency & limits
- Idempotent on `runIdempotencyKey`.
- 1 in-flight run per ruleset.
- A `Full` run on a 10M+ record graph can take 30-90 minutes.

Errors
- 404 NOT_FOUND, 409 JOB_IN_PROGRESS, 503 SOURCE_DMO_UNAVAILABLE.

Example request

run_identity_resolution_ruleset_now({
  "identityResolution": "",
  "callingApp": "",
  "callingAppInfo": ""
})

Example result

{ }
