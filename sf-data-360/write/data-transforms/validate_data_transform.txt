Tool: validate_data_transform

Description
Validate a Data Transform definition (SQL + target schema)
without persisting it. Useful for "compile-only" checks in CI/CD.

Salesforce API
Connect plane.

Endpoint
POST {instanceUrl}/services/data/v{ver}/ssot/data-transforms-validation

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
{
  "type": "Batch",
  "targetObject": "UnifiedIndividual__dlm",
  "sql": "SELECT Id__c, FirstName__c FROM Contact__dlm"
}

Input (parameters)
name (string, required) - Developer/API name of the data transform to validate (e.g. 'My_Transform'). No spaces.
type ("Batch" | "Streaming", required) - Execution type of the transform at the root payload level. " + "Use 'Batch' for STL
node-graph transforms. " + "This is SEPARATE from definition.type which must always be
'STL' — " + "both fields are required simultaneously.
definition (object, required) - Full transform definition object. " + "definition.type MUST be 'STL'. definition.version
should be '65.0'. " + "definition.nodes: object map of node keys (e.g. LOAD_DATASET0,
OUTPUT0) to node objects. " + "LOAD node: action='load', parameters.dataset={name,
type:'dataLakeObject'}, parameters.fields=[...], " +
"parameters.sampleDetails={sortBy:[], type:'TopN'}, sources=[]. " + "OUTPUT node:
action='outputD360', parameters.name, parameters.type='dataLakeObject', " +
"parameters.fieldsMappings=[{sourceField, targetField}], parameters.dedupOrder=[], " +
"parameters.writeMode='OVERWRITE'|'UPSERT', sources=['LOAD_DATASET0']. " +
"definition.outputDataObjects: array with category, label, name, type='dataLakeObject',
" + "fields=[{isPrimaryKey, label, name, type}] — use 'type' key (not 'dataType'), never
include 'id'.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only at the persistence layer; idempotent.

Errors
- 400 INVALID_QUERY (compile error returned in `errors[]`).

Example request

validate_data_transform({
  "name": "",
  "type": "",
  "definition": {}
})

Example result

{ }
