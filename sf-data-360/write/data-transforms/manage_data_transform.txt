Tool: manage_data_transform

Description
Create, update, or delete a Data Transform. Use PUT for replace-
update semantics (the v1 API doesn't expose PATCH on data
transforms).

Salesforce API
Connect plane.

Endpoint
POST {salesforceInstanceUrl}/services/data/v65.0/ssot/data-transforms
POST {salesforceInstanceUrl}/services/data/v65.0/ssot/data-transforms/{dataTransformNameOrId}
POST {salesforceInstanceUrl}/services/data/v65.0/ssot/data-transforms/{dataTransformNameOrId}/actions/run
PUT {salesforceInstanceUrl}/services/data/v65.0/ssot/data-transforms
PUT {salesforceInstanceUrl}/services/data/v65.0/ssot/data-transforms/{dataTransformNameOrId}
DELETE {salesforceInstanceUrl}/services/data/v65.0/ssot/data-transforms/{dataTransformNameOrId}

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body (create)
{
  "developerName": "build_unified_individual",
  "label": "Build Unified Individual",
  "type": "Batch",
  "targetObject": "UnifiedIndividual__dlm",
  "sql": "SELECT Id__c, FirstName__c FROM Contact__dlm",
  "schedule": { "scheduleType": "Cron", "cronExpression": "0 0 * * * ?" }
}

Input (parameters)
operation ("create" | "update" | "delete" | "run", required) - The operation to perform: create (POST), update (PUT), delete, or run (trigger
execution)
dataTransformNameOrId (string, optional) - Developer name or 18-character Salesforce ID. Required for update, delete, and run.
name (string, optional) - Developer/API name of the data transform (no spaces). Alias: developerName. Required for
create; cannot be changed after creation.
developerName (string, optional) - Alias for name — developer/API name of the data transform
label (string, optional) - Human-readable display label for the data transform. Required for create.
description (string, optional) - Human-readable description of what this data transform does
type ("Batch" | "Streaming", optional) - Execution type: Batch (bulk STL node-graph processing) or Streaming (real-time SQL
pipeline). Required for create.
schedule (object, optional) - Schedule configuration for automatic transform execution
operationType ("Full" | "Incremental", optional) - Execution mode for run operation: Full (re-process all data) or Incremental (process
only changes). Used with operation='run'.
primarySource (string, optional) - Primary input data source for the transform (used when the transformation contains table
joins)
dataSpaceName (string, optional) - Data Space this transform belongs to

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Hard delete; in-flight runs are aborted.

Errors
- 409 DUPLICATE_VALUE, 400 INVALID_QUERY (sql compile error),
  404 NOT_FOUND.

Example request

manage_data_transform({
  "operation": ""
})

Example result

{ }
