Tool: manage_dmo_relationship

Description
Create or delete a DMO-to-DMO relationship. Relationships unlock
Profile API child reads, Data Graph traversals, and Segment joins
across DMOs.

Salesforce API
Connect plane.

Endpoint
POST {salesforceInstanceUrl}/services/data/v65.0/{basePath}
Optional query: dataspace
DELETE {salesforceInstanceUrl}/services/data/v65.0/ssot/data-model-objects/relationships/{name}

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body (create)
{
  "name": "EngagementHistory",
  "label": "Engagement History",
  "fromField": "Id__c",
  "toDmo": "EngagementHistory__dlm",
  "toField": "IndividualId__c",
  "cardinality": "OneToMany"
}

Input (parameters)
operation ("create" | "delete", required) - The operation to perform: create or delete
dataModelObjectName (string, optional) - Name of the data model object (DMO), either the source DMO or the target DMO. Required
for create and delete.
dataspace (string, optional) - Name of the data space. If unspecified, the default data space is used. Applies to
create only.
relationships (object[], optional) - List of field source target relationships to be created. Required for create. Each entry
must specify sourceObjectName, targetObjectName, sourceFieldName, and targetFieldName.
name (string, optional) - Auto-generated relationship name returned by Salesforce. Required for delete.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Hard delete; existing Data Graphs / Segments referencing the
  relationship break.

Errors
- 409 DUPLICATE_VALUE, 404 NOT_FOUND, 400 INVALID_FIELD.

Example request

manage_dmo_relationship({
  "operation": ""
})

Example result

{ }
