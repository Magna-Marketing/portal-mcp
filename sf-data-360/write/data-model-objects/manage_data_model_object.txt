Tool: manage_data_model_object

Description
Create, update, or delete a Data Model Object. Standard DMOs
(provided by Data Cloud / packaged Data Kits) cannot be deleted;
only Custom DMOs are removable.

Salesforce API
Connect plane.

Endpoint
POST   {instanceUrl}/services/data/v{ver}/ssot/data-model-objects                          (operation="create")
PATCH  {instanceUrl}/services/data/v{ver}/ssot/data-model-objects/:dataModelObjectName     (operation="update")
DELETE {instanceUrl}/services/data/v{ver}/ssot/data-model-objects/:dataModelObjectName     (operation="delete")

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body (create)
{
  "developerName": "ExtOrder__dlm",
  "label": "External Order",
  "category": "Engagement",
  "primaryKeyField": "Id__c",
  "fields": [
    { "apiName": "Id__c",        "dataType": "TEXT",     "isPrimaryKey": true },
    { "apiName": "Amount__c",    "dataType": "DECIMAL" },
    { "apiName": "OrderDate__c", "dataType": "DATE_TIME" }
  ]
}

Input (parameters)
operation ("create" | "update" | "delete", required) - The operation to perform: create, update, or delete
dataModelObjectName (string, optional) - API name of the existing DMO. Required for update and delete.
name (string, optional) - API name of the object to create. Required for create.
label (string, optional) - Label of the object to create. Required for create.
description (string, optional) - Description of the object to create.
dataSpaceName (string, optional) - Name of the data space. If unspecified, the default data space is used. Required for
data graph resources.
category ("Engagement" | "Other" | "Profile", optional) - Category of the data object: Engagement, Other, or Profile.
eventDateTimeFieldName (string, optional) - Name of the event date and time field. Required when category is 'Engagement'.
recordModifiedFieldName (string, optional) - Record modified field name.
type ("DataLakeObject" | "DataModelObject", optional) - Type of data object: DataLakeObject or DataModelObject.
status ("Active" | "Error" | "Inactive" | "Processing", optional) - Status of the DMO: Active, Error, Inactive, or Processing.
primaryKeyField (string, optional) - API name of the field designated as the primary key. Required for create.
fields (object[], optional) - Fields in the data object. Required for create.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Standard DMOs error on `delete` with `409 STANDARD_DMO_PROTECTED`.
- Removing a field on update fails if any mapping uses it; remove
  the mapping first.

Errors
- 409 DUPLICATE_VALUE, 409 STANDARD_DMO_PROTECTED, 400 INVALID_FIELD,
  404 NOT_FOUND.

Example request

manage_data_model_object({
  "operation": ""
})

Example result

{ }
