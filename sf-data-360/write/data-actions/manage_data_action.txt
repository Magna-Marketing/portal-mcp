Tool: manage_data_action

Description
Create a Data Action. The Postman collection only exposes
`Create` on data actions — to update or delete, use the runtime
Connect plane via the standard Data 360 metadata APIs.

Salesforce API
Connect plane.

Endpoint
POST {instanceUrl}/services/data/v{ver}/ssot/data-actions

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
{
  "apiName": "ltv_threshold_alert",
  "label": "LTV Threshold Alert",
  "sourceDmo": "UnifiedIndividual__dlm",
  "eventType": "DmoUpdate",
  "condition": {
    "rootGroup": "AND",
    "conditions": [{ "field": "LifetimeValue__c", "op": "gte", "value": 10000 }]
  },
  "targetApiName": "WebhookTarget__dat",
  "payloadTemplate": "{\"individualId\":\"{{Id__c}}\",\"ltv\":{{LifetimeValue__c}}}"
}

Input (parameters)
apiName (string, required) - API name for the data action
label (string, required) - Display label for the data action
sourceDmo (string, required) - API name of the source Data Model Object that triggers this action
eventType ("DmoInsert" | "DmoUpdate" | "DmoDelete" | "Calculated", required) - Type of event that triggers the action: DmoInsert, DmoUpdate, DmoDelete, or Calculated
targetApiName (string, required) - API name of the data action target to send the payload to
payloadTemplate (string, required) - Template defining the payload structure sent to the target. Supports merge fields from
the source DMO
condition (string, optional) - Optional condition expression that must be met for the action to fire

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Idempotent on `apiName`.

Errors
- 409 DUPLICATE_VALUE, 404 NOT_FOUND (target), 400 INVALID_TEMPLATE.

Example request

manage_data_action({
  "apiName": "",
  "label": "",
  "sourceDmo": "",
  "eventType": "",
  "targetApiName": "",
  "payloadTemplate": ""
})

Example result

{ }
