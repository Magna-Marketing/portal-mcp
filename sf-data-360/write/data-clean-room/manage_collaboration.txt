Tool: manage_dcr_collaboration

Description
Create a new Data Clean Room collaboration with a partner. Only the
"create" operation is exposed — accepting / rejecting incoming
invitations is in `respond_collaboration_invitation`. To end an
active collaboration use the Data Cloud Setup UI.

Salesforce API
Connect plane.

Endpoint
POST {instanceUrl}/services/data/v{ver}/ssot/data-clean-room/collaborations

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
{
  "apiName": "MTG_PartnerX",
  "label": "MTG ↔ Partner X",
  "providerIdOrName": "MTG_Snowflake_DCR",
  "partnerOrgIdentifier": "ORG_PARTNER_X",
  "sharedDmos": ["UnifiedIndividual__dlm"],
  "specifications": ["PartnerX_OverlapSpec"]
}

Input (parameters)
operation ("create", required) - The operation to perform. Currently only 'create' is supported.
apiName (string, required) - Unique developer/API name for the collaboration, e.g. 'MTG_PartnerX'.
label (string, required) - Human-readable label for the collaboration.
providerIdOrName (string, required) - ID or developer name of the registered DCR provider to use for this collaboration.
partnerOrgIdentifier (string, required) - Identifier the partner uses on their side (account name, org ID, etc.).
sharedDmos (string[], required) - Array of DMO API names whose data may participate in the collaboration, e.g.
['UnifiedIndividual__dlm'].
specifications (string[], optional) - Array of pre-approved query specification API names to attach to this collaboration.
description (string, optional) - Optional description of the collaboration purpose.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Idempotent on `apiName`.

Errors
- 409 DUPLICATE_VALUE, 400 INVALID_PROVIDER, 404 NOT_FOUND
  (specification).

Example request

manage_dcr_collaboration({
  "operation": "",
  "apiName": "",
  "label": "",
  "providerIdOrName": "",
  "partnerOrgIdentifier": "",
  "sharedDmos": []
})

Example result

{ }
