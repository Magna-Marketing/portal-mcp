Tool: manage_dcr_specification

Description
Create a Data Clean Room specification — a binding of a provider +
template + output target. Postman exposes only `Create`.

Salesforce API
Connect plane.

Endpoint
POST {salesforceInstanceUrl}/services/data/v65.0/ssot/data-clean-room/specifications
DELETE {salesforceInstanceUrl}/services/data/v65.0/ssot/data-clean-room/specifications/{specificationIdOrApiName}

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
{
  "apiName": "PartnerX_OverlapSpec",
  "label": "Partner X overlap (audience minimum 1000)",
  "providerIdOrName": "MTG_Snowflake_DCR",
  "templateApiName": "OverlapAudience",
  "parameters": { "minOverlapCount": 1000 },
  "outputDmoApiName": "PartnerXOverlap__dlm"
}

Input (parameters)
operation ("create" | "delete", required) - The operation to perform: 'create' or 'delete'.
specificationIdOrApiName (string, optional) - ID or API name of the specification. Required for delete.
apiName (string, optional) - Unique developer/API name for the specification. Required for create.
label (string, optional) - Human-readable label for the specification. Required for create.
providerIdOrName (string, optional) - ID or developer name of the DCR provider. Required for create.
templateApiName (string, optional) - API name of the query template to bind. Required for create.
parameters (object, optional) - Default parameter map for the template (e.g., { minOverlapCount: 1000 }). Required for
create.
outputDmoApiName (string, optional) - API name of the DMO where query results will be materialized.
description (string, optional) - Optional description of the specification.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Idempotent on `apiName`.

Errors
- 409 DUPLICATE_VALUE, 404 NOT_FOUND (provider or template).

Example request

manage_dcr_specification({
  "operation": ""
})

Example result

{ }
