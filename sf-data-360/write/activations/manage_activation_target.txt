Tool: manage_activation_target

Description
Create or update an Activation Target. Targets reference an
External Platform + a target-specific config (Data Extension key,
S3 bucket prefix, etc.).

Salesforce API
Connect plane.

Endpoint
POST  {instanceUrl}/services/data/v{ver}/ssot/activation-targets                              (operation="create")
PATCH {instanceUrl}/services/data/v{ver}/ssot/activation-targets/:activationTargetId          (operation="update")

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body (create)
{
  "name": "MTG_MCE_DE_EMEA",
  "label": "MCE DE EMEA",
  "targetType": "MarketingCloudEngagement",
  "externalPlatformName": "MTG_MCE_Default",
  "targetConfig": {
    "dataExtensionExternalKey": "DE_EMEA_HIGH_VALUE",
    "memberId": 5001234
  }
}

Input (parameters)
operation ("create" | "update", required) - The operation to perform: create or update
activationTargetId (string, optional) - Unique identifier of the activation target. Required for update.
dataSpaceName (string, optional) - Data space name (usually 'default'). Required for create.
name (string, optional) - Name of the activation target. Required for create.
description (string, optional) - Description for the activation target
platformType ("AmazonS3" | "AzureBlob" | "DataCloud" | "ExternalPlatform" | "GoogleCloudStorage" | "SalesforceMarketingCloud" | "Sftp", optional) - Platform type. Required for create.
isCappingEnabled (boolean, optional) - Whether communication capping is enabled
connector (object, optional) - Connector configuration. Properties vary by platformType. For AmazonS3: { name,
outputFormat, bucketName, folderName, accessKey, secretKey }. Required for create.
egressProperties (object, optional) - Egress properties for file-based targets (AmazonS3, AzureBlob, GoogleCloudStorage, Sftp)

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Idempotent on `name` for create.

Errors
- 409 DUPLICATE_VALUE, 404 NOT_FOUND, 400 INVALID_TARGET_CONFIG.

Example request

manage_activation_target({
  "operation": ""
})

Example result

{ }
