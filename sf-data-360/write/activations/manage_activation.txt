Tool: manage_activation

Description
Create, update, or delete an Activation. Activation maps a Segment
to an Activation Target with field-level mapping rules.

Salesforce API
Connect plane.

Endpoint
PUT {salesforceInstanceUrl}/services/data/v65.0/ssot/activations/{activationId}
DELETE {salesforceInstanceUrl}/services/data/v65.0/ssot/activations/{activationId}

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body (create)
{
  "apiName": "EMEA_to_MC",
  "label": "EMEA High-value -> MC Engagement",
  "segmentId": "0YS580000000001",
  "activationTargetId": "0YT580000000001",
  "schedule": { "scheduleType": "Cron", "cronExpression": "0 0 6 * * ?" },
  "contactPoints": [
    { "apiName": "Email",     "sourceField": "EmailAddress__c" },
    { "apiName": "FirstName", "sourceField": "FirstName__c" }
  ]
}

Input (parameters)
operation ("update" | "delete", required) - The operation to perform. " + ""update" — PUT updated fields to an existing activation
(requires activationId). " + ""delete" — permanently delete an activation (requires
activationId). " + "To create a new activation use write.create_activation.
activationId (string, optional) - Unique 18-char Salesforce ID of the activation to update or delete. Required. " +
"Example: "85RgL00000025YHUAY"
name (string, optional) - Updated developer/API name
description (string, optional) - Updated human-readable description
dataSpaceName (string, optional) - Updated data space name
refreshType ("FULL_REFRESH" | "INCREMENTAL", optional) - Updated refresh type
activationTargetName (string, optional) - Updated activation target name
segmentApiName (string, optional) - Updated segment API name
marketSegmentId (string, optional) - Updated segment ID
activationTargetSubjectConfig (string, optional) - Updated root DMO config
attributesConfig (object[], optional) - Updated output attributes config
shouldExcludeDeletes (boolean, optional)
shouldExcludeUpdates (boolean, optional)
staticDataConfig (string[], optional)

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Hard delete; in-flight publishes are aborted.

Errors
- 409 DUPLICATE_VALUE, 400 MISSING_CONTACT_POINTS, 404 NOT_FOUND.

Example request

manage_activation({
  "operation": ""
})

Example result

{ }
