Tool: publish_activation

Description
Publish (run) a Batch DMO Activation — pushes the latest segment
snapshot to the configured target. Async; returns a `runId`.

Salesforce API
Connect plane.

Endpoint
POST {salesforceInstanceUrl}/services/data/v66.0/ssot/activations/{activationId}/actions/publish

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
POST: fullRefresh

Input (parameters)
activationId (string, required) - Unique identifier of the activation to publish (market segment activation ID or
developer name). Required.
fullRefresh (boolean, optional) - true = full refresh (re-sends all records); false = incremental (only new/changed).
Defaults to false.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Idempotent on `runIdempotencyKey`.
- 1 in-flight publish per activation.

Errors
- 404 NOT_FOUND, 409 JOB_IN_PROGRESS, 503 TARGET_UNAVAILABLE.

Example request

publish_activation({
  "activationId": ""
})

Example result

{ }
