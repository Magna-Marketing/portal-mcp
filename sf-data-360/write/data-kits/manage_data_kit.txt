Tool: manage_data_kit

Description
Create, update components in, or delete a Data Kit. Update only
manages the **components** list (which assets the kit packages);
the kit's metadata (label, description) is set at create time.

Salesforce API
Connect plane.

Endpoint
POST   {instanceUrl}/services/data/v{ver}/ssot/data-kits                           (operation="create")
PATCH  {instanceUrl}/services/data/v{ver}/ssot/data-kits/:dataKitDevName           (operation="updateComponents")
DELETE {instanceUrl}/services/data/v{ver}/ssot/data-kits/:dataKitDevName           (operation="delete")

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
POST: components
PATCH: components

Input (parameters)
operation ("create" | "updateComponents" | "delete", required) - The operation to perform: create, updateComponents, or delete.
dataKitDevName (string, optional) - Developer/API name of the data kit. Required for all operations.
label (string, optional) - Human-readable label for the data kit. Required for create.
description (string, optional) - Description of the data kit.
components (object[], optional) - Array of components to include in the data kit. Required for create and
updateComponents.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Hard delete. Components themselves remain in the org; only the
  Data Kit packaging is removed.

Errors
- 409 DUPLICATE_VALUE, 400 INVALID_COMPONENT, 404 NOT_FOUND.

Example request

manage_data_kit({
  "operation": ""
})

Example result

{ }
