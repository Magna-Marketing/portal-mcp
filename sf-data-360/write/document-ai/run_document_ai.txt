Tool: run_document_ai

Description
Trigger a Document AI processing run for a configuration. Async;
the platform processes pending documents (or a supplied batch) and
ingests the extracted records into the target DMO.

Salesforce API
Connect plane.

Endpoint
POST {instanceUrl}/services/data/v{ver}/ssot/document-processing/configurations/:idOrApiName/actions/run

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
{
  "documentRefs": ["s3://magnatech-docs/invoices/2026-04/"],
  "runMode": "Batch"
}

Input (parameters)
idOrApiName (string, required) - Configuration ID or API name to run
runMode ("Batch" | "OnDemand", required) - Execution mode: 'Batch' for scheduled processing, 'OnDemand' for immediate
documentRefs (string[], optional) - Array of document references (e.g., ContentVersion IDs) to process.
runIdempotencyKey (string, optional) - Idempotency key to prevent duplicate runs.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Idempotent on `runIdempotencyKey`.
- Subject to org-level Document AI quota.

Errors
- 404 NOT_FOUND, 409 JOB_IN_PROGRESS, 400 INVALID_DOCUMENT_REFS.

Example request

run_document_ai({
  "idOrApiName": "",
  "runMode": ""
})

Example result

{ }
