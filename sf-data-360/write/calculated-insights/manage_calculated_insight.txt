Tool: manage_calculated_insight

Description
Create, update, or delete a Calculated Insight definition.

Salesforce API
Connect plane.

Endpoint
POST   {instanceUrl}/services/data/v{ver}/ssot/calculated-insights              (operation="create")
PATCH  {instanceUrl}/services/data/v{ver}/ssot/calculated-insights/:apiName     (operation="update")
DELETE {instanceUrl}/services/data/v{ver}/ssot/calculated-insights/:apiName     (operation="delete")

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body (create)
{
  "apiName": "CustomerLTV__cio",
  "label": "Customer LTV",
  "dataSpace": "default",
  "refreshFrequency": "Daily",
  "sql": "SELECT IndividualId__c, SUM(Amount__c) AS LifetimeValue__c FROM Order__dlm GROUP BY IndividualId__c",
  "measures": [
    { "apiName": "LifetimeValue__c", "label": "Lifetime Value", "dataType": "DECIMAL", "aggregation": "SUM" }
  ],
  "dimensions": [
    { "apiName": "IndividualId__c", "label": "Individual",     "dataType": "TEXT" }
  ]
}

Input (parameters)
operation ("create" | "update" | "delete", required) - The operation to perform: create, update, or delete
apiName (string, required) - API name of the calculated insight. Used as the identifier for update/delete and as the
name for create. Note: Salesforce appends '__cio' to the name on creation.
definitionType ("CALCULATED_METRIC" | "EXTERNAL_METRIC" | "STREAMING_METRIC", optional) - Type of calculated insight definition. Required for create. CALCULATED_METRIC is the
standard type for SQL-based insights.
displayName (string, optional) - Human-readable display label for the calculated insight
dataSpaceName (string, optional) - Data space name for the calculated insight (e.g. 'default')
description (string, optional) - Optional description of what the calculated insight measures
expression (string, optional) - SQL SELECT query that defines the calculated insight logic. Measures and dimensions are
derived automatically by Salesforce from this expression.
publishScheduleInterval ("One" | "Six" | "Twelve" | "TwentyFour" | "NotScheduled" | "ExternallyManaged" | "Streaming" | "SystemManaged", optional) - How often the calculated insight is published. One=hourly, Six=every 6h, Twelve=every
12h, TwentyFour=daily, NotScheduled=paused.
publishScheduleStartDateTime (string, optional) - ISO 8601 datetime when the publish schedule starts, e.g. '2025-12-11T12:00'. Required
when setting a publishScheduleInterval.
publishScheduleEndDate (string, optional) - Date when the publish schedule ends, e.g. '2026-12-31'. Omit or set to null for no end
date.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Hard delete; downstream segments referencing the CI break.

Errors
- 409 DUPLICATE_VALUE, 400 INVALID_QUERY (sql), 404 NOT_FOUND.

Example request

manage_calculated_insight({
  "operation": "",
  "apiName": ""
})

Example result

{ }
