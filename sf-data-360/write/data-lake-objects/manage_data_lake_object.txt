Tool: manage_data_lake_object

Description
Create, update, or delete a Data Lake Object. Most DLOs are
implicitly created by Data Streams; this tool is needed only for
ad-hoc / external DLOs (e.g. when ingesting via the Streaming or
Bulk Ingestion API directly to a DLO without a Data Stream
wrapper).

Salesforce API
Connect plane.

Endpoint
POST   {instanceUrl}/services/data/v{ver}/ssot/data-lake-objects                                (operation="create")
PATCH  {instanceUrl}/services/data/v{ver}/ssot/data-lake-objects/:recordIdOrDeveloperName       (operation="update")
DELETE {instanceUrl}/services/data/v{ver}/ssot/data-lake-objects/:recordIdOrDeveloperName       (operation="delete")

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body (create)
{
  "developerName": "ext_orders__dll",
  "label": "External Orders",
  "category": "Engagement",
  "fields": [
    { "apiName": "Id__c",        "dataType": "TEXT", "isPrimaryKey": true },
    { "apiName": "Amount__c",    "dataType": "DECIMAL" },
    { "apiName": "OrderDate__c", "dataType": "DATE_TIME" }
  ]
}

Input (parameters)
operation ("create" | "update" | "delete", required) - The operation to perform: create, update, or delete.
recordIdOrDeveloperName (string, optional) - Record ID or developer name (with __dll suffix) of the DLO. Required for update and
delete.
developerName (string, optional) - Developer name of the DLO (e.g., 'ext_orders__dll'). Required for create.
label (string, optional) - Human-readable display label for the DLO. Required for create.
category ("Profile" | "Engagement" | "Other", optional) - Category of the DLO: Profile, Engagement, or Other. Defaults to Other if not specified.
eventDatetimeFieldName (string, optional) - API name of the DateTime field to use as the Event Date Time field. Required when
category is 'Engagement' and the designated field is of type DateTime (e.g.,
'OrderDate__c').
eventDateFieldName (string, optional) - API name of the Date field to use as the Event Date field. Required when category is
'Engagement' and the designated field is of type Date.
fields (object[], optional) - Field definitions for the DLO. Required for create. Each field needs apiName, dataType,
and isPrimaryKey.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Hard delete; downstream DMO mappings break.

Errors
- 409 DUPLICATE_VALUE, 400 INVALID_FIELD, 404 NOT_FOUND.

Example request

manage_data_lake_object({
  "operation": ""
})

Example result

{ }
