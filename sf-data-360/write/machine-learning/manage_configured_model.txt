Tool: manage_configured_model

Description
Update or delete a Configured Model. The Postman collection only
exposes `Update` and `Delete` (no Create — register new models via
Einstein Studio / BYOM in Setup; this tool reflects that scope).

Salesforce API
Connect plane.

Endpoint
PATCH {salesforceInstanceUrl}/services/data/v65.0/ssot/machine-learning/{configuredModelIdOrName}
DELETE {salesforceInstanceUrl}/services/data/v65.0/ssot/machine-learning/{configuredModelIdOrName}

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body (update)
{
  "label": "Churn Predictor (production)",
  "status": "Active",
  "modelArtifactId": "MA_001"
}

Input (parameters)
operation ("update" | "delete", required) - The operation to perform: update or delete
configuredModelIdOrName (string, required) - Configured model ID or API name
label (string, optional) - Updated display label for the configured model.
status ("Active" | "Draft" | "Failed", optional) - Updated status of the configured model.
modelArtifactId (string, optional) - ID of the model artifact to associate.
inputSchema (object, optional) - Input schema definition for the model.
outputSchema (object, optional) - Output schema definition for the model.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Hard delete; `predict` calls referencing the model fail
  immediately.

Errors
- 404 NOT_FOUND, 409 ARTIFACT_INCOMPATIBLE.

Example request

manage_configured_model({
  "operation": "",
  "configuredModelIdOrName": ""
})

Example result

{ }
