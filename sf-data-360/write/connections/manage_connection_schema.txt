Tool: manage_connection_schema

Description
Upsert the cached schema (object + field definitions) on a
Connection. Typically called after a `run_connection_action
command="discover-schema"` to persist what was discovered.

Salesforce API
Connect plane.

Endpoint
PUT {instanceUrl}/services/data/v{ver}/ssot/connections/:connectionId/schema

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
PUT: objects

Input (parameters)
connectionId (string, required) - ID of the connection to update the schema for
objects (object[], required) - Array of schema objects, each with name, label, and fields array. Fields have apiName,
dataType, isPrimaryKey, isExternalId, isRequired

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Idempotent on object/field name. Fields not included in the new
  payload are removed.

Errors
- 404 NOT_FOUND, 400 INVALID_FIELD (unknown dataType).

Example request

manage_connection_schema({
  "connectionId": "",
  "objects": []
})

Example result

{ }
