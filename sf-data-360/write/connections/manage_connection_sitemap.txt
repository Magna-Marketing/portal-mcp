Tool: manage_connection_sitemap

Description
Upsert the site map (curated path / bucket / folder list) on a
file-based Connection. Replaces the existing site map.

Salesforce API
Connect plane.

Endpoint
PUT {instanceUrl}/services/data/v{ver}/ssot/connections/:connectionId/sitemap

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
PUT: paths

Input (parameters)
connectionId (string, required) - ID of the connection to update the sitemap for
paths (object[], required) - Array of path objects, each with path, type ('Bucket'|'Prefix'|'File'|'Folder'), and
optional label, includeRecursive, fileFormat

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Idempotent on (path, type) pair.

Errors
- 404 NOT_FOUND, 400 INVALID_CONNECTOR_TYPE.

Example request

manage_connection_sitemap({
  "connectionId": "",
  "paths": []
})

Example result

{ }
