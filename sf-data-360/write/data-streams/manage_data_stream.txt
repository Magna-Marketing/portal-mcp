Tool: manage_data_stream

Description
Create, update, or delete a Data Stream. Create resolves the source
Connection's schema and produces a Data Lake Object; the DLO must
then be mapped to a DMO before downstream consumers see data.

Salesforce API
Connect plane.

Endpoint
POST {salesforceInstanceUrl}/services/data/v65.0/ssot/data-streams
Optional query: dataspaceName
PATCH {salesforceInstanceUrl}/services/data/v65.0/ssot/data-streams/{recordIdOrDeveloperName}
DELETE {salesforceInstanceUrl}/services/data/v65.0/ssot/data-streams/{recordIdOrDeveloperName}

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body (create)
{
  "developerName": "mc_sends",
  "label": "MCE Sends",
  "connectionId": "0Z65800000000ABCAA",
  "sourceObject": "Send",
  "refreshMode": "Incremental",
  "category": "Engagement",
  "schedule": {
    "scheduleType": "INTERVAL",
    "intervalMinutes": 60
  },
  "primaryKeyFields": ["ID"],
  "lastModifiedFieldName": "ModifiedDate",
  "filter": null
}

Input (parameters)
operation ("create" | "update" | "delete", required) - The operation to perform: create, update, or delete
recordIdOrDeveloperName (string, optional) - 18-character Salesforce record ID or stream name. Required for update and delete.

Result
Raw Salesforce response JSON, returned unchanged.
_debug (value) - included in the JSON returned by the tool.
url (value) - included in the JSON returned by the tool.
resolutionDebug (value) - included in the JSON returned by the tool.
requestBody (value) - included in the JSON returned by the tool.

Required scopes
- `api`.

Idempotency & limits
- Hard delete; running jobs are aborted.
- Creating an Incremental stream without `primaryKeyFields` returns
  `400 MISSING_PRIMARY_KEY`.

Errors
- 400 INVALID_FIELD, 404 NOT_FOUND, 409 DUPLICATE_VALUE,
  502 SOURCE_UNAVAILABLE.

Example request

manage_data_stream({
  "operation": ""
})

Example result

{ }
