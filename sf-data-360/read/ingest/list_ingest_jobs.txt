Tool: list_ingest_jobs

Description
List Bulk Ingestion jobs (runtime plane). Each job moves through
`Open → UploadComplete → JobComplete` (or `Failed | Aborted`).

Salesforce API
Runtime plane.

Endpoint
GET {instanceUrl}/api/v1/ingest/jobs
Optional query: states, limit, offset, orderBy

Headers
Authorization: Bearer <data_cloud_token>
Accept: application/json

Body
None.

Input (parameters)
limit (number, optional) - Maximum number of jobs to return, from 1 through 100. Salesforce defaults to 20 when
omitted.
offset (number, optional) - Number of jobs to skip before returning results.
orderBy (string, optional) - Field used by Salesforce to order job results. Salesforce defaults to systemModstamp
when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `cdp_ingest_api`.

Idempotency & limits
- Read-only.

Errors
- 401 invalid_token.

Example request

list_ingest_jobs({})

Example result

{ }
