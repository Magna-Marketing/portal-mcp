Tool: list_data_action_targets

Description
List Data Action Targets — the destinations a Data Action can fire
to (Webhook, MuleSoft endpoint, AWS Lambda, etc.).

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-action-targets
Optional query: batchSize, offset, orderby

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
batchSize (number, optional) - Number of data action targets to return. Salesforce controls the default when omitted.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderby (string, optional) - Field sort expression for the result set, for example 'apiName ASC' or 'label DESC'.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_data_action_targets({})

Example result

{ }
