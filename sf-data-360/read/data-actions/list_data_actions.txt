Tool: list_data_actions

Description
List Data Actions — declarative rules that fire payloads to a
Data Action Target when a Data Cloud event matches a condition.
Used for low-latency triggered orchestration (e.g. send a webhook
when LTV crosses a threshold).

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-actions
Optional query: batchSize, dataspace, offset, orderby

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
batchSize (number, optional) - Number of data actions to return. Salesforce controls the default when omitted.
dataspace (string, optional) - Data 360 data space from which to return data actions, for example 'default'.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderby (string, optional) - Field sort expression for the result set, for example 'developerName ASC' or
'dataActionStatus DESC'.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_data_actions({})

Example result
