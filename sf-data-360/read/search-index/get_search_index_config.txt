Tool: get_search_index_config

Description

models, retrieval settings, and quotas.

Salesforce API
Connect plane.

Endpoint

Headers

Accept: application/json

Body
None.

Input (parameters)
None.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits

Errors
