Tool: get_identity_resolution

Description
Read a single Identity Resolution ruleset by id or api name. Returns
the full match + reconciliation rules and run history.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/identity-resolutions/{identityResolutionId}

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
identityResolutionId (string, required) - Unique Salesforce ID of the Identity Resolution ruleset, such as '1ir1Q0000004CKHQA2'.

Result
Raw Salesforce response JSON, returned unchanged.
Note returned with the JSON: Note: It is not possible to retrieve details about an identity resolution ruleset’s
processing history. Whereas Data Transforms do have a dedicated /run-history API, the
Identity Resolution API does not provide an endpoint to retrieve Identity Resolution
Ruleset’s Processing History.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_identity_resolution({
  "identityResolutionId": ""
})

Example result

{ }
