Tool: get_data_stream

Description
Read a single Data Stream by id or developer name. Returns the
full configuration: source mapping rules, schedule, filter, and
metadata.

Salesforce API
Connect plane.

Endpoint
GET {instanceUrl}/services/data/v{ver}/ssot/data-streams/:recordIdOrDeveloperName

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
recordIdOrDeveloperName (string, required).

Result
Raw Salesforce response JSON, returned unchanged.
Note returned with the JSON: Note: It is not possible to retrieve details about a data stream's run history. Whereas
Data Transforms do have a dedicated /run-history API, the Data Stream API does not
provide an endpoint to retrieve Data Stream run history.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_data_stream({ "recordIdOrDeveloperName": "mc_sends" })

Example result

{ }
