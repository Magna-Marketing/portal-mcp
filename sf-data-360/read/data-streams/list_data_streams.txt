Tool: list_data_streams

Description
List Data Streams — the configured pipelines that ingest from a
source Connection into a Data Lake Object (and downstream into
DMOs via mappings). Each Data Stream has a refresh mode, schedule,
and last-run status.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-streams
Optional query: connectionName, filter, includeMappings, limit, offset, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
connectionName (string, optional) - Name of the data stream connection to filter by.
filter (string, optional) - Filter for a narrower result set, such as connector type filters 'MC' or 'SFDC'.
includeMappings (unknown, required)
limit (number, optional) - Maximum number of rows to return, from 1 through 200. Salesforce defaults to 10 when
omitted.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderBy (string, optional) - Sort order for the result set. Salesforce supports ordering by fields such as Id,
DataConnectorId, DataConnectorType, DataSourceId, or DeveloperName.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_data_streams({
  "includeMappings": ""
})

Example result

{ }
