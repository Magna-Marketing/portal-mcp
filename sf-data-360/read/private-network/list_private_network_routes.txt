Tool: list_private_network_routes

Description
List Private Network Routes — VPC / PrivateLink / private-DNS
routes that allow Data 360 to reach customer-controlled networks
(VPC-private databases, on-prem APIs, private S3 endpoints).

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/private-network-routes
Optional query: limit, offset

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
limit (number, optional) - Maximum number of private network routes to return, from 1 through 1000. Salesforce
returns 100 rows when omitted.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips 0 rows when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_private_network_routes({})

Example result

{ }
