Tool: list_provider_templates

Description
List the query templates available for a Data Clean Room provider.
Templates are pre-approved SQL shapes that can be parameterized
and run inside a collaboration.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-clean-room/providers/{providerIdOrName}/templates
Optional query: filters, limit, offset, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
providerIdOrName (string, required) - Data Clean Room provider ID or developer name whose templates should be listed.
filters (string, optional) - Salesforce filter expression as a comma-separated list of equality expressions, such as
'developerName eq MyCleanRoom'. No filter is applied when omitted.
limit (number, optional) - Maximum number of records to return, from 1 through 20. Salesforce defaults to 20 when
omitted.
offset (number, optional) - Number of records to skip before returning results. Salesforce skips no rows when
omitted.
orderBy (string, optional) - Sort order for the result set. Specify a field and ASC or DESC, such as 'createdDate
DESC'. Salesforce returns items in retrieval order when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

list_provider_templates({
  "providerIdOrName": ""
})

Example result

{ }
