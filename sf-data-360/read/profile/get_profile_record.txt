Tool: get_profile_record

Description
Read one or more profile records from a DMO. Unifies the various
Postman read patterns under `lookupBy`:

- `id` (default) - Read by primary-key value.
- `searchKey` - Read by a configured searchable key (e.g.
  `EmailAddress__c`, `PhoneNumber__c`).
- `withChildren` - Read by id and expand a related child DMO via
  the relationship name.
- `withCalculatedInsight` - Read by id and join in a CIO's measures.

Optionally projects fields and expands related records via
`relationships`.

Salesforce API
Runtime plane.

Endpoint
GET {instanceUrl}/api/v1/profile/{dmoApiName}
Optional query: fields, filters, limit, offset, orderby
(lookupBy=list)

GET {instanceUrl}/api/v1/profile/{dmoApiName}/{recordId}
Optional query: fields
(lookupBy=id, the default)

GET {instanceUrl}/api/v1/profile/{dmoApiName}/{recordId}
Optional query: fields, searchkey
(lookupBy=searchKey). searchkey is the field name; recordId is the key value. There is no :searchKey path segment.

GET {instanceUrl}/api/v1/profile/{dmoApiName}/{recordId}/{childDmoApiName}
Optional query: fields, filters, limit, offset, orderby, searchkey
(lookupBy=withChildren)

GET {instanceUrl}/api/v1/profile/{dmoApiName}/{recordId}/calculated-insights/{calculatedInsightName}
Optional query: fields
(lookupBy=withCalculatedInsight)

Headers
Authorization: Bearer <data_cloud_token>
Accept: application/json

Body
None.

Input (parameters)
dmoApiName (string, required) - Profile DMO API name, for example `ssot__Individual__dlm` or `Individual__dlm`.
lookupBy ("list" | "id" | "searchKey" | "withChildren" | "withCalculatedInsight", optional) - `list` calls /profile/{dataModelName}; `id` calls /profile/{dataModelName}/{Id};
`searchKey` also sends `searchkey`; `withChildren` calls the child DMO endpoint;
`withCalculatedInsight` calls the calculated insights endpoint.
recordId (string, optional) - Record identifier path value. For `id`, this is the primary key value. For `searchKey`,
this is the secondary key value.
searchKey (string, optional) - Secondary key field name sent as Salesforce query parameter `searchkey`, for example
`Email__c`.
childDmoApiName (string, optional) - Child DMO API name required when lookupBy is `withChildren`, for example
`ContactPointEmail__dlm`.
calculatedInsightName (string, optional) - Calculated Insight API name required when lookupBy is `withCalculatedInsight`, for
example `TotalSales__cio`.
fields (string[], optional) - Optional fields to return. Salesforce accepts up to 50 fields and returns up to 10
fields when omitted.
filters (string, optional) - Optional equality filters for list and child reads in Salesforce format, for example
`[FirstName__c=John]`. Only AND/equality filters are supported by Salesforce.
limit (number, optional) - Maximum records to return. Salesforce's Profile API page limit is 4,999 records.
offset (number, optional) - Number of records to skip before returning results.
orderby (string, optional) - Sort expression, for example `LastName__c,-FirstName__c`.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `cdp_profile_api_read` (runtime) or `api` (connect).

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND, 400 INVALID_FIELD, 401 invalid_token.

Example request

get_profile_record({
  "dmoApiName": ""
})

Example result

{ }
