Tool: get_dmo_metadata

Description
Read the metadata of a single Profile-category DMO — the
queryable fields, the primary key, the searchable keys, and the
related-object relationship list.

Salesforce API
Runtime plane.

Endpoint
GET {instanceUrl}/api/v1/profile/metadata/{dmoApiName}

Headers
Authorization: Bearer <data_cloud_token>
Accept: application/json

Body
None.

Input (parameters)
dmoApiName (string, required) - Profile DMO API name, for example `ssot__Individual__dlm` or `Individual__dlm`.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api` or `cdp_profile_api_read`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_dmo_metadata({
  "dmoApiName": ""
})

Example result

{ }
