Tool: get_profile_metadata

Description
List the Profile-eligible DMOs (DMOs whose `category=Profile`) along
with their searchable identifiers and relationships. Used as a
discovery endpoint before calling `get_profile_record`.

Salesforce API
Runtime plane.

Endpoint
GET {instanceUrl}/api/v1/metadata
Optional query: entityType, entityCategory

Headers
Authorization: Bearer <data_cloud_token>
Accept: application/json

Body
None.

Input (parameters)
entityName (string, optional) - Optional Profile DMO API name to filter the metadata response, for example
`ssot__Individual__dlm` or `Individual__dlm`.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api` (connect) or `cdp_profile_api_read` (runtime).

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

get_profile_metadata({})
