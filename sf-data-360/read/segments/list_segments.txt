Tool: list_segments

Description
List Data 360 Segments — saved population queries against a
DMO. Each segment can be published to materialize the membership
list and then activated downstream.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/segments
Optional query: batchSize, offset, dataspace, filters, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
batchSize (number, optional) - Maximum number of segments to return, from 1 through 200. Salesforce applies its
endpoint default when omitted.
offset (number, optional) - Number of segments to skip before returning results. Salesforce skips no rows when
omitted.
dataspace (string, optional) - Data space name. Salesforce uses the default data space when omitted.
filters (string, optional) - Salesforce Data 360 filter expression for segment attributes, such as `SegmentStatus eq
Active` or `Name contains Promo`.
orderBy (string, optional) - Sort expression for the result set, such as `Name ASC` or `CreatedDate DESC`.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

list_segments({})
