Tool: get_segment

Description
Read a single Segment by api name or id. Returns the full criteria
graph + the latest publish status.

Salesforce API
Connect plane.

Endpoint
GET {instanceUrl}/services/data/v{ver}/ssot/segments/:segmentApiNameOrId

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
segmentApiName (string, required) - API name of the segment to retrieve, for example `Running_Shoe_Promo_Audience`.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_segment({
  "segmentApiName": ""
})

Example result

{ }
