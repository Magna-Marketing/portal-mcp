Tool: get_segment_members

Description
List the materialized members of a published Segment — page-by-
page. Use the runtime Query API for ad-hoc joins or projections;
this endpoint is the canonical "members of segment X" lookup.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/segments/{segmentApiName}/members
Optional query: batchSize, offset, fields, filters, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
segmentApiName (string, required) - API name of the segment whose materialized members should be retrieved.
batchSize (number, optional) - Maximum number of segment members to return, from 1 through 1000. Salesforce applies its
endpoint default when omitted.
offset (number, optional) - Number of segment members to skip before returning results. Salesforce skips no rows
when omitted.
fields (string[], optional) - Segment member fields to return, such as `Id__c`, `FirstName__c`, or `EmailAddress__c`.
filters (string, optional) - Salesforce Data 360 filter expression for segment member fields.
orderBy (string, optional) - Sort expression for segment members, such as `Id__c ASC` or `LastName__c DESC`.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only. Subject to the segment's `publishStatus=Published`
  state — `Stale` or `NotPublished` returns `409 NOT_PUBLISHED`.

Errors
- 404 NOT_FOUND, 409 NOT_PUBLISHED.

Example request

get_segment_members({
  "segmentApiName": ""
})

Example result

{ }
