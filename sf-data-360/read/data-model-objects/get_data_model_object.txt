Tool: get_data_model_object

Description
Read a single DMO by developer name with full field definitions
and record count.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-model-objects/{dataModelObjectName}
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-model-objects/{dataModelObjectName}/relationships

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
dataModelObjectName (string, required) - DMO developer name, including suffix, for example `UnifiedIndividual__dlm` or
`ssot__Individual__dlm`.
dataspace (string, optional) - Data space name. Salesforce uses the default data space when omitted.
includeRelationships (boolean, optional) - When true, also calls GET /ssot/data-model-objects/{dataModelObjectName}/relationships
and returns `{ dataModelObject, relationships }`.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_data_model_object({
  "dataModelObjectName": ""
})

Example result

{ }
