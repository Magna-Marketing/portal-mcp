Tool: get_dmo_mapping

Description
Read a single DMO mapping by developer name.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-model-object-mappings/{objectSourceTargetMapDeveloperName}
Optional query: dataspace

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
objectSourceTargetMapDeveloperName (string, required) - Developer name of the object source target mapping. Retrieve it from
read.list_dmo_mappings.
dataspace (string, optional) - Data space name. Salesforce uses the default data space when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_dmo_mapping({
  "objectSourceTargetMapDeveloperName": ""
})

Example result

{ }
