Tool: list_data_model_objects

Description
List Data Model Objects (DMOs) — the curated business schema in
Data Cloud. DMOs are populated from DLOs via mappings; downstream
segmentation, activation, and Profile API reads run on top of them.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-model-objects
Optional query: dataspace, category, creationType, nameContains, sortBy, limit, offset, orderBy
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-model-objects/{encodedName}
Optional query: dataspace, category, creationType, nameContains, sortBy, limit, offset, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
dataspace (string, optional) - Data space name. Salesforce uses the default data space when omitted.
category (string, optional) - Optional DMO category filter, for example `PROFILE`, `ENGAGEMENT`, or the category value
returned by Salesforce.
creationType (string, optional) - Optional creation type filter, such as `Standard` or `Custom`, when supported by the org
API version.
nameContains (string, optional) - Optional server-side name substring filter when supported by the Salesforce endpoint.
sortBy (string, optional) - Field on which to sort results when supported by the Salesforce endpoint.
limit (number, optional) - Maximum number of records to return. Salesforce applies its endpoint default when
omitted.
offset (number, optional) - Number of records to skip before returning results. Salesforce skips no rows when
omitted.
orderBy (string, optional) - Sort order for the result set, such as `ASC` or `DESC`, when supported by the Salesforce
endpoint.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_data_model_objects({})
