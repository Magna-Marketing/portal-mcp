Tool: list_dmo_mappings

Description
List Data Model Object mappings — the rules that copy data from
a Data Lake Object (source) into a DMO (target). Each mapping has
field-level mappings underneath.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-model-object-mappings
Optional query: dataspace, dloDeveloperName, dmoDeveloperName

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
dataspace (string, optional) - Data space name. Salesforce uses the default data space when omitted.
dloDeveloperName (string, optional) - Optional Data Lake Object (DLO) source developer name filter, for example
`mc_sends__dll`.
dmoDeveloperName (string, optional) - Optional Data Model Object (DMO) target developer name filter, for example
`ssot__Individual__dlm`.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_dmo_mappings({})

Example result

{ }
