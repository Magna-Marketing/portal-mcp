Tool: list_data_space_members

Description
List the DMOs / Calculated Insights / Activations that belong to a
Data Space. Membership controls which assets are visible in the
Data Space.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-spaces/{idOrName}/members/{dataSpaceMemberObjectName}

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
idOrName (string, required) - ID or API name of the data space whose members should be retrieved.
dataSpaceMemberObjectName (string, optional) - Developer name of a specific data space member, such as a DLO developer name. When
omitted, all members are listed.
limit (number, optional) - Maximum number of items to return, from 1 through 4999. Salesforce defaults to 50 when
omitted.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderBy (string, optional) - Sort order for the result set, either ASC or DESC. Salesforce returns ascending results
when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

list_data_space_members({
  "idOrName": ""
})

Example result

{ }
