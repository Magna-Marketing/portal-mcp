Tool: list_data_spaces

Description
List Data Spaces — tenant-within-tenant scopes that isolate DMOs,
segments, calculated insights, and activations (e.g. one Data Space
per brand or geography). All DMO-scoped APIs honor a `dataSpace`
query parameter.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-spaces
Optional query: limit, offset, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
limit (number, optional) - Maximum number of items to return, from 1 through 4999. Salesforce defaults to 50 when
omitted.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderBy (string, optional) - Sort order for the result set, either ASC or DESC. Salesforce returns ascending results
when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_data_spaces({})
