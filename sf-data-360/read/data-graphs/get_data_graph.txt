Tool: get_data_graph

Description
Read a single Data Graph definition by developer name. Returns the
full graph schema (which DMOs are joined how) and the JSON shape
that runtime queries return.

Salesforce API
Connect plane (default) or runtime plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/api/v1/dataGraph/metadata
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-graphs/{dataGraphName}
GET {instanceUrl}/api/v1/dataGraph/metadata
GET {instanceUrl}/api/v1/ssot/data-graphs/{dataGraphName}

Headers
Authorization: Bearer <core_access_token>      (connect)
Authorization: Bearer <data_cloud_token>       (runtime)
Accept: application/json

Body
None.

Input (parameters)
dataGraphName (string, required) - API name of the data graph, for example `UnifiedIndividual_DG`.
plane ("connect" | "runtime", optional) - API plane to call. `connect` returns the graph definition from
`/ssot/data-graphs/{dataGraphName}`; `runtime` returns metadata from
`/api/v1/dataGraph/metadata`. Defaults to connect.
dataspace (string, optional) - Data 360 data space to query when using the runtime metadata endpoint. Salesforce uses
the default data space when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api` (connect) or `cdp_api` (runtime).

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_data_graph({
  "dataGraphName": ""
})

Example result

{ }
