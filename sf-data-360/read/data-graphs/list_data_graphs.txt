Tool: list_data_graphs

Description
List Data Graphs — pre-joined, denormalized views over a "primary"
DMO + its related DMOs, optimized for low-latency profile lookups
(used by Marketing Cloud Next personalization, Agentforce, etc.).
Each graph captures the primary DMO, the joined related DMOs, the
cardinality, and the refresh schedule.

Salesforce API
Connect plane (default) or runtime plane (`plane="runtime"`,
hits `{cdpTenantUrl}/api/v1/dataGraph/metadata`). Both return
metadata; pick whichever is closer.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/api/v1/dataGraph/metadata
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-graphs/metadata
GET {instanceUrl}/api/v1/dataGraph/metadata
GET {instanceUrl}/api/v1/ssot/data-graphs/metadata

Headers
Authorization: Bearer <core_access_token>      (connect)
Authorization: Bearer <data_cloud_token>       (runtime)
Accept: application/json

Body
None.

Input (parameters)
plane ("connect" | "runtime", optional) - API plane to call. `connect` uses `/ssot/data-graphs/metadata`; `runtime` uses
`/api/v1/dataGraph/metadata`. Defaults to connect.
dataspace (string, optional) - Data 360 data space to query. Supported by the Connect metadata endpoint; Salesforce
uses the default data space when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api` (connect) or `cdp_api` (runtime).

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID / invalid_token.

Example request

list_data_graphs({})
