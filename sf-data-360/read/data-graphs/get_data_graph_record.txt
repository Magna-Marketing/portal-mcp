Tool: get_data_graph_record

Description
Pull the denormalized profile-and-children record for a single
primary entity from a Data Graph. The Postman collection exposes
two access patterns:

- By primary key (id): hits `/data-graphs/data/:entity/:id` (connect)
  or `/api/v1/dataGraph/:name/:recordId` (runtime).
- By lookup keys: hits `/data-graphs/data/:entity?lookup1=...&...`
  (connect) or `/api/v1/dataGraph/:name?key=...` (runtime).

Use the runtime plane for high-throughput personalization queries.

Salesforce API
Connect plane or runtime plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/api/v1/dataGraph/{dataGraphEntityName}/{id}
GET {salesforceInstanceUrl}/services/data/v65.0/api/v1/dataGraph/{dataGraphEntityName}
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-graphs/data/{dataGraphEntityName}/{id}
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-graphs/data/{dataGraphEntityName}
GET {instanceUrl}/api/v1/dataGraph/{dataGraphEntityName}/{id}
GET {instanceUrl}/api/v1/dataGraph/{dataGraphEntityName}
GET {instanceUrl}/api/v1/ssot/data-graphs/data/{dataGraphEntityName}/{id}
GET {instanceUrl}/api/v1/ssot/data-graphs/data/{dataGraphEntityName}

Headers
Authorization: Bearer <core_access_token> (connect) or <data_cloud_token> (runtime)
Accept: application/json

Body
None.

Input (parameters)
plane ("connect" | "runtime", optional) - API plane to call. `runtime` uses `/api/v1/dataGraph/...`; `connect` uses
`/ssot/data-graphs/data/...`. Defaults to runtime.
dataGraphEntityName (string, optional) - API name of the data graph entity to query, for example `UnifiedIndividual_DG`.
dataGraphName (string, optional) - Compatibility alias for dataGraphEntityName.
id (string, optional) - Record ID to retrieve. Must be the primary key value of the primary DMO. Mutually
exclusive with lookupKeys.
live (boolean, optional) - Runtime or Connect ID lookup option to retrieve live data when supported. Salesforce
retrieves precalculated data when omitted.
dataspace (string, optional) - Data 360 data space to query. Salesforce uses the default data space when omitted.
noCache (boolean, optional) - Connect lookup option for /ssot/data-graphs/data/{dataGraphEntityName}; true reads the
standard, non-real-time data graph according to Salesforce's Connect reference.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api` (connect) or `cdp_api` / `cdp_profile_api_read` (runtime).

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND, 401 invalid_token.
