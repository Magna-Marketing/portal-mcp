Tool: query_data_cloud_sql_v1

Description
Run an ANSI-SQL query (Query API v1) against Data 360 — DMOs,
DLOs, CIOs. v1 returns the entire result set in one synchronous
response (capped at 100k rows). For larger results or chunked
streaming, use `query_data_cloud_sql_v2` (which returns
`nextBatchId`).

Salesforce API
Runtime plane.

Endpoint
POST {instanceUrl}/api/v1/query
Optional query: limit, offset, orderby

Headers
Authorization: Bearer <data_cloud_token>
Content-Type: application/json
Accept: application/json

Body
{
  "sql": "SELECT Id__c, EmailAddress__c FROM UnifiedIndividual__dlm LIMIT 100"
}

Input (parameters)
sql (string, required) - Data 360 SQL statement to execute against Data Cloud objects, such as DMOs, DLOs, CIOs,
profile, engagement, or unified data objects.
limit (number, optional) - Maximum records to return for legacy Query API v1. Salesforce defaults to 49,999 when
omitted.
offset (number, optional) - Number of records to skip before returning legacy Query API v1 results.
orderby (string, optional) - Comma-separated sort order for legacy Query API v1, for example `GenderId__c ASC,
Occupation__c DESC`.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api` (connect) or `cdp_query_api_read` (runtime).

Idempotency & limits
- Read-only.
- Max 100k rows per response. Per-query timeout: 5 minutes.

Errors
- 400 INVALID_QUERY, 401 invalid_token, 408 QUERY_TIMEOUT,
  429 REQUEST_LIMIT_EXCEEDED.

Example request

query_data_cloud_sql_v1({
  "sql": ""
})

Example result

{ }
