Tool: get_async_sql_query

Description
Submit an async SQL query, poll its status, or fetch its result
rows. The async Query API is the new "/ssot/query-sql" surface
that supports billion-row results, paged via `/rows`. Unifies the
three Postman endpoints under `subOperation`.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/query-sql
Optional query: dataspace, workloadName, waitTimeMs, rowLimit, offset, omitSchema
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/query-sql/{queryId}
Optional query: dataspace, workloadName, waitTimeMs, rowLimit, offset, omitSchema
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/query-sql/{queryId}/rows
Optional query: dataspace, workloadName, waitTimeMs, rowLimit, offset, omitSchema
POST {salesforceInstanceUrl}/services/data/v65.0/ssot/query-sql
Optional query: dataspace, workloadName, waitTimeMs, rowLimit, offset, omitSchema
POST {salesforceInstanceUrl}/services/data/v65.0/ssot/query-sql/{queryId}
Optional query: dataspace, workloadName, waitTimeMs, rowLimit, offset, omitSchema
POST {salesforceInstanceUrl}/services/data/v65.0/ssot/query-sql/{queryId}/rows
Optional query: dataspace, workloadName, waitTimeMs, rowLimit, offset, omitSchema

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body (submit)
{
  "sql": "SELECT * FROM UnifiedIndividual__dlm",
  "outputFormat": "JSON"
}

Input (parameters)
subOperation ("submit" | "status" | "rows", required) - Operation to perform: `submit` starts a query, `status` polls a query, and `rows`
fetches query result rows.
sql (string, optional) - Data 360 SQL statement to submit. Required when subOperation is `submit`.
queryId (string, optional) - Query ID returned by the submit response. Required for `status` and `rows`. Pass the ID
as returned by Salesforce; IDs containing slashes are usually already URL-encoded.
rowLimit (number, optional) - For `submit`, maximum rows in the first response chunk. For `rows`, maximum rows to
return in this page.
offset (number, optional) - Zero-based row offset for `rows` pagination.
omitSchema (boolean, optional) - For `rows`, omit metadata/schema from subsequent pages to reduce response size.
waitTimeMs (number, optional) - For `status`, long-poll wait time in milliseconds. Salesforce supports up to 10,000 ms.
sqlParameters (object[], optional) - Named bind parameters for parameterized SQL. Reference each item in SQL as `:name`.
dataspace (string, optional) - Data space where the query executes. Salesforce uses the default data space when
omitted.
workloadName (string, optional) - Human-readable workload label included in Salesforce logs to help with debugging and
support.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Submit is not idempotent; supply your own dedupe key.
- Job retention: 24 hours.
- Max result size: 1 billion rows.

Errors
- 404 NOT_FOUND, 409 NOT_COMPLETE (rows fetched before status is
  Complete), 400 INVALID_QUERY.

Example request

get_async_sql_query({
  "subOperation": ""
})

Example result

{ }
