Tool: query_data_cloud_sql_v2

Description
Run an ANSI-SQL query against Data 360 with cursor-based pagination
(Query API v2). The first response includes the first chunk plus
`nextBatchId` if more data is available; subsequent chunks are
fetched by passing `nextBatchId` back in.

Salesforce API
Runtime plane.

Endpoint
GET {instanceUrl}/api/v2/query/{nextBatchId}
POST {instanceUrl}/api/v2/query

Headers
Authorization: Bearer <data_cloud_token>
Content-Type: application/json
Accept: application/json

Body
{
  "sql": "SELECT Id__c, EmailAddress__c FROM UnifiedIndividual__dlm WHERE LastModifiedDate__c >= '2026-04-01'"
}

Input (parameters)
sql (string, optional) - Data 360 SQL statement for the initial Query API v2 request. Required when `nextBatchId`
is not provided.
nextBatchId (string, optional) - Batch cursor returned by a previous Query API v2 response. When provided, the tool
fetches the next batch instead of submitting SQL.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api` (connect) or `cdp_query_api_read` (runtime).

Idempotency & limits
- Read-only.
- Cursor TTL: 5 minutes between chunk requests.

Errors
- 400 INVALID_QUERY, 408 CURSOR_EXPIRED (cursor TTL exceeded),
  401 invalid_token.

Example request

query_data_cloud_sql_v2({})

Example result

{ }
