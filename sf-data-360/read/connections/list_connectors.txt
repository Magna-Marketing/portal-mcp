Tool: list_connectors

Description
List the Connector types available to this org (the catalogue of
"what kinds of connections can I create"). Each connector type
declares its required configuration fields.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/connectors
Optional query: fieldGroup, filters, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
fieldGroup ("SMALL" | "MEDIUM" | "BIG", optional) - Field group to include in the result. SMALL returns minimal fields, MEDIUM returns more
fields, and BIG returns all fields. Salesforce defaults to SMALL.
filters (string, optional) - Comma-separated filters in the Salesforce format field=value. Example:
'name=SalesforceMarketingCloud'.
orderBy (string, optional) - Sort by connector field, such as 'name', 'label', 'name ASC', or 'label DESC'.
Salesforce defaults to name ASC.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only. Catalog-style; cache per session.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_connectors({})

{ }
