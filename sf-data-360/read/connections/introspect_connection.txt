Tool: introspect_connection

Description
Run a live introspection call against a Connection — list the
databases, schemas, objects, fields, or preview rows from the
source system at runtime (not the cached schema). The Postman
collection exposes these as several POST endpoints under one
introspection family; this tool unifies them with `subOperation`.

Salesforce API
Connect plane.

Endpoint
POST {instanceUrl}/services/data/v{ver}/ssot/connections/:connectionId/databases             (subOperation="databases")
POST {instanceUrl}/services/data/v{ver}/ssot/connections/:connectionId/database-schemas      (subOperation="schemas")
POST {instanceUrl}/services/data/v{ver}/ssot/connections/:connectionId/objects               (subOperation="objects")
POST {instanceUrl}/services/data/v{ver}/ssot/connections/:connectionId/objects/:resourceName/fields  (subOperation="fields")
POST {instanceUrl}/services/data/v{ver}/ssot/connections/:connectionId/objects/:resourceName/preview (subOperation="preview")

Headers
Authorization: Bearer <core_access_token>
Content-Type: application/json
Accept: application/json

Body
POST: advancedAttributes

Input (parameters)
connectionId (string, required) - ID of the Data 360 connection to introspect.
subOperation ("databases" | "schemas" | "objects" | "fields" | "preview", required) - Introspection operation. Uses POST /databases, /database-schemas, /objects,
/objects/{resourceName}/fields, or /objects/{resourceName}/preview.
resourceName (string, optional) - Required for fields and preview. Use 'files' for file-based connectors,
object/table/view name for object or database connectors, custom object ID for data
extensions, or data stream name for Marketing Cloud bundle streams.
databaseName (string, optional) - Convenience alias added to advancedAttributes.databaseName when provided.
database (string, optional) - Compatibility alias for databaseName.
schemaName (string, optional) - Convenience alias added to advancedAttributes.schemaName when provided.
schema (string, optional) - Compatibility alias for schemaName.
fields (string[], optional) - Required for preview. List of source fields to return in preview records.
limit (number, optional) - Maximum number of records for preview. Salesforce defaults to 100 when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only at the API boundary, but each call hits the source
  system. Subject to source-side rate limits.

Errors
- 401 INVALID_SESSION_ID, 502 SOURCE_UNAVAILABLE (source down /
  credentials expired), 404 NOT_FOUND.

Example request

introspect_connection({
  "connectionId": "",
  "subOperation": ""
})

Example result

{ }
