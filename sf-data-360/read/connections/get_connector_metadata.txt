Tool: get_connector_metadata

Description
Read the full config metadata for one connector type — the schema
of fields the caller needs to populate when creating a Connection
of that type.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/connectors
Optional query: filters

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
connectorType (string, required).

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND, 401 INVALID_SESSION_ID.

Example request

get_connector_metadata({ "connectorType": "Snowflake" })

Example result

{ }
