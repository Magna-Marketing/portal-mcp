Tool: list_connections

Description
List Data 360 Connections — the source-system bindings (S3, SFTP,
Snowflake, Marketing Cloud, MC Engagement, Salesforce sObjects,
GA4, etc.) that Data Streams pull from. One row per configured
connection.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/connections
Optional query: connectorType, devName, label, organizationId, limit, offset, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
connectorType (string, required) - Required connector type, such as SalesforceMarketingCloud, SalesforceDotCom,
AwsRdsPostgres, AzureBlob, Databricks, Gcs, IngestApi, Sftp, or StreamingApp.
devName (string, optional) - Developer name of the connection to filter on.
label (string, optional) - Label or public-facing name of the connection to filter on.
organizationId (string, optional) - Organization ID to filter on.
limit (number, optional) - Maximum number of connections to return.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderBy (string, optional) - Sort by supported fields label, createdDate, or lastModifiedDate, optionally with ASC or
DESC.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID, 403 INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_connections({
  "connectorType": ""
})

Example result

{ }
