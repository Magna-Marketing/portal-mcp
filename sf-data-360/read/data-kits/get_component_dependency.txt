Tool: get_component_dependency

Description
Read the dependency tree of a single component within a Data Kit
— which other components must be installed first / are referenced.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-kits/{dataKitName}/components/{componentName}/dependencies
Optional query: componentType, dataspace

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
None.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_component_dependency({})
