Tool: list_available_components

Description
List the components in the org that are eligible to be added to a
Data Kit (or for browsing what's available before creating one).

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-kits/available-components
Optional query: componentType, dataKitDevName, limit, offset

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
limit (number, optional) - Maximum number of records to return, from 1 through 200. Salesforce defaults to 200 when
omitted.
offset (number, optional) - Number of records to skip before returning results. Salesforce skips no rows when
omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_available_components({})

{ }
