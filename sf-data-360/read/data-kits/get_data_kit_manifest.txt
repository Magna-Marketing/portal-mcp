Tool: get_data_kit_manifest

Description
Read the manifest of a Data Kit — the full list of components it
contains, their dependencies, and per-component install status.

Salesforce API
Connect plane.

Endpoint
GET {instanceUrl}/services/data/v{ver}/ssot/datakit/:dataKitDevName/manifest

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
None.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_data_kit_manifest({})

Example result

{ }
