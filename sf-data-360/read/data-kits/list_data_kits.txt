Tool: list_data_kits

Description
List Data Kits — packaged collections of Data Cloud assets (DMOs,
DLOs, Calculated Insights, Segments, Data Streams, mappings) that
can be installed / uninstalled together. Used for Industry Cloud,
ISV solutions, and inter-org migration.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-kits
Optional query: namespace

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
namespace (string, optional) - Namespace prefix of the data kit package. Omit to let Salesforce use its default scope.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_data_kits({})

Example result

{ }
