Tool: list_activations

Description
List Activations — the bridges from Segments to external Data
Action Targets (Marketing Cloud Engagement, S3, AppExchange,
Snowflake share, ad networks, etc.).

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/activations
Optional query: batchSize, offset, orderBy, filters

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
batchSize (number, optional) - Number of results to return, from 1 through 200. Salesforce defaults to 20 when omitted.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderBy (string, optional) - Sort by createdDate, for example 'createdDate desc'. If omitted, Salesforce returns
items by ID in ascending order.
filters (string, optional) - Salesforce filter expression. Supported filter names: name, marketSegmentId,
activationTargetId, activationRefreshType, activationStatus. Example: 'activationStatus
in active AND activationRefreshType in incremental'.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

list_activations({})
