Tool: list_activation_targets

Description
List Activation Targets — the destination end-points (a specific
MCE BU + DE, an S3 bucket, an ad network connector) that an
Activation can publish to. One row per configured target.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/activation-targets
Optional query: batchSize, offset, orderBy, filters

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
batchSize (number, optional) - Number of results to return, from 1 through 200. Salesforce defaults to 20 when omitted.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderBy (string, optional) - Sort by createdDate, for example 'createdDate desc'. If omitted, Salesforce returns
items by ID in ascending order.
filters (string, optional) - Salesforce filter expression. Supported filter names: masterLabel, targetStatus,
connectionType, platformName. Example: 'targetStatus in active AND platformName in
Amazon S3'.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_activation_targets({})
