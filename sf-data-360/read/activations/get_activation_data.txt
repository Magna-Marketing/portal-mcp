Tool: get_activation_data

Description
Read the materialized Audience-DMO records produced by an Activation
(the rows that were sent to the target on the last run). Useful for
auditing what got pushed.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/activations/{activationId}/data
Optional query: batchSize, offset, fields, filters, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
activationId (string, required) - Unique identifier of the activation, such as the activation ID or developer name.
batchSize (number, optional) - Maximum number of activation records to return. Omit to use the Salesforce default.
offset (number, optional) - Number of activation records to skip before returning results.
fields (string[], optional) - Field API names to include in returned activation records. Sent as a comma-separated
fields query parameter.
filters (string, optional) - Filter expression for the activation records, when supported by the Salesforce endpoint.
orderBy (string, optional) - Sort order for returned activation records, for example 'Timestamp__c desc'.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_activation_data({
  "activationId": ""
})

Example result

{ }
