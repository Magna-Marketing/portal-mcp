Tool: get_metadata_entities

Description
List the entity-type taxonomy supported by the Data 360 metadata
service — useful for deciding which `entityType` value to pass to
`get_metadata`.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/metadata-entities
Optional query: dataspace, entityType, entityCategory

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
dataspace (string, optional) - Data space name in which metadata entities are requested. Salesforce uses the default
data space when omitted.
entityType (unknown, optional) - Metadata entity type filter. Salesforce supports `DataLakeObject`, `DataModelObject`,
and `CalculatedInsight`.
entityCategory (unknown, optional) - Metadata entity category filter. Salesforce supports `Activation_Audience`,
`CG_Audience`, `Content`, `Directory_Table`, `Engagement`, `Profile`, `Related`,
`Segment_Membership`, and `Vector_Embedding`.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

get_metadata_entities({})

Example result

{ }
