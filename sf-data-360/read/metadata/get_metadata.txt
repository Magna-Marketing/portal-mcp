Tool: get_metadata

Description
List Data 360 metadata across the whole catalogue, filtered by
type / entity / category, or fetch the global summary. Unifies the
Postman variants under `mode`.

Salesforce API
Connect plane (default) or runtime plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/api/v1/metadata/
Optional query: dataspace
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/metadata
Optional query: dataspace
GET {instanceUrl}/api/v1/metadata/
Optional query: dataspace
GET {instanceUrl}/api/v1/ssot/metadata
Optional query: dataspace

Headers
Authorization: Bearer <core_access_token>      (connect)
Authorization: Bearer <data_cloud_token>       (runtime)
Accept: application/json

Body
None.

Input (parameters)
plane ("connect" | "runtime", optional) - API plane to call. `connect` uses `/ssot/metadata`; `runtime` uses `/api/v1/metadata/`.
Defaults to connect.
entityType (unknown, optional) - Metadata entity type filter. Salesforce supports `DataLakeObject`, `DataModelObject`,
and `CalculatedInsight`.
entityCategory (unknown, optional) - Metadata entity category filter. Salesforce supports `Profile`, `Engagement`, and
`Related`; the filter is not applicable to Calculated Insight entities.
entityName (string, optional) - Metadata entity API name, for example `UnifiedIndividual__dlm`. Omit to return all
matching entities.
dataspace (string, optional) - Data space name for the Connect REST endpoint. Salesforce uses the default data space
when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api` (connect) or `cdp_api` (runtime).

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID / invalid_token.

Example request

get_metadata({})

Example result
