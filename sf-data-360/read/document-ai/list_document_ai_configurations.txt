Tool: list_document_ai_configurations

Description
List Document AI configurations — schemas + extraction logic for
processing documents (invoices, contracts, PDFs) into Data Cloud
DMOs.

Salesforce API
Connect plane.

Endpoint
GET {instanceUrl}/services/data/v{ver}/ssot/document-processing/configurations

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
status (string, optional) - Optional configuration status filter. Known values include Active, Draft, and Failed;
Salesforce may return or accept org-specific values.
documentType (string, optional) - Optional document type filter, such as Invoice, Contract, PurchaseOrder, Receipt,
Resume, or Custom.
nameContains (string, optional) - Optional case-sensitive or case-insensitive name substring filter, depending on
Salesforce endpoint behavior.
limit (number, optional) - Maximum number of configurations to return. Salesforce applies its endpoint default when
omitted.
dataspace (unknown, required)

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_document_ai_configurations({
  "dataspace": ""
})

Example result

{ }
