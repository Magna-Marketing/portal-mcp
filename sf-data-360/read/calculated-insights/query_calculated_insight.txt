Tool: query_calculated_insight

Description
Query the values of a Calculated Insight (CIO) — returns aggregated
measure rows, optionally filtered / projected. Runs on the runtime
plane for low-latency.

For ad-hoc SQL on a CIO, use `query_data_cloud_sql_v2` instead.

Salesforce API
Runtime plane.

Endpoint
GET {instanceUrl}/api/v1/insight/calculated-insights/{ciName}

Headers
Authorization: Bearer <data_cloud_token>
Accept: application/json

Body
None.

Input (parameters)
ciName (string, required) - Calculated insight API name to query, for example 'CustomerLTV__cio'.
filters (string, optional) - Salesforce filter expression, for example '[CustomerId__c=A003]' or
'[GenderId__c=Male,FirstName__c=Angel]'.
orderby (string, optional) - Comma-separated sort order, for example 'GenderId__c ASC,Occupation__c DESC'.
limit (number, optional) - Maximum rows to return. Salesforce documents a maximum of 4,999 rows per request.
batchSize (number, optional) - Compatibility alias for limit. If both limit and batchSize are provided, limit is used.
offset (number, optional) - Number of rows to skip before returning results.
timeGranularity ("HOUR" | "DAY" | "MONTH" | "QUARTER" | "YEAR", optional) - Time aggregation level for time-based calculated insight measures.

Result
data (array<object>) - Each row keyed by selected dimensions /
  measures.
metadata (object) - { columns: [{ name, type }] }.
done (boolean).
nextPageToken (string|null).

Required scopes
- `cdp_calculated_insight_api`.

Idempotency & limits
- Read-only.

Errors
- 401 invalid_token, 404 NOT_FOUND, 400 INVALID_FIELD.

Example request

query_calculated_insight({
  "ciName": ""
})

Example result
{
  "data": [
    { "IndividualId__c": "IND_001", "LifetimeValue__c": 12450.00 }
  ],
  "metadata": { "columns": [
    { "name": "IndividualId__c",  "type": "TEXT" },
    { "name": "LifetimeValue__c", "type": "DECIMAL" }
  ] }
}
