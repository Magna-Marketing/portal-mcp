Tool: list_calculated_insights

Description
List Calculated Insight Objects (CIOs) — derived metrics computed
from DMOs (lifetime value, propensity scores, engagement recency).

Salesforce API
Connect plane.

Endpoint
GET {instanceUrl}/services/data/v{ver}/ssot/calculated-insights

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
definitionType ("CALCULATED_METRIC" | "EXTERNAL_METRIC" | "STREAMING_METRIC", optional) - Calculated insight definition type to list. Defaults to CALCULATED_METRIC for standard
calculated insights.
batchSize (number, optional) - Maximum number of definitions to return, from 1 through 200. Salesforce defaults to 25
when omitted.
offset (number, optional) - Number of definitions to skip before returning results.
dataspace (string, optional) - Data space name to filter by. Omit to use the org default data space.
orderby (string, optional) - Sort order for the result set, such as 'Name ASC' or 'LastModifiedDate DESC'.
pageToken (string, optional) - Page token returned by Salesforce for fetching a subsequent page.

Result
calculatedInsights (array) - Each: { id, apiName, label, dataSpace,
  status, refreshFrequency, sourceDmos, measures (array),
  dimensions (array), lastRunStatus, lastRunDate, createdDate,
  lastModifiedDate }.
totalSize (number).

Required scopes
- `api` (or `cdp_calculated_insight_api` for the runtime fall-through).

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_calculated_insights({})

Example result
{
  "calculatedInsights": [
    { "apiName": "CustomerLTV__cio",
      "label": "Customer LTV",
      "status": "Active",
      "refreshFrequency": "Daily" }
  ]
}
