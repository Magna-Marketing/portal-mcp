Tool: list_data_lake_objects

Description
List Data Lake Objects (DLOs) — the raw / staged storage produced
by Data Streams. DLOs are the inputs to DMOs via mappings.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-lake-objects
Optional query: limit, offset, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
limit (number, optional) - Maximum number of rows or relationships to return. Salesforce defaults to 20 when
omitted.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderBy (string, optional) - Sort order for the result set, such as 'ASC' or 'DESC'. Salesforce returns results in
ascending order when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_data_lake_objects({})
