Tool: get_data_lake_object

Description
Read a single DLO by id or developer name with full field
metadata.

Salesforce API
Connect plane.

Endpoint
GET {instanceUrl}/services/data/v{ver}/ssot/data-lake-objects/:recordIdOrDeveloperName

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
recordIdOrDeveloperName (string, required) - Salesforce record ID or developer name of the Data Lake Object, such as '1dl...' or
'MyObject__dll'.
limit (number, optional) - Maximum number of rows or relationships to return. Salesforce defaults to 20 when
omitted.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderBy (string, optional) - Sort order for the result set, such as 'ASC' or 'DESC'. Salesforce returns results in
ascending order when omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_data_lake_object({
  "recordIdOrDeveloperName": ""
})

Example result

{ }
