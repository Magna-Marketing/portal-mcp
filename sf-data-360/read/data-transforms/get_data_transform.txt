Tool: get_data_transform

Description
Read a single Data Transform by id or name with the full SQL
definition and source / target metadata.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-transforms/{dataTransformNameOrId}
Optional query: filterGroup

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
dataTransformNameOrId (string, required).

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_data_transform({ "dataTransformNameOrId": "build_unified_individual" })

Example result

{ }
