Tool: list_data_transforms

Description
List Data Transforms — SQL-based transformations that shape DLO /
DMO data into curated datasets. Each transform has a target DMO
(or DLO), a SQL definition, a schedule, and a run history.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-transforms
Optional query: filterGroup, limit, offset, orderBy

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
filterGroup (unknown, required)
limit (number, optional) - Maximum number of rows to return, from 1 through 20. Salesforce defaults to 20 when
omitted.
offset (number, optional) - Number of rows to skip before returning results. Salesforce skips no rows when omitted.
orderBy ("DataTransformStatusAsc" | "DataTransformStatusDesc" | "LabelAsc" | "LabelDesc" | "LastRunStatusAsc" | "LastRunStatusDesc" | "LastRunTimeAsc" | "LastRunTimeDesc" | "MruAsc" | "MruDesc" | "NameAsc" | "NameDesc" | "TypeAsc" | "TypeDesc", optional) - Sort order for the result set. Salesforce returns records in retrieval order when
omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_data_transforms({
  "filterGroup": ""
})

Example result

{ }
