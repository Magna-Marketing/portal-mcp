Tool: get_data_transform_schedule

Description
Read the schedule for a Data Transform.

Salesforce API
Connect plane.

Endpoint
GET {instanceUrl}/services/data/v{ver}/ssot/data-transforms/:dataTransformNameOrId/schedule

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
dataTransformNameOrId (string, required).

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_data_transform_schedule({
  "dataTransformNameOrId": "build_unified_individual"
})

Example result

{ }
