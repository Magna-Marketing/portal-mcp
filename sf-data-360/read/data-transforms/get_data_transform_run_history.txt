Tool: get_data_transform_run_history

Description
Read the recent run history of a Data Transform — start / end
times, status, records processed / failed, error references.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/data-transforms/{dataTransformNameOrId}/run-history
Optional query: limit, offset

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
dataTransformNameOrId (string, required) - Name or ID of the data transform to retrieve run history for.
limit (number, optional) - Maximum number of run history records to return. Omit to use Salesforce's default.
offset (number, optional) - Number of run history records to skip for pagination. Salesforce skips no rows when
omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

get_data_transform_run_history({
  "dataTransformNameOrId": ""
})

Example result

{ }
