Tool: lookup_universal_id

Description
Resolve a source-system record identifier to its Data 360 Unified
Record ID — given a `(dataSourceId, dataSourceObjectId, sourceRecordId)`
triple, returns the unified profile id (e.g. `UnifiedIndividual__dlm.Id__c`).
Used by integration layers to bridge external IDs (CRM Lead/Contact id,
MCE Subscriber Key, web pixel piVID) to the unified profile.

Salesforce API
Runtime plane.

Endpoint
GET {instanceUrl}/api/v1/universalIdLookup/{entityName}/{dataSourceId}/{dataSourceObjectId}/{sourceRecordId}

Headers
Authorization: Bearer <data_cloud_token>
Accept: application/json

Body
None.

Input (parameters)
entityName (string, required) - Name of the bridge table entity to query, for example `UnifiedIndividualLink__dlm` or
another configured bridge entity.
dataSourceId (string, required) - Value for Salesforce path parameter `DataSourceId__c`, the data source ID for the source
record.
dataSourceObjectId (string, required) - Value for Salesforce path parameter `DataSourceObjectId__c`, the data source object ID
for the source record.
sourceRecordId (string, required) - Value for Salesforce path parameter `SourceRecordId__c`, the primary key of the source
data record.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `cdp_profile_api_read` or `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND (no match), 401 invalid_token.

Example request

lookup_universal_id({
  "entityName": "",
  "dataSourceId": "",
  "dataSourceObjectId": "",
  "sourceRecordId": ""
})

Example result

{ }
