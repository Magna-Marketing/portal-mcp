Tool: list_configured_models

Description
List Configured Models — ML models registered with Data 360 (via
Einstein Studio / Model Builder, BYOM, or AppExchange) that are
available for `predict` calls.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/machine-learning/configured-models
Optional query: status, modelType, nameContains, limit, offset

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
nameContains (string, optional) - Optional server-side name substring filter when supported by the Salesforce endpoint.
limit (number, optional) - Maximum number of records to return. Salesforce applies the endpoint default when
omitted.
offset (number, optional) - Number of records to skip before returning results. Salesforce skips no rows when
omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_configured_models({})

Example result

{ }
