Tool: list_model_artifacts

Description
List Model Artifacts — the underlying packaged ML model files
(weights, code, metadata) that Configured Models reference.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/machine-learning/model-artifacts
Optional query: runtimeFramework, status, limit, offset

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
limit (number, optional) - Maximum number of records to return. Salesforce applies the endpoint default when
omitted.
offset (number, optional) - Number of records to skip before returning results. Salesforce skips no rows when
omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 401 INVALID_SESSION_ID.

Example request

list_model_artifacts({})

Example result

{ }
