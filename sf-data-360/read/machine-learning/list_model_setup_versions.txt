Tool: list_model_setup_versions

Description
List the versions of a Model Setup — Einstein Studio / Model Builder
training configurations. Each version captures a snapshot of the
training config, dataset, and resulting metrics.

Salesforce API
Connect plane.

Endpoint
GET {salesforceInstanceUrl}/services/data/v65.0/ssot/machine-learning/model-setups/{modelSetupIdOrName}/setup-versions
Optional query: active, limit, offset

Headers
Authorization: Bearer <core_access_token>
Accept: application/json

Body
None.

Input (parameters)
modelSetupIdOrName (string, required) - ID or developer name of the Salesforce Data 360 model setup.
active (boolean, optional) - Whether to filter to active setup versions. Salesforce returns both active and inactive
versions when omitted.
limit (number, optional) - Maximum number of records to return. Salesforce applies the endpoint default when
omitted.
offset (number, optional) - Number of records to skip before returning results. Salesforce skips no rows when
omitted.

Result
Raw Salesforce response JSON, returned unchanged.

Required scopes
- `api`.

Idempotency & limits
- Read-only.

Errors
- 404 NOT_FOUND.

Example request

list_model_setup_versions({
  "modelSetupIdOrName": ""
})

Example result

{ }
