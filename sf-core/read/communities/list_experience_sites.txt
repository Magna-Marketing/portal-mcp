Tool: list_experience_sites

Description
List Experience Cloud sites (`Network` sObject) — public communities,
partner portals, customer portals. Returns identity, status, URL,
template, login policy, and member count.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, UrlPathPrefix, Status, Description, OptionsReputationEnabled, OptionsSelfRegistrationEnabled, SelfRegProfileId, CreatedById, CreatedDate, LastModifiedById, LastModifiedDate, SystemModstamp FROM Network

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
status (string, optional) - Network status filter; string matched exactly against
Network.Status; no default; example: Live; do not pass multiple values, labels in
another language, or status text unknown to the org.
pattern (string, optional) - Network text pattern matched against Name, UrlPathPrefix,
or Description; string using * and ? wildcards converted to SOQL LIKE; no default;
example: Customer*; do not pass regex, raw LIKE syntax, or multiple patterns.
urlPathPrefix (string, optional) - Experience site URL path prefix filter; string
matched exactly against Network.UrlPathPrefix; no default; example: customers; do not
pass a full URL, leading slash, or domain.
whereClause (string, optional) - Additional SOQL WHERE condition for Network; string
with or without WHERE; no default; example: CreatedDate = LAST_N_DAYS:30; do not pass
SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for Network; string with or without
ORDER BY; default Name ASC; example: LastModifiedDate DESC; do not pass WHERE, LIMIT,
SELECT, or FROM.
limit (integer, optional) - Maximum Network rows to return; integer from 1 to 2000;
default 200; example: 50; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Manage Experiences" / "Create and Set Up Experiences".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_experience_sites({
  "status": "Live",
  "pattern": "Customer*",
  "urlPathPrefix": "customers"
})
