Tool: view_experience_site

Description
Get a single Experience site's full configuration: navigation, branding
sets, audiences, member profiles allowed, login flows, page snapshots.

Salesforce API
Connect REST API, v66.0.
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/
GET /services/data/v66.0/connect/communities/{resolvedSiteId}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
siteId (string, optional) - Network Id.
siteName (string, optional).
  One required.

Result
raw Connect API Experience Cloud site JSON for /connect/communities/{communityId}.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Create and Set Up Experiences".

Idempotency & limits
- Read-only.

Errors
- NOT_FOUND.

Example request

view_experience_site({ "siteName": "Customer_Hub" })
