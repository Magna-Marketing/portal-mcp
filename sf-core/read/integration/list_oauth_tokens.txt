Tool: list_oauth_tokens

Description
List active OAuth tokens (`OauthToken`): which user, which app, last
used time, and use count. Use to audit / revoke stale tokens
(`revoke_oauth_token`). Fields returned follow the SOQL SELECT.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, UserId, AppName, AppMenuItemId, LastUsedDate, UseCount FROM OauthToken

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
userId (string, optional) - OauthToken.UserId filter; Salesforce User Id string; no
default; example: 0055g000000abcAAA; do not pass usernames, names, or multiple Ids.
appNamePattern (string, optional) - OauthToken.AppName filter; string using * and ?
wildcards converted to SOQL LIKE; no default; example: Mobile*; do not pass regex, raw
LIKE syntax, or multiple patterns.
sinceLastUsedHours (number, optional) - Relative LastUsedDate filter; positive number of
hours back from now; no default; example: 24; do not pass 0, negatives, dates, or values
when you need never-used tokens.
whereClause (string, optional) - Additional SOQL WHERE condition for OauthToken; string
with or without WHERE; no default; example: UseCount > 10; do not pass SELECT, FROM,
ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for OauthToken; string with or without
ORDER BY; default LastUsedDate DESC; example: UseCount DESC; do not pass WHERE, LIMIT,
SELECT, or FROM.
limit (integer, optional) - Maximum OAuth token rows to return; integer from 1 to 2000;
default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Manage Connected Apps" + "Manage Users".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_oauth_tokens({
  "userId": "0055g000000abcAAA",
  "appNamePattern": "Mobile*",
  "sinceLastUsedHours": 24
})
