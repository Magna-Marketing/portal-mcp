Tool: list_connected_apps

Description
List Connected Apps in the org with OAuth scopes, callback URLs, and
policy settings. For modern apps prefer External Client Apps
(`list_external_client_apps`).

Salesforce API
Tooling API + Metadata API, v66.0. `ConnectedApplication`.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, Name, CreatedDate, OptionsAllowAdminApprovedUsersOnly FROM ConnectedApplication
POST /services/Soap/m/66.0   (readMetadata ConnectedApp for full XML)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional) - ConnectedApplication.Name filter; string using * and ?
wildcards converted to SOQL LIKE; no default; example: Mobile_*; do not pass regex, raw
LIKE syntax, or multiple patterns.
whereClause (string, optional) - Additional SOQL WHERE condition for
ConnectedApplication; string with or without WHERE; no default; example: CreatedDate =
LAST_N_DAYS:30; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for ConnectedApplication; string with
or without ORDER BY; default Name ASC; example: CreatedDate DESC; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum connected app rows to return; integer from 1 to
2000; default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce Tooling QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Manage Connected Apps" / "View Setup and Configuration".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_connected_apps({
  "namePattern": "Mobile_*",
  "whereClause": "CreatedDate = LAST_N_DAYS:30",
  "orderBy": "CreatedDate DESC"
})
