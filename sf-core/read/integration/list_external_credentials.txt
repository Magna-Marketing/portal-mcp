Tool: list_external_credentials

Description
List External Credentials (modern auth provider container). Each
external credential references one auth protocol (OAuth 2.0, AWS Sig
V4, Custom, etc.) and one or more permission set mappings that grant
end-users access. Pair with `list_named_credentials` to see who calls
what.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName FROM ExternalCredential

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional).
includePrincipalMappings (boolean, optional, default true).

Result
Standard Tooling query response body:
- size (number) - count of records in this response.
- totalSize (number) - total matching rows for the query.
- done (boolean) - whether the query is complete (no further pages).
- queryLocator (string|null) - cursor for next batch when paginated; null when done.
- entityTypeName (string) - "ExternalCredential".
- records (array) - each record: attributes { type ("ExternalCredential"), url (string) }, Id, DeveloperName (additional fields appear if included in the SELECT).

Required permissions
- "Customize Application" + "Manage External Connections".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_external_credentials({})
