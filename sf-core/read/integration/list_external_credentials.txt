Tool: list_external_credentials

Description
List External Credentials (modern auth provider container). Each
external credential references one auth protocol (OAuth 2.0, AWS Sig
V4, Custom, etc.) and one or more permission set mappings that grant
end-users access. Pair with `list_named_credentials` to see who calls
what.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, AuthenticationProtocol, Description, Language, ManageableState, NamespacePrefix FROM ExternalCredential

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional) - DeveloperName or MasterLabel filter; string using * and
? wildcards converted to SOQL LIKE; no default; example: AWS_*; do not pass regex, raw
LIKE syntax, or multiple patterns.
authenticationProtocol (string, optional) - ExternalCredential.AuthenticationProtocol
filter; string matching Salesforce picklist values such as AwsSv4, Basic, Custom, Jwt,
JwtExchange, NoAuthentication, Oauth, or Password; no default; example: Oauth; do not
pass UI labels or multiple values.
whereClause (string, optional) - Additional SOQL WHERE condition for ExternalCredential;
string with or without WHERE; no default; example: NamespacePrefix = null; do not pass
SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for ExternalCredential; string with or
without ORDER BY; default DeveloperName ASC; example: MasterLabel ASC; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum external credential rows to return; integer from 1
to 2000; default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce Tooling QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Customize Application" + "Manage External Connections".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_external_credentials({
  "namePattern": "AWS_*",
  "authenticationProtocol": "Oauth",
  "whereClause": "NamespacePrefix = null"
})
