Tool: list_named_credentials

Description
List Named Credentials in the org via Tooling API. Each record includes
identity fields and the callout endpoint URL when exposed to the query
(Endpoint may be null depending on credential type or visibility).

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, NamedCredentialType, CalloutStatus, Endpoint, Protocol, PrincipalType, NamespacePrefix FROM NamedCredential

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional) - DeveloperName or MasterLabel filter; string using * and
? wildcards converted to SOQL LIKE; no default; example: Billing_*; do not pass regex,
raw LIKE syntax, or multiple patterns.
endpointPattern (string, optional) - NamedCredential.Endpoint filter for legacy named
credentials; string using * and ? wildcards converted to SOQL LIKE; no default; example:
https://api.example.com*; do not pass regex, raw LIKE syntax, or multiple patterns.
calloutStatus ("Enabled" | "Disabled", optional) - NamedCredential.CalloutStatus filter;
enum Enabled or Disabled; no default; example: Enabled; do not pass lowercase values or
multiple statuses.
whereClause (string, optional) - Additional SOQL WHERE condition for NamedCredential;
string with or without WHERE; no default; example: NamedCredentialType =
'SecuredEndpoint'; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for NamedCredential; string with or
without ORDER BY; default DeveloperName ASC; example: MasterLabel ASC; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum named credential rows to return; integer from 1 to
2000; default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce Tooling QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Customize Application" + "Manage External Connections".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_named_credentials({
  "namePattern": "Billing_*",
  "endpointPattern": "https://api.example.com*",
  "calloutStatus": "Enabled"
})
