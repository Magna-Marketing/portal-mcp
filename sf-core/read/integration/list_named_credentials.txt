Tool: list_named_credentials

Description
List Named Credentials in the org via Tooling API. Each record includes
identity fields and the callout endpoint URL when exposed to the query
(Endpoint may be null depending on credential type or visibility).

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, Endpoint FROM NamedCredential

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional).

Result
Standard Tooling query response body:
- size (number) - count of records in this response.
- totalSize (number) - total matching rows for the query.
- done (boolean) - whether the query is complete (no further pages).
- queryLocator (string|null) - cursor for next batch when paginated; null when done.
- entityTypeName (string) - "NamedCredential".
- records (array) - each record: attributes { type ("NamedCredential"), url (string) }, Id, DeveloperName, MasterLabel, Endpoint (string|null; additional fields appear if included in the SELECT).

Required permissions
- "Customize Application" + "Manage External Connections".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_named_credentials({})
