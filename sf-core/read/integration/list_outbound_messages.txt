Tool: list_outbound_messages

Description
List Outbound Message definitions from Tooling API (`WorkflowOutboundMessage`):
each row is Id, human-readable Name, and EntityDefinitionId (the sObject
the message is tied to). For endpoint URL, fields payload, and integration
user, use Metadata API read on `Workflow` / outbound message metadata.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, Name, EntityDefinitionId, IntegrationUserId, ApiVersion, NamespacePrefix, ManageableState FROM WorkflowOutboundMessage

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional) - WorkflowOutboundMessage.Name filter; string using * and
? wildcards converted to SOQL LIKE; no default; example: Send_*; do not pass regex, raw
LIKE syntax, or multiple patterns.
entityDefinitionId (string, optional) - WorkflowOutboundMessage.EntityDefinitionId
filter; object definition Id string; no default; example: Account; do not pass object
labels or multiple values.
whereClause (string, optional) - Additional SOQL WHERE condition for
WorkflowOutboundMessage; string with or without WHERE; no default; example:
NamespacePrefix = null; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user
input.
orderBy (string, optional) - SOQL ORDER BY clause for WorkflowOutboundMessage; string
with or without ORDER BY; default Name ASC; example: ApiVersion DESC; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum outbound message rows to return; integer from 1 to
2000; default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce Tooling QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View Setup and Configuration" / "Customize Application".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_outbound_messages({
  "namePattern": "Send_*",
  "entityDefinitionId": "Account",
  "whereClause": "NamespacePrefix = null"
})
