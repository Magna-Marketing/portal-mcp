Tool: list_outbound_messages

Description
List Outbound Message definitions from Tooling API (`WorkflowOutboundMessage`):
each row is Id, human-readable Name, and EntityDefinitionId (the sObject
the message is tied to). For endpoint URL, fields payload, and integration
user, use Metadata API read on `Workflow` / outbound message metadata.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, Name, EntityDefinitionId FROM WorkflowOutboundMessage

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional).
limit (number, optional, default 500).

Result
Standard Tooling query response body:
- size (number) - count of records in this response.
- totalSize (number) - total matching rows for the query.
- done (boolean) - whether the query is complete (no further pages).
- queryLocator (string|null) - cursor for next batch when paginated; null when done.
- entityTypeName (string) - "WorkflowOutboundMessage".
- records (array) - each record: attributes { type ("WorkflowOutboundMessage"), url (string) }, Id, Name, EntityDefinitionId (additional fields appear if included in the SELECT).

Required permissions
- "View Setup and Configuration" / "Customize Application".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_outbound_messages({})
