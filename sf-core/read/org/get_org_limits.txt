Tool: get_org_limits

Description
Get org-wide REST API limits and current usage: DailyApiRequests,
DataStorageMB, FileStorageMB, DailyAsyncApexExecutions,
DailyBulkApiBatches, ConcurrentSyncLongRunningApexExecutions, etc.
Use to monitor headroom before bulk loads or scheduled jobs.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/limits

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
None.

Result
Returns the raw limits object keyed by limit name with Max and Remaining values.

Required permissions
- "View Setup and Configuration".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

get_org_limits({})
