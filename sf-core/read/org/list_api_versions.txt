Tool: list_api_versions

Description
List all REST API versions available on the running instance, with
release labels and root URLs. Use to validate that a chosen `apiVersion`
in tools is supported.

Salesforce API
Salesforce API, v66.0.

Endpoint
GET /services/data/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
None.

Result
Returns the raw Salesforce versions array with label, url, and version values.

Required permissions
- "API Enabled".

Idempotency & limits
- Read-only.

Errors
- N/A (no auth required for the GET; tool still uses bearer).

Example request

list_api_versions({})
