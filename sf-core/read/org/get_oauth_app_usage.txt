Tool: get_oauth_app_usage

Description
Get OAuth usage stats for Connected Apps and External Client Apps:
which apps have accepted users, token activity, last activity time,
and aggregate API call counts. Use for security audits and to spot
deprecated apps.

Salesforce API
REST API (Connect API), v66.0. `/services/data/v66.0/apps/oauth/usage`.

Endpoint
GET /services/data/v66.0/apps/oauth/usage?page=0&pageSize=100
GET /services/data/v66.0/apps/oauth/usage/{appId}/users?page=0&pageSize=100
GET /services/data/v66.0/apps/oauth/usage/{appId}/users/tokens

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional) - ConnectedApplication Name filter using * and ?
wildcards; string converted to SOQL LIKE; no default; example: Salesforce*; do not pass
raw LIKE syntax, regex, client secrets, or comma-separated names.
startUrlPattern (string, optional) - StartUrl filter using * and ? wildcards; string
converted to SOQL LIKE; no default; example: https://app.example.com/*; do not pass
regex, SOQL fragments, or callback URLs unless they are stored in StartUrl.
whereClause (string, optional) - Additional SOQL WHERE condition for
ConnectedApplication; string without WHERE; no default; example:
OptionsAllowAdminApprovedUsersOnly = true; do not pass SELECT, FROM, ORDER BY, LIMIT, or
untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for ConnectedApplication; string without
ORDER BY; default Name; example: Name ASC; do not pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum ConnectedApplication rows to query; positive integer
clamped to 2000; default 200; example: 50; do not pass 0, negatives, decimals, or
offsets.

Result
Returns the raw Salesforce QueryResult for ConnectedApplication records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Manage Connected Apps" + "View Setup and Configuration".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY, INVALID_FIELD on bad slice.

Example request

get_oauth_app_usage({
  "namePattern": "Salesforce*",
  "startUrlPattern": "https://app.example.com/*",
  "whereClause": "OptionsAllowAdminApprovedUsersOnly = true"
})
