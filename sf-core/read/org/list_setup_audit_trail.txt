Tool: list_setup_audit_trail

Description
List `SetupAuditTrail` rows: who changed what in Setup, when, with the
section and detailed action. Use for compliance reporting, change
forensics, and to confirm a deploy actually fired.

Salesforce API
REST API (Data), v66.0. SOQL on `SetupAuditTrail`.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Action, Section, Display, CreatedById, CreatedBy.Name, DelegateUser, CreatedDate, ResponsibleNamespacePrefix FROM SetupAuditTrail WHERE CreatedDate >= ... ORDER BY CreatedDate DESC

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
action (string, optional) - SetupAuditTrail Action exact match; string category of the
setup change; no default; example: PermSetCreate; do not pass Display text, multiple
actions, or SOQL operators.
actionPattern (string, optional) - Action filter using * and ? wildcards; string
converted to SOQL LIKE; no default; example: PermSet*; do not pass raw LIKE syntax,
regex, or Display text.
sectionPattern (string, optional) - Section filter using * and ? wildcards; string
converted to SOQL LIKE; no default; example: Manage Users; do not pass raw LIKE syntax,
regex, or Action values.
createdById (string, optional) - CreatedById reference filter; Salesforce User Id
string; no default; example: 0055g00000ABCDe; do not pass usernames, emails, multiple
Ids, or relationship fields.
createdDateFrom (string, optional) - Minimum CreatedDate filter; ISO-8601 dateTime or
Salesforce date literal string; no default; example: 2026-05-01T00:00:00.000Z; do not
pass local-only dates or untrusted SOQL fragments.
createdDateTo (string, optional) - Maximum CreatedDate filter; ISO-8601 dateTime or
Salesforce date literal string; no default; example: 2026-05-16T00:00:00.000Z; do not
pass local-only dates or an end value earlier than the start value.
whereClause (string, optional) - Additional SOQL WHERE condition for SetupAuditTrail;
string without WHERE; no default; example: DelegateUser != null; do not pass SELECT,
FROM, ORDER BY, LIMIT, aggregate queries, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for SetupAuditTrail; string without ORDER BY;
default CreatedDate DESC; example: Action ASC, CreatedDate DESC; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum SetupAuditTrail rows to query; positive integer
clamped to 2000; default 200; example: 200; do not pass 0, negatives, decimals, or
offsets.

Result
Returns the raw Salesforce QueryResult for SetupAuditTrail records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View Setup and Configuration" / "Modify All Data".

Idempotency & limits
- Read-only.
- Retention: 180 days for most editions, 6+ months for enterprise.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_setup_audit_trail({
  "action": "PermSetCreate",
  "actionPattern": "PermSet*",
  "sectionPattern": "Manage Users"
})
