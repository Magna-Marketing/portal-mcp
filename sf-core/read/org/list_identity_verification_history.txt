Tool: list_identity_verification_history

Description
List `IdentityVerificationEvent` rows: MFA challenges and verification
attempts (success / failure / abandoned), method (TOTP, SMS, Email,
SecurityKey, etc.), and outcome. Use for security incident
investigation alongside `list_login_history`.

Salesforce API
REST API (Data), v66.0. SOQL on `IdentityVerificationEvent`.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, UserId, EventDate, Status, Method, Activity, VerificationMethod, VerificationTime, SourceIpAddress, City, Country, Browser, Platform FROM IdentityVerificationEvent

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
userId (string, optional) - VerificationHistory UserId reference filter; Salesforce User
Id string; no default; example: 0055g00000ABCDe; do not pass usernames, emails, multiple
Ids, or SOQL fragments.
status (string, optional) - VerificationHistory Status exact match; string value
returned by Salesforce; no default; example: Success; do not pass lowercase guesses,
multiple statuses, or SOQL operators.
verificationTimeFrom (string, optional) - Minimum VerificationTime filter; ISO-8601
dateTime or Salesforce date literal string; no default; example:
2026-05-01T00:00:00.000Z; do not pass local-only dates or untrusted SOQL fragments.
verificationTimeTo (string, optional) - Maximum VerificationTime filter; ISO-8601
dateTime or Salesforce date literal string; no default; example:
2026-05-16T00:00:00.000Z; do not pass local-only dates or an end value earlier than the
start value.
whereClause (string, optional) - Additional SOQL WHERE condition for
VerificationHistory; string without WHERE; no default; example: Status != 'Success'; do
not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for VerificationHistory; string without ORDER
BY; default VerificationTime DESC; example: VerificationTime DESC; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum VerificationHistory rows to query; positive integer
clamped to 2000; default 200; example: 100; do not pass 0, negatives, decimals, or
offsets.

Result
Returns the raw Salesforce QueryResult for VerificationHistory records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Manage Users" / "View Setup and Configuration".

Idempotency & limits
- Read-only.
- Retention: 180 days.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_identity_verification_history({
  "userId": "0055g00000ABCDe",
  "status": "Success",
  "verificationTimeFrom": "2026-05-01T00:00:00.000Z"
})
