Tool: get_event_log_file

Description
Download the contents of an `EventLogFile` (CSV-shaped events). The
tool can return raw CSV or parse into structured rows using the
`fieldNames`/`fieldTypes` from the file's metadata.

Salesforce API
REST API (Data), v66.0. `GET /sobjects/EventLogFile/{id}/LogFile`.

Endpoint
GET /services/data/v66.0/sobjects/EventLogFile/{id}/LogFile

Headers
Authorization: Bearer <access_token>
Accept: text/csv

Body
None.

Input (parameters)
id (string, required) - EventLogFile record Id whose LogFile field is retrieved;
Salesforce Id string, usually 15 or 18 characters; required with no default; example:
0AT5g00000ABCDeGAH; do not pass EventType, filenames, URLs, comma-separated Ids, or SOQL
fragments.

Result
Returns the raw Salesforce LogFile response, typically CSV text for the event type
schema.

Required permissions
- "View Event Log Files" + Event Monitoring license.

Idempotency & limits
- Read-only.
- Files can be 10s of MB; large parses may be capped by maxRows.

Errors
- NOT_FOUND.

Example request

get_event_log_file({
  "id": "0AT5g00000ABCDeGAH"
})
