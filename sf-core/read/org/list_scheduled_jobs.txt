Tool: list_scheduled_jobs

Description
List `CronTrigger` rows (the schedule layer of Scheduled Apex /
Scheduled Flow / Reporting Snapshots). Each shows next/previous fire
time, state (WAITING|ACQUIRED|EXECUTING|...), cron expression, owner,
and what's scheduled (CronJobDetail joined view).

Salesforce API
REST API (Data), v66.0. SOQL on `CronTrigger` and `CronJobDetail`.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, OwnerId, Owner.Name, CronExpression, CronJobDetailId, CronJobDetail.Name, CronJobDetail.JobType, NextFireTime, PreviousFireTime, State, StartTime, EndTime, TimesTriggered, TimeZoneSidKey FROM CronTrigger

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
state ("WAITING" | "ACQUIRED" | "EXECUTING" | "COMPLETE" | "ERROR" | "DELETED" | "PAUSED" | "BLOCKED" | "PAUSED_BLOCKED", optional) -
CronTrigger State exact match; documented uppercase picklist value; no default; example:
WAITING; do not pass lowercase values, multiple states, or SOQL operators.
cronJobDetailId (string, optional) -
CronJobDetailId reference filter; Salesforce Id string; no default; example:
08e5g00000ABCDe; do not pass job names, multiple Ids, or relationship fields.
ownerId (string, optional) -
OwnerId reference filter; Salesforce User Id string; no default; example:
0055g00000ABCDe; do not pass usernames, emails, multiple Ids, or SOQL fragments.
whereClause (string, optional) -
Additional SOQL WHERE condition for CronTrigger; string without WHERE; no default;
example: NextFireTime != null; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted
user input.
orderBy (string, optional) -
SOQL ORDER BY for CronTrigger; string without ORDER BY; default NextFireTime ASC;
example: State ASC, NextFireTime ASC; do not pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) -
Maximum CronTrigger rows to query; positive integer clamped to 2000; default 200;
example: 100; do not pass 0, negatives, decimals, or offsets.

Result
Returns the raw Salesforce QueryResult for CronTrigger records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View Setup and Configuration" / "Modify All Data".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_scheduled_jobs({
  "state": "WAITING",
  "cronJobDetailId": "08e5g00000ABCDe",
  "ownerId": "0055g00000ABCDe"
})
