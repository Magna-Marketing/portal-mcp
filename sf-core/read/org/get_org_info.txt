Tool: get_org_info

Description
Get the org's identity: organization name, edition, instance URL,
namespace prefix, default locale/language, fiscal year start,
sandbox flag, trial expiration, organization Id (15+18 char), and a
list of accepted API versions.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
None.

Result
Returns the raw Salesforce QueryResult for Organization records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "API Enabled".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

get_org_info({})
