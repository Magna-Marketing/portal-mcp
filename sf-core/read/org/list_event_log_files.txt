Tool: list_event_log_files

Description
List `EventLogFile` rows for Event Monitoring. Each row is a CSV file
of events for a specific event type (Login, API, ApexExecution,
ReportExport, ContentDocumentLink, etc.) and a date range. Use
`get_event_log_file` to download.

Salesforce API
REST API (Data), v66.0. SOQL on `EventLogFile`. Requires Event
Monitoring add-on license.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, EventType, LogDate, LogFileLength, ApiVersion, CreatedDate, Sequence, Interval, LogFileFieldNames, LogFileFieldTypes FROM EventLogFile

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
eventType (string, optional) - EventLogFile EventType exact match; string picklist value
from Event Monitoring; no default; example: API; do not pass labels, comma-separated
values, regex, or SOQL operators.
eventTypePattern (string, optional) - EventType filter using * and ? wildcards; string
converted to SOQL LIKE; no default; example: Login*; do not pass raw LIKE syntax, regex,
or multiple patterns.
logDateFrom (string, optional) - Minimum LogDate filter; ISO-8601 dateTime or Salesforce
date literal string; no default; example: 2026-05-01T00:00:00.000Z; do not pass
local-only dates, unquoted SOQL fragments, or end dates earlier than this value.
logDateTo (string, optional) - Maximum LogDate filter; ISO-8601 dateTime or Salesforce
date literal string; no default; example: 2026-05-16T00:00:00.000Z; do not pass
local-only dates, unquoted SOQL fragments, or start dates later than this value.
whereClause (string, optional) - Additional SOQL WHERE condition for EventLogFile;
string without WHERE; no default; example: LogFileLength > 0; do not pass SELECT, FROM,
ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for EventLogFile; string without ORDER BY;
default LogDate DESC; example: EventType ASC, LogDate DESC; do not pass WHERE, LIMIT,
SELECT, or FROM.
limit (integer, optional) - Maximum EventLogFile rows to query; positive integer clamped
to 2000; default 200; example: 200; do not pass 0, negatives, decimals, or offsets.

Result
Returns the raw Salesforce QueryResult for EventLogFile records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View Event Log Files" + Event Monitoring license.

Idempotency & limits
- Read-only.
- Retention: 30 days (or 6 months on Shield Event Monitoring).

Errors
- LICENSE_NOT_AVAILABLE: Event Monitoring not enabled.

Example request

list_event_log_files({
  "eventType": "API",
  "eventTypePattern": "Login*",
  "logDateFrom": "2026-05-01T00:00:00.000Z"
})
