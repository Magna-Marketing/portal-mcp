Tool: read_apex

Description
Read Apex class source code, metadata, or list classes by pattern.
Backed by the Tooling API's `ApexClass` sObject. Two modes:
1. Single class: provide `name` to fetch full Body, Status, ApiVersion,
   IsValid, LengthWithoutComments, NamespacePrefix, ManageableState.
2. List/pattern: provide `pattern` (with `*`) to enumerate matching
   classes (metadata only, no Body unless `includeBody=true`).

Use `read_apex_trigger` for triggers. Use `write_apex` to create/update
classes. For dependency analysis at component level use
`get_component_dependencies` (it traverses controller references).

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/sobjects/{type}/{id}
GET /services/data/v66.0/tooling/query/?q=SELECT Id, Name, NamespacePrefix, ApiVersion, Status, IsValid, BodyCrc, LengthWithoutComments, ManageableState, CreatedById, CreatedDate, LastModifiedById, LastModifiedDate, SystemModstamp FROM ApexClass

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
id (string, optional) - ApexClass record Id to retrieve directly; 15- or 18-character
Tooling API Id; no default; example: 01p5g000000ABCdAAO; do not pass class names,
ContentEntityId values, or multiple Ids.
name (string, optional) - Exact Apex class name; non-empty ApexClass.Name value; no
default; example: AccountTriggerHandler; do not pass wildcards, namespace prefixes, or
file names ending in .cls.
pattern (string, optional) - Apex class name pattern for list mode; string using * and ?
wildcards converted to SOQL LIKE; no default; example: *Service; do not pass regex, raw
LIKE syntax, or a pattern with name or id.
includeBody (boolean, optional) - Body field inclusion flag; boolean controlling whether
Body is selected in SOQL list/name mode, while direct id retrieval returns Salesforce's
default sObject payload; default true for name reads and false for list reads; example:
true; do not pass strings or expect SymbolTable references from ApexClass.
includeSymbolTable (boolean, optional) - SymbolTable field inclusion flag for SOQL
reads; boolean that can make queries slower because Salesforce may compile symbols in
the background; default false; example: true; do not pass true for broad listings unless
needed.
includeInactive (boolean, optional) - Inactive/deleted status inclusion flag; boolean;
default true includes all Status values; example: false; do not pass strings such as
Active or Inactive.
namespacePrefix (string, optional) - NamespacePrefix filter; string matched exactly, or
an empty string for unmanaged/default namespace; no default; example: acme; do not pass
namespace-qualified class names or package labels.
managedOnly (boolean, optional) - Managed package filter; boolean that limits
ManageableState to installed or released; default false; example: true; do not pass a
namespace value here.
whereClause (string, optional) - Additional SOQL WHERE condition for ApexClass; string
with or without WHERE; no default; example: ApiVersion < 60; do not pass SELECT, FROM,
ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for ApexClass list mode; string with
or without ORDER BY; default Name ASC; example: LastModifiedDate DESC; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum ApexClass rows in list mode; integer from 1 to 2000;
default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Tooling API sObject record for id/name reads, or raw Tooling API QueryResult with
totalSize, done, records for list reads.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- API Enabled.
- "View All Data" or "Author Apex" to read class bodies. Without these,
  the tool returns metadata only (no Body) and adds a warning.

Idempotency & limits
- Read-only; safe to retry.
- Tooling SOQL counts toward DailyApiRequests.
- Class Body can be up to 1 MB; pattern mode strips Body unless asked.

Errors
- INVALID_TYPE: namespace/managed combination invalid.
- INSUFFICIENT_ACCESS_OR_READONLY: no permission to read class bodies.
- NOT_FOUND: class with `name` not found in the requested namespace.

Example request

read_apex({
  "id": "01p5g000000ABCdAAO",
  "name": "AccountTriggerHandler",
  "pattern": "*Service"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "ApexClass"
      }
    }
  ]
}
