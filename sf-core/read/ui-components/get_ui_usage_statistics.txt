Tool: get_ui_usage_statistics

Description
Org-wide UI inventory and usage statistics:
- Counts of Aura, Visualforce, and FlexiPage metadata.
- Custom vs managed breakdown.
- Average / median components per Lightning Page.
- API version distribution.

Use as a once-a-quarter dashboard input or before a UI cleanup project.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
includeUsageMetrics (boolean, optional) - Whether to include a sampled
MetadataComponentDependency count; boolean; default false; example: true; do not expect
runtime traffic or page-view analytics.
sinceDays (integer, optional) - Optional recent LastModifiedDate window for additional
counts; positive integer days; no default; example: 30; do not pass decimals, negative
values, or date strings.
includeBreakdownByApi (boolean, optional) - Whether to include ApiVersion aggregate
queries where the object supports ApiVersion; boolean; default false; example: true; do
not use for FlexiPage because it has no ApiVersion field.
componentType (string, optional) - Optional focus family for clients; string value lwc,
aura, visualforce, or flexipage; no default and does not suppress other count queries;
example: lwc; do not pass arrays.

Result
raw Salesforce QueryResults for count and optional aggregate queries.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Customize Application", "View All Setup".
- Lightning Usage stats require "Modify All Data" or the
  "View Setup and Configuration" + "Lightning Usage" permset.

Idempotency & limits
- Read-only; safe to retry.
- Lightweight inventory queries; usage metrics depend on the date window.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY for traffic stats; tool falls back
  with trafficStats=null.

Example request

get_ui_usage_statistics({
  "includeUsageMetrics": true,
  "sinceDays": 30,
  "includeBreakdownByApi": true
})
