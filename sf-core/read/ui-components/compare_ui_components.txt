Tool: compare_ui_components

Description
Compare two UI components of the same type to identify differences in
metadata, file contents, exposure settings, and references. Useful for
deduplication ("are projectCard and projectCardV2 actually the same?")
and consolidation analysis. Outputs a structured diff grouped by file
plus metadata-level diffs.

Salesforce API
Tooling API, v66.0. Reads each component fully (LWC bundle files via
`LightningComponentResource`, Aura defs via `AuraDefinition`, VF via
`ApexPage`, FlexiPage XML via `FlexiPage`).

Endpoint
GET /services/data/v66.0/tooling/sobjects/{type}/{id}
GET /services/data/v66.0/tooling/query/?q=SELECT Source, FilePath, Format FROM LightningComponentResource WHERE LightningComponentBundleId = '{id}'

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
component1 (string, optional) - First component name; string exact DeveloperName or Name
for the selected type; required unless name1 is set; example: accountSummary; do not
pass file paths, labels, or multiple names.
component2 (string, optional) - Second component name; string exact DeveloperName or
Name for the selected type; required unless name2 is set; example: accountSummaryV2; do
not pass file paths, labels, or multiple names.
name1 (string, optional) - Alias for component1; string exact component name; ignored
when component1 is present; example: Account_Record_Page; do not pass multiple names.
name2 (string, optional) - Alias for component2; string exact component name; ignored
when component2 is present; example: Account_Record_Page_New; do not pass multiple
names.
type (string, optional) - Component family for both names; string accepted values lwc,
aura, visualforce, or flexipage; default lwc; example: visualforce; do not pass two
types.
componentType (string, optional) - Alias for type; string component family; ignored when
type is present; example: aura; do not pass arrays or metadata labels.

Result
raw Salesforce QueryResults for the left and right component plus simple comparison
flags.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
type (value) - included in the JSON returned by the tool.
left (value) - included in the JSON returned by the tool.
right (value) - included in the JSON returned by the tool.
differences (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application" / "View All Setup".

Idempotency & limits
- Read-only; safe to retry.
- Heavy for bundles >50 files; use `diffFormat: "summary"` for fast pass.

Errors
- NOT_FOUND on either component name.

Example request

compare_ui_components({
  "component1": "accountSummary",
  "component2": "accountSummaryV2",
  "name1": "Account_Record_Page"
})
