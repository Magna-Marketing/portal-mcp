Tool: read_lwc_file

Description
Read a single file from an LWC bundle. Useful when only one file is
needed (the JS, the meta XML, or one of multiple SVG/icon files). Use
`read_lwc_comprehensive` to get every file in the bundle.

Salesforce API
Tooling API, v66.0. `LightningComponentResource` (file rows).

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, FilePath, Format, Source FROM LightningComponentResource WHERE LightningComponentBundleId = '{bundleId}' AND FilePath LIKE '%/{fileName}'

Or by Id once known:
GET /services/data/v66.0/tooling/sobjects/LightningComponentResource/{resourceId}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
bundleName (string, optional) - LWC DeveloperName containing the file; string folder
name; required unless resourceId is provided; example: accountSummary; do not pass
labels, namespaces, or full file paths.
componentName (string, optional) - Alias for bundleName; string LWC DeveloperName;
ignored when bundleName is present; example: contactTile; do not pass
lwc/contactTile/contactTile.js.
fileName (string, optional) - Resource file name inside the LWC folder; string including
extension; required unless fileType or resourceId is provided; example:
accountSummary.js-meta.xml; do not pass directory traversal, absolute paths, or lwc/
prefixes.
fileType ("js" | "html" | "css" | "xml" | "svg", optional) - Common LWC file extension
used to derive the file name; enum js, html, css, xml, or svg; no default; example:
html; do not pass js-meta.xml, json, or multiple extensions.
resourceId (string, optional) - LightningComponentResource Id; Salesforce Id string;
bypasses bundleName and fileName lookup when present; example: 0Rb5g0000001234CAA; do
not pass bundle Ids or DeveloperName values.

Result
raw LightningComponentResource JSON object.

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only; safe to retry.
- File source can be up to 1 MB.

Errors
- NOT_FOUND: bundle or file not found.

Example request

read_lwc_file({
  "bundleName": "accountSummary",
  "componentName": "contactTile",
  "fileName": "accountSummary.js-meta.xml"
})

Example result

raw LightningComponentResource JSON object.
