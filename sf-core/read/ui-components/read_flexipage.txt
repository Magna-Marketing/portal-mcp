Tool: read_flexipage

Description
Read a Lightning Page (FlexiPage). Returns the FlexiPage row, its type
(RecordPage / AppPage / HomePage / EmbeddedServiceMinView /
CommApp), the associated sObject (for RecordPage), and the structural
composition: regions and the components placed in each. To go deeper
(per-component property values, region details) use
`read_flexipage_detailed`. For a list across the org use
`list_lightning_pages`.

Salesforce API
Tooling API, v66.0. `FlexiPage` sObject + Metadata API for the structured
XML when needed.

Endpoint
GET /services/data/v66.0/tooling/sobjects/FlexiPage/{id}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
name (string, required) - FlexiPage DeveloperName; string exact API name; no default;
example: Account_Record_Page; do not pass labels, URLs, Metadata API file paths, or
multiple names.

Result
object with raw queried FlexiPage row and raw Tooling sObject response.

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only; safe to retry.

Errors
- NOT_FOUND on name.

Example request

read_flexipage({
  "name": "Account_Record_Page"
})

Example result

object with raw queried FlexiPage row and raw Tooling sObject response.
