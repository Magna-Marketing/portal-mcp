Tool: analyze_component_usage

Description
For a single UI component, query `MetadataComponentDependency`; the first
API call returns all dependency results in `records`. For each record, use
`RefMetadataComponentType` ("FlexiPage"|"LightningComponentBundle"|"ApexPage")
and `RefMetadataComponentId` to read the referenced metadata and determine
where the component is used. Use to safely change or remove a component.

Salesforce API
Tooling API, v66.0. `MetadataComponentDependency` filtered to FlexiPage
parents, plus FlexiPage metadata reads for identifier/region.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, MetadataComponentId, MetadataComponentName, MetadataComponentType, RefMetadataComponentId, RefMetadataComponentName, RefMetadataComponentType FROM MetadataComponentDependency
GET /services/data/v66.0/tooling/sobjects/FlexiPage/{RefMetadataComponentId}     (per match)
GET /services/data/v66.0/tooling/sobjects/ApexPage/{RefMetadataComponentId}    
GET /services/data/v66.0/tooling/sobjects/LightningComponentBundle/{RefMetadataComponentId}    

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
name (string, required) - Component name (LWC DeveloperName,
  "lightning:relatedList", etc.).
type (string, required) - "LightningComponentBundle" | "AuraDefinitionBundle"
  | "ApexPage" | "StandardLightningComponent".
includePropertyValues (boolean, optional, default true).

Result
size (number).
totalSize (number).
done (boolean).
queryLocator (string|null).
entityTypeName (string) - "MetadataComponentDependency".
records (array) - Each MetadataComponentDependency record:
  attributes (object) - { type, url }.
  Id (string).
  MetadataComponentId (string).
  MetadataComponentName (string).
  MetadataComponentType (string).
  RefMetadataComponentId (string).
  RefMetadataComponentName (string).
  RefMetadataComponentType (string).

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only; safe to retry.

Errors
- NOT_FOUND on name.

Example request

analyze_component_usage({ "name": "projectCard", "type": "LightningComponentBundle" })
