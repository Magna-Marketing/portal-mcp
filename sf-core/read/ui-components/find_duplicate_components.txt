Tool: find_duplicate_components

Description
Identify potentially duplicate or near-duplicate UI components by
combining:
- Name-similarity scoring (Levenshtein + token similarity on
  DeveloperName).
- File-content similarity (Jaccard over tokens for the JS / HTML / XML
  files of LWC bundles, or .cmp/.cmp-meta.xml for Aura).
- Same target / sObject / exposure settings.

Returns clusters of components that may be candidates for consolidation.
Use with `compare_ui_components` for a precise diff between two
candidates and `deprecate_lwc_component` to retire one.

Salesforce API
Tooling API, v66.0. Reads metadata + content per candidate.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, ApiVersion, IsExposed, ManageableState FROM LightningComponentBundle WHERE ManageableState = 'unmanaged' OR ManageableState = null

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
type (string, optional) - Component family to inspect; string accepted values lwc, aura,
or visualforce; default lwc; example: aura; do not pass flexipage or multiple values.
componentType (string, optional) - Alias for type; string component family; ignored when
type is present; example: visualforce; do not pass arrays or metadata labels.
namespacePrefix (string, optional) - NamespacePrefix filter; string namespace without
trailing __; no default; example: mypkg; do not pass component-qualified names.
nameSimilarityThreshold (number, optional) - Minimum name similarity threshold for
future scoring; number from 0 to 1; default 0.8; example: 0.9; do not pass percentages
or strings.
maxClusters (integer, optional) - Maximum duplicate clusters to return; integer from 1
to 2000; default 25; example: 20; do not pass 0, decimals,.
whereClause (string, optional) - Additional SOQL WHERE condition for the selected
object; string with or without WHERE; no default; example: LastModifiedDate =
LAST_N_DAYS:365; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for the selected object; string with or
without ORDER BY; default name field ascending; example: LastModifiedDate DESC; do not
pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum source records to inspect; integer from 1 to 2000;
default 1000; example: 500; do not pass offsets, decimals,.

Result
raw candidate records grouped into derived duplicate clusters.
type (value) - included in the JSON returned by the tool.
source (value) - included in the JSON returned by the tool.
clusters (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only; safe to retry.
- Expensive in big orgs; cache result for daily reports.

Errors
- INVALID_FIELD on bad type.

Example request

find_duplicate_components({
  "type": "aura",
  "componentType": "visualforce",
  "namespacePrefix": "mypkg"
})
