Tool: get_lwc_bundle_info

Description
Get LWC bundle metadata from `LightningComponentBundle` in one call,
including the bundle name, label, API version, exposure settings,
namespace, manageable state, description, and audit fields.

Use this when you already have the bundle Id and need the component's
Tooling metadata without reading individual LWC resource files. Pair with
`read_lwc_comprehensive` if you also need file source.

Salesforce API
Tooling API, v66.0. `LightningComponentBundle`.

Endpoint
GET /services/data/v66.0/tooling/sobjects/LightningComponentBundle/{id}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
id (string, required) - LightningComponentBundle Id.

Result
attributes (object) - { type, url }.
Id (string).
DeveloperName (string).
MasterLabel (string).
ApiVersion (number).
IsExposed (boolean).
NamespacePrefix (string|null).
ManageableState (string|null).
Description (string|null).
CreatedDate (string).
LastModifiedDate (string).
LastModifiedById (string).

Required permissions
- "Customize Application" / "View Setup and Configuration".

Idempotency & limits
- Read-only; safe to retry.

Errors
- NOT_FOUND on id.

Example request

get_lwc_bundle_info({ "id": "0Rb4Q00000abcDE" })
