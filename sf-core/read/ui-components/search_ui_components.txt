Tool: search_ui_components

Description
Search UI components by name pattern across all component types
(`LightningComponentResource`, `AuraDefinitionBundle`, `ApexPage`,
`FlexiPage`). Supports `*` and `?` wildcards. Use to discover candidates
when you don't know whether something is an LWC vs Aura vs VF page.

For type-specific listing use `list_ui_components`. For Lightning Pages
specifically (record/app/home pages) use `list_lightning_pages`.

Salesforce API
Tooling API, v66.0. Multiple SOQL queries unioned by the MCP layer.
The SOQL in the `q` parameter must be URL-encoded when testing directly.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT%20Id%2C%20FilePath%2C%20Format%2C%20LightningComponentBundleId%20FROM%20LightningComponentResource%20WHERE%20FilePath%20LIKE%20%27%25Card%25%27%20LIMIT%20200
GET /services/data/v66.0/tooling/query/?q=SELECT%20Id%2C%20DeveloperName%2C%20MasterLabel%2C%20ApiVersion%2C%20NamespacePrefix%2C%20Description%2C%20LastModifiedDate%20FROM%20AuraDefinitionBundle%20WHERE%20DeveloperName%20LIKE%20%27%25Card%25%27%20LIMIT%20200
GET /services/data/v66.0/tooling/query/?q=SELECT%20Id%2C%20Name%2C%20MasterLabel%2C%20ApiVersion%2C%20NamespacePrefix%2C%20Description%2C%20LastModifiedDate%20FROM%20ApexPage%20WHERE%20Name%20LIKE%20%27%25Card%25%27%20LIMIT%20200
GET /services/data/v66.0/tooling/query/?q=SELECT%20Id%2C%20DeveloperName%2C%20MasterLabel%2C%20Type%2C%20NamespacePrefix%2C%20Description%2C%20LastModifiedDate%20FROM%20FlexiPage%20WHERE%20DeveloperName%20LIKE%20%27%25Card%25%27%20LIMIT%20200

Replace `Card` with the search term. For no filter, remove the encoded
`WHERE ...` portion and keep `LIMIT 200`.

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
pattern (string, optional) - Name pattern for DeveloperName or Name; string with * and ?
wildcards converted to SOQL LIKE; required unless namePattern is set; example:
*Account*; do not pass regex, raw LIKE syntax, or comma-separated names.
namePattern (string, optional) - Alias for pattern; string with * and ? wildcards;
ignored when pattern is present; example: Contact*; do not pass full SOQL predicates.
types (string[], optional) - Component families to search; array values lwc, aura,
visualforce, or flexipage; default searches all four; example: [\"lwc\",\"aura\"]; do
not pass metadata object names or empty strings.
componentType (string, optional) - Single component family when types is omitted; string
accepted values lwc, aura, visualforce, or flexipage; no default by itself; example:
flexipage; do not pass multiple values.
namespacePrefix (string, optional) - NamespacePrefix filter where supported; string
namespace without trailing __; no default; example: mypkg; do not pass labels or
component-qualified names.
managedOnly (boolean, optional) - Managed package filter; boolean; default false;
example: true; do not use for permission filtering.
whereClause (string, optional) - Additional SOQL WHERE condition appended to every
selected object query; string with or without WHERE; no default; example:
LastModifiedDate = LAST_N_DAYS:30; do not pass SELECT, FROM, ORDER BY, LIMIT, or
untrusted user input.
orderBy (string, optional) - SOQL ORDER BY used for every selected object query; string
with or without ORDER BY; default uses the object name field ascending; example:
LastModifiedDate DESC; do not pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum rows per component family; integer from 1 to 1000;
default 200; example: 50; do not pass offsets, decimals,.

Result
object keyed by component family, each value a raw Salesforce QueryResult.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Customize Application" / "View Setup and Configuration".

Idempotency & limits
- Read-only; safe to retry.

Errors
- INVALID_FIELD on bad type.

Example request

search_ui_components({
  "pattern": "*Account*",
  "namePattern": "Contact*",
  "types": "[\\\"lwc\\\",\\\"aura\\\"]"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "SObject"
      }
    }
  ]
}
