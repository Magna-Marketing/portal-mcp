Tool: analyze_lightning_page

Description
Analyze a Lightning Page's structure and produce performance/UX
recommendations. Heuristic checks include:
- Total component count vs Lightning best practice (<25 in main region).
- Custom components without `lazy` loading.
- Heavy related lists in primary regions (suggest moving to tabs).
- Components with unrecognized properties (probably broken).
- Excessive nesting via tabs and accordions.
- Visibility rules that always evaluate true/false.

Read-only; no changes are made. Pair recommendations with
`update_flexipage` / `update_component_properties` /
`reorder_region_components`.

Salesforce API
Tooling API, v66.0. Reads `FlexiPage` metadata.

Endpoint
GET /services/data/v66.0/tooling/sobjects/FlexiPage/{id}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
name (string, optional) - FlexiPage DeveloperName to analyze; string exact API name;
required unless pageName is set; example: Account_Record_Page; do not pass labels, URLs,
or multiple names.
pageName (string, optional) - Alias for name; string exact FlexiPage DeveloperName;
ignored when name is present; example: Home_Page; do not pass Metadata API file paths.
strict (boolean, optional) - Whether warnings should be treated as stricter review
signals; boolean; default false; example: true; do not pass for Salesforce validation
because this tool is advisory only.

Result
raw FlexiPage row and metadata plus derived metrics, findings, recommendations, and
score.
flexiPage (value) - included in the JSON returned by the tool.
metadata (value) - included in the JSON returned by the tool.
metrics (value) - included in the JSON returned by the tool.
findings (value) - included in the JSON returned by the tool.
recommendations (value) - included in the JSON returned by the tool.
overallScore (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only; safe to retry.

Errors
- NOT_FOUND on name.

Example request

analyze_lightning_page({
  "name": "Account_Record_Page",
  "pageName": "Home_Page",
  "strict": true
})

Example result

{
  "flexiPage": null,
  "metadata": null,
  "metrics": null,
  "findings": null,
  "recommendations": null,
  "overallScore": null
}
