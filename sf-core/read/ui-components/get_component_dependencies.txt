Tool: get_component_dependencies

Description
Get the dependency graph for a UI component:
- Lightning Pages where the component is placed.
- Apex controllers / classes referenced from the component's JS or markup.
- Custom labels, static resources, and other Lightning components used.
- Static parent component references (where this component is imported
  by other LWCs/Aura).

Backed by the Tooling API's `MetadataComponentDependency` view (the same
view powering "Where is this used?" in Setup -> Lightning Components).
Resolve the component's Tooling Id first, then query dependencies by Id;
`MetadataComponentName` can be selected but should not be used in `WHERE`.
Use this before refactoring or deleting components.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, MetadataComponentId, MetadataComponentName, MetadataComponentType, RefMetadataComponentId, RefMetadataComponentName, RefMetadataComponentType, RefMetadataComponentNamespace FROM MetadataComponentDependency

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
name (string, optional) - Metadata component name to resolve; string exact DeveloperName
or Name for the selected type; required unless componentId is set; example:
accountSummary; do not pass file paths or labels.
componentName (string, optional) - Alias for name; string exact component name; ignored
when name is present; example: Account_Record_Page; do not pass multiple names.
type (string, optional) - Metadata component type to resolve; string such as lwc, aura,
visualforce, flexipage, LightningComponentBundle, AuraDefinitionBundle, ApexPage, or
FlexiPage; default LightningComponentBundle; example: flexipage; do not pass labels.
componentType (string, optional) - Alias for type; string metadata component type;
ignored when type is present; example: aura; do not pass multiple values.
componentId (string, optional) - Tooling API component Id to use directly; Salesforce Id
string; no default; example: 0Rb5g0000001234CAA; do not pass record URLs or names.
direction ("outgoing" | "incoming" | "both", optional) - Dependency direction; enum
outgoing, incoming, or both; default both; example: incoming; do not pass arbitrary
relationship names.
whereClause (string, optional) - Additional SOQL WHERE condition added to dependency
queries; string with or without WHERE; no default; example: RefMetadataComponentType =
'FlexiPage'; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for MetadataComponentDependency; string with
or without ORDER BY; no default; example: RefMetadataComponentType ASC; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum dependency rows per query; integer from 1 to 2000;
default 200; example: 200; do not pass offsets, decimals,.

Result
raw Salesforce QueryResult or grouped raw QueryResults by direction.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View All Setup", "Modify All Data", or "Customize Application".

Idempotency & limits
- Read-only; safe to retry.
- `MetadataComponentDependency` is eventually consistent; brand-new
  components may not appear for a few minutes.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.
- INVALID_TYPE: bad component type.

Example request

get_component_dependencies({
  "name": "accountSummary",
  "componentName": "Account_Record_Page",
  "type": "flexipage"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "MetadataComponentDependency"
      }
    }
  ]
}
