Tool: get_component_dependencies

Description
Get the dependency graph for a UI component:
- Lightning Pages where the component is placed.
- Apex controllers / classes referenced from the component's JS or markup.
- Custom labels, static resources, and other Lightning components used.
- Static parent component references (where this component is imported
  by other LWCs/Aura).

Backed by the Tooling API's `MetadataComponentDependency` view (the same
view powering "Where is this used?" in Setup -> Lightning Components).
Resolve the component's Tooling Id first, then query dependencies by Id;
`MetadataComponentName` can be selected but should not be used in `WHERE`.
Use this before refactoring or deleting components.

Salesforce API
Tooling API, v66.0. `MetadataComponentDependency` (read-only Tooling
sObject; introduced for dependency tracing).

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel FROM {type} WHERE DeveloperName = '{name}'
GET /services/data/v66.0/tooling/query/?q=SELECT Id, MetadataComponentId, MetadataComponentName, MetadataComponentType, RefMetadataComponentId, RefMetadataComponentName, RefMetadataComponentType, RefMetadataComponentNamespace FROM MetadataComponentDependency WHERE MetadataComponentId = '{componentId}'
GET /services/data/v66.0/tooling/query/?q=SELECT Id, MetadataComponentId, MetadataComponentName, MetadataComponentType, RefMetadataComponentId, RefMetadataComponentName, RefMetadataComponentType, RefMetadataComponentNamespace FROM MetadataComponentDependency WHERE RefMetadataComponentId = '{componentId}'

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
name (string, required) - Component DeveloperName or Name.
type (string, required) - Tooling component type ("LightningComponentBundle",
  "AuraDefinitionBundle", "ApexPage", "FlexiPage", "ApexClass", etc.).
direction (string, optional, default "both") - "outgoing" (this component
  references X), "incoming" (X references this component), or "both".
includeStandardRefs (boolean, optional, default false) - Include refs to
  standard Lightning components (`lightning-record-form`, etc.).
includeFlexiPages (boolean, optional, default true) - When this is an
  LWC/Aura, also enumerate `FlexiPage` placements (region info).

Result
size (number).
totalSize (number).
done (boolean).
queryLocator (string|null).
entityTypeName (string) - "MetadataComponentDependency".
records (array) - Each MetadataComponentDependency record:
  attributes (object) - { type, url }.
  Id (string).
  MetadataComponentId (string).
  MetadataComponentName (string).
  MetadataComponentType (string).
  RefMetadataComponentId (string).
  RefMetadataComponentName (string).
  RefMetadataComponentType (string).
  RefMetadataComponentNamespace (string|null).

Required permissions
- "View All Setup", "Modify All Data", or "Customize Application".

Idempotency & limits
- Read-only; safe to retry.
- `MetadataComponentDependency` is eventually consistent; brand-new
  components may not appear for a few minutes.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.
- INVALID_TYPE: bad component type.

Example request

get_component_dependencies({
  "name": "projectCard",
  "type": "LightningComponentBundle",
  "direction": "both"
})
