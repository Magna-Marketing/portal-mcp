Tool: analyze_object_ui_usage

Description
For a given sObject, query `FlexiPage` record pages that target that object.
Use `Type = 'RecordPage'` and `EntityDefinition.QualifiedApiName = '{sObject}'`
in the `WHERE` condition. The first API call returns matching FlexiPage
records; use each record Id to read FlexiPage metadata and inspect the UI
components on that object page.

Salesforce API
Tooling API, v66.0.
- `FlexiPage WHERE Type = 'RecordPage' AND EntityDefinition.QualifiedApiName = '{sObject}'`.
- For each FlexiPage, parse `Metadata.flexiPageRegions[].itemInstances`.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, Type, EntityDefinitionId FROM FlexiPage WHERE Type = 'RecordPage' AND EntityDefinition.QualifiedApiName = '{sObject}'

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
sObject (string, required) - sObject API name.
includeStandardComponents (boolean, optional, default true).
includeRelatedListsAsRefs (boolean, optional, default true).

Result
size (number).
totalSize (number).
done (boolean).
queryLocator (string|null).
entityTypeName (string) - "FlexiPage".
records (array) - Each FlexiPage record:
  attributes (object) - { type, url }.
  Id (string).
  DeveloperName (string).
  MasterLabel (string).
  Type (string) - "RecordPage".
  EntityDefinitionId (string|null).

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only; safe to retry.

Errors
- INVALID_TYPE: bad sObject.

Example request

analyze_object_ui_usage({ "sObject": "Project__c" })
