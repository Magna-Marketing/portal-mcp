Tool: list_ui_components

Description
List all UI components of a given type with names, labels, and API
versions. Three component types are supported, each from its own
Tooling sObject:
- LWC -> `LightningComponentBundle`.
- Aura -> `AuraDefinitionBundle`.
- VisualForce -> `ApexPage`.
For LWCs use `read_lwc` / `get_lwc_bundle_info` to drill in. For
FlexiPages (Lightning Pages) use `list_lightning_pages` (different
sObject `FlexiPage`).

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, ApiVersion, NamespacePrefix, IsExposed, ManageableState, CreatedDate, LastModifiedDate FROM LightningComponentBundle [WHERE ...]
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, ApiVersion, NamespacePrefix, ManageableState, Description, CreatedDate, LastModifiedDate FROM AuraDefinitionBundle [WHERE ...]
GET /services/data/v66.0/tooling/query/?q=SELECT Id, Name, MasterLabel, ApiVersion, NamespacePrefix, ManageableState, IsAvailableInTouch, ControllerKey FROM ApexPage [WHERE ...]

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
type (string, optional) - UI component family to list; string accepted values lwc, aura,
visualforce, or flexipage; default lwc; example: aura; do not pass metadata type names
unless using componentType for compatibility.
componentType (string, optional) - Alias for type; string accepted values lwc, aura,
visualforce, or flexipage; ignored when type is present; example: visualforce; do not
pass multiple values.
pattern (string, optional) - Name pattern for DeveloperName or Name; string with * and ?
wildcards converted to SOQL LIKE; no default; example: Account*; do not pass regex, raw
LIKE syntax, or comma-separated names.
namespacePrefix (string, optional) - NamespacePrefix filter; string namespace without
trailing __; no default; example: mypkg; pass an empty string only by omitting this
field, not as a literal filter.
managedOnly (boolean, optional) - Managed package filter; boolean; default false;
example: true; do not pass true together with includeUnmanaged-only expectations.
includeUnmanaged (boolean, optional) - Whether unmanaged components can be returned when
managedOnly is false; boolean; default true; example: false; do not use for object-level
security filtering.
modifiedSince (string, optional) - LastModifiedDate lower bound; ISO-8601 date or
datetime string accepted by SOQL; no default; example: 2026-01-01T00:00:00Z; do not pass
relative dates or unquoted SOQL snippets.
whereClause (string, optional) - Additional SOQL WHERE condition for the selected
Tooling object; string with or without WHERE; no default; example: ApiVersion >= 60.0;
do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for the selected Tooling object; string with
or without ORDER BY; default uses name field ascending; example: LastModifiedDate DESC;
do not pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum rows to return; integer from 1 to 2000; default 200;
example: 100; do not pass 0, negatives, decimals, offsets,.

Result
raw Salesforce QueryResult with totalSize, done, and records for the selected Tooling
object.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Customize Application" or "View Setup and Configuration".

Idempotency & limits
- Read-only; safe to retry.

Errors
- INVALID_FIELD: invalid type value.

Example request

list_ui_components({
  "type": "aura",
  "componentType": "visualforce",
  "pattern": "Account*"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "SObject"
      }
    }
  ]
}
