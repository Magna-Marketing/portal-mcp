Tool: compare_lightning_pages

Description
Compare two Lightning Pages (FlexiPages) and report metadata + region +
component differences. Useful when consolidating record-page variants
(e.g. profile-specific or record-type-specific pages) or migrating from
one page to another.

Salesforce API
Tooling API, v66.0. Two reads of FlexiPage detailed metadata, then a
client-side structural diff.

Endpoint
GET /services/data/v66.0/tooling/sobjects/FlexiPage/{id}     (twice)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
page1 (string, required) - First FlexiPage DeveloperName; string exact API name; no
default; example: Account_Record_Page; do not pass labels, URLs, or multiple names.
page2 (string, required) - Second FlexiPage DeveloperName; string exact API name; no
default; example: Account_Record_Page_v2; do not pass labels, URLs, or multiple names.

Result
raw FlexiPage rows and metadata for both pages plus derived difference flags.
pages (value) - included in the JSON returned by the tool.
differences (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only; safe to retry.

Errors
- NOT_FOUND on either name.

Example request

compare_lightning_pages({
  "page1": "Account_Record_Page",
  "page2": "Account_Record_Page_v2"
})
