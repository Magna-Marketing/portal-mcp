Tool: validate_ui_component

Description
Validate a UI component's configuration. Static checks include:
- Required files present (LWC must have js + js-meta.xml; Aura must have
  .cmp + .cmp-meta.xml).
- Metadata XML wellformed.
- API version not below the org's minimum.
- For LWCs: `isExposed=true` requires at least one `target`.
- For FlexiPages: regions referenced have unique IDs and exist.
- VF pages: controller exists if specified.
- Static-resource references resolve.
Issues are categorized error / warning / info.

Use this before a deploy or after edits to catch obvious metadata
mistakes that the platform would otherwise reject.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
type (string, optional) - Component family to validate; string accepted values lwc,
aura, visualforce, or flexipage; default lwc; example: lwc; do not pass metadata labels
or multiple values.
componentType (string, optional) - Alias for type; string component family; ignored when
type is present; example: visualforce; do not pass arrays.
name (string, optional) - Component name to validate; string exact DeveloperName or Name
for the selected type; required unless componentName is set; example: accountSummary; do
not pass file paths or labels.
componentName (string, optional) - Alias for name; string exact component name; ignored
when name is present; example: Account_Record_Page; do not pass multiple names.
strict (boolean, optional) - Whether warnings make the derived summary invalid; boolean;
default false; example: true; do not use as a substitute for Salesforce deployment
validation.

Result
raw Tooling API records plus derived validation summary and issues.
component (value) - included in the JSON returned by the tool.
summary (value) - included in the JSON returned by the tool.
issues (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application" / "View Setup and Configuration".

Idempotency & limits
- Read-only; safe to retry.

Errors
- NOT_FOUND on name.

Example request

validate_ui_component({
  "type": "lwc",
  "componentType": "visualforce",
  "name": "accountSummary"
})

Example result

{
  "component": null,
  "summary": null,
  "issues": null
}
