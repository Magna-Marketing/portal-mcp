Tool: list_scratch_orgs

Description
List scratch org definitions and active scratch orgs (`ScratchOrgInfo`).
Each row shows the configuration, status, expiration, and connected
edition. Scratch orgs are managed from a Dev Hub org.

Salesforce API
Tooling API, v66.0. `ScratchOrgInfo`.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, OrgName, Status, ExpirationDate, Edition, Country, Description, Features, Namespace, ConnectedAppConsumerKey, ConnectedAppCallbackUrl, AdminEmail, Username, AuthCode, LoginUrl, SignupInstance, ScratchOrg, ScratchOrgInfoVersion, CreatedById, CreatedDate FROM ScratchOrgInfo

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
status (string, optional) - ScratchOrgInfo Status exact match; string; no default;
example: Active; do not pass labels, arrays, or SOQL fragments.
orgNamePattern (string, optional) - OrgName filter using * and ? wildcards; string
converted to SOQL LIKE; no default; example: feature-*; do not pass raw LIKE syntax,
regex, or usernames.
usernamePattern (string, optional) - Username filter using * and ? wildcards; string
converted to SOQL LIKE; no default; example: test-*@example.com; do not pass raw LIKE
syntax or comma-separated usernames.
includeExpired (boolean, optional) - Whether expired scratch orgs are included by
omitting the ExpirationDate filter; boolean; default false filters to today or later;
example: true; do not pass strings such as \"false\".
whereClause (string, optional) - Additional SOQL WHERE condition for ScratchOrgInfo;
string without WHERE; no default; example: Edition = 'Developer'; do not pass SELECT,
FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for ScratchOrgInfo; string without ORDER BY;
default CreatedDate DESC; example: ExpirationDate ASC NULLS LAST; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum ScratchOrgInfo rows to query; positive integer
clamped to 2000; default 200; example: 100; do not pass 0, negatives, decimals, or
offsets.

Result
Returns a JSON object with query and raw query result.
query (value) - included in the JSON returned by the tool.
result (value) - included in the JSON returned by the tool.

Required permissions
- Run from a Dev Hub org with "Manage Dev Hub" + "View All Data".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY, INVALID_ORG_TYPE if not Dev Hub.

Example request

list_scratch_orgs({
  "status": "Active",
  "orgNamePattern": "feature-*",
  "usernamePattern": "test-*@example.com"
})
