Tool: view_sandbox

Description
Get detailed sandbox info: identity, status, source org, refresh
history, post-copy script class, activation timestamps, host name (if
provisioned).

Salesforce API
Tooling API, v66.0. `SandboxInfo` + `SandboxProcess` for refresh
history.

Endpoint
GET /services/data/v66.0/tooling/sobjects/SandboxInfo/{id}
GET /services/data/v66.0/tooling/query/?q=SELECT Id, SandboxInfoId, SandboxName, Status, ActivatedDate, EndDate, LicenseType, CopyArchivedActivities, CopyChatter, Description FROM SandboxProcess WHERE SandboxInfoId = '{id}'

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
sandboxName (string, required) - SandboxInfo SandboxName to match exactly; string with
the sandbox name only; required; example: DEV01; do not pass wildcards, production org
names, domains, or empty strings.

Result
Returns a JSON object with query and raw Tooling API result.
query (value) - included in the JSON returned by the tool.
result (value) - included in the JSON returned by the tool.

Required permissions
- "Manage Sandboxes".

Idempotency & limits
- Read-only.

Errors
- NOT_FOUND.

Example request

view_sandbox({
  "sandboxName": "DEV01"
})
