Tool: get_deployment_status

Description
Get a single deployment's full status, including per-component success
and failure rows, run tests result, and code coverage warnings. Used by
CI / CD pipelines after `deploy_metadata` to wait for completion.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
deployId (string, required) - Deployment request Id to check; Salesforce Id string,
commonly returned by metadata deployRequest or DeployRequest; required; example:
0Af5g00000ABCDe; do not pass a job name, URL, empty string, or comma-separated Ids.
includeToolingRecord (boolean, optional) - Whether to also query the Tooling API
DeployRequest row; boolean; default true; example: false; pass false if the Metadata
REST status response alone is enough.

Result
Returns a JSON object with deployRequestUrl, raw deployRequestResult, optional
toolingQuery, and optional raw toolingResult.
deployRequestUrl (value) - included in the JSON returned by the tool.
deployRequestResult (value) - included in the JSON returned by the tool.
toolingQuery (value) - included in the JSON returned by the tool.
toolingResult (value) - included in the JSON returned by the tool.

Required permissions
- "Modify Metadata Through Metadata API Functions".

Idempotency & limits
- Read-only.

Errors
- NOT_FOUND.

Example request

get_deployment_status({
  "deployId": "0Af5g00000ABCDe"
})
