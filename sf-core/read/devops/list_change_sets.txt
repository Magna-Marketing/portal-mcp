Tool: list_change_sets

Description
List inbound and outbound Change Sets and their components. Outbound
change sets are uploaded packages awaiting send to a target org;
inbound are received and either deployed, validated, or pending.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, MetadataPackageId, Name, MajorVersion, MinorVersion, PatchVersion, BuildNumber, IsDeprecated, ReleaseState FROM MetadataPackageVersion

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
metadataPackageId (string, optional) - Parent MetadataPackageId to match; Salesforce Id
string; no default; example: 0335g00000ABCDe; do not pass package names, version Ids, or
comma-separated Ids.
namePattern (string, optional) - MetadataPackageVersion Name filter using * and ?
wildcards; string converted to SOQL LIKE; no default; example: Release_*; do not pass
raw LIKE syntax or regex.
releaseState (string, optional) - ReleaseState exact match from MetadataPackageVersion;
string; no default; example: Beta; do not pass labels, arrays, or SOQL fragments.
whereClause (string, optional) - Additional Tooling SOQL WHERE condition for
MetadataPackageVersion; string without WHERE; no default; example: IsDeprecated = false;
do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - Tooling SOQL ORDER BY for MetadataPackageVersion; string
without ORDER BY; default Id DESC; example: MajorVersion DESC, MinorVersion DESC; do not
pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum MetadataPackageVersion rows to query; positive
integer clamped to 2000; default 200; example: 100; do not pass 0, negatives, decimals,
or offsets.

Result
Returns a JSON object with query and raw Tooling API result.
query (value) - included in the JSON returned by the tool.
result (value) - included in the JSON returned by the tool.

Required permissions
- "Deploy Change Sets" / "Modify Metadata Through Metadata API Functions".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_change_sets({
  "metadataPackageId": "0335g00000ABCDe",
  "namePattern": "Release_*",
  "releaseState": "Beta"
})
