Tool: list_deployments

Description
List recent Metadata API deployments (`DeployRequest`). Each row shows
status (Pending|InProgress|Succeeded|Failed|Canceled|SucceededPartial),
component counts, test results, time taken, and the user who submitted.
Use to audit who deployed what and confirm pipelines.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, Status, NumberComponentsTotal, NumberComponentsDeployed, NumberComponentErrors FROM DeployRequest

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
status (string | string[], optional) - DeployRequest Status value or values; string or
string array; no default; example: [\"Succeeded\", \"Failed\"]; do not pass labels,
empty strings, or SOQL fragments.
sinceHours (number, optional) - StartDate lookback window in hours; non-negative number;
default 168; example: 24; pass 0 only when you want deployments since the current
instant.
checkOnlyOnly (boolean, optional) - Whether to filter by validation-only deployments;
boolean; no default means both CheckOnly true and false; example: true; do not pass
strings such as \"true\".
createdById (string, optional) - Submitting user Id stored in CreatedById; Salesforce Id
string; no default; example: 0055g00000ABCDe; do not pass usernames, names, or
comma-separated Ids.
whereClause (string, optional) - Additional Tooling SOQL WHERE condition for
DeployRequest; string without WHERE; no default; example: ErrorStatusCode != null; do
not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - Tooling SOQL ORDER BY for DeployRequest; string without
ORDER BY; default StartDate DESC; example: CompletedDate DESC NULLS LAST; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum DeployRequest rows to query; positive integer
clamped to 2000; default 200; example: 50; do not pass 0, negatives, decimals, or
offsets.

Result
Returns a JSON object with query and raw Tooling API result.
query (value) - included in the JSON returned by the tool.
result (value) - included in the JSON returned by the tool.

Required permissions
- "Modify Metadata Through Metadata API Functions" / "Manage Deployments".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_deployments({
  "status": "[\\\"Succeeded\\\", \\\"Failed\\\"]",
  "sinceHours": 24,
  "checkOnlyOnly": true
})
