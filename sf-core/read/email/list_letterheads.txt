Tool: list_letterheads

Description
List Letterheads (`BrandTemplate`) used as a header/footer container
for HTML email templates.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, Description, LastReferencedDate, LastViewedDate, LetterheadHeader, LetterheadFooter FROM EnhancedLetterhead

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional) - Pattern for EnhancedLetterhead.Name; string using * and
? wildcards converted to SOQL LIKE; no default; example: Brand*; do not pass regex, raw
LIKE syntax, or multiple patterns.
includeBody (boolean, optional) - Whether to include LetterheadHeader and
LetterheadFooter fields; boolean; default false; example: true; do not pass true when
avoiding large HTML content.
whereClause (string, optional) - Additional SOQL WHERE condition for EnhancedLetterhead;
string with or without WHERE; no default; example: LastViewedDate = LAST_N_DAYS:30; do
not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for EnhancedLetterhead; string with or
without ORDER BY; default Name ASC; example: LastReferencedDate DESC NULLS LAST; do not
pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum EnhancedLetterhead rows to return; integer from 1 to
2000; default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "API Enabled".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_letterheads({
  "namePattern": "Brand*",
  "includeBody": true,
  "whereClause": "LastViewedDate = LAST_N_DAYS:30"
})
