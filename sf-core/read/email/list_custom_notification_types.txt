Tool: list_custom_notification_types

Description
List Custom Notification Types (`CustomNotificationType`). These are
the channels you can `publish_custom_notification` to (in-app + mobile).
Each type has its supported channels (Desktop / Mobile) and an icon.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, Description, CustomNotifTypeName, Desktop, Mobile, NamespacePrefix, ManageableState FROM CustomNotificationType

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional) - Pattern for DeveloperName, MasterLabel, or
CustomNotifTypeName; string using * and ? wildcards converted to SOQL LIKE; no default;
example: Approval*; do not pass regex, raw LIKE syntax, or multiple patterns.
namespacePrefix (string, optional) - Namespace prefix filter; string compared to
NamespacePrefix, with empty string meaning unpackaged notification types; no default;
example: mypkg; do not pass package labels or multiple namespaces.
whereClause (string, optional) - Additional SOQL WHERE condition for
CustomNotificationType; string with or without WHERE; no default; example: Desktop =
true; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for CustomNotificationType; string
with or without ORDER BY; default DeveloperName ASC; example: MasterLabel ASC; do not
pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum CustomNotificationType rows to return; integer from
1 to 2000; default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce Tooling QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "API Enabled" + "Customize Application".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_custom_notification_types({
  "namePattern": "Approval*",
  "namespacePrefix": "mypkg",
  "whereClause": "Desktop = true"
})
