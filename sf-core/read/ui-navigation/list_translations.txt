Tool: list_translations

Description
List translation entries (Salesforce Translation Workbench). Returns
labels translated per language for custom labels, custom fields, picklist
values, custom buttons, validation messages, and quick actions.

Salesforce API
Metadata API (`Translations`), v66.0.

Endpoint
POST /services/Soap/m/66.0   (readMetadata Translations per language)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
language (string, optional) - Translation.Language exact filter; Salesforce language
code string; no default; example: fr; do not pass locale display names, labels, or
multiple languages.
languagePattern (string, optional) - Translation.Language pattern filter; string using *
and ? wildcards converted to SOQL LIKE; no default; example: en*; do not pass regex, raw
LIKE syntax, or multiple patterns.
onlyActive (boolean, optional) - Active-language filter for IsActive; boolean; default
false means no IsActive filter; example: true; do not pass string booleans.
onlyManageable (boolean, optional) - Manageability filter for CanManage; boolean;
default false means no CanManage filter; example: true; do not pass this to infer user
permissions outside Translation rows.
whereClause (string, optional) - Additional SOQL WHERE condition for Translation; string
with or without WHERE; no default; example: IsActive = true; do not pass SELECT, FROM,
ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for Translation; string with or
without ORDER BY; default Language ASC; example: Language DESC; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum Translation rows to return; integer from 1 to 2000;
default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View Setup and Configuration", "Manage Translation".

Idempotency & limits
- Read-only.

Errors
- TRANSLATION_NOT_ENABLED if Translation Workbench is off.

Example request

list_translations({
  "language": "fr",
  "languagePattern": "en*",
  "onlyActive": true
})
