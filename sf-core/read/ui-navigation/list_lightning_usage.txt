Tool: list_lightning_usage

Description
Lightning Experience usage metrics: page views, exits, top users by
page, FlexiPage performance, browser/app distribution, and toggle
metrics. Useful for adoption reporting and performance tuning.

Salesforce API
REST API, v66.0. `/lightning/usage*`.

Endpoint
GET /services/data/v66.0/lightning/usagetoggle?startDate=...&endDate=...                    (toggles)
GET /services/data/v66.0/lightning/usagebypage?startDate=...&endDate=...                    (per page)
GET /services/data/v66.0/lightning/usagebybrowser?startDate=...&endDate=...                 (browsers)
GET /services/data/v66.0/lightning/usagebyapptype?startDate=...&endDate=...                 (app types)
GET /services/data/v66.0/lightning/usagebyflexipage?startDate=...&endDate=...               (FlexiPages)
GET /services/data/v66.0/lightning/exitbypage?startDate=...&endDate=...                     (exit metrics)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
slice (unknown, required) - Metric slice to query; enum toggle, byPage, byBrowser,
byAppType, byFlexiPage, or exitByPage; required; example: byPage; do not pass sObject
API names directly.
startDate (string, required) - Inclusive MetricsDate lower bound; date string in
YYYY-MM-DD format; required; example: 2026-05-01; do not pass datetimes, relative dates,
or locale-formatted dates.
endDate (string, required) - Inclusive MetricsDate upper bound; date string in
YYYY-MM-DD format; required; example: 2026-05-15; do not pass datetimes, relative dates,
or a date earlier than startDate.
pageNamePattern (string, optional) - PageName pattern for slices with PageName; string
using * and ? wildcards converted to SOQL LIKE; no default; example: Account*; do not
pass regex, raw LIKE syntax, or use with slices without PageName.
userId (string, optional) - UserId filter for slices that include UserId; Salesforce 15-
or 18-character user ID string; no default; example: 005xx0000012345AAA; do not pass
usernames, emails, or multiple IDs.
whereClause (string, optional) - Additional SOQL WHERE condition for the selected metric
object; string with or without WHERE; no default; example: TotalCount > 0; do not pass
SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for the selected metric object; string
with or without ORDER BY; default MetricsDate DESC; example: MetricsDate DESC, PageName
ASC; do not pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum metric rows to return; integer from 1 to 2000;
default 200; example: 200; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce QueryResult with totalSize, done, records; byAppType returns grouped
MetricsDate/AppExperience rows with TotalCount.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
warning (value) - included in the JSON returned by the tool.
objectName (value) - included in the JSON returned by the tool.
soql (value) - included in the JSON returned by the tool.
message (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration" + "Modify All Data" (for some slices).

Idempotency & limits
- Read-only.
- Date range max 30 days per call.

Errors
- INVALID_DATE_RANGE, INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_lightning_usage({
  "slice": "byPage",
  "startDate": "2026-05-01",
  "endDate": "2026-05-15"
})
