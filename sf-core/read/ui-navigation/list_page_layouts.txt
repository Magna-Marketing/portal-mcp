Tool: list_page_layouts

Description
List page layouts for an sObject and (optionally) per-record-type assignment per profile. Returns the layout name, related sObject, and the sections / fields / related lists configured.

Salesforce API
Tooling API + Metadata API, v66.0. `Layout` (Tooling for IDs, Metadata for full body).

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, Name, EntityDefinition.QualifiedApiName FROM Layout WHERE EntityDefinition.QualifiedApiName = '{sObject}'
POST /services/Soap/m/66.0   (readMetadata Layout for full XML)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
sObject (string, required) - Object API name whose layouts are requested; non-empty
Salesforce sObject API name; required; example: Account; do not pass labels, record IDs,
field API names, or multiple objects.
recordTypeId (string, optional) - RecordType ID used by the REST layouts endpoint; 15-
or 18-character Salesforce ID; no default means all layouts for the object; example:
012xx0000001234AAA; do not pass record type developer names, labels, object IDs, or
multiple IDs.

Result
raw sObject Layouts response with layouts, recordTypeMappings, and
recordTypeSelectorRequired when returned by Salesforce.

Required permissions
- "View Setup and Configuration" / "Customize Application".

Idempotency & limits
- Read-only.

Errors
- INVALID_TYPE on bad sObject.

Example request

list_page_layouts({
  "sObject": "Account"
})
