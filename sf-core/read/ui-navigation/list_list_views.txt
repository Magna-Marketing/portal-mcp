Tool: list_list_views

Description
List List Views for an sObject and (optionally) describe one or fetch
its results. List Views are the saved per-user / per-org filtered
views ("My Open Cases", "All Open Opportunities").

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (readMetadata ListView)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
sObject (string, required) - Object API name whose ListView records are requested;
non-empty Salesforce sObject API name; required; example: Account; do not pass labels,
record IDs, field API names, or multiple objects.
namePattern (string, optional) - Pattern for ListView Name or DeveloperName; string
using * and ? wildcards converted to SOQL LIKE; no default; example: My_*; do not pass
regex, raw LIKE syntax, or multiple patterns.
includeManaged (boolean, optional) - Managed package inclusion flag based on
NamespacePrefix; boolean; default false excludes namespaced records; example: true; do
not pass a namespace value here.
whereClause (string, optional) - Additional SOQL WHERE condition for ListView; string
with or without WHERE; no default; example: IsSoqlCompatible = true; do not pass SELECT,
FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for ListView; string with or without
ORDER BY; default Name ASC; example: LastModifiedDate DESC; do not pass WHERE, LIMIT,
SELECT, or FROM.
includeMetadata (boolean, optional) - Whether to include raw Metadata API ListView
details such as columns, filters, filterScope, and sharedTo; boolean; default true;
example: false; do not pass true if ListView row fields are enough.
limit (integer, optional) - Maximum ListView rows to return; integer from 1 to 2000;
default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
Salesforce QueryResult with totalSize, done, records; records include metadata when
includeMetadata is true and Salesforce exposes it.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "API Enabled" + read on the sObject.

Idempotency & limits
- Read-only.
- Some list views are flagged `soqlCompatible: false` (they use SOSL or scoring); cannot fetch via results endpoint.

Errors
- INVALID_LIST_VIEW_ID.

Example request

list_list_views({
  "sObject": "Account"
})
