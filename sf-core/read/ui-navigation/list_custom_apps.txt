Tool: list_custom_apps

Description
List Custom Applications (Lightning Apps and Classic apps): label, default tabs, navigation type (Standard | Console), utility bar items, branding, and which profiles have access.

Salesforce API
Metadata API (`CustomApplication`) + Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, Label, NamespacePrefix, ManageableState FROM CustomApplication
POST /services/Soap/m/66.0     (readMetadata CustomApplication)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
type (unknown, optional) - AppMenuItem Type value; enum ConnectedApplication, Network,
ServiceProvider, or TabSet; no default; example: TabSet; do not pass labels,
comma-separated values, or custom app metadata names.
namePattern (string, optional) - Pattern for AppMenuItem Name or Label; string using *
and ? wildcards converted to SOQL LIKE; no default; example: Sales*; do not pass regex,
raw LIKE syntax, or multiple patterns.
onlyVisible (boolean, optional) - Visibility filter for IsVisible; boolean; default
false means no IsVisible filter; example: true; do not pass string booleans.
onlyAccessible (boolean, optional) - Accessibility filter for IsAccessible; boolean;
default false means no IsAccessible filter; example: true; do not pass this to infer
permission reasons.
includeManaged (boolean, optional) - Managed package inclusion flag based on
NamespacePrefix; boolean; default false excludes namespaced records; example: true; do
not pass a namespace value here.
whereClause (string, optional) - Additional SOQL WHERE condition for AppMenuItem; string
with or without WHERE; no default; example: SortOrder > 0; do not pass SELECT, FROM,
ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for AppMenuItem; string with or
without ORDER BY; default SortOrder ASC, Label ASC; example: Label ASC; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum AppMenuItem rows to return; integer from 1 to 2000;
default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View Setup and Configuration" / "Customize Application".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_custom_apps({
  "type": "TabSet",
  "namePattern": "Sales*",
  "onlyVisible": true
})
