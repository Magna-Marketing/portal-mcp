Tool: get_mydomain_settings

Description
Read the org's MyDomain configuration: domain name, deploy status, login policy, redirect policy, embedded login disabled flag, partial login policy, branding domain, and the org's instance URL aliases.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (readMetadata MyDomainSettings)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
None.

Result
object containing raw myDomainSettings, organization QueryResult, and domains
QueryResult responses.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
myDomainSettings (value) - included in the JSON returned by the tool.
organization (value) - included in the JSON returned by the tool.
domains (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

get_mydomain_settings({})
