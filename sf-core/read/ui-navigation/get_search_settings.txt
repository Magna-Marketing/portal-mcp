Tool: get_search_settings

Description
Read the running user's search scope and order ("which objects show up
first in the global search dropdown") plus org-level search settings
(`SearchSettings`).

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (readMetadata SearchSettings)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
None.

Result
object containing raw searchScopeOrder, searchSettings, organization QueryResult, and
organizationSObject responses.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
searchScopeOrder (value) - included in the JSON returned by the tool.
searchSettings (value) - included in the JSON returned by the tool.
organization (value) - included in the JSON returned by the tool.
organizationSObject (value) - included in the JSON returned by the tool.

Required permissions
- "API Enabled".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY for org settings (requires "Customize Application").

Example request

get_search_settings({})
