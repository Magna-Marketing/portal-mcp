Tool: analyze_user_permissions_from_groups

Description
For one user, enumerate every permission they receive transitively via
the permission set groups they're assigned to. Returns one row per group
with its member permission sets and the union of effective system /
object / field permissions. Use this to explain "why does this user
have ModifyAllData?" when the answer might be hiding inside a PSG.

Pair with `analyze_user_permissions` (which adds the profile baseline +
direct permission sets) for a complete effective view.

Salesforce API
REST API (Data) + Tooling, v66.0. The MCP server stitches together:
- `PermissionSetAssignment WHERE AssigneeId = '<userId>' AND PermissionSetGroupId != NULL`.
- For each PSG, `PermissionSetGroupComponent`.
- Union of `ObjectPermissions` / `FieldPermissions` / system perms over
  the underlying permission sets.

Endpoint
GET /services/data/v66.0/query/?q=SELECT PermissionSetGroupId, PermissionSetGroup.DeveloperName, PermissionSetGroup.MasterLabel FROM PermissionSetAssignment WHERE AssigneeId = '{userId}' AND PermissionSetGroupId != NULL

(Plus the queries documented in view_permission_set_group and view_permission_set, called per group.)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
userId (string, optional) - Salesforce User Id whose group assignments are inspected;
15- or 18-character Id string; required when username is omitted; example:
0055g00000ABCDe; do not pass names, emails, multiple Ids, or SOQL fragments.
username (string, optional) - Salesforce Username whose group assignments are inspected;
exact username string; required when userId is omitted and ignored when userId is
present; example: user@example.com; do not pass display names, wildcards, or
comma-separated usernames.
includeInactiveUser (boolean, optional) - Whether an inactive user may be matched;
boolean; default false; example: true; do not pass when only active users should be
considered.
includeExpiredAssignments (boolean, optional) - Whether expired group assignments are
included; boolean; default false filters ExpirationDate before today; example: true; do
not pass to focus on active assignments.

Result
Returns raw Salesforce QueryResult objects for the user, group assignments, and group
components.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
user (value) - included in the JSON returned by the tool.
groupAssignments (value) - included in the JSON returned by the tool.
groupComponents (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration" or "Manage Users".

Idempotency & limits
- Read-only; safe to retry.
- Heavy when a user has many groups; total query count ~= 1 + 2*groupCount.

Errors
- NOT_FOUND: user not found / inactive without includeInactiveUsers.

Example request

analyze_user_permissions_from_groups({
  "userId": "0055g00000ABCDe",
  "username": "user@example.com",
  "includeInactiveUser": true
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "User"
      }
    }
  ]
}
