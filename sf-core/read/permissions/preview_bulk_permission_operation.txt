Tool: preview_bulk_permission_operation

Description
Dry-run a `bulk_assign_permissions` / `bulk_remove_permissions` /
`bulk_update_permissions` request. Returns:
- The exact list of users that would be touched (by criteria).
- The current and would-be state for each affected user (added,
  removed, kept).
- Estimated number of metadata API operations.
- License-availability check (would the assignment fit under the
  permission-set license caps).
- Risk flags ("user would lose Object.delete on Opportunity").

This tool **never** mutates anything. Always run before
`bulk_assign_permissions` / `bulk_remove_permissions` /
`bulk_update_permissions` in a production org.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
operation ("assign" | "remove", required) - Bulk operation being previewed; enum string;
required with no default; example: assign; do not pass write verbs like upsert or
delete.
permissionSetId (string, optional) - PermissionSet Id targeted by the operation;
Salesforce Id string; required unless permissionSetGroupId is provided; example:
0PS5g000000ABCd; do not pass names, group Ids, multiple Ids, or SOQL fragments.
permissionSetGroupId (string, optional) - PermissionSetGroup Id targeted by the
operation; Salesforce Id string; required unless permissionSetId is provided; example:
0PG5g000000ABCd; do not pass names, permission set Ids, multiple Ids, or SOQL fragments.
userIds (string[], optional) - Specific User Ids to preview; array of Salesforce Id
strings; no default; example: [\"0055g00000ABCDe\"]; do not pass usernames, names,
duplicates, or SOQL fragments.
usernamePattern (string, optional) - Username pattern for target users; string with *
and ? wildcards converted to SOQL LIKE; no default; example: *@example.com; do not pass
regex, raw LIKE syntax, or comma-separated usernames.
profileNamePattern (string, optional) - Profile Name pattern for target users; string
with * and ? wildcards converted to SOQL LIKE; no default; example: Sales*; do not pass
profile Ids, regex, raw LIKE syntax, or multiple names.
whereClause (string, optional) - Additional SOQL WHERE condition for User selection;
string without WHERE; no default; example: Department = 'Sales'; do not pass SELECT,
FROM, ORDER BY, LIMIT, or untrusted user input.
includeInactiveUsers (boolean, optional) - Whether inactive users can be previewed;
boolean; default false; example: true; do not pass when only active users are valid
targets.
limit (integer, optional) - Maximum user rows to preview; integer from 1 to 2000;
default 200; example: 200; do not pass 0, negatives, decimals, or offsets.

Result
Returns raw Salesforce QueryResult objects for matching users and existing assignments.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
operation (value) - included in the JSON returned by the tool.
users (value) - included in the JSON returned by the tool.
existingAssignments (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration" + read on the metadata sObjects.

Idempotency & limits
- Read-only; safe to retry.
- Big selections (10k+ users) are expensive but safe.

Errors
- INVALID_REQUEST: missing required selection criteria.

Example request

preview_bulk_permission_operation({
  "operation": "assign"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "User"
      }
    }
  ]
}
