Tool: generate_permission_matrix

Description
Generate a 2D permission matrix (rows = permissions, columns = users)
suitable for compliance reporting, screenshots, or dropping into a
spreadsheet. Each cell is true / false / "—" (when not applicable to the
user's license). Use for SOX/SOC2 reviews where you must demonstrate
who has what at a point in time. The output is structured (JSON), the
caller renders the table.

Use `compare_user_permissions` for a divergence-focused diff. Use
`audit_permissions` for risk-focused aggregation across the whole org.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, Label, Type, ProfileId, Profile.Name, PermissionSetGroupId, IsCustom, IsOwnedByProfile, NamespacePrefix FROM PermissionSet
GET /services/data/v66.0/query/?q=SELECT Id, ParentId, Parent.Name, Parent.Label, SObjectType, PermissionsRead, PermissionsCreate, PermissionsEdit, PermissionsDelete, PermissionsViewAllRecords, PermissionsModifyAllRecords, PermissionsViewAllFields FROM ObjectPermissions
GET /services/data/v66.0/query/?q=SELECT Id, ParentId, Parent.Name, Parent.Label, SObjectType, Field, PermissionsRead, PermissionsEdit FROM FieldPermissions

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
permissionSetNamePattern (string, optional) - PermissionSet Name pattern to include;
string with * and ? wildcards converted to SOQL LIKE; no default; example: Ops_*; do not
pass labels, regex, raw LIKE syntax, or comma-separated names.
sObjectType (string, optional) - ObjectPermissions and FieldPermissions SObjectType
filter; Salesforce object API name string; no default; example: Opportunity; do not pass
labels, relationship names, or SOQL fragments.
includeFieldPermissions (boolean, optional) - Whether FieldPermissions are queried;
boolean; default true; example: false; do not pass false when field-level access is
needed.
whereClause (string, optional) - Additional SOQL WHERE condition for PermissionSet;
string without WHERE; no default; example: IsOwnedByProfile = false; do not pass SELECT,
FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for PermissionSet; string without ORDER BY;
default Name ASC; example: Label ASC; do not pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum rows per query; integer from 1 to 2000; default 200;
example: 200; do not pass 0, negatives, decimals, or offsets.

Result
Returns raw Salesforce QueryResult objects for the selected permission data.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
permissionSets (value) - included in the JSON returned by the tool.
objectPermissions (value) - included in the JSON returned by the tool.
fieldPermissions (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration".

Idempotency & limits
- Read-only; safe to retry.
- O(users * permissions). With 50 users and 200 permissions, expect 5-10 s.

Errors
- INVALID_FIELD: unknown system permission.
- INVALID_TYPE: unknown sObject in `objects[].sObject`.

Example request

generate_permission_matrix({
  "permissionSetNamePattern": "Ops_*",
  "sObjectType": "Opportunity",
  "includeFieldPermissions": false
})
