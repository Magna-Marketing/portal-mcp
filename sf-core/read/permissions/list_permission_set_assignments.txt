Tool: list_permission_set_assignments

Description
List all users with a given permission set assigned. Returns assignment
rows joined to the User: name, username, email, isActive, profile, and
the assignment Id (needed by `unassign_permission_set`). Use this to
audit current scope before bulk operations or after migrations.

For permission set groups use `list_permission_set_group_assignments`.
For "what does THIS user have?" use `analyze_user_permissions`.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, AssigneeId, Assignee.Name, Assignee.Username, Assignee.Email, Assignee.IsActive, Assignee.Profile.Name, PermissionSetId, PermissionSet.Name, PermissionSet.Label, PermissionSet.IsOwnedByProfile, ExpirationDate, IsActive, SystemModstamp FROM PermissionSetAssignment

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
permissionSetId (string, optional) - PermissionSet Id to filter direct assignments;
Salesforce Id string; no default; example: 0PS5g000000ABCd; do not pass group Ids,
names, multiple Ids, or SOQL fragments.
permissionSetNamePattern (string, optional) - PermissionSet Name pattern; string with *
and ? wildcards converted to SOQL LIKE; no default; example: Sales_*; do not pass
labels, group names, regex, or raw LIKE syntax.
assigneeNamePattern (string, optional) - Assigned user's Name pattern; string with * and
? wildcards converted to SOQL LIKE; no default; example: Ada*; do not pass usernames,
regex, raw LIKE syntax, or comma-separated names.
includeProfileOwned (boolean, optional) - Whether profile-owned permission set
assignments are included; boolean; default false; example: true; do not pass true when
only explicit permission set assignments are needed.
includeInactiveUsers (boolean, optional) - Whether inactive assigned users are included;
boolean; default false; example: true; do not pass when only active users should be
listed.
includeExpiredAssignments (boolean, optional) - Whether expired assignments are
included; boolean; default false filters ExpirationDate before today; example: true; do
not pass for current assignments only.
whereClause (string, optional) - Additional SOQL WHERE condition for
PermissionSetAssignment; string without WHERE; no default; example: SystemModstamp =
LAST_N_DAYS:30; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for PermissionSetAssignment; string without
ORDER BY; default Assignee.Name ASC; example: SystemModstamp DESC; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum assignment rows to query; integer from 1 to 2000;
default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
Returns the raw Salesforce QueryResult for PermissionSetAssignment records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- API Enabled.
- "View Setup and Configuration" or "Manage Users".
- Read on `PermissionSetAssignment`, `User`, `Profile`.

Idempotency & limits
- Read-only; safe to retry.
- Permsets used by hundreds of users return paginated; the tool follows
  nextRecordsUrl until limit or end.

Errors
- NOT_FOUND: permset name/id not found.
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_permission_set_assignments({
  "permissionSetId": "0PS5g000000ABCd",
  "permissionSetNamePattern": "Sales_*",
  "assigneeNamePattern": "Ada*"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "PermissionSetAssignment"
      }
    }
  ]
}
