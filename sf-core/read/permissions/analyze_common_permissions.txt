Tool: analyze_common_permissions

Description
Analyze permissions that are shared across multiple profiles (or
permission sets) to identify candidates for consolidation into a
reusable permission set or PSG. Surfaces:
- Object perms held in common across N profiles.
- Field perms held in common.
- System perms held in common.
- "Almost-common" perms (held by ≥ threshold percent of profiles).

Use to plan deduplication before running `generate_migration_plan` or
`extract_permissions_from_profile`.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, Label, Description, Type, ProfileId, Profile.Name, LicenseId, PermissionSetGroupId, IsCustom, IsOwnedByProfile, NamespacePrefix, CreatedDate, LastModifiedDate, PermissionsApiEnabled, PermissionsModifyAllData, PermissionsViewAllData, PermissionsManageUsers, PermissionsCustomizeApplication, PermissionsAuthorApex, PermissionsViewSetup FROM PermissionSet

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional) - PermissionSet Name pattern to match; string with * and
? wildcards converted to SOQL LIKE; no default; example: Sales_*; do not pass regex, raw
LIKE syntax, labels, or comma-separated names.
whereClause (string, optional) - Additional SOQL WHERE condition for PermissionSet;
string without WHERE; no default; example: IsCustom = true AND IsOwnedByProfile = false;
do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for PermissionSet; string without ORDER BY;
default Name ASC; example: LastModifiedDate DESC; do not pass WHERE, LIMIT, SELECT, or
FROM.
limit (integer, optional) - Maximum PermissionSet rows to query; integer from 1 to 2000;
default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
Returns a raw Salesforce QueryResult for PermissionSet records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View Setup and Configuration", read on metadata sObjects.

Idempotency & limits
- Read-only; safe to retry.
- O(N * fields) where N = number of profiles/permsets analyzed.

Errors
- INVALID_FIELD: bad scope value.

Example request

analyze_common_permissions({
  "namePattern": "Sales_*",
  "whereClause": "IsCustom = true AND IsOwnedByProfile = false",
  "orderBy": "LastModifiedDate DESC"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "PermissionSet"
      }
    }
  ]
}
