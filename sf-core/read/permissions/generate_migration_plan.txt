Tool: generate_migration_plan

Description
Generate a profile-to-permission-sets migration plan. Salesforce is
moving away from per-profile permission management toward minimal
profiles + permission sets / permission set groups. This tool inspects
the existing profiles, their object/field/system perms, and current
assignments, then produces:
- A recommended minimal profile (login defaults only).
- A list of permission sets / permission set groups to extract.
- Per-user delta showing which permsets each currently active user
  would receive after the migration.
- A phased timeline with batch-size suggestions.

Read-only; produces a plan but does not modify any metadata. Apply with
`extract_permissions_from_profile`, `create_permission_set`,
`create_permission_set_group`, `bulk_assign_permissions` etc.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, UserType, UserLicenseId, UserLicense.Name, CreatedDate, LastModifiedDate FROM Profile

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
profileNamePattern (string, optional) - Profile Name pattern to include; string with *
and ? wildcards converted to SOQL LIKE; no default; example: Sales*; do not pass regex,
raw LIKE syntax, or comma-separated profile names.
whereClause (string, optional) - Additional SOQL WHERE condition for Profile; string
without WHERE; no default; example: UserType = 'Standard'; do not pass SELECT, FROM,
ORDER BY, LIMIT, or untrusted user input.
includeObjectPermissions (boolean, optional) - Whether to query ObjectPermissions for
profile-owned permission sets; boolean; default true; example: false; do not pass when
object access is needed.
includeFieldPermissions (boolean, optional) - Whether to query FieldPermissions for
profile-owned permission sets; boolean; default true; example: false; do not pass when
field access is needed.
orderBy (string, optional) - SOQL ORDER BY for Profile; string without ORDER BY; default
Name ASC; example: LastModifiedDate DESC; do not pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum profile rows to query; integer from 1 to 2000;
default 200; example: 50; do not pass 0, negatives, decimals, or offsets.

Result
Returns raw Salesforce QueryResult objects for profiles and selected permission records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
profiles (value) - included in the JSON returned by the tool.
profilePermissionSets (value) - included in the JSON returned by the tool.
objectPermissions (value) - included in the JSON returned by the tool.
fieldPermissions (value) - included in the JSON returned by the tool.

Required permissions
- "View All Setup" / "Modify All Data" recommended (read-only here, but
  some setup queries require elevated perms).

Idempotency & limits
- Read-only; safe to retry.
- Can be expensive: in a 50-profile org with FLS expansion, expect 5-10
  minutes of internal queries.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.
- INVALID_FIELD on bad sourceProfiles entries.

Example request

generate_migration_plan({
  "profileNamePattern": "Sales*",
  "whereClause": "UserType = 'Standard'",
  "includeObjectPermissions": false
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "PermissionSet"
      }
    }
  ]
}
