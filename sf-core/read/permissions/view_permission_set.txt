Tool: view_permission_set

Description
Get the full detail of a permission set: identity, license, system
permissions (the boolean Permissions* flags), object permissions
(CRUD + viewAll/modifyAll per sObject), field permissions (read/edit
per field), Apex class access, Visualforce page access, custom tab
visibility, and user-license / permission-set-license restrictions.
Use this before assigning a permset (`assign_permission_set`) or
auditing what a group of users actually gets. Pair with
`list_permission_set_assignments` to find who's already on it.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
id (string, optional) - PermissionSet Id to retrieve; Salesforce Id string; required
when name is omitted and preferred for exact lookup; example: 0PS5g000000ABCd; do not
pass labels, multiple Ids, or SOQL fragments.
name (string, optional) - PermissionSet API Name to retrieve; exact Name string;
required when id is omitted; example: Sales_Manager_Access; do not pass labels,
wildcards, or comma-separated names.
includeObjectPermissions (boolean, optional) - Whether ObjectPermissions child rows are
queried; boolean; default true; example: false; do not pass false when object CRUD
access is needed.
includeFieldPermissions (boolean, optional) - Whether FieldPermissions child rows are
queried; boolean; default true; example: false; do not pass false when field-level
access is needed.
includeSetupEntityAccess (boolean, optional) - Whether SetupEntityAccess rows are
queried; boolean; default true; example: false; do not pass false when Apex,
Visualforce, custom permissions, or related setup access is needed.
includeTabSettings (boolean, optional) - Whether PermissionSetTabSetting rows are
queried; boolean; default false; example: true; do not pass true unless tab visibility
is needed.

Result
Returns raw Salesforce QueryResult objects for the permission set and requested child
objects.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
permissionSet (value) - included in the JSON returned by the tool.
objectPermissions (value) - included in the JSON returned by the tool.
fieldPermissions (value) - included in the JSON returned by the tool.
setupEntityAccess (value) - included in the JSON returned by the tool.
tabSettings (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration" + read on `PermissionSet`,
  `ObjectPermissions`, `FieldPermissions`, `SetupEntityAccess`. (Granted
  by default to system administrators.)

Idempotency & limits
- Read-only; safe to retry.
- For permsets with many fields the FieldPermissions query can return
  >10k rows; the tool paginates internally.

Errors
- NOT_FOUND: permission set name/id not present.
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

view_permission_set({
  "id": "0PS5g000000ABCd",
  "name": "Sales_Manager_Access",
  "includeObjectPermissions": false
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "PermissionSet"
      }
    }
  ]
}
