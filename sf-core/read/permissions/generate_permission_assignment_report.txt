Tool: generate_permission_assignment_report

Description
Produce a detailed report of permission set and permission set group
assignments for a chosen set of users. Per user: profile, direct
permsets, group memberships, expiration dates, totals. Includes summary
statistics (avg assignments per user, total distinct permsets/groups,
top users by assignment count). Shaped for HR or change-control
documentation.

Differs from `audit_permissions` in scope: this is a roster of
assignments for specific users; `audit_permissions` is org-wide risk.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, AssigneeId, Assignee.Name, Assignee.Username, Assignee.Email, Assignee.IsActive, Assignee.Profile.Name, PermissionSetId, PermissionSet.Name, PermissionSet.Label, PermissionSet.IsOwnedByProfile, PermissionSetGroupId, PermissionSetGroup.DeveloperName, PermissionSetGroup.MasterLabel, PermissionSetGroup.Status, ExpirationDate, IsActive, SystemModstamp FROM PermissionSetAssignment

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
assigneeNamePattern (string, optional) - Assigned user's Name pattern; string with * and
? wildcards converted to SOQL LIKE; no default; example: Maria*; do not pass usernames,
regex, raw LIKE syntax, or multiple names.
permissionSetNamePattern (string, optional) - PermissionSet Name pattern for direct
assignments; string with * and ? wildcards converted to SOQL LIKE; no default; example:
Sales_*; do not pass labels, group names, regex, or raw LIKE syntax.
permissionSetGroupNamePattern (string, optional) - PermissionSetGroup DeveloperName
pattern for group assignments; string with * and ? wildcards converted to SOQL LIKE; no
default; example: Revenue_*; do not pass labels, permission set names, regex, or raw
LIKE syntax.
includeInactiveUsers (boolean, optional) - Whether inactive assigned users are included;
boolean; default false; example: true; do not pass when only active users should be
reported.
includeExpiredAssignments (boolean, optional) - Whether expired assignments are
included; boolean; default false filters ExpirationDate before today; example: true; do
not pass for active-only assignment reporting.
whereClause (string, optional) - Additional SOQL WHERE condition for
PermissionSetAssignment; string without WHERE; no default; example: PermissionSetId !=
null; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for PermissionSetAssignment; string without
ORDER BY; default Assignee.Name ASC; example: SystemModstamp DESC; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum assignment rows to query; integer from 1 to 2000;
default 200; example: 500; do not pass 0, negatives, decimals, or offsets.

Result
Returns the raw Salesforce QueryResult for PermissionSetAssignment records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View Setup and Configuration" / "Manage Users".

Idempotency & limits
- Read-only; safe to retry.

Errors
- NOT_FOUND on usernames not in org.

Example request

generate_permission_assignment_report({
  "assigneeNamePattern": "Maria*",
  "permissionSetNamePattern": "Sales_*",
  "permissionSetGroupNamePattern": "Revenue_*"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "PermissionSetAssignment"
      }
    }
  ]
}
