Tool: compare_user_permissions

Description
Compare effective permissions across multiple users to see who has what.
Produces a per-user permission summary plus a diff matrix highlighting
where users disagree. Useful when onboarding a new user against an
established peer, or auditing "two PMs but only one can delete".

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, Username, Email, IsActive, ProfileId, Profile.Name, Profile.UserLicense.Name, UserType, Department, UserRole.Name FROM User
GET /services/data/v66.0/query/?q=SELECT Id, AssigneeId, Assignee.Name, Assignee.Username, PermissionSetId, PermissionSet.Name, PermissionSet.Label, PermissionSet.IsOwnedByProfile, PermissionSetGroupId, PermissionSetGroup.DeveloperName, PermissionSetGroup.MasterLabel, PermissionSetGroup.Status, ExpirationDate, IsActive, SystemModstamp FROM PermissionSetAssignment

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
leftUserId (string, optional) - First Salesforce User Id; 15- or 18-character Id string;
required when leftUsername is omitted; example: 0055g00000ABCDe; do not pass names,
emails, multiple Ids, or SOQL fragments.
leftUsername (string, optional) - First Salesforce Username; exact username string;
required when leftUserId is omitted and ignored when leftUserId is present; example:
admin@example.com; do not pass display names, wildcards, or comma-separated usernames.
rightUserId (string, optional) - Second Salesforce User Id; 15- or 18-character Id
string; required when rightUsername is omitted; example: 0055g00000XYZAb; do not pass
names, emails, multiple Ids, or SOQL fragments.
rightUsername (string, optional) - Second Salesforce Username; exact username string;
required when rightUserId is omitted and ignored when rightUserId is present; example:
rep@example.com; do not pass display names, wildcards, or comma-separated usernames.
includeExpiredAssignments (boolean, optional) - Whether expired assignments are included
for both users; boolean; default false filters ExpirationDate before today; example:
true; do not pass to focus on currently active assignments.

Result
Returns raw Salesforce QueryResult objects for each user and assignment set.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
leftUser (value) - included in the JSON returned by the tool.
leftAssignments (value) - included in the JSON returned by the tool.
rightUser (value) - included in the JSON returned by the tool.
rightAssignments (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration" / "Manage Users".

Idempotency & limits
- Read-only; safe to retry.
- O(N) where N = users compared (each does its own analyze_user_permissions
  expansion). Heavy with FLS on.

Errors
- INVALID_REQUEST: fewer than 2 or more than 10 users.

Example request

compare_user_permissions({
  "leftUserId": "0055g00000ABCDe",
  "leftUsername": "admin@example.com",
  "rightUserId": "0055g00000XYZAb"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "User"
      }
    }
  ]
}
