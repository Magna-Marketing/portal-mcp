Tool: view_permission_set_group

Description
View a permission set group (PSG) and the permission sets it bundles.
Returns identity, status (calculation state), member permission sets,
muting permset (if any), description, and current assignment count. Use
to confirm what a PSG actually grants before assigning it. For users
assigned to the group use `list_permission_set_group_assignments`. For
the effective permission union use `analyze_user_permissions_from_groups`
on a representative user.

Salesforce API
REST API (Data), v66.0.
- Identity: SOQL on `PermissionSetGroup`.
- Members: SOQL on `PermissionSetGroupComponent` joined to `PermissionSet`.
- Assignment count: SOQL `COUNT()` on `PermissionSetAssignment WHERE
  PermissionSetGroupId = '{psgId}'`.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, DeveloperName, MasterLabel, Description, Status FROM PermissionSetGroup WHERE DeveloperName = '{name}' OR Id = '{id}'
GET /services/data/v66.0/query/?q=SELECT PermissionSet.Id, PermissionSet.Name, PermissionSet.Label, PermissionSet.IsCustom FROM PermissionSetGroupComponent WHERE PermissionSetGroupId = '{psgId}'
GET /services/data/v66.0/query/?q=SELECT COUNT() FROM PermissionSetAssignment WHERE PermissionSetGroupId = '{psgId}'

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
id (string, optional) - PermissionSetGroup Id to retrieve; Salesforce Id string;
required when name is omitted and preferred for exact lookup; example: 0PG5g000000ABCd;
do not pass permission set Ids, labels, multiple Ids, or SOQL fragments.
name (string, optional) - PermissionSetGroup DeveloperName to retrieve; exact
DeveloperName string; required when id is omitted; example: Revenue_Team_Group; do not
pass MasterLabel, wildcards, or comma-separated names.
includeComponents (boolean, optional) - Whether PermissionSetGroupComponent rows are
queried; boolean; default true; example: false; do not pass false when component
permission sets are needed.
includeAssignments (boolean, optional) - Whether PermissionSetAssignment rows for the
group are queried; boolean; default false; example: true; do not pass true unless
assigned users are needed.

Result
Returns raw Salesforce QueryResult objects for the group and requested related records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
permissionSetGroup (value) - included in the JSON returned by the tool.
components (value) - included in the JSON returned by the tool.
assignments (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration".
- Read on `PermissionSetGroup`, `PermissionSetGroupComponent`,
  `PermissionSetAssignment`.

Idempotency & limits
- Read-only; safe to retry.
- PSG `Status` reflects an asynchronous recalculation; treat
  "Updating"/"Outdated" as transient.

Errors
- NOT_FOUND: PSG not found.
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

view_permission_set_group({
  "id": "0PG5g000000ABCd",
  "name": "Revenue_Team_Group",
  "includeComponents": false
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "PermissionSetGroup"
      }
    }
  ]
}
