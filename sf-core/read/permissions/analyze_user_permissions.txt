Tool: analyze_user_permissions

Description
For one user, return the full effective permission set: profile baseline
+ direct permission set assignments + permission set group memberships,
unioned. Includes system permissions, object CRUD/viewAll/modifyAll, and
(optionally) field-level read/edit. This is the single source of truth
for "what can this user do today?". Pair with `audit_permissions` to
flag risk.

Use `analyze_user_permissions_from_groups` if you only want the
group-derived slice. Use `compare_user_permissions` to diff users.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
userId (string, optional) - Salesforce User Id to inspect; 15- or 18-character Id
string; required when username is omitted; example: 0055g00000ABCDe; do not pass names,
emails, multiple Ids, or SOQL fragments.
username (string, optional) - Salesforce Username to inspect; exact username string;
required when userId is omitted and ignored when userId is present; example:
user@example.com; do not pass display names, wildcards, or comma-separated usernames.
includeInactiveUser (boolean, optional) - Whether an inactive user may be matched;
boolean; default false; example: true; do not pass when you only want active users.
includeExpiredAssignments (boolean, optional) - Whether expired PermissionSetAssignment
rows are included; boolean; default false filters ExpirationDate before today; example:
true; do not pass to treat expired assignments as inactive.

Result
Returns raw Salesforce QueryResult objects for the user and assignments.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
user (value) - included in the JSON returned by the tool.
assignments (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration" or "Manage Users".

Idempotency & limits
- Read-only; safe to retry.
- Heavy when the user has many assignments; expect 0.5–3 s.

Errors
- NOT_FOUND: user not found / inactive.
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

analyze_user_permissions({
  "userId": "0055g00000ABCDe",
  "username": "user@example.com",
  "includeInactiveUser": true
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "User"
      }
    }
  ]
}
