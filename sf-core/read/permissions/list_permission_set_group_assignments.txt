Tool: list_permission_set_group_assignments

Description
List all users assigned to a permission set group. Same shape as
`list_permission_set_assignments` but filters on
`PermissionSetGroupId`. Use to audit who has the bundle and to feed
`unassign_permission_set_group` (each row's `assignmentId` is the
PermissionSetAssignment Id you'd remove).

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, AssigneeId, Assignee.Name, Assignee.Username, Assignee.Email, Assignee.IsActive, Assignee.Profile.Name, PermissionSetGroupId, PermissionSetGroup.DeveloperName, PermissionSetGroup.MasterLabel, PermissionSetGroup.Status, ExpirationDate, IsActive, SystemModstamp FROM PermissionSetAssignment

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
permissionSetGroupId (string, optional) - PermissionSetGroup Id to filter assignments;
Salesforce Id string; no default; example: 0PG5g000000ABCd; do not pass permission set
Ids, names, multiple Ids, or SOQL fragments.
groupNamePattern (string, optional) - PermissionSetGroup DeveloperName pattern; string
with * and ? wildcards converted to SOQL LIKE; no default; example: Revenue_*; do not
pass labels, permission set names, regex, or raw LIKE syntax.
assigneeNamePattern (string, optional) - Assigned user's Name pattern; string with * and
? wildcards converted to SOQL LIKE; no default; example: Sam*; do not pass usernames,
regex, raw LIKE syntax, or comma-separated names.
includeInactiveUsers (boolean, optional) - Whether inactive assigned users are included;
boolean; default false; example: true; do not pass when only active users should be
listed.
includeExpiredAssignments (boolean, optional) - Whether expired group assignments are
included; boolean; default false filters ExpirationDate before today; example: true; do
not pass for current assignments only.
whereClause (string, optional) - Additional SOQL WHERE condition for
PermissionSetAssignment; string without WHERE; no default; example:
PermissionSetGroup.Status = 'Updated'; do not pass SELECT, FROM, ORDER BY, LIMIT, or
untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for PermissionSetAssignment; string without
ORDER BY; default PermissionSetGroup.DeveloperName ASC, Assignee.Name ASC; example:
SystemModstamp DESC; do not pass WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum group assignment rows to query; integer from 1 to
2000; default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
Returns the raw Salesforce QueryResult for group assignment records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View Setup and Configuration" or "Manage Users".

Idempotency & limits
- Read-only; safe to retry.

Errors
- NOT_FOUND: PSG not found.

Example request

list_permission_set_group_assignments({
  "permissionSetGroupId": "0PG5g000000ABCd",
  "groupNamePattern": "Revenue_*",
  "assigneeNamePattern": "Sam*"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "PermissionSetAssignment"
      }
    }
  ]
}
