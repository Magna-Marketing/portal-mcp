Tool: audit_permissions

Description
Org-wide permission audit oriented at security/compliance. Reports:
- High-risk system permission distribution (ModifyAllData, ViewAllData,
  ManageUsers, ManageProfilesPermissionSets, ManageSession, AuthorApex,
  CustomizeApplication).
- Counts by source (profile vs permset vs PSG).
- Permission sets with no current assignment (cleanup candidates).
- Permission set groups with `Status != "Updated"` (broken or recalc-pending).
- Session settings tied to high-risk perms.
- Optional per-user enumeration for the high-risk perms.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, Label, Type, ProfileId, Profile.Name, PermissionSetGroupId, IsCustom, IsOwnedByProfile, NamespacePrefix, CreatedDate, LastModifiedDate, PermissionsModifyAllData, PermissionsViewAllData, PermissionsApiEnabled, PermissionsManageUsers, PermissionsCustomizeApplication, PermissionsViewSetup FROM PermissionSet
GET /services/data/v66.0/query/?q=SELECT Id, ParentId, Parent.Name, Parent.Label, SObjectType, PermissionsRead, PermissionsCreate, PermissionsEdit, PermissionsDelete, PermissionsViewAllRecords, PermissionsModifyAllRecords, PermissionsViewAllFields FROM ObjectPermissions
GET /services/data/v66.0/query/?q=SELECT Id, ParentId, Parent.Name, Parent.Label, SObjectType, Field, PermissionsRead, PermissionsEdit FROM FieldPermissions

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
permissionSetNamePattern (string, optional) - PermissionSet Name pattern to audit;
string with * and ? wildcards converted to SOQL LIKE; no default; example: Finance_*; do
not pass labels, regex, raw LIKE syntax, or multiple names.
sObjectType (string, optional) - ObjectPermissions or FieldPermissions SObjectType
filter; Salesforce object API name string; no default; example: Account; do not pass
object labels, relationship names, or SOQL fragments.
field (string, optional) - FieldPermissions Field filter; fully qualified field API
name; no default; example: Account.AnnualRevenue; do not pass unqualified field names,
labels, or wildcards.
whereClause (string, optional) - Additional SOQL WHERE condition applied to
PermissionSet; string without WHERE; no default; example: IsOwnedByProfile = false; do
not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for PermissionSet; string without ORDER BY;
default Name ASC; example: LastModifiedDate DESC; do not pass WHERE, LIMIT, SELECT, or
FROM.
limit (integer, optional) - Maximum rows per query; integer from 1 to 2000; default 200;
example: 250; do not pass 0, negatives, decimals, or offsets.

Result
Returns raw Salesforce QueryResult objects grouped by queried object.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.
permissionSets (value) - included in the JSON returned by the tool.
objectPermissions (value) - included in the JSON returned by the tool.
fieldPermissions (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration".

Idempotency & limits
- Read-only; safe to retry.
- Heavy: O(profiles + permsets + groups + users). Run during off-peak
  for orgs > 5,000 users.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

audit_permissions({
  "permissionSetNamePattern": "Finance_*",
  "sObjectType": "Account",
  "field": "Account.AnnualRevenue"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "PermissionSet"
      }
    }
  ]
}
