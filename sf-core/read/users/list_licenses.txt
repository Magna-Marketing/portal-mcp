Tool: list_licenses

Description
List the org's user licenses, permission set licenses, and (optionally) feature licenses. Returns total / used / available counts and the assignments for each. Use to confirm capacity before bulk user creation, permission set rollout, or feature enablement.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, MasterLabel, LicenseDefinitionKey, Status, UsedLicenses, TotalLicenses, UsedLicensesLastUpdated FROM UserLicense

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
pattern (string, optional) - License text pattern matched against Name, MasterLabel, or
LicenseDefinitionKey; string using * and ? wildcards converted to SOQL LIKE; no default;
example: Salesforce*; do not pass regex, raw LIKE syntax, or profile names.
status ("Active" | "Disabled", optional) - UserLicense status filter; enum Active or
Disabled; no default; example: Active; do not pass lowercase values, labels, or multiple
statuses.
licenseDefinitionKey (string, optional) - Exact LicenseDefinitionKey filter; string key
that identifies a user license; no default; example: SFDC; do not pass the
human-readable license label.
whereClause (string, optional) - Additional SOQL WHERE condition for UserLicense; string
with or without WHERE; no default; example: TotalLicenses > 0; do not pass SELECT, FROM,
ORDER BY, LIMIT, UsedLicenses filters in API v64.0 or later, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for UserLicense; string with or
without ORDER BY; default Name ASC; example: TotalLicenses DESC; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum UserLicense rows to return; integer from 1 to 2000;
default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Manage Internal Users" / "View Setup and Configuration".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_licenses({
  "pattern": "Salesforce*",
  "status": "Active",
  "licenseDefinitionKey": "SFDC"
})
