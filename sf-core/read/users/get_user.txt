Tool: get_user

Description
Get a single user with everything reasonable to know in one call: profile, role, manager, license, active state, last login, mobile/phone, time zone/locale/language, federation Id, time-tracking flags, plus a count of permission set + group assignments. For deep effective permissions use `analyze_user_permissions`. For login history use `list_login_history`.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, Username, Email, Alias, IsActive, ProfileId, Profile.Name, Profile.UserLicense.Name, UserRoleId, UserRole.Name, ManagerId, Manager.Name, Manager.Username, UserType, Department, Title, Phone, MobilePhone, TimeZoneSidKey, LocaleSidKey, EmailEncodingKey, LanguageLocaleKey, FederationIdentifier, IsPortalEnabled, UserPermissionsMarketingUser, UserPermissionsSupportUser, LastLoginDate, CreatedDate, LastModifiedDate FROM User

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
userId (string, required) - Salesforce User Id to fetch; 15- or 18-character string with
the 005 key prefix; required with no default; example: 0055g00000ABCdEAA1; do not pass
usernames, emails, quoted Ids, or comma-separated Ids.

Result
raw Salesforce QueryResult with totalSize, done, and records containing zero or one User
record.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View All Users" or "Manage Users".

Idempotency & limits
- Read-only; safe to retry.

Errors
- NOT_FOUND.

Example request

get_user({
  "userId": "0055g00000ABCdEAA1"
})
