Tool: list_sharing_rules

Description
List sharing rules for one or more objects: criteria-based, owner-based, and territory-based. Each rule shows its access level (Read | ReadWrite | TransferAccess | All), the source (group / role / role+sub / queue), and the target group. Use as input to consolidation and audits.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (readMetadata SharingRules)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
sObject (string, optional) -
Object API name whose SharingRules metadata should be read; string Salesforce sObject
API name; no default; example: Account or Invoice__c; do not pass a sharing-rule name,
label, SOQL, or multiple values.
sObjectNames (string[], optional) -
Object API names whose SharingRules metadata should be read; array of Salesforce sObject
API names; default uses sObject or metadata listing; example: [\"Account\",
\"Invoice__c\"]; do not pass labels, share object names, empty strings, or
comma-separated text.
sObjectPattern (string, optional) -
Object API name pattern used against SharingRules metadata fullName; string with * and ?
wildcards; no default; example: *_Invoice__c; do not pass regex, SOQL LIKE syntax, or
multiple patterns.
orderBy ("fullNameASC" | "fullNameDESC" | "lastModifiedDateASC" | "lastModifiedDateDESC", optional) -
Metadata listing sort order before reading SharingRules; enum value; default fullName
ASC; example: lastModifiedDate DESC; do not pass SOQL ORDER BY, arbitrary fields, or
lowercase variants.
limit (integer, optional) -
Maximum SharingRules components to read when using metadata listing; integer from 1 to
2000; default 200; example: 50; do not pass 0, negatives, decimals, or offsets.
includeMetadataListing (boolean, optional) -
Whether to include raw FileProperties from Metadata API listMetadata; boolean; default
false; example: true; do not pass when only SharingRules metadata is needed.

Result
Returns raw SharingRules metadata and optional raw FileProperties metadata listing.

Required permissions
- "View Setup and Configuration".

Idempotency & limits
- Read-only.

Errors
- INVALID_TYPE on bad sObject.

Example request

list_sharing_rules({
  "sObject": "Account or Invoice__c",
  "sObjectNames": "[\\\"Account\\\", \\\"Invoice__c\\\"]",
  "sObjectPattern": "*_Invoice__c"
})
