Tool: list_workflow_rules

Description
List Workflow Rules (legacy automation; mostly migrated to Flow but still common in older orgs). Returns the trigger criteria, evaluation criteria, time-based triggers, and the actions invoked (field updates, email alerts, outbound messages, tasks).

Salesforce API
Tooling API, v66.0.
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (readMetadata Workflow)
GET /services/data/v66.0/tooling/query/?q=SELECT Id, Name, TableEnumOrId, ManageableState, NamespacePrefix FROM WorkflowRule

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
sObjects (string[], optional) - Object API names whose Workflow containers are read;
string array; no default resolves objects from WorkflowRule Tooling rows; example:
[\"Account\", \"Case\"]; do not pass labels, relationship names, or SOQL fragments.
namePattern (string, optional) - WorkflowRule Name filter using * and ? wildcards
against the Tooling API Name field; string converted to SOQL LIKE; no default; example:
Renewal_*; do not pass raw LIKE syntax, object-qualified names, or regex.
whereClause (string, optional) - Additional Tooling SOQL WHERE condition for
WorkflowRule; string without WHERE; no default; example: ManageableState = 'unmanaged';
do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - Tooling SOQL ORDER BY for WorkflowRule; string without
ORDER BY; default TableEnumOrId, Name; example: Name DESC; do not pass WHERE, LIMIT,
SELECT, or FROM.
limit (integer, optional) - Maximum WorkflowRule rows used to scope metadata reads;
positive integer clamped to 2000; default 500; example: 100; do not pass 0, negatives,
decimals, or offsets.

Result
Returns a JSON object with query, toolingResult, metadataFullNames, and metadataResult.
query (value) - included in the JSON returned by the tool.
toolingResult (value) - included in the JSON returned by the tool.
metadataFullNames (value) - included in the JSON returned by the tool.
metadataResult (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration" / "Customize Application".

Idempotency & limits
- Read-only.

Errors
- INVALID_TYPE on bad sObject.

Example request

list_workflow_rules({
  "sObjects": "[\\\"Account\\\", \\\"Case\\\"]",
  "namePattern": "Renewal_*",
  "whereClause": "ManageableState = 'unmanaged'"
})
