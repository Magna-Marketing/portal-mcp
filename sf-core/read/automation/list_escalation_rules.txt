Tool: list_escalation_rules

Description
List Case escalation rules and their entries (criteria, business hours, escalation actions). Escalation actions can reassign the case, notify users, and update fields based on age/status.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0   (readMetadata EscalationRules for Case)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
sObject ("Case", optional) - EscalationRules container object API name; only Case is
supported by Salesforce; default Case; example: Case; do not pass custom objects,
labels, or SOQL fragments.
namePattern (string, optional) - Rule fullName selection hint using * and ? wildcards;
string; no default; example: Premium_*; Metadata API reads the whole Case container, so
this does not trim returned container data; do not pass regex or SOQL LIKE syntax.

Result
Returns a JSON object with metadataFullNames and metadataResult.
metadataFullNames (value) - included in the JSON returned by the tool.
metadataResult (value) - included in the JSON returned by the tool.

Required permissions
- "View Setup and Configuration" / "Customize Application".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_escalation_rules({
  "sObject": "Case",
  "namePattern": "Premium_*"
})
