Tool: list_pending_approvals

Description
List `ProcessInstance` rows currently pending approval, optionally scoped to a specific approver, submitter, or sObject. Each row shows the work item that someone needs to act on, the record under approval, and the steps already taken.

Salesforce API
REST API (Data), v66.0. SOQL on `ProcessInstance`, `ProcessInstanceWorkitem`, `ProcessInstanceStep`.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, TargetObjectId, TargetObject.Name, Status, ProcessDefinitionId, ProcessDefinition.Name, SubmittedById, SubmittedBy.Name, CreatedDate FROM ProcessInstance WHERE Status = 'Pending'
GET /services/data/v66.0/query/?q=SELECT Id, ProcessInstanceId, ActorId, Actor.Name, OriginalActorId FROM ProcessInstanceWorkitem WHERE ProcessInstanceId IN (...)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
approverId (string, optional) - User or queue Id assigned to a pending
ProcessInstanceWorkitem; Salesforce Id string; no default; example: 005xx0000012345AAA;
do not pass usernames, names, or comma-separated values.
approverUsername (string, optional) - Username used to resolve a User Id for pending
workitem filtering; string username; no default; example: approver@example.com; ignored
when approverId is supplied, and do not pass display names or SOQL.
submitterId (string, optional) - SubmittedById exact filter for ProcessInstance;
Salesforce User Id string; no default; example: 005xx0000012345AAA; do not pass
usernames or names.
sObject (string, optional) - TargetObject polymorphic type filter; object API name
string; no default; example: Opportunity; do not pass labels, record Ids, relationship
names, or SOQL fragments.
processDefinitionName (string, optional) - ProcessDefinition.Name exact filter; string
developer name; no default; example: Discount_Approval; do not pass labels unless they
are the API Name.
processDefinitionNamePattern (string, optional) - ProcessDefinition.Name wildcard filter
using * and ?; string converted to SOQL LIKE; no default; example: Discount_*; do not
combine with processDefinitionName unless both should apply.
sinceHours (integer, optional) - Relative CreatedDate filter using LAST_N_HOURS;
positive integer hours; no default; example: 24; do not pass 0, negatives, decimals, or
date strings.
includeSteps (boolean, optional) - Whether to query ProcessInstanceStep rows for
returned instances; boolean; default false; example: true; pass false to avoid
audit-history volume.
whereClause (string, optional) - Additional SOQL WHERE condition for ProcessInstance;
string without WHERE; no default; example: CreatedDate = LAST_N_DAYS:7; do not pass
SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY for ProcessInstance; string without ORDER BY;
default CreatedDate DESC; example: CreatedDate ASC; do not pass WHERE, LIMIT, SELECT, or
FROM.
limit (integer, optional) - Maximum ProcessInstance rows to query; positive integer
clamped to 2000; default 200; example: 50; do not pass 0, negatives, decimals, or
offsets.

Result
Returns a JSON object with processInstanceQuery, processInstanceResult, workitemsResult,
and optional stepsResult.
approverUserResult (value) - included in the JSON returned by the tool.
approverWorkitemsResult (value) - included in the JSON returned by the tool.
processInstanceQuery (value) - included in the JSON returned by the tool.
processInstanceResult (value) - included in the JSON returned by the tool.
workitemsQuery (value) - included in the JSON returned by the tool.
workitemsResult (value) - included in the JSON returned by the tool.
stepsQuery (value) - included in the JSON returned by the tool.
stepsResult (value) - included in the JSON returned by the tool.

Required permissions
- "View All Data" or be an actor on the records.

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_pending_approvals({
  "approverId": "005xx0000012345AAA",
  "approverUsername": "approver@example.com",
  "submitterId": "005xx0000012345AAA"
})
