Tool: list_global_value_sets

Description
List Global Value Sets (`GlobalValueSet`). These are reusable picklist
value lists that can be referenced from picklist fields across objects.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/
GET /services/data/v66.0/tooling/sobjects/GlobalValueSet/{Id}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
namePattern (string, optional) - Pattern for MasterLabel; string using * and ? wildcards
converted to SOQL LIKE; no default; example: Industry*; do not pass regex, raw LIKE
syntax, or multiple patterns.
includeValues (boolean, optional) - Whether to include the Tooling API CustomValue
field; boolean; default true; example: false; do not pass true when avoiding large
picklist value arrays.
whereClause (string, optional) - Additional SOQL WHERE condition for GlobalValueSet;
string with or without WHERE; no default; example: MasterLabel LIKE 'Account%'; do not
pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for GlobalValueSet; string with or
without ORDER BY; default MasterLabel ASC; example: MasterLabel DESC; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum GlobalValueSet rows to return; integer from 1 to
2000; default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce Tooling QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_global_value_sets({
  "namePattern": "Industry*",
  "includeValues": false,
  "whereClause": "MasterLabel LIKE 'Account%'"
})
