Tool: read_static_resource

Description
Download a static resource's bytes (or a single file path inside a zip
resource). Returns base64 by default; for known text content types the
tool returns plain text.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/sobjects/StaticResource/{param}
GET /services/data/v66.0/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json or content type

Body
None.

Input (parameters)
name (string, optional) - Resource name (lookup by name).
id (string, optional) - StaticResource Id.
  One required.
filePath (string, optional) - For zip resources, path to a single file inside.
asBase64 (boolean, optional, default false) - When true, always return base64 (binary safety).

Result
object with raw StaticResource metadata, responseContentType, byteLength, filePath, and
either text or base64 content.
resource (value) - included in the JSON returned by the tool.
responseContentType (value) - included in the JSON returned by the tool.
byteLength (value) - included in the JSON returned by the tool.
filePath (value) - included in the JSON returned by the tool.
text (value) - included in the JSON returned by the tool.
base64 (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only.
- Resource body limited to 5 MB.

Errors
- NOT_FOUND on name/id.
- INVALID_REQUEST when filePath specified but resource isn't a zip.

Example request

read_static_resource({ "name": "MTG_BrandLogo" })
