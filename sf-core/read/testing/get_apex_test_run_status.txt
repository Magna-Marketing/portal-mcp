Tool: get_apex_test_run_status

Description
Get the live status of an Apex test run by `AsyncApexJob` Id. Returns
queue items, completion progress, and (when finished) the per-method
results. For just the results once complete, use `list_apex_test_results`
filtered by the same parent job.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, AsyncApexJobId, Status, StartTime, EndTime, ClassesCompleted, ClassesEnqueued, MethodsCompleted, MethodsEnqueued, MethodsFailed, TestSetupTime, TestTime, UserId, IsAllTests, Source FROM ApexTestRunResult

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
asyncApexJobId (string, required) - AsyncApexJob Id for the Apex test run; Salesforce Id
string, typically starting with 707; required with no default; example: 7075g0000012345;
do not pass ApexClass Ids, run result Ids, multiple Ids, or SOQL fragments.

Result
Returns the raw Salesforce QueryResult with totalSize, done, and matching
ApexTestRunResult records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View All Data" / "Author Apex".

Idempotency & limits
- Read-only.

Errors
- NOT_FOUND.

Example request

get_apex_test_run_status({
  "asyncApexJobId": "7075g0000012345"
})
