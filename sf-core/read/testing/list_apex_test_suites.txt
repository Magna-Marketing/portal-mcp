Tool: list_apex_test_suites

Description
List `ApexTestSuite` records and their member test classes. Use to run
a curated subset of tests (`run_apex_tests` with `testSuiteNames`).

Salesforce API
Tooling API, v66.0. `ApexTestSuite` + `TestSuiteMembership`.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, TestSuiteName FROM ApexTestSuite
GET /services/data/v66.0/tooling/query/?q=SELECT ApexTestSuiteId, ApexClassId, ApexClass.Name FROM TestSuiteMembership WHERE ApexTestSuiteId IN (...)

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
testSuiteNamePattern (string, optional) - ApexTestSuite TestSuiteName pattern to match;
string with * and ? wildcards converted to SOQL LIKE; no default; example: Regression*;
do not pass regex, raw LIKE syntax, Ids, or comma-separated names.
whereClause (string, optional) - Additional SOQL WHERE condition for ApexTestSuite;
string with or without WHERE; no default; example: TestSuiteName = 'Regression'; do not
pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for ApexTestSuite; string with or
without ORDER BY; default TestSuiteName ASC; example: TestSuiteName DESC; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum ApexTestSuite rows to return; integer from 1 to
2000; default 200; example: 50; do not pass 0, negatives, decimals, or offsets.

Result
Returns the raw Salesforce QueryResult with totalSize, done, and records containing Id
and TestSuiteName.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "View All Data" / "Author Apex".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_apex_test_suites({
  "testSuiteNamePattern": "Regression*",
  "whereClause": "TestSuiteName = 'Regression'",
  "orderBy": "TestSuiteName DESC"
})
