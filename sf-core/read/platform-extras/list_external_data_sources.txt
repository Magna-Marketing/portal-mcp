Tool: list_external_data_sources

Description
List External Data Sources (Salesforce Connect) and the External
Objects defined under each. External objects appear like sObjects
(suffix `__x`) but live in another system (OData, Cross-Org adapter,
custom Apex Connector).

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, Endpoint, Type, Protocol, Repository, ManageableState, NamespacePrefix, AuthProviderId, CustomConfiguration, IsWritable, Language, NamedCredentialId, PrincipalType FROM ExternalDataSource

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
type (string, optional) - ExternalDataSource Type exact match; string API value; no
default; example: SalesforceConnect:OData2; do not pass labels, wildcards,
comma-separated values, or SOQL operators.
pattern (string, optional) - External data source name or label pattern; string using *
and ? wildcards converted to SOQL LIKE; no default; example: SAP*; do not pass regex or
raw LIKE syntax.
whereClause (string, optional) - Additional ExternalDataSource SOQL WHERE condition;
string with or without WHERE; no default; example: IsWritable = true; do not pass
SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - ExternalDataSource SOQL ORDER BY clause; string with or
without ORDER BY; default DeveloperName ASC; example: MasterLabel ASC; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum ExternalDataSource rows to return; integer from 1 to
2000; default 200; example: 100; do not pass 0, decimals, negatives, or offsets.

Result
raw Salesforce Tooling QueryResult for ExternalDataSource records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Customize Application" / "Manage External Connections".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_external_data_sources({
  "type": "SalesforceConnect:OData2",
  "pattern": "SAP*",
  "whereClause": "IsWritable = true"
})
