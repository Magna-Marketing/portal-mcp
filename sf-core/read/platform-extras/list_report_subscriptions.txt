Tool: list_report_subscriptions //low priority

Description
List report subscriptions (scheduled email deliveries of a report's
results to one or more users). Each subscription shows the report,
recipients, schedule, conditions for sending, and last run.

Salesforce API
Analytics REST API, v66.0. `/analytics/notifications`.

Endpoint
GET /services/data/v66.0/analytics/notifications?source=lightningReportSubscribe

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
reportId (string, optional) - Report record Id to pass as analytics notifications
recordId; Salesforce report Id string; no default; example: 00O5g0000012345; do not pass
report names, URLs, or multiple Ids.
ownerId (string, optional) - Owner user Id for notifications when permitted; Salesforce
user Id string; no default; example: 0055g0000012345; do not pass usernames, emails, or
multiple Ids.

Result
raw Analytics Notifications JSON array with notification fields such as id, source,
recordId, schedule, and thresholds.

Required permissions
- "API Enabled" + "Schedule Reports".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_report_subscriptions({
  "reportId": "00O5g0000012345",
  "ownerId": "0055g0000012345"
})
