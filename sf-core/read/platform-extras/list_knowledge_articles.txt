Tool: list_knowledge_articles

Description
List Salesforce Knowledge articles (`KnowledgeArticleVersion`) with
status (Draft|Online|Archived), language, validation status, and
categorization. Filter by article type.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, KnowledgeArticleId, Title, UrlName, ArticleNumber, ArticleType, Language, PublishStatus, ValidationStatus, IsLatestVersion, IsVisibleInPkb, IsVisibleInCsp, IsVisibleInPrm, FirstPublishedDate, LastPublishedDate FROM KnowledgeArticleVersion WHERE PublishStatus IN ('Online','Draft','Archived')

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
articleType (string, optional) - KnowledgeArticleVersion ArticleType exact match; string
API value; no default; example: Knowledge; do not pass labels, wildcards,
comma-separated values, or object API names.
language (string, optional) - Article language filter; string language code stored by
Salesforce; no default; example: en_US; do not pass locale labels or multiple values.
status (string | string[], optional) - PublishStatus filter; string or array of strings;
default Online, Draft, and Archived; example: Online; do not pass lowercase UI labels or
empty arrays.
isLatestVersionOnly (boolean, optional) - Whether only latest article versions are
returned; boolean; default true; example: false; do not pass strings or expect
archived-only filtering.
pattern (string, optional) - Article title or URL name pattern; string using * and ?
wildcards converted to SOQL LIKE; no default; example: Password*; do not pass regex or
raw LIKE syntax.
whereClause (string, optional) - Additional KnowledgeArticleVersion SOQL WHERE
condition; string with or without WHERE; no default; example: LastPublishedDate =
LAST_N_DAYS:30; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - KnowledgeArticleVersion SOQL ORDER BY clause; string with
or without ORDER BY; default LastPublishedDate DESC; example: Title ASC; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum KnowledgeArticleVersion rows to return; integer from
1 to 2000; default 200; example: 100; do not pass 0, decimals, negatives, or offsets.

Result
raw Salesforce QueryResult for KnowledgeArticleVersion records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Read Knowledge".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY, KNOWLEDGE_NOT_ENABLED.

Example request

list_knowledge_articles({
  "articleType": "Knowledge",
  "language": "en_US",
  "status": "Online"
})
