Tool: list_dashboard_subscriptions

Description
List dashboard subscriptions (scheduled refresh + email delivery of a
dashboard). Returns recipients, schedule, conditions, last run.

Salesforce API
Analytics REST API, v66.0. `/analytics/notifications?source=dashboard`.

Endpoint
GET /services/data/v66.0/analytics/notifications?source=lightningDashboardSubscribe

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
dashboardId (string, optional) - Dashboard record Id to pass as analytics notifications
recordId; Salesforce dashboard Id string; no default; example: 01Z5g0000012345; do not
pass dashboard names, URLs, or multiple Ids.
ownerId (string, optional) - Owner user Id for notifications when permitted; Salesforce
user Id string; no default; example: 0055g0000012345; do not pass usernames, emails, or
multiple Ids.

Result
raw Analytics Notifications JSON array with notification fields such as id, source,
recordId, schedule, and thresholds.

Required permissions
- "API Enabled" + "Subscribe to Dashboards".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_dashboard_subscriptions({
  "dashboardId": "01Z5g0000012345",
  "ownerId": "0055g0000012345"
})
