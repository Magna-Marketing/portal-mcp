Tool: list_external_objects

Description
List External Objects (`__x`) and the data source each is bound to.
External Objects are queryable via SOQL but reads forward to the
external system.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
pattern (string, optional) - External Object API name or label pattern; string using *
and ? wildcards converted to SOQL LIKE; no default; example: SAP*__x; do not pass regex,
raw LIKE syntax, or multiple patterns.
whereClause (string, optional) - Additional EntityDefinition SOQL WHERE condition;
string with or without WHERE; no default; example: NamespacePrefix = null; do not pass
SELECT, FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - EntityDefinition SOQL ORDER BY clause; string with or
without ORDER BY; default QualifiedApiName ASC; example: Label ASC; do not pass WHERE,
LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum EntityDefinition rows to return; integer from 1 to
2000; default 200; example: 100; do not pass 0, decimals, negatives, or offsets.

Result
raw Salesforce Tooling QueryResult for EntityDefinition records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_external_objects({
  "pattern": "SAP*__x",
  "whereClause": "NamespacePrefix = null",
  "orderBy": "Label ASC"
})
