Tool: download_file_content

Description
Download the binary content of a `ContentVersion` (a file in
Salesforce Files). Returns base64 by default; for known text content
types (text/*, application/json) the tool returns plain text.

Salesforce API
REST API (Data), v66.0. `GET /sobjects/ContentVersion/{id}/VersionData`.

Endpoint
GET /services/data/v66.0/sobjects/ContentVersion/{contentVersionId}/VersionData

Headers
Authorization: Bearer <access_token>
Accept: <content type>

Body
None.

Input (parameters)
contentVersionId (string, required) - ContentVersion Id whose VersionData should be
downloaded; string Id in 15- or 18-character format; required with no default; example:
068xx0000004D3FAAU; do not pass ContentDocument, Attachment, or ContentDocumentLink Ids.

Result
Returns a JSON object with raw ContentVersion metadata, response headers, byte size, and
base64 content.
contentVersionId (value) - included in the JSON returned by the tool.
contentVersion (value) - included in the JSON returned by the tool.
headers (value) - included in the JSON returned by the tool.
encoding (value) - included in the JSON returned by the tool.
size (value) - included in the JSON returned by the tool.
content (value) - included in the JSON returned by the tool.

Required permissions
- File read share.

Idempotency & limits
- Read-only.
- File size cap depends on org setting (default 2 GB but practical MCP cap ~50 MB).

Errors
- NOT_FOUND.
- FILE_TOO_LARGE for very large binaries.

Example request

download_file_content({
  "contentVersionId": "068xx0000004D3FAAU"
})
