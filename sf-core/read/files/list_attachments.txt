Tool: list_attachments

Description
List legacy `Attachment` rows (now superseded by `ContentVersion`). Many
older orgs still have Attachment data. Use this to inventory and plan
migration to Files.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, ParentId, OwnerId, ContentType, BodyLength, IsPrivate, IsEncrypted, IsPartnerShared, Description, CreatedDate, LastModifiedDate FROM Attachment

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
parentId (string, optional) - Attachment ParentId filter; string Id for a supported
parent record in 15- or 18-character format; no default; example: 001xx000003DGbYAAW; do
not pass object names or multiple Ids.
ownerId (string, optional) - Attachment OwnerId filter; string User or Calendar Id; no
default; example: 005xx000001Sv6rAAC; do not pass usernames or owner names.
pattern (string, optional) - Attachment Name wildcard filter using * and ? converted to
SOQL LIKE; string; no default; example: *.pdf; do not pass regex or raw SOQL LIKE
syntax.
namePattern (string, optional) - Legacy alias for pattern against Attachment Name;
string with * and ? wildcards; ignored when pattern is provided; example: Contract*;
prefer pattern and do not pass regex.
whereClause (string, optional) - Additional Attachment SOQL WHERE conditions without the
WHERE keyword; string appended with AND after built-in filters; no default; example:
IsPrivate = false; do not pass SELECT, FROM, ORDER BY, LIMIT, or untrusted user text.
orderBy (string, optional) - Attachment ORDER BY clause without the ORDER BY keyword;
string; default LastModifiedDate DESC; example: Name ASC; do not pass WHERE, LIMIT, or
fields unavailable on Attachment.
limit (integer, optional) - Maximum Attachment rows to return; integer from 1 to 2000;
default 200; example: 25; do not pass 0, negatives, decimals, or offsets.

Result
Returns the raw Attachment query response as a JSON object.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "API Enabled" + parent record read.

Idempotency & limits
- Read-only.
- To download an attachment's body: `GET /sobjects/Attachment/{id}/Body` (separate tool: download via `dml_records` or extend later).

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_attachments({
  "parentId": "001xx000003DGbYAAW",
  "ownerId": "005xx000001Sv6rAAC",
  "pattern": "*.pdf"
})
