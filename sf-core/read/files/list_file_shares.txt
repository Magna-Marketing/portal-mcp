Tool: list_file_shares

Description
List `ContentDocumentLink` rows for a file or for a record (the inverse
of `list_files` filtered by recordId). Each row shows the entity (record,
user, library, group), share type ('V' viewer, 'C' collaborator, 'I'
inferred), and visibility scope.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, ContentDocumentId, LinkedEntityId, ShareType,Visibility FROM ContentDocumentLink WHERE ContentDocumentId='{{contentDocumentId}}'

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
contentDocumentId (string, optional) - ContentDocumentLink ContentDocumentId filter;
string Id in 15- or 18-character format; no default but Salesforce requires this,
linkedEntityId, or an equivalent whereClause; example: 069xx0000004C92AAE; do not pass
ContentVersion Ids.
linkedEntityId (string, optional) - ContentDocumentLink LinkedEntityId filter; string Id
for a record, user, group, or library; no default but Salesforce requires this,
contentDocumentId, or an equivalent whereClause; example: 001xx000003DGbYAAW; do not
pass object names.
shareType ("V" | "C" | "I", optional) - ShareType exact filter; enum V, C, or I; no
default; example: V; do not pass labels such as Viewer or Collaborator.
visibility ("AllUsers" | "InternalUsers" | "SharedUsers", optional) - Visibility exact
filter; enum AllUsers, InternalUsers, or SharedUsers; no default; example:
InternalUsers; do not pass lowercase values.
whereClause (string, optional) - Additional ContentDocumentLink SOQL WHERE conditions
without the WHERE keyword; string appended with AND after built-in filters; no default;
example: LinkedEntityId IN ('001xx000003DGbYAAW'); must include ContentDocumentId or
LinkedEntityId when no direct filter is set; do not pass SELECT, FROM, ORDER BY, LIMIT,
or untrusted user text.
orderBy (string, optional) - ContentDocumentLink ORDER BY clause without the ORDER BY
keyword; string; default Id ASC; example: ShareType ASC; do not pass WHERE, LIMIT, or
fields unavailable on ContentDocumentLink.
limit (integer, optional) - Maximum ContentDocumentLink rows to return; integer from 1
to 2000; default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
Returns the raw ContentDocumentLink query response as a JSON object.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- File or record read.

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_file_shares({
  "contentDocumentId": "069xx0000004C92AAE",
  "linkedEntityId": "001xx000003DGbYAAW",
  "shareType": "V"
})
