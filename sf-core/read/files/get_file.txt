Tool: get_file

Description
Get a file's metadata: latest version + every version, all sharing
links, owner, content type, size, custom fields. To download the bytes
use `download_file_content`.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
contentDocumentId (string, required) - ContentDocument Id for the Salesforce File;
string Id in 15- or 18-character format; required with no default; example:
069xx0000004C92AAE; do not pass ContentVersion, Attachment, or ContentDocumentLink Ids.
includeShares (boolean, optional) - Whether to query ContentDocumentLink rows for the
file; boolean; default false; example: true; do not pass strings such as \"true\".

Result
Returns a JSON object with raw file, latestVersion, and optional shares query response.
file (value) - included in the JSON returned by the tool.
latestVersion (value) - included in the JSON returned by the tool.

Required permissions
- File read share or "View All Data".

Idempotency & limits
- Read-only.

Errors
- NOT_FOUND, INSUFFICIENT_ACCESS_OR_READONLY.

Example request

get_file({
  "contentDocumentId": "069xx0000004C92AAE"
})
