Tool: query_record_types

Description
Discover record types across one or more sObjects. Returns the standard
RecordType row plus visibility settings for the running user's profile
and (optionally) for all profiles. Use this to resolve a developer name
to a record type Id (needed by `get_picklist_values`,
`manage_field_permissions`, page assignments, etc.) and to audit which
profiles can see which record types.

Use `describe_object` if you only need the record type list for a single
object — it returns the same recordTypeInfos plus everything else.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, DeveloperName, IsActive, Description, NamespacePrefix, SobjectType, BusinessProcessId FROM RecordType

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
sObject (string, optional) - The sObject API name whose record types should be returned;
string such as "Account" or "Opportunity"; no default means all objects; example:
"Case"; do not pass labels, relationship paths, or comma-separated object names.
namePattern (string, optional) - The RecordType Name or DeveloperName pattern; string
using * as any characters and ? as one character, converted to SOQL LIKE; no default;
example: "Business_*"; do not pass regex, raw LIKE syntax, or multiple patterns.
whereClause (string, optional) - Additional SOQL WHERE condition for RecordType without
the WHERE keyword; string; no default; example: "NamespacePrefix = null"; do not pass
SELECT, FROM, ORDER BY, LIMIT, or untrusted raw input.
orderBy (string, optional) - The SOQL ORDER BY clause without the ORDER BY keyword;
string; default "SobjectType ASC, DeveloperName ASC"; example: "Name ASC"; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - The maximum RecordType rows to return; integer from 1 to
2000; default 200; example: 100; do not pass 0, decimals, negatives, offsets,.
includeInactive (boolean, optional) - Whether inactive record types are included;
boolean; default false; example: true; do not pass true when only assignable active
record types are needed.

Result
raw Salesforce QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- API Enabled.
- Read on RecordType (granted by default).
- Tooling API access for visibility data ("View Setup and Configuration").

Idempotency & limits
- Read-only; safe to retry.
- Visibility query may be heavy in orgs with many profiles; pre-filter
  with `profile`.

Errors
- INVALID_TYPE: sObject doesn't exist.

Example request

query_record_types({
  "sObject": "Case",
  "namePattern": "Business_*",
  "whereClause": "NamespacePrefix = null"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "SObject"
      }
    }
  ]
}
