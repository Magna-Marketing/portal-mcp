Tool: list_reports

Description
List reports with pagination. Returns report Id, name, folder name,
description, creator name, and last-run timestamp. Uses SOQL on the
`Report` object via the REST Query resource. The API returns `records`,
`done`, and `totalSize`; when
`done` is false, repeat `GET` on `nextRecordsUrl` until all needed
batches are read (continuation requests must not include the `q`
parameter).

Use `describe_report` for a single report's full metadata, `run_report`
to execute one synchronously, or `manage_report_instance` to run async.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/?q=SELECT Id, Name, DeveloperName, FolderName, Description, Format, LastRunDate, CreatedById, CreatedBy.Name, CreatedDate, LastModifiedById, LastModifiedBy.Name, LastModifiedDate FROM Report

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
pattern (string, optional) - Report text pattern matched against Name, DeveloperName,
FolderName, or Description; string using * and ? wildcards converted to SOQL LIKE; no
default; example: Sales*Pipeline; do not pass regex, raw LIKE syntax, or multiple
patterns.
folderName (string, optional) - Report folder API/name filter; string compared to
Report.FolderName exactly; no default; example: Unfiled Public Reports; do not pass
folder Ids, comma-separated values, or LIKE syntax.
format (string, optional) - Report format filter; string compared to Report.Format when
the field is available; no default; example: Summary; do not pass labels from the UI if
the org stores a different API value.
whereClause (string, optional) - Additional SOQL WHERE condition for Report; string with
or without WHERE; no default; example: LastRunDate = LAST_N_DAYS:30; do not pass SELECT,
FROM, ORDER BY, LIMIT, or untrusted user input.
orderBy (string, optional) - SOQL ORDER BY clause for Report; string with or without
ORDER BY; default Name ASC; example: LastModifiedDate DESC NULLS LAST; do not pass
WHERE, LIMIT, SELECT, or FROM.
limit (integer, optional) - Maximum Report rows to return; integer from 1 to 2000;
default 200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
raw Salesforce QueryResult with totalSize, done, records.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- "API Enabled".
- User must be allowed to see reports per org sharing (folder/report access).

Idempotency & limits
- Read-only; safe to retry.
- Query batches use the platform batch size (locator suffix often reflects
  row chunk size, e.g. `...-2000` in docs); follow `nextRecordsUrl` for more.

Errors
- MALFORMED_QUERY / INVALID_FIELD on invalid SOQL or field list (see SOQL
  SELECT reference).
- INSUFFICIENT_ACCESS_OR_READONLY when `Report` rows are not visible.

Example request

list_reports({
  "pattern": "Sales*Pipeline",
  "folderName": "Unfiled Public Reports",
  "format": "Summary"
})

Example result

{
  "totalSize": 1,
  "done": true,
  "records": [
    {
      "attributes": {
        "type": "Report"
      }
    }
  ]
}
