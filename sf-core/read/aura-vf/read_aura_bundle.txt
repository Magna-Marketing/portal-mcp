Tool: read_aura_bundle

Description
Read a single Aura bundle with all its definitions inline:
.cmp/.app/.evt/.intf, controller (.js), helper (.js), renderer (.js),
style (.css), documentation (.auradoc), design (.design), svg (.svg).

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, AuraDefinitionBundleId, CreatedById, CreatedDate, DefType, Format, IsDeleted, LastModifiedById, LastModifiedDate, Source, SystemModstamp FROM AuraDefinitionBundle
GET /services/data/v66.0/tooling/query/?q=SELECT Id, AuraDefinitionBundleId, CreatedById, CreatedDate, DefType, Format, IsDeleted, LastModifiedById, LastModifiedDate, Source, SystemModstamp FROM AuraDefinition

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
name (string, required) - AuraDefinitionBundle DeveloperName; string API name with
letters, numbers, or underscores; no default; example: forceRecordLayout; do not pass
namespace prefix, wildcards, SOQL, or file extensions.

Result
Returns a JSON object with raw bundle and definitions query results.
bundleResult (value) - included in the JSON returned by the tool.
definitionsResult (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Idempotency & limits
- Read-only.

Errors
- NOT_FOUND.

Example request

read_aura_bundle({
  "name": "forceRecordLayout"
})
