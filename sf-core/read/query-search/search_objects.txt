Tool: search_objects

Description
Discover sObjects in the org by name pattern. Returns the matching
objects from the global describe with high-level metadata (label, custom
flag, queryable/createable flags, key prefix). Use this to resolve a
human label or partial API name to an exact sObject API name before
calling `describe_object`, `query_records`, or `dml_records`. For full
field/relationship/recordType detail of a single object use
`describe_object`.

Salesforce API
REST API (Data), v66.0. Backed by the global describe at
`GET /sobjects/`. The MCP server filters and ranks results.

Endpoint
GET https://{instance}.my.salesforce.com/services/data/v66.0/sobjects/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None (GET request).

Input (parameters)
pattern (string, optional) - The sObject API-name or label match pattern; string using *
as any characters and ? as one character; default "*" returns all matching objects;
example: "Account*" or "*Invoice*"; do not pass regex, SOQL LIKE syntax, or a
comma-separated list.
includeCustomOnly (boolean, optional) - Whether to return only custom objects where
Salesforce marks custom as true; boolean; default false; example: true; do not combine
with includeStandardOnly.
includeStandardOnly (boolean, optional) - Whether to return only standard objects where
Salesforce marks custom as false; boolean; default false; example: true; do not combine
with includeCustomOnly.
queryableOnly (boolean, optional) - Whether to return only objects Salesforce marks
queryable; boolean; default false; example: true; do not use when you need non-queryable
metadata objects.
limit (integer, optional) - The maximum matching sObject entries to return for this page
after filtering; integer from 1 to 200; default 50; example: 25; do not pass 0,
decimals, negative values, offsets or values greater than 200.
offset (integer, optional) - The zero-based filtered result offset for pagination;
integer 0 or greater; default 0; example: 200; pass the previous response nextOffset
with the same filters to retrieve the next page; do not pass decimals, negative values,
or Salesforce nextRecordsUrl values.

Result
global describe-style JSON with totalMatches, offset, limit, nextOffset, hasMore, and
raw sobjects entries for the current page.
totalMatches (value) - included in the JSON returned by the tool.
offset (value) - included in the JSON returned by the tool.
limit (value) - included in the JSON returned by the tool.
nextOffset (value) - included in the JSON returned by the tool.
hasMore (value) - included in the JSON returned by the tool.
sobjects (value) - included in the JSON returned by the tool.

Required permissions
- API Enabled.
- Object read on each sObject (filtered objects with no read are omitted).

Idempotency & limits
- Read-only; safe to retry.
- Global describe is cached; tool may serve from local cache for ~5 min.

Errors
- INVALID_TYPE: pattern is malformed.

Example request

search_objects({
  "pattern": "Account*\" or \"*Invoice*",
  "includeCustomOnly": true,
  "includeStandardOnly": true
})

Example result

{
  "totalMatches": null,
  "offset": null,
  "limit": null,
  "nextOffset": null,
  "hasMore": null,
  "sobjects": null
}
