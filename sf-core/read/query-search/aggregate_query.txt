Tool: aggregate_query

Description
Run an aggregate SOQL query (`COUNT`, `COUNT_DISTINCT`, `SUM`, `AVG`,
`MIN`, `MAX`) optionally grouped with `GROUP BY` and filtered with
`HAVING`. Use this for summary reporting; use `query_records` for raw
rows. For a single total count without grouping, omit `groupByFields` (or
pass an empty array) — the tool will run `SELECT COUNT() FROM Object
[WHERE ...]` which returns just `totalSize`.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
sObject (string, required) - The Salesforce sObject API name used in FROM; string such
as "Opportunity"; no default; example: "Account"; do not pass labels, relationship
paths, SOQL clauses, or comma-separated objects.
aggregates (object[], optional) - The aggregate expressions for SELECT; non-empty array;
no default; example: [{"function":"SUM","field":"Amount","alias":"totalAmount"}]; do not
pass an empty array.
  function (string, required) - The SOQL aggregate function; enum string; no default;
  example: "COUNT"; do not pass non-aggregate functions or lowercase-only custom text.
  field (string, optional) - The field API name inside the aggregate function; string;
  optional only for COUNT(); example: "Amount"; do not pass aliases, formulas, commas,
  or relationship subqueries.
  alias (string, optional) - The optional SOQL alias for the aggregate expression;
  string identifier; no default; example: "totalAmount"; do not pass spaces, quoted
  labels, or duplicate aliases.
groupByFields (string[], optional) - The fields or supported date grouping functions for
GROUP BY; array of strings; defaults to no GROUP BY; example: ["StageName"] or
["CALENDAR_MONTH(CloseDate)"]; do not pass aggregate expressions or aliases.
where (string, optional) - The SOQL WHERE condition without the WHERE keyword; string;
no default; example: "CloseDate = THIS_FISCAL_QUARTER"; do not pass SELECT, FROM, GROUP
BY, HAVING, ORDER BY, LIMIT, or untrusted raw input.
having (string, optional) - The SOQL HAVING condition without the HAVING keyword;
string; requires groupByFields; example: "COUNT(Id) > 5"; do not pass WHERE, GROUP BY,
ORDER BY, LIMIT, or use without grouping.
orderBy (string, optional) - The SOQL ORDER BY clause without the ORDER BY keyword;
string; no default; example: "totalAmount DESC"; do not pass WHERE, GROUP BY, HAVING,
LIMIT, SELECT, or FROM.
limit (integer, optional) - The maximum aggregate rows to return; integer from 1 to
2000; no default; example: 100; do not pass 0, decimals, negatives, offsets,.

Result
raw Salesforce QueryResult with totalSize, done, and records containing AggregateResult
attributes and aggregate fields or aliases.
totalSize (number) - QueryResult totalSize.
done (boolean) - true when this response contains the full result.
records (array) - sObject rows from the query. Returned unchanged; not renamed.
nextRecordsUrl (string, optional) - present when done is false.

Required permissions
- API Enabled.
- Read on sObject and all fields referenced.

Idempotency & limits
- Read-only; safe to retry.
- Max 2,000 grouping rows. Add LIMIT or refine groupByFields to fit.
- CPU/heap limits apply to the host transaction.

Errors
- MALFORMED_QUERY: aggregates require GROUP BY when mixing fields and
  aggregates. Mixing non-grouped fields and aggregates is rejected.
- HAVING_WITH_NO_GROUP_BY: HAVING used without grouping.
- AGGREGATE_QUERY_TOO_LARGE: result exceeds 2,000 rows.

Example request

aggregate_query({
  "sObject": "Account"
})
