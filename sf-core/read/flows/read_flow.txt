Tool: read_flow

Description
Read one Salesforce Flow **version** by its Tooling `Flow` record Id. The
GET returns the full Tooling row: identity fields plus a nested
`Metadata` object (the flow definition as JSON: `start`, element
arrays such as `recordLookups` / `recordUpdates` / `decisions` /
`screens`, `variables`, `processMetadataValues`, etc.). When
`includeXml` is true, the same flow is also loaded as raw `<Flow>` XML
via Metadata `readMetadata` (SOAP), keyed by `FullName` on the record.
Use `list_flows` (or another discovery path) to obtain a
`flowVersionId` before calling this tool.

Salesforce API
Tooling API, v66.0.
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (readMetadata Flow)
GET /services/data/v66.0/tooling/sobjects/{type}/{id}

Headers
Authorization: Bearer <access_token>
GET: Accept application/json
POST readMetadata: Content-Type text/xml; SOAPAction per Metadata WSDL
(handled by MCP).

Body
None for the GET. SOAP envelope for readMetadata when `includeXml` is
true (handled by MCP).

Input (parameters)
flowVersionId (string, required) -
Tooling API Flow version Id; string Id in 15- or 18-character format; required with no
default; example: 301xx0000008abcAAA; do not pass FlowDefinition Ids, flow API names,
labels, or version numbers.
includeMetadata (boolean, optional) -
Whether to also call Metadata API readMetadata('Flow', FullName); boolean; default
false; example: true; do not pass true for managed-package flows whose metadata is
protected or when FullName is unavailable.
includeXml (boolean, optional) -
Legacy alias for includeMetadata; boolean; default false and ignored when
includeMetadata is provided; example: true; returns the raw Metadata API result, not an
XML conversion; do not pass strings such as \"true\".

Result
Returns a JSON object with the raw Tooling Flow record and optional raw Metadata API
read result.
flowVersion (value) - included in the JSON returned by the tool.

Required permissions
- API Enabled.
- Access to read the Flow version in Tooling; "Manage Flow" / metadata
  access as required by your org for readMetadata when requesting XML.

Idempotency & limits
- Read-only; safe to retry.
- readMetadata adds load; cache XML when possible.

Errors
- NOT_FOUND: `flowVersionId` is invalid or not visible to the user.
- INSUFFICIENT_ACCESS_OR_READONLY: missing rights to Tooling or metadata.

Example request

read_flow({
  "flowVersionId": "301xx0000008abcAAA"
})

Example result

{
  "flowVersion": null
}
