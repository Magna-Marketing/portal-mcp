Tool: read_flow

Description
Read one Salesforce Flow **version** by its Tooling `Flow` record Id. The
GET returns the full Tooling row: identity fields plus a nested
`Metadata` object (the flow definition as JSON: `start`, element
arrays such as `recordLookups` / `recordUpdates` / `decisions` /
`screens`, `variables`, `processMetadataValues`, etc.). When
`includeXml` is true, the same flow is also loaded as raw `<Flow>` XML
via Metadata `readMetadata` (SOAP), keyed by `FullName` on the record.
Use `list_flows` (or another discovery path) to obtain a
`flowVersionId` before calling this tool.

Salesforce API
Tooling REST and Metadata API (SOAP), v66.0 only.

Endpoint
GET /services/data/v66.0/tooling/sobjects/Flow/{flowVersionId}
POST /services/Soap/m/66.0   (Metadata API readMetadata for raw XML)

Headers
Authorization: Bearer <access_token>
GET: Accept application/json
POST readMetadata: Content-Type text/xml; SOAPAction per Metadata WSDL
(handled by MCP).

Body
None for the GET. SOAP envelope for readMetadata when `includeXml` is
true (handled by MCP).

Input (parameters)
flowVersionId (string, required) - 18-character Id of the Tooling
  `Flow` row (a specific version), not the FlowDefinition Id.
includeXml (boolean, optional, default false) - When true, also return
  raw Flow XML from Metadata `readMetadata` (SOAP). Heavier; off by
  default.

Result
flowVersion (object) - Body of GET .../tooling/sobjects/Flow/{id}
  (same shape Salesforce returns). Typical top-level fields include:
  - attributes: { type: "Flow", url: "<.../Flow/{Id}>" }
  - Id, DefinitionId, MasterLabel, ManageableState, VersionNumber,
    Status, Description, ProcessType
  - CreatedDate, CreatedById, LastModifiedDate, LastModifiedById
  - Metadata: nested flow definition (apiVersion, label, processType,
    status, start { object, triggerType, recordTriggerType, connector,
    ... }, recordCreates, recordLookups, recordUpdates, decisions,
    screens, actionCalls, variables, formulas, loops, subflows, etc.;
    many arrays are empty on simple flows)
  - FullName: DeveloperName (used for readMetadata when includeXml)
  - IsTemplate, IsOverridable, SourceTemplate, OverriddenFlow,
    TriggerOrder, RunInMode, ApiVersion, Environments, TimeZoneSidKey,
    ProgressStatus, IsPaused, AreMetricsLoggedToDataCloud
  Exact fields depend on API version and flow type.
xml (string|null) - When `includeXml` is true: raw `<Flow>` XML from
  readMetadata; otherwise null or omitted.

Required permissions
- API Enabled.
- Access to read the Flow version in Tooling; "Manage Flow" / metadata
  access as required by your org for readMetadata when requesting XML.

Idempotency & limits
- Read-only; safe to retry.
- readMetadata adds load; cache XML when possible.

Errors
- NOT_FOUND: `flowVersionId` is invalid or not visible to the user.
- INSUFFICIENT_ACCESS_OR_READONLY: missing rights to Tooling or metadata.

Example request

read_flow({ "flowVersionId": "3013u000000NDkvAAG", "includeXml": false })
