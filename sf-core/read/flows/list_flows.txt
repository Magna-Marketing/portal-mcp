Tool: list_flows

Description
List and filter Flow definitions in the org. Filter by status, process
type, sObject (for record-triggered flows), DeveloperName pattern, and
creator/last-modified user. Supports sorting and grouping for inventory
reports. Returns FlowDefinition rows with their active and latest
version numbers; pair with `read_flow` to get a single flow's full
detail or XML.

Salesforce API
Tooling API, v66.0.

Endpoint
GET /services/data/v66.0/tooling/query/?q=SELECT Id, DefinitionId, Definition.DeveloperName, MasterLabel, Description, ProcessType, Status, VersionNumber, ApiVersion, RunInMode, Environments, IsTemplate, ManageableState, TimeZoneSidKey, CreatedById, CreatedBy.Name, CreatedDate, LastModifiedById, LastModifiedBy.Name, LastModifiedDate FROM Flow

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
status (string | string[], optional) - Flow Status filter; enum or array of Active,
Draft, Obsolete, UnderReview, or InvalidDraft; no default; example: [\"Active\",
\"Draft\"]; do not pass lowercase labels or lifecycle values not supported by Tooling
API v66.0.
processType (string | string[], optional) - Flow ProcessType filter; string or array
using Salesforce Tooling values such as Flow, AutoLaunchedFlow, Workflow,
InvocableProcess, CustomEvent, PromptFlow, or OrchestrationFlow; no default; example:
AutoLaunchedFlow; do not pass UI labels such as Screen Flow.
pattern (string, optional) - Definition.DeveloperName wildcard filter using * and ?
converted to SOQL LIKE; string; no default; example: Account_*; do not pass regex,
labels, or raw LIKE syntax.
namePattern (string, optional) - Legacy alias for pattern against
Definition.DeveloperName; string with * and ? wildcards; ignored when pattern is
provided; example: *_Subflow; prefer pattern and do not pass regex.
createdById (string, optional) - CreatedById filter for the flow version; string User Id
in 15- or 18-character format; no default; example: 005xx000001Sv6rAAC; do not pass
usernames.
lastModifiedById (string, optional) - LastModifiedById filter for the flow version;
string User Id in 15- or 18-character format; no default; example: 005xx000001Sv6rAAC;
do not pass usernames.
modifiedSince (string, optional) - Lower bound for LastModifiedDate; ISO 8601 datetime
string; no default; example: 2026-01-01T00:00:00.000Z; do not pass relative dates or
locale-formatted dates.
whereClause (string, optional) - Additional Tooling SOQL WHERE conditions for Flow
without the WHERE keyword; string appended with AND after built-in filters; no default;
example: ApiVersion >= 60.0; do not pass SELECT, FROM, ORDER BY, LIMIT, Metadata,
FullName, or untrusted user text.
orderBy (string, optional) - Flow ORDER BY clause without the ORDER BY keyword; string;
default Definition.DeveloperName ASC, VersionNumber DESC; example: LastModifiedDate
DESC; do not pass WHERE, LIMIT, Metadata, FullName, or fields unavailable on Tooling
Flow.
sortBy (string, optional) - Structured sort field kept for compatibility; enum of common
Flow sortable fields; ignored when orderBy is provided; default
Definition.DeveloperName; example: LastModifiedDate; do not pass labels or Metadata.
sortDirection ("ASC" | "DESC", optional) - Direction for sortBy when orderBy is omitted;
enum ASC or DESC; default ASC; example: DESC; do not pass lowercase values.
limit (integer, optional) - Maximum Flow rows to return; integer from 1 to 2000; default
200; example: 100; do not pass 0, negatives, decimals, or offsets.

Result
Returns the raw Tooling API Flow query response as a JSON object.

Required permissions
- API Enabled.
- "View All Data" or "Manage Flow" to see all flows.

Idempotency & limits
- Read-only; safe to retry.
- Tooling SOQL governor limits apply.

Errors
- INVALID_FIELD: bad sortBy or groupBy.
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_flows({
  "status": "[\\\"Active\\\", \\\"Draft\\\"]",
  "processType": "AutoLaunchedFlow",
  "pattern": "Account_*"
})

Example result

Returns the raw Tooling API Flow query response as a JSON object.
