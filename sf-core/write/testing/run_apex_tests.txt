Tool: run_apex_tests

Description
Run Apex tests synchronously or asynchronously. Synchronous mode is
fastest for a small set; asynchronous returns a job Id that can be
polled with `get_apex_test_run_status`. Selection options: by class
list, by suite list, by namespace, by individual test methods, or all
local tests / all tests in org.

Salesforce API
Tooling API, v66.0.

Endpoint
POST /services/data/v66.0/tooling/{path}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (sync)
{
  "tests": [
    { "className": "ProjectServiceTest", "testMethods": ["testCreate","testUpdate"] }
  ],
  "maxFailedTests": 0
}

Body (async)
{
  "classNames": "ProjectServiceTest,ProjectTriggerHandlerTest",
  "testLevel": "RunSpecifiedTests"
}

Input (parameters)
mode ("sync" | "async", required) - Execution mode. Sync is limited by Salesforce to one
Apex class; async supports multiple classes and suites.
classNames (string[], optional) - Apex test class names. In async mode these are sent as
the Tooling API classNames comma-list unless testMethods is supplied.
classIds (string[], optional) - ApexClass Ids. In async mode these are sent as the
Tooling API classids comma-list unless testMethods is supplied.
suiteNames (string[], optional) - Apex test suite names for async runs, sent as the
Tooling API suiteNames comma-list.
suiteIds (string[], optional) - ApexTestSuite Ids for async runs, sent as the Tooling
API suiteids comma-list.
testMethods (object[], optional) - Individual test method selections. Sent in the
Tooling API tests array.
  className (string, optional) - Apex class name containing the test method.
  classId (string, optional) - ApexClass Id containing the test method.
  namespace (string, optional) - Namespace prefix for managed-package test classes.
  methodName (string, optional) - Single test method name.
  testMethods (string[], optional) - Multiple test method names in the same class.
testLevel (string, optional) - Salesforce test level. Defaults to RunSpecifiedTests when
selecting classes/suites/methods, otherwise RunLocalTests for async.
maxFailedTests (integer, optional) - Maximum failed tests before Salesforce stops the
run. Use -1 for no limit where supported.
skipCodeCoverage (boolean, optional) - For async runs, true opts out of code coverage
collection. Included for sync only when supplied.

Result
the raw Salesforce Tooling API response, usually a sync result object or async test run
ID.

Required permissions
- "Author Apex".
- "Run Tests" if running tests not authored by self.

Idempotency & limits
- Each run is independent (not idempotent).
- Sync runs: 10 min wall-clock, results returned in one response.
- Async: governor limits per test method.

Errors
- INVALID_TYPE on bad class/suite name.
- TEST_RUN_FAILED with details.

Example request

run_apex_tests({
  "mode": "example"
})
