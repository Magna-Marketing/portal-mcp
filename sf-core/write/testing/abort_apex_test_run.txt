Tool: abort_apex_test_run

Description
Abort an in-progress async Apex test run by job Id. Updates the
`AsyncApexJob.Status` to "Aborted" and any pending `ApexTestQueueItem`
rows to "Aborted".

Salesforce API
Tooling API, v66.0.
REST API (Data), v66.0.

Endpoint
PATCH /services/data/v66.0/sobjects/AsyncApexJob/{jobId}
PATCH /services/data/v66.0/tooling/sobjects/ApexTestQueueItem/{Id}
GET /services/data/v66.0/tooling/query/

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "Status": "Aborted" }

Input (parameters)
jobId (string, required) - AsyncApexJob Id for the Apex test run, usually the Id
returned by runTestsAsynchronous.
queueItemIds (string[], optional) - Optional ApexTestQueueItem Ids to abort instead of
discovering items by ParentJobId.
abortParentJob (boolean, optional) - Also PATCH /sobjects/AsyncApexJob/{jobId} with
Status='Aborted'. Defaults to false; ApexTestQueueItem patching is the Tooling API abort
mechanism.
includeProcessing (boolean, optional) - Also attempt to abort queue items currently in
Processing status. Defaults to true.

Result
grouped raw Salesforce lookup and patch responses.

Required permissions
- "Author Apex" / "Modify All Data".

Idempotency & limits
- Idempotent (already-aborted job: no-op).

Errors
- NOT_FOUND on jobId.

Example request

abort_apex_test_run({
  "jobId": "example"
})
