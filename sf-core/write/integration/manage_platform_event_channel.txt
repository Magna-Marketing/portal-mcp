Tool: manage_platform_event_channel

Description
Create / update / delete custom Platform Event channels and add / remove members.
Custom channels (channelType=event) let you bundle multiple Platform Events for a
single subscription. For Change Data Capture channels (channelType=data) use
manage_change_data_capture_channel instead.

Salesforce API
SOAP Metadata API, v66.0.
Metadata types: PlatformEventChannel + PlatformEventChannelMember.
Use conn.metadata.create / update / delete (jsforce).

Endpoint
SOAP /services/Soap/m/{version}   (via jsforce metadata client)

Channel naming
fullName must end with __chn, e.g. MTG_Project_Stream__chn.

Member selectedEntity
For channelType=event: Platform Event API name ending with __e, e.g. Project_Status_Update__e.
For channelType=data: sObject API name.

PlatformEventChannelMember fullName pattern: "{channelFullName}.{selectedEntity}"
e.g. "MTG_Project_Stream__chn.Project_Status_Update__e"

Input (parameters)
operation (string, required) - "create" | "update" | "delete" | "addMember" | "removeMember".
fullName (string, required) - Channel API name ending with __chn.
masterLabel (string, required for create).
channelType (string, optional, default "event") - "event" | "data".
description (string, optional).
members (object[], optional) - For addMember/removeMember/create:
  selectedEntity (string, required).
  filterExpression (string, optional).

Result
create: { create: <SaveResult>, members: [<SaveResult>] }
update: { update: <SaveResult> }
delete: { delete: <DeleteResult> }
addMember: { addMember: [<SaveResult>] }
removeMember: { removeMember: [{ fullName, delete | error }] }

Required permissions
- "Customize Application".

Idempotency & limits
- addMember/removeMember idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME (channel already exists).

Example request

manage_platform_event_channel({
  "operation": "create",
  "fullName": "MTG_Project_Stream__chn",
  "masterLabel": "MTG Project Stream",
  "channelType": "event",
  "members": [{ "selectedEntity": "Project_Status_Update__e" }]
})
