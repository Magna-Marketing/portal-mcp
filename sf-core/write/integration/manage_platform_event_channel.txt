Tool: manage_platform_event_channel

Description
Create / update / delete custom Platform Event channels and add / remove members.
Custom channels (channelType=event) let you bundle multiple Platform Events for a
single subscription. For Change Data Capture channels (channelType=data) use
manage_change_data_capture_channel instead.

Salesforce API
Tooling API, v66.0.

Endpoint
POST /services/data/v66.0/tooling/sobjects/PlatformEventChannel
POST /services/data/v66.0/tooling/sobjects/PlatformEventChannelMember
PATCH /services/data/v66.0/tooling/sobjects/PlatformEventChannel/{recordId}
DELETE /services/data/v66.0/tooling/sobjects/PlatformEventChannel/{recordId}
DELETE /services/data/v66.0/tooling/sobjects/PlatformEventChannelMember/{recordId}
GET /services/data/v66.0/tooling/query/

Input (parameters)
operation ("create" | "update" | "delete" | "addMember" | "removeMember", required) -
Action to perform; enum create, update, delete, addMember, or removeMember; no default;
example addMember; do not use this tool for CDC data channels.
fullName (string, required) - Platform Event Channel full name; string ending in __chn;
required for every operation; example MTG_Project_Stream__chn; do not pass an event
object name.
masterLabel (string, optional) - Channel label stored as Metadata.label; string;
required for create and optional for update; example MTG Project Stream; do not pass for
member-only operations.
channelType ("event" | "data", optional) - Channel type; enum event or data; defaults to
event but this tool is intended for event channels; example event; do not pass data
unless intentionally creating CDC metadata outside the CDC tool.
description (string, optional) - Channel description; string; omitted leaves it
unchanged on update; example Partner event stream; do not include secrets.
members (object[], optional) - Channel member definitions; array of selected entities
and optional filters; required for addMember/removeMember and optional on create;
example [{\"selectedEntity\":\"Project_Status_Update__e\"}]; do not pass duplicate
selectedEntity values.
  selectedEntity (string, required) - Selected event entity; Platform Event API name
  ending in __e for event channels; no default; example Project_Status_Update__e; do not
  pass AccountChangeEvent here unless using a data channel.
  filterExpression (string, optional) - Member filter expression; SOQL-like subset
  string supported by event filters; omitted means no filter; example City__c = 'San
  Francisco'; do not pass arbitrary JavaScript or CEL syntax.

Result
Returns the raw Tooling API create, patch, delete, query-not-found, or member operation
JSON response.
success (value) - included in the JSON returned by the tool.
message (value) - included in the JSON returned by the tool.
channelResult (value) - included in the JSON returned by the tool.
memberResults (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Idempotency & limits
- addMember/removeMember idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME (channel already exists).

Example request

manage_platform_event_channel({
  "operation": "example",
  "fullName": "example"
})
