Tool: publish_platform_event

Description
Publish one or many Platform Events synchronously. Subscribers (Apex triggers, Flows,
CDC listeners, external Pub/Sub API clients, Event Relay) receive events within seconds.
Returns the API response including EventUuid per event.

Salesforce API
REST API (Data), v66.0.

Endpoint
Single event:   POST /services/data/v66.0/sobjects/{EventName}__e
Multiple events: POST /services/data/v66.0/composite/sobjects

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (single)
{ "Project_Id__c": "a01Qg00000abcDE", "New_Status__c": "Active" }

Body (composite/bulk)
{
  "allOrNone": false,
  "records": [
    { "attributes": { "type": "Order_Notification__e" }, "Order_Id__c": "001...", "Status__c": "Shipped" },
    { "attributes": { "type": "Order_Notification__e" }, "Order_Id__c": "002...", "Status__c": "Delivered" }
  ]
}

Input (parameters)
eventName (string, required) - Platform Event API name WITHOUT the __e suffix,
  e.g. Project_Status_Update (not Project_Status_Update__e). The tool appends __e automatically.
events (object[], required) - Array of field maps. One object per event. Field keys use the
  full API name including __c suffix for custom fields.
allOrNone (boolean, optional, default false) - For multiple events: roll back all on any failure.

Result
Single event:    { id, success, errors[] } — sObject insert result. id is the EventUuid.
Multiple events: [{ id, success, errors[] }] — array of results in publish order.

Required permissions
- "API Enabled" (+ specific Platform Event access if restricted).

Idempotency & limits
- NOT idempotent — each call produces new events.
- Org hourly publish cap: HourlyPublishedPlatformEvents in org limits (use get_org_limits).
- Max 200 records per composite/sobjects call.

Errors
- INVALID_TYPE - Event API name not found or __e suffix issue.
- REQUEST_LIMIT_EXCEEDED - hourly publish cap hit.

Example request

publish_platform_event({
  "eventName": "Project_Status_Update",
  "events": [{ "Project_Id__c": "a01Qg00000abcDE", "New_Status__c": "Active" }]
})

publish_platform_event({
  "eventName": "Order_Notification",
  "events": [
    { "Order_Id__c": "001...", "Status__c": "Shipped" },
    { "Order_Id__c": "002...", "Status__c": "Delivered" }
  ],
  "allOrNone": true
})
