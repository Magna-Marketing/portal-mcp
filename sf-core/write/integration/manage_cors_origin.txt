Tool: manage_cors_origin

Description
Add, remove, or update an entry in the org's CORS allowlist (CorsWhitelistEntry).
Origins in the allowlist can request Salesforce REST resources, Apex REST endpoints,
and Lightning Out from browser JavaScript. Unlisted origins receive HTTP 403.

Salesforce API
REST API (sObjects), v66.0. CorsWhitelistEntry is a standard sObject, NOT a Tooling
API object. It supports create(), delete(), query(), retrieve(), update(), upsert()
via the standard Data REST API.

Endpoint
POST   /services/data/v66.0/sobjects/CorsWhitelistEntry           (add)
PATCH  /services/data/v66.0/sobjects/CorsWhitelistEntry/{id}      (update)
DELETE /services/data/v66.0/sobjects/CorsWhitelistEntry/{id}      (remove)
GET    /services/data/v66.0/query?q=SELECT+Id+FROM+CorsWhitelistEntry+WHERE+UrlPattern=... (lookup)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (add/update)
{
  "UrlPattern": "https://*.magnatech.com",
  "MasterLabel": "Magnatech Wildcard",
  "DeveloperName": "Magnatech_Wildcard"
}

Input (parameters)
operation (string, required) - "add" | "remove" | "update".
urlPattern (string, optional) - Required for add. For remove/update, used to look up the record when id is not supplied.
id (string, optional) - 18-char record Id. When provided for remove/update, skips the SOQL lookup.
masterLabel (string, optional) - Display label. Defaults to urlPattern value on add.
developerName (string, optional) - API name. Auto-generated by Salesforce when omitted.

Result
add/update: { id, success, errors }  — standard sObject insert/update response.
remove:     null or { success: true, id } when DELETE returns 204 No Content.

Required permissions
- "Customize Application".

UrlPattern rules
- Must include the HTTPS protocol (or localhost for local dev).
- Wildcard (*) supported only in front of a second-level domain: https://*.example.com
- Can be an IP address.
- Chrome extension: chrome-extension:// (API 53+).
- Firefox extension: moz-extension:// (API 53+).

Idempotency & limits
- add: DUPLICATE_VALUE error if the same UrlPattern already exists.
- remove/update: idempotent when id is supplied.

Errors
- DUPLICATE_VALUE - entry already exists.
- INVALID_URL_PATTERN - malformed URL pattern.

Example request

manage_cors_origin({ "operation": "add", "urlPattern": "https://*.magnatech.com" })
manage_cors_origin({ "operation": "remove", "urlPattern": "https://*.magnatech.com" })
