Tool: manage_external_credential

Description
Create / update / delete External Credentials and their principals. External Credentials
define the authentication protocol (OAuth, Basic, AWS SigV4, JWT, Custom) used for
outbound callouts and are linked to Named Credentials that provide the endpoint URL.

Salesforce API
Connect REST API, v66.0.
REST API (Data), v66.0.

Endpoint
POST   /services/data/v66.0/connect/named-credentials/external-credentials           (create)
PUT    /services/data/v66.0/connect/named-credentials/external-credentials/{developerName}  (update — replaces full credential)
DELETE /services/data/v66.0/connect/named-credentials/external-credentials/{developerName}  (delete)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (create example)
{
  "developerName": "MTG_Partner_OAuth",
  "masterLabel": "MTG Partner OAuth",
  "authenticationProtocol": "OAuth",
  "authenticationProtocolVariant": "JwtBearer",
  "principals": [
    { "principalName": "default", "principalType": "NamedPrincipal", "sequenceNumber": 1 }
  ]
}

Input (parameters)
operation ("create" | "update" | "delete", required) -
Action to perform; enum create, update, or delete; no default; example create; do not
pass patch because update uses PUT replacement.
developerName (string, required) -
External Credential developer name; string API name; required for every operation;
example MTG_Partner_OAuth; do not include callout: prefix.
masterLabel (string, optional) -
Display label; string; required for create and preserved on PUT only when included;
example MTG Partner OAuth; do not omit on replacement updates unless intentionally
clearing.
authenticationProtocol ("AwsSv4" | "Basic" | "Custom" | "Jwt" | "OAuth" | "NoAuthentication", optional) -
Authentication protocol; enum AwsSv4, Basic, Custom, Jwt, OAuth, or NoAuthentication;
required for create; example OAuth; do not pass protocol names from legacy Named
Credential metadata.
authenticationProtocolVariant (string, optional) -
Authentication protocol variant; string constrained by protocol such as JwtBearer or
ClientCredentialsClientSecret for OAuth and AwsSv4_STS or RolesAnywhere for AwsSv4;
omitted when not required; example JwtBearer; do not pass an OAuth variant for Basic
auth.
parameters (object[], optional) -
Credential-level authentication parameters; array of parameter objects; required
depending on authenticationProtocol; example
[{\"parameterName\":\"TokenEndpoint\",\"parameterType\":\"AuthProviderUrl\",\"parameterValue\":\"https://login.example.com/token\"}];
do not pass empty arrays on PUT unless you intend replacement.
  id (string, optional) -
  Existing parameter Id; Salesforce Id string used for update replacement when returned
  by the API; no default; example 0pt000000000001AAA; do not invent Ids.
  parameterName (string, required) -
  Parameter name; string defined by the credential type; no default; example Scope; do
  not pass labels.
  parameterType (string, required) -
  Parameter type; string such as AuthParameter, AuthProviderUrl,
  AuthProviderUrlQueryParameter, JwtBodyClaim, NamedPrincipal, PerUserPrincipal, or
  SigningCertificate; no default; example AuthProviderUrl; do not pass Named Credential
  parameter types unless supported.
  parameterValue (string, required) -
  Parameter value; string literal or reference value; no default; example
  https://login.salesforce.com/services/oauth2/token; do not pass unencrypted secrets
  when a principal credential should hold them.
  parameterDescription (string, optional) -
  Parameter description; string; omitted leaves it blank or replaced by API behavior;
  example Token endpoint; do not include secrets.
principals (object[], optional) -
Authentication principals; array defining named, per-user, or anonymous auth context; at
least one is typically required; example
[{\"principalName\":\"default\",\"principalType\":\"NamedPrincipal\",\"sequenceNumber\":1}];
do not pass unrelated permission assignments.
  principalName (string, required) -
  Principal name; string; no default; example default; do not use a permission set name
  unless the API expects it for that principal.
  principalType ("NamedPrincipal" | "PerUserPrincipal" | "AnonymousUser", required) -
  Principal type; enum NamedPrincipal, PerUserPrincipal, or AnonymousUser; no default;
  example NamedPrincipal; do not mix incompatible principal types for the same auth
  model.
  sequenceNumber (number, required) -
  Principal order; number, usually 1-based integer; no default; example 1; do not pass
  duplicate sequence numbers.
  parameters (object[], optional) -
  Principal-level parameters; array of parameter objects; omitted means none or
  replacement on PUT; example
  [{\"parameterName\":\"Scope\",\"parameterType\":\"AuthParameter\",\"parameterValue\":\"api\"}];
  do not pass empty arrays unintentionally.
customHeaders (object[], optional) -
Custom headers attached to callouts using this credential; array of header objects;
omitted means none or replacement on PUT; example
[{\"headerName\":\"X-Client\",\"headerValue\":\"magna\",\"sequenceNumber\":1}]; do not
duplicate headers managed by the auth protocol.
  headerName (string, required) -
  HTTP header name; string; no default; example X-Client; do not include colon.
  headerValue (string, required) -
  HTTP header value; string; no default; example magna; do not store secrets here unless
  required by your security policy.
  sequenceNumber (number, required) -
  Header order; number, usually 1-based integer; no default; example 1; do not pass
  duplicate sequence numbers.

Result
GET/PUT response: External Credential object (developerName, masterLabel, authenticationProtocol, principals, etc.)
DELETE: 204 No Content (returns { success: true, developerName } from tool)

Required permissions
- "Customize Application" + "Manage External Connections".

Idempotency & limits
- PUT (update) replaces the full credential; supply all principals and parameters.

Errors
- DUPLICATE_DEVELOPER_NAME (on create).
- NOT_FOUND (on update/delete with unknown developerName).

Example request

manage_external_credential({
  "operation": "example",
  "developerName": "example"
})
