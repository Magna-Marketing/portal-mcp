Tool: manage_named_credential

Description
Create / update / delete Named Credentials. Stores the callout endpoint URL and links
to an External Credential for authentication. Pair with manage_external_credential
for OAuth, Basic, AWS SigV4, JWT, or Custom auth flows.

Salesforce API
Connect REST API, v66.0.
REST API (Data), v66.0.

Endpoint
POST   /services/data/v66.0/connect/named-credentials/named-credentials           (create)
PUT    /services/data/v66.0/connect/named-credentials/named-credentials/{developerName}  (update — full replace)
DELETE /services/data/v66.0/connect/named-credentials/named-credentials/{developerName}  (delete)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (create example)
{
  "developerName": "MTG_Partner_API",
  "masterLabel": "MTG Partner API",
  "calloutUrl": "https://api.partner.com",
  "type": "SecuredEndpoint",
  "externalCredentials": [{ "developerName": "MTG_Partner_OAuth" }],
  "calloutOptions": {
    "generateAuthorizationHeader": true,
    "allowMergeFieldsInHeader": false,
    "allowMergeFieldsInBody": false
  }
}

Input (parameters)
operation ("create" | "update" | "delete", required) - Action to perform; enum create,
update, or delete; no default; example create; do not pass patch because update uses PUT
replacement.
developerName (string, required) - Named Credential developer name; string API name;
required for every operation; example MTG_Partner_API; do not include callout: prefix.
masterLabel (string, optional) - Display label; string; required for create and PUT
update; example MTG Partner API; do not omit on update because PUT replaces the
resource.
calloutUrl (string, optional) - Base endpoint URL; URL string; required for create and
preserved only if included on PUT update; example https://api.partner.com; do not pass a
path containing secrets.
type ("SecuredEndpoint" | "Endpoint", optional) - Named Credential type; enum
SecuredEndpoint or Endpoint; defaults to SecuredEndpoint; example SecuredEndpoint; do
not use legacy Endpoint for new authenticated callouts.
externalCredentials (object[], optional) - External Credentials linked to this Named
Credential; array of objects; required for SecuredEndpoint create unless auth is
configured separately; example [{\"developerName\":\"MTG_Partner_OAuth\"}]; do not link
credentials from unrelated endpoints.
  developerName (string, required) - External Credential developer name; string API
  name; no default; example MTG_Partner_OAuth; do not include namespace unless the
  credential name requires it.
calloutOptions (object, optional) - Callout security options; object; omitted uses
Salesforce defaults or leaves values unchanged only when the API preserves them; example
{\"generateAuthorizationHeader\":true}; do not pass unrelated auth settings.
  generateAuthorizationHeader (boolean, optional) - Whether Salesforce generates the
  Authorization header; boolean; defaults to Salesforce behavior when omitted; example
  true; do not set false unless custom headers provide auth.
  allowMergeFieldsInHeader (boolean, optional) - Whether Apex merge fields are allowed
  in headers; boolean; defaults to Salesforce behavior when omitted; example false; do
  not enable for untrusted header values.
  allowMergeFieldsInBody (boolean, optional) - Whether Apex merge fields are allowed in
  request bodies; boolean; defaults to Salesforce behavior when omitted; example false;
  do not enable unless the integration needs runtime body substitution.
customHeaders (object[], optional) - Custom headers appended to callouts; array of
header objects; omitted means none are sent or existing values can be replaced on PUT;
example
[{\"headerName\":\"Accept\",\"headerValue\":\"application/json\",\"sequenceNumber\":1}];
do not pass Authorization here when generateAuthorizationHeader is true.
  headerName (string, required) - HTTP header name.
  headerValue (string, required) - HTTP header value; string; no default; example
  application/json; do not pass secrets unless the org policy allows storing them here.
  sequenceNumber (number, required) - Header order; number, usually 1-based integer; no
  default; example 1; do not pass duplicate sequence numbers.
parameters (object[], optional) - Advanced Named Credential parameters; array of
parameter objects; omitted means no extra parameters or replacement on PUT; example
[{\"parameterName\":\"endpoint\",\"parameterType\":\"Url\",\"parameterValue\":\"https://api.partner.com\"}];
avoid unless the Connect REST API field is required for your credential type.
  parameterName (string, required) - Parameter name; string; no default; example
  endpoint; do not pass display labels.
  parameterType (string, required) - Parameter type; string such as Url, Authentication,
  OutboundNetworkConnection, or HttpHeader; no default; example Url; do not pass
  External Credential parameter types here unless supported.
  parameterValue (string, required) - Parameter value; string; no default; example
  https://api.partner.com; do not pass unencrypted secrets.

Result
GET/PUT response: Named Credential object.
DELETE: 204 No Content (returns { success: true, developerName } from tool).

Required permissions
- "Customize Application" + "Manage External Connections".

Idempotency & limits
- PUT (update) replaces the full credential; supply all fields.

Errors
- DUPLICATE_DEVELOPER_NAME (on create).
- NOT_FOUND (on update/delete with unknown developerName).
- INVALID_FIELD.

Example request

manage_named_credential({
  "operation": "example",
  "developerName": "example"
})
