Tool: manage_named_credential

Description
Create / update / delete Named Credentials. Stores the callout endpoint URL and links
to an External Credential for authentication. Pair with manage_external_credential
for OAuth, Basic, AWS SigV4, JWT, or Custom auth flows.

Salesforce API
Connect REST API, v66.0 (available since API 58.0).

Endpoint
POST   /services/data/v66.0/connect/named-credentials/named-credentials           (create)
PUT    /services/data/v66.0/connect/named-credentials/named-credentials/{developerName}  (update — full replace)
DELETE /services/data/v66.0/connect/named-credentials/named-credentials/{developerName}  (delete)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (create example)
{
  "developerName": "MTG_Partner_API",
  "masterLabel": "MTG Partner API",
  "calloutUrl": "https://api.partner.com",
  "type": "SecuredEndpoint",
  "externalCredentials": [{ "developerName": "MTG_Partner_OAuth" }],
  "calloutOptions": {
    "generateAuthorizationHeader": true,
    "allowMergeFieldsInHeader": false,
    "allowMergeFieldsInBody": false
  }
}

Input (parameters)
operation (string, required) - "create" | "update" | "delete".
developerName (string, required).
masterLabel (string, required for create and update/PUT).
calloutUrl (string, required for create) - Endpoint URL, e.g. https://api.partner.com.
  NOTE: The API field is "calloutUrl", not "endpoint".
type (string, optional, default "SecuredEndpoint") - "SecuredEndpoint" | "Endpoint".
  NOTE: "Endpoint" is the legacy type and is deprecated.
externalCredentials (object[], optional) - [{ developerName: "..." }] — link to External Credentials.
calloutOptions (object, optional) - {
  generateAuthorizationHeader (boolean, default true),
  allowMergeFieldsInHeader (boolean, default false),
  allowMergeFieldsInBody (boolean, default false)
}.
customHeaders (object[], optional) - { headerName, headerValue, sequenceNumber }.
parameters (object[], optional) - Advanced parameters, e.g. ManagedByNamespace for packaged creds.

Result
GET/PUT response: Named Credential object.
DELETE: 204 No Content (returns { success: true, developerName } from tool).

Required permissions
- "Customize Application" + "Manage External Connections".

Idempotency & limits
- PUT (update) replaces the full credential; supply all fields.

Errors
- DUPLICATE_DEVELOPER_NAME (on create).
- NOT_FOUND (on update/delete with unknown developerName).
- INVALID_FIELD.

Example request

manage_named_credential({
  "operation": "create",
  "developerName": "MTG_Partner_API",
  "masterLabel": "MTG Partner API",
  "calloutUrl": "https://api.partner.com",
  "externalCredentials": [{ "developerName": "MTG_Partner_OAuth" }]
})
