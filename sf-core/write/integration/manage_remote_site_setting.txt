Tool: manage_remote_site_setting

Description
Create / update / delete a Remote Site Setting. Allows Apex and Visualforce code to
make outbound HTTP callouts to external URLs. For new integrations prefer Named
Credentials (manage_named_credential), which store credentials alongside the endpoint
and support OAuth. Use Remote Site Settings only when Named Credentials are unsuitable.

Salesforce API
SOAP Metadata API, v66.0. Metadata type: RemoteSiteSetting.
Use conn.metadata.create / update / delete (jsforce).

Endpoint
SOAP /services/Soap/m/{version}   (via jsforce metadata client)

Input (parameters)
operation (string, required) - "create" | "update" | "delete".
fullName (string, required) - DeveloperName of the Remote Site Setting.
url (string, optional) - Endpoint URL. Required for create.
description (string, optional).
isActive (boolean, optional, default true).
disableProtocolSecurity (boolean, optional, default false) - Allows http:// when true.

Result
{ create | update | delete: <Metadata API SaveResult / DeleteResult> }

Required permissions
- "Customize Application".

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME - fullName already exists (on create).

Example request

manage_remote_site_setting({
  "operation": "create",
  "fullName": "Partner_Webhook",
  "url": "https://webhook.partner.com",
  "description": "Outbound webhook for partner integration"
})
