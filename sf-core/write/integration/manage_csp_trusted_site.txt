Tool: manage_csp_trusted_site

Description
Create / update / delete / activate / deactivate CSP Trusted Sites — endpoints
whitelisted in the org's Content Security Policy so that LWC, Aura, and Lightning
Out components can make callouts to them from the browser.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (createMetadata CspTrustedSite)

Input (parameters)
operation ("create" | "update" | "delete" | "activate" | "deactivate", required) -
Action to perform; enum create, update, delete, activate, or deactivate; no default;
example create; do not pass enable or disable.
fullName (string, required) - CSP Trusted Site metadata fullName; string API name;
required for every operation; example Partner_CDN; do not include .cspTrustedSite.
endpointUrl (string, optional) - Trusted endpoint URL; URL string with domain and
optional port; required for create and unchanged when omitted on update; example
https://cdn.partner.com; do not pass paths that rely on runtime parameters.
description (string, optional) - Trusted site description; string; omitted leaves it
unchanged; example Partner CDN; do not include credentials.
isActive (boolean, optional) - Whether the entry is active; boolean; defaults to true on
create and activate/deactivate override it; example true; do not pass with delete.
context ("All" | "LEX" | "Communities", optional) - Lightning context for the trusted
URL; enum All, LEX, or Communities; defaults to All on create and unchanged when omitted
on update; example LEX; do not pass unsupported site contexts.
isApplicableToConnectSrc (boolean, optional) - Whether connect-src can use the URL;
boolean; defaults to true on create if no directive is supplied; example true; do not
set all directive flags false in API v66.0.
isApplicableToFrameSrc (boolean, optional) - Whether frame-src can use the URL; boolean;
defaults to false when omitted; example false; do not enable unless frames are needed.
isApplicableToImgSrc (boolean, optional) - Whether img-src can use the URL; boolean;
defaults to false when omitted; example true; do not enable for non-image hosts.
isApplicableToStyleSrc (boolean, optional) - Whether style-src can use the URL; boolean;
defaults to false when omitted; example true; do not enable for untrusted CSS.
isApplicableToFontSrc (boolean, optional) - Whether font-src can use the URL; boolean;
defaults to false when omitted; example true; do not enable for unrelated asset hosts.
isApplicableToMediaSrc (boolean, optional) - Whether media-src can use the URL; boolean;
defaults to false when omitted; example false; do not enable unless audio or video loads
are required.
canAccessCamera (boolean, optional) - Whether the origin can access camera features when
permissions policy is enabled; boolean; defaults to false when omitted; example false;
do not enable without explicit user-facing need.
canAccessMicrophone (boolean, optional) - Whether the origin can access microphone
features when permissions policy is enabled; boolean; defaults to false when omitted;
example false; do not enable without explicit user-facing need.

Result
{ create | update | delete: <Metadata API SaveResult / DeleteResult> }

Required permissions
- "Customize Application".

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME — fullName already exists (on create).
- sf:INVALID_CROSS_REFERENCE_KEY — fullName not found (on update/delete).

Example request

manage_csp_trusted_site({
  "operation": "example",
  "fullName": "example"
})
