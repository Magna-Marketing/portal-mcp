Tool: manage_csp_trusted_site

Description
Create / update / delete / activate / deactivate CSP Trusted Sites — endpoints
whitelisted in the org's Content Security Policy so that LWC, Aura, and Lightning
Out components can make callouts to them from the browser.

Salesforce API
SOAP Metadata API, v66.0. Metadata type: CspTrustedSite.
Use conn.metadata.create / update / delete (jsforce).

Endpoint
SOAP /services/Soap/m/{version}   (via jsforce metadata client)

Input (parameters)
operation (string, required) - "create" | "update" | "delete" | "activate" | "deactivate".
fullName (string, required) - DeveloperName of the CSP Trusted Site, e.g. Partner_CDN.
endpointUrl (string, optional) - Endpoint URL to allow. Required for create.
description (string, optional).
isActive (boolean, optional, default true) - Whether the entry is active. activate/deactivate set this automatically.
context (string, optional, default "All") - "All" | "LEX" | "Communities".

Result
{ create | update | delete: <Metadata API SaveResult / DeleteResult> }

Required permissions
- "Customize Application".

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME — fullName already exists (on create).
- sf:INVALID_CROSS_REFERENCE_KEY — fullName not found (on update/delete).

Example request

manage_csp_trusted_site({
  "operation": "create",
  "fullName": "Partner_CDN",
  "endpointUrl": "https://cdn.partner.com",
  "context": "LEX"
})
