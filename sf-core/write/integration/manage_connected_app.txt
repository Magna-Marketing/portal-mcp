Tool: manage_connected_app

Description
Create / update / delete Connected Apps. Configure OAuth scopes, callback URL,
IP relaxation, and refresh token policy. For modern apps, strongly prefer External
Client Apps (manage_external_client_app).

NOTE: Connected App creation has been restricted since Spring '26. Salesforce
recommends using External Client Apps for all new integrations. Contact Salesforce
Support if you must still create Connected Apps.

Salesforce API
SOAP Metadata API, v66.0. Metadata type: ConnectedApp.
Use conn.metadata.create / update / delete (jsforce).

Endpoint
SOAP /services/Soap/m/{version}   (via jsforce metadata client)

Input (parameters)
operation (string, required) - "create" | "update" | "delete".
fullName (string, required) - DeveloperName of the Connected App.
label (string, required for create).
contactEmail (string, required for create).
description (string, optional).
oauth (object, optional) - {
  scopes (string[])  - Api, Basic, Chatter, CustomPermissions, Email, FullAccess, Id,
                       OpenId, Profile, RefreshToken, Wave, Web.
  callbackUrl (string) - OAuth redirect_uri. Multiple URLs are newline-separated.
  consumerKey (string, auto-generated if omitted).
  isPkceRequired (boolean, default false).
  isSecretRequiredForRefreshToken (boolean, default false).
  isTokenExchangeEnabled (boolean, default false).
}.
policies (object, optional) - {
  ipRelaxation ("enforceIpRestrictions" | "relaxIpRestrictions" | "relaxIpRestrictionsWithSecondFactor").
  refreshTokenPolicy ("specific_lifetime" | "infinite" | "expire_immediate" | "expire_on_logout").
  isAdminApprovedUsersOnly (boolean, default false).
  singleLogoutUrl (string).
}.

Result
{ create | update | delete: <Metadata API SaveResult / DeleteResult> }

Required permissions
- "Manage Connected Apps".

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME.

Example request

manage_connected_app({
  "operation": "create",
  "fullName": "MTG_External_Integration",
  "label": "MTG External Integration",
  "contactEmail": "ops@magnatech.com",
  "oauth": {
    "scopes": ["Api", "RefreshToken"],
    "callbackUrl": "https://ops.magnatech.com/oauth/callback",
    "isPkceRequired": true
  },
  "policies": { "isAdminApprovedUsersOnly": true, "refreshTokenPolicy": "specific_lifetime" }
})
