Tool: manage_connected_app

Description
Create / update / delete Connected Apps. Configure OAuth scopes, callback URL,
IP relaxation, and refresh token policy. For modern apps, strongly prefer External
Client Apps (manage_external_client_app).

NOTE: Connected App creation has been restricted since Spring '26. Salesforce
recommends using External Client Apps for all new integrations. Contact Salesforce
Support if you must still create Connected Apps.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (createMetadata ConnectedApp)

Input (parameters)
operation ("create" | "update" | "delete", required) - Action to perform; enum create,
update, or delete; no default; example update; do not pass deploy or upsert.
fullName (string, required) - Connected App metadata fullName and DeveloperName; string
API name; required for every operation; example MyApp; do not include the .connectedApp
suffix.
label (string, optional) - User-facing app label; string; required for create and
unchanged when omitted on update; example My App; avoid labels that imply a different
client.
contactEmail (string, optional) - Admin contact email; email string; required for create
and unchanged when omitted on update; example admin@example.com; do not pass an
unmonitored mailbox.
description (string, optional) - App description; string; omitted leaves existing text
unchanged; example Partner API client; do not pass secrets or client credentials.
oauth (object, optional) - OAuth configuration block; object matching
ConnectedAppOauthConfig; omitted leaves OAuth config unchanged on update; example
{\"scopes\":[\"Api\"],\"callbackUrl\":\"https://example.com/callback\"}; do not include
secrets in descriptions.
  scopes (string[], optional) - OAuth access scopes; array of
  ConnectedAppOauthAccessScope values; omitted leaves scopes unchanged on update;
  example [\"Api\", \"RefreshToken\"]; do not pass unknown scope strings.
  callbackUrl (string, optional) - OAuth redirect URI list; string URL or
  newline-separated URLs and required when creating OAuth config; example
  https://example.com/callback; do not pass comma-separated URLs.
  consumerKey (string, optional) - OAuth client id; string; Salesforce generates it when
  omitted on create; example 3MVG9...; do not invent one unless migrating an existing
  app.
  isPkceRequired (boolean, optional) - Whether Authorization Code flow requires PKCE;
  boolean; defaults to Salesforce behavior when omitted; example true; do not disable
  for public clients without reason.
  isSecretRequiredForRefreshToken (boolean, optional) - Whether refresh token requests
  require the client secret; boolean; defaults to Salesforce behavior when omitted;
  example true; do not set false for confidential clients unless required.
  isTokenExchangeEnabled (boolean, optional) - Whether OAuth 2.0 Token Exchange is
  enabled; boolean; defaults to Salesforce behavior when omitted; example false; do not
  enable unless the integration uses token exchange.
  singleLogoutUrl (string, optional) - Single logout endpoint; URL string; omitted
  leaves existing logout URL unchanged; example https://example.com/logout; do not pass
  a non-HTTPS production URL.
oauthPolicy (object, optional) - OAuth access policy block; object matching
ConnectedAppOauthPolicy; omitted leaves policy unchanged; example
{\"refreshTokenPolicy\":\"expire_on_logout\"}; do not pass session-policy-only fields.
  ipRelaxation ("enforceIpRestrictions" | "relaxIpRestrictions" |
  "relaxIpRestrictionsWithSecondFactor", optional) - IP restriction behavior; enum
  value; omitted leaves policy unchanged; example enforceIpRestrictions; do not use
  relaxed values for high-risk apps without approval.
  refreshTokenPolicy ("specific_lifetime" | "infinite" | "expire_immediate" |
  "expire_on_logout", optional) - Refresh token lifetime behavior; enum value; omitted
  leaves policy unchanged; example expire_on_logout; do not use infinite for short-lived
  integrations.
  isAdminApprovedUsersOnly (boolean, optional) - Whether only admin-approved users can
  use the app; boolean; defaults to Salesforce behavior when omitted; example true; do
  not set false for restricted integrations.

Result
{ create | update | delete: <Metadata API SaveResult / DeleteResult> }

Required permissions
- "Manage Connected Apps".

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME.

Example request

manage_connected_app({
  "operation": "example",
  "fullName": "example"
})
