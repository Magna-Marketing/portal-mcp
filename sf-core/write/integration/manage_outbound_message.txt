Tool: manage_outbound_message

Description
Create / update / delete a Workflow Outbound Message (SOAP webhook fired by a Workflow
Rule). Configures endpoint URL, fields included, and integration user used to
authenticate the message.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (readMetadata Workflow)

Input (parameters)
operation (string, required) - "create" | "update" | "delete".
sObject (string, required) - sObject API name owning this message, e.g. Opportunity.
fullName (string, required) - DeveloperName of the outbound message only (no sObject prefix),
  e.g. Notify_Partner_On_Won.
name (string, required for create/update) - Human-readable label.
endpointUrl (string, required for create) - HTTPS webhook URL.
fields (string[], optional) - Field API names to include in the SOAP payload.
integrationUser (string, optional) - Username of the Salesforce user sending the message.
apiVersion (number, optional, default 66.0).
includeSessionId (boolean, optional, default false).
useDeadLetterQueue (boolean, optional, default false).

Result
Returns the raw Metadata API create or update result, or a lookup-not-found JSON
response.
success (value) - included in the JSON returned by the tool.
message (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME.
- INVALID_FIELD - bad field API name in fields array.

Example request

manage_outbound_message({
  "operation": "create",
  "sObject": "Opportunity",
  "fullName": "Notify_Partner_On_Won",
  "name": "Notify Partner on Won",
  "endpointUrl": "https://webhook.partner.com/sf/opportunity",
  "fields": ["Id", "Name", "Amount", "CloseDate"]
})
