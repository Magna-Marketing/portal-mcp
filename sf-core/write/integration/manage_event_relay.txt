Tool: manage_event_relay

Description
Create / update / delete / start / stop Event Relay configurations
(forward Platform Events and CDC events to AWS EventBridge).

Salesforce API
Tooling API, v66.0.

Endpoint
POST /services/data/v66.0/tooling/sobjects/EventRelayConfig
PATCH /services/data/v66.0/tooling/sobjects/EventRelayConfig/{recordId}
DELETE /services/data/v66.0/tooling/sobjects/EventRelayConfig/{recordId}
GET /services/data/v66.0/tooling/query/

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (create)
{
  "FullName": "MTG_Project_To_AWS",
  "Metadata": {
    "label": "MTG Project to AWS",
    "eventChannel": "MTG_Project_Stream__chn",
    "destinationResourceName": "callout:AWS_Account",
    "state": "STOP",
    "relayOption": "{\"ReplayRecovery\":\"LATEST\"}"
  }
}

Body (PATCH for start)
{
  "FullName": "MTG_Project_To_AWS",
  "Metadata": { "state": "RUN" }
}

Input (parameters)
operation (string, required) - "create" | "update" | "delete" | "start" | "stop".
developerName (string, required) - FullName / DeveloperName of the EventRelayConfig.
masterLabel (string, required for create).
eventChannel (string, required for create) - Channel FullName including __chn suffix.
destinationResourceName (string, required for create) - "callout:{NamedCredentialDeveloperName}".
state (string, optional) - "RUN" | "PAUSE" | "STOP". For start/stop use those operations.
relayOption (string, optional) - JSON string: '{"ReplayRecovery":"LATEST"}' (default)
  or '{"ReplayRecovery":"EARLIEST"}' to replay all stored events (up to 3 days).

Result
Returns the raw Tooling API create, patch, delete, or lookup-not-found JSON response.
success (value) - included in the JSON returned by the tool.
message (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application" + "Modify All Data".

Idempotency & limits
- start / stop idempotent.

Errors
- INVALID_FIELD - bad destinationResourceName format or unknown channel.
- NOT_FOUND - developerName not found (on update/delete/start/stop).

Example request

manage_event_relay({
  "operation": "create",
  "developerName": "MTG_Project_To_AWS",
  "masterLabel": "MTG Project to AWS",
  "eventChannel": "MTG_Project_Stream__chn",
  "destinationResourceName": "callout:AWS_Account"
})

manage_event_relay({ "operation": "start", "developerName": "MTG_Project_To_AWS" })
