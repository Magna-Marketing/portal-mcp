Tool: manage_external_client_app

Description
Create / update / delete External Client Applications — the modern OAuth-managed app
surface introduced in API version 59.0. Supersedes Connected Apps for all new
integrations requiring OAuth or API access.

NOTE: Requires the "Opt in to External Client Apps" permission enabled in Setup.
OAuth settings (scopes, callback URL) are managed separately via ExtlClntAppOauthSettings
metadata type and are NOT included in this tool. Deploy OAuth settings alongside the
ExternalClientApplication using manage_external_client_app + a separate OAuth settings
deploy, or configure them in Setup UI after creation.

Salesforce API
SOAP Metadata API, v66.0. Metadata type: ExternalClientApplication (available API 59.0+).
Use conn.metadata.create / update / delete (jsforce).

Endpoint
SOAP /services/Soap/m/{version}   (via jsforce metadata client)

Input (parameters)
operation (string, required) - "create" | "update" | "delete".
fullName (string, required) - DeveloperName of the External Client App.
label (string, required for create) - Display label.
contactEmail (string, required for create).
contactPhone (string, optional).
description (string, optional).
iconUrl (string, optional).
logoUrl (string, optional).
distributionState (string, optional, default "Local") - "Local" | "Protected" | "Deprecated".
isProtected (boolean, optional, default false) - Managed package visibility flag.

Result
{ create | update | delete: <Metadata API SaveResult / DeleteResult> }

Required permissions
- "Manage Connected Apps".

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME.

Example request

manage_external_client_app({
  "operation": "create",
  "fullName": "MTG_Partner_Integration",
  "label": "MTG Partner Integration",
  "contactEmail": "ops@magnatech.com"
})
