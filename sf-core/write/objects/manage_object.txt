Tool: manage_object

Description
Create, update, upsert, or delete a custom Salesforce object using the
Metadata API (CustomObject type) v66.0.

Only custom objects (__c suffix) can be created or deleted. Standard objects
support a limited 'update' to change labels and some settings.

The Metadata API call is synchronous from the tool's perspective — jsforce
handles the underlying SOAP createMetadata / updateMetadata / deleteMetadata
call and returns the result directly.

Salesforce API
Metadata API (CustomObject type), v66.0.
Underlying SOAP endpoint: /services/Soap/m/66.0
jsforce abstraction: conn.metadata.create/update/delete('CustomObject', ...)

Corrections vs original documentation:
- Original doc listed "POST /services/data/v66.0/metadata/deployRequest" as the
  endpoint. While that REST endpoint exists, it requires a ZIP file upload
  (multipart/form-data) with package.xml and XML component definitions. The
  implementation uses jsforce's Metadata SOAP API instead (createMetadata /
  updateMetadata / deleteMetadata), which is the correct programmatic approach
  and does not require ZIP file assembly.
- "checkOnly" and "testLevel" are deploy-level options for the deployRequest
  REST endpoint only, not for individual createMetadata/updateMetadata SOAP
  calls. They have been removed from this tool.
- 'upsert' operation: Tries createMetadata first; on DUPLICATE_DEVELOPER_NAME
  falls back to updateMetadata — making it idempotent on fullName.
- Added 'recordTypeTrackHistory', 'visibility', 'enableLicensing',
  'startingNumber' for nameField AutoNumber, and full description/label
  fields per official CustomObject metadata type spec.

Headers (managed by jsforce internally)
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8
SOAPAction: createMetadata | updateMetadata | deleteMetadata

Input (parameters)
operation (string, required) - "create" | "update" | "upsert" | "delete".
fullName (string, required) - sObject API name including __c suffix
  (e.g. "Project__c"). For standard objects only "update" is supported.
label (string, required for create) - Singular display label.
pluralLabel (string, required for create) - Plural label. Defaults to
  label + 's' if omitted.
description (string, optional) - Object description. Max 1000 characters.
nameField (object, required for create) - Name field config:
  { type: "Text" | "AutoNumber", label: string,
    displayFormat: string (AutoNumber only, e.g. "PRJ-{0000}"),
    startingNumber: number (AutoNumber only, default 1) }.
  Defaults to { type: "Text", label: "Name" } if omitted.
deploymentStatus (string, optional, default "Deployed") - "Deployed" |
  "InDevelopment".
sharingModel (string, optional, default "ReadWrite") - "Private" | "Read" |
  "ReadWrite" | "ReadWriteTransfer" | "FullAccess" |
  "ControlledByParent" (required for junction objects on master-detail).
enableActivities (boolean, optional) - Enable Activity (Task/Event) tracking.
enableHistory (boolean, optional) - Enable field history tracking.
enableReports (boolean, optional) - Allow in reports.
enableSearch (boolean, optional) - Enable global search.
enableBulkApi (boolean, optional) - Allow Bulk API access.
enableSharing (boolean, optional) - Enable sharing rules.
enableStreamingApi (boolean, optional) - Enable Streaming API.
enableLicensing (boolean, optional) - Enable ISV subscriber licensing.
visibility (string, optional, default "Public") - "Public" | "Protected".
recordTypeTrackHistory (boolean, optional) - Track record type changes.

Result
{ operation, fullName, result: SaveResult }
SaveResult: { fullName, success (boolean), errors (array) }
or array of the same for batch operations.

Required permissions
- Customize Application
- Modify All Data

Idempotency & limits
- "upsert" is idempotent on fullName (create-or-update).
- "create" fails with DUPLICATE_DEVELOPER_NAME if the object already exists.
- Custom objects count against the org's object limit.
- Production changes may require test coverage via separate deploy.

Errors
- DUPLICATE_DEVELOPER_NAME: object with this fullName already exists (create).
- INVALID_FIELD: unsupported combination of nameField type or sharingModel.
- DEPLOY_FAILED: validation error in the metadata definition.

Example request (create with AutoNumber name)

manage_object({
  "operation": "create",
  "fullName": "Project__c",
  "label": "Project",
  "pluralLabel": "Projects",
  "nameField": {
    "type": "AutoNumber",
    "label": "Project Number",
    "displayFormat": "PRJ-{0000}"
  },
  "sharingModel": "ReadWrite",
  "deploymentStatus": "Deployed",
  "enableActivities": true,
  "enableHistory": true,
  "enableReports": true,
  "enableSearch": true,
  "enableBulkApi": true,
  "enableSharing": true,
  "enableStreamingApi": true
})

Response:
{ "operation": "create", "fullName": "Project__c",
  "result": { "fullName": "Project__c", "success": true, "errors": [] } }

Example request (update sharing model)

manage_object({
  "operation": "update",
  "fullName": "Project__c",
  "sharingModel": "Private",
  "enableActivities": true
})

Example request (delete)

manage_object({ "operation": "delete", "fullName": "Project__c" })
