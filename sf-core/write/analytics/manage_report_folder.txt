Tool: manage_report_folder

Description
Manage report and dashboard folders using the Analytics Folders REST API v66.0.
Operations: `list`, `describe`, `create`, `update`, `delete`, `children`,
`shares`, `addShares`, `replaceShares`. Use to organize reports/dashboards and
manage access via sharing entries.

Salesforce API
Analytics Folders REST API, v66.0.
Base path: /services/data/v66.0/folders  (NOT /analytics/folders — that was incorrect).

Corrections vs. original documentation:
- The base path is /folders, not /analytics/folders.
- The contents endpoint was incorrectly listed as /folders/{id}/folderItems.
  The correct endpoint for subfolders is /folders/{id}/children.
- Folder shares have dedicated endpoints: /folders/{id}/shares (GET/POST/PUT).
- type values in the API are lowercase: "report" and "dashboard" (not "Report"/"Dashboard").

Endpoints
GET    /services/data/v66.0/folders                               (list — optional ?type=report|dashboard)
POST   /services/data/v66.0/folders                               (create)
GET    /services/data/v66.0/folders/{folderId}                    (describe)
PATCH  /services/data/v66.0/folders/{folderId}                    (update)
DELETE /services/data/v66.0/folders/{folderId}                    (delete)
GET    /services/data/v66.0/folders/{folderId}/children           (list first-level subfolders)
GET    /services/data/v66.0/folders/{folderId}/shares             (list shares)
POST   /services/data/v66.0/folders/{folderId}/shares             (add shares)
PUT    /services/data/v66.0/folders/{folderId}/shares             (replace all shares)

Headers
Authorization: Bearer <access_token>
Accept: application/json
Content-Type: application/json    (POST/PATCH/PUT)

Body (create example)
{
  "name": "MTG Sales",
  "developerName": "MTG_Sales",
  "type": "report",
  "accessType": "Hidden"
}

Input (parameters)
operation ("list" | "describe" | "create" | "update" | "delete" | "children" | "shares" | "addShares" | "replaceShares", required) -
Folder operation; enum value; no default; example: 'create'; do not pass unsupported
folder actions.
folderId (string, optional) -
Folder ID; Salesforce folder ID required for operations targeting one folder; no
default; example: '00l5g000000ABCd'; do not pass the folder name.
type ("report" | "dashboard", optional) -
Folder content type; enum report or dashboard; required for create and optional list
filter; example: 'report'; do not pass capitalized values.
name (string, optional) -
Folder display label; string required for create and optional for update; maps to
Salesforce label; no default; example: 'Sales Reports'; do not pass the API unique name
here.
developerName (string, optional) -
Folder unique API name; maps to Salesforce name; auto-derived from name when omitted;
example: 'Sales_Reports'; do not include spaces.
parentId (string, optional) -
Parent folder ID; Salesforce folder ID for subfolder create/update; no default; example:
'00l5g000000ABCd'; only valid for subfolders.
accessType ("Public" | "Hidden" | "PublicInternal", optional) -
Folder visibility; applied via folder shares after create/update, not in the folder
body; Public and PublicInternal grant organization view access; Hidden leaves the folder
private; example: 'Hidden'.
shares (object[], optional) -
Folder share entries; array required for addShares and replaceShares; applied after
create when provided; no default; example: [{ sharedTo: '0055g000000ABCd', shareType:
'User', accessLevel: 'View' }]; replaceShares overwrites existing shares.
  sharedTo (string, optional) -
  Share target ID; user, role, or group ID; omit for AllInternalUsers; no default;
  example: '0055g000000ABCd'; do not pass names.
  shareType ("User" | "Role" | "RoleAndSubordinates" | "Group" | "AllInternalUsers", required) -
  Share target type; enum value mapped to Salesforce shareType; no default; example:
  'User'; do not pass object API names.
  accessLevel ("View" | "Edit" | "Manage", required) -
  Folder access level; enum View, Edit, or Manage; no default; example: 'Edit'; do not
  pass CRUD words like read/write.
confirm (boolean, optional) -
Deletion confirmation flag; boolean; defaults to false; example: true; only pass true
when permanent folder deletion is intended.

Result
raw Salesforce folder, folder collection, child collection, share collection, or delete
response from the selected endpoint.
warning (value) - included in the JSON returned by the tool.

Required permissions
- "Manage All Reports and Dashboards" (or "Manage Reports/Dashboards in Public Folders").
- "Modify All Data" for some folder operations.

Idempotency & limits
- Idempotent for update on equal input.
- A folder cannot be deleted while it contains items (reports, dashboards, subfolders).

Errors
- INVALID_FOLDER_ID, FOLDER_NOT_EMPTY, INSUFFICIENT_ACCESS_OR_READONLY.

Example request

manage_report_folder({
  "operation": "create"
})
