Tool: manage_dashboard_component

Description
Manage individual components within a Salesforce dashboard. Operations:
- `list`: list components in a dashboard (lightweight, describe-only).
- `describe`: get full metadata for one component.
- `add`: append a new component.
- `update`: merge properties into an existing component.
- `remove`: remove a component.
- `layout`: replace the entire dashboard layout object.

Component types include `Bar`, `Column`, `Line`, `Pie`, `Donut`,
`Funnel`, `Scatter`, `Gauge`, `Metric`, `Table`.

Salesforce API
Analytics REST API, v66.0.

Corrections vs. original documentation:
- There is NO dedicated /components sub-resource on the dashboard endpoint.
  The old implementation's use of POST/PATCH/DELETE on
  /analytics/dashboards/{id}/components is INCORRECT.
- The correct approach is a read-modify-write pattern:
  1. GET /analytics/dashboards/{id}/describe  — read current dashboardMetadata.
  2. Modify the `components` array (or `layout`) in memory.
  3. PATCH /analytics/dashboards/{id} with { dashboardMetadata: { components, layout } }.
- The `layout` operation replaces `dashboardMetadata.layout` (not a component-level property).

Endpoints
GET   /services/data/v66.0/analytics/dashboards/{dashboardId}/describe     (read metadata)
PATCH /services/data/v66.0/analytics/dashboards/{dashboardId}              (write back changes)

Headers
Authorization: Bearer <access_token>
Accept: application/json
Content-Type: application/json    (PATCH)

Body (PATCH — add component example)
{
  "dashboardMetadata": {
    "components": [
      {
        "componentType": "Bar",
        "header": "Pipeline by Stage",
        "report": "00OQg0000004aBcDE",
        "groupingColumn": "STAGE_NAME",
        "aggregateColumn": "s!AMOUNT",
        "displayUnits": "Auto"
      }
    ],
    "layout": { "columns": [{ "components": [] }] }
  }
}

Input (parameters)
operation (string, required) - "list" | "describe" | "add" | "update" | "remove" | "layout".
dashboardId (string, required).
componentId (string, required for describe / update / remove).
component (object, required for add / update) - Component definition:
  componentType (string), header (string), report (string ID),
  groupingColumn (string), aggregateColumn (string),
  displayUnits ("Auto"|"Thousands"|"Millions"|"Billions"|"Trillions"),
  drillEnabled (boolean), drillToFilter (boolean), drillToUrl (string),
  filterColumns (array), legendPosition ("Bottom"|"Right"|"OnChart"|"Hidden"),
  showPercentage (boolean), showValues (boolean), useReportChart (boolean).
layout (object, required for layout) - Full replacement layout object:
  { columns: [{ components: [{ id, columnSpan, rowSpan }] }] }.
confirm (boolean, required for remove) - Must be true.

Result (list)
{ dashboardId, totalCount, components: [{ id, componentType, header, report, groupingColumn }] }

Result (describe)
{ dashboardId, component: <full component object> }

Result (add / update / remove / layout)
Raw PATCH response from the API — the updated dashboardMetadata.

Required permissions
- "Manage Dashboards" (or "Modify All Data").
- Read on the source report(s).

Idempotency & limits
- add: not idempotent (each call appends a new component).
- update / remove / layout: idempotent on equal input.
- Maximum 25 components per dashboard (DASHBOARD_COMPONENT_LIMIT).

Errors
- DASHBOARD_COMPONENT_LIMIT (add when at 25 components).
- INVALID_REPORT_ID (source report doesn't exist or caller lacks read access).

Example request (add a bar chart)

manage_dashboard_component({
  "operation": "add",
  "dashboardId": "01ZQg0000004ZyAA",
  "component": {
    "componentType": "Bar",
    "header": "Pipeline by Stage",
    "report": "00OQg0000004aBcDE",
    "groupingColumn": "STAGE_NAME",
    "aggregateColumn": "s!AMOUNT",
    "displayUnits": "Auto"
  }
})

Example request (replace layout)

manage_dashboard_component({
  "operation": "layout",
  "dashboardId": "01ZQg0000004ZyAA",
  "layout": {
    "columns": [
      { "components": [{ "id": "01aABC000001XyzAAA", "columnSpan": 6, "rowSpan": 4 }] }
    ]
  }
})
