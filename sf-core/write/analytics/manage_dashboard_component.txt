Tool: manage_dashboard_component

Description
Manage individual components within a Salesforce dashboard. Operations:
- `list`: list components in a dashboard (lightweight, describe-only).
- `describe`: get full metadata for one component.
- `add`: append a new component.
- `update`: merge properties into an existing component.
- `remove`: remove a component.
- `layout`: replace the entire dashboard layout object.

Component types include `Bar`, `Column`, `Line`, `Pie`, `Donut`,
`Funnel`, `Scatter`, `Gauge`, `Metric`, `Table`.

Salesforce API
Metadata API (SOAP), v66.0.
Analytics REST API, v66.0.

Endpoint
GET /services/data/v66.0/analytics/dashboards/{dashboardId}/describe
PATCH /services/data/v66.0/analytics/dashboards/{dashboardId}
POST /services/Soap/m/66.0  (updateMetadata)

Headers
Authorization: Bearer <access_token>
Accept: application/json
Content-Type: application/json    (PATCH)

Body (PATCH — add component example)
{
  "dashboardMetadata": {
    "components": [
      {
        "componentType": "Bar",
        "header": "Pipeline by Stage",
        "report": "00OQg0000004aBcDE",
        "groupingColumn": "STAGE_NAME",
        "aggregateColumn": "s!AMOUNT",
        "displayUnits": "Auto"
      }
    ],
    "layout": { "columns": [{ "components": [] }] }
  }
}

Input (parameters)
operation ("list" | "describe" | "add" | "update" | "remove" | "layout", required) -
Component operation. 'list' returns all components. 'describe' returns one component by
componentId. 'add' appends a new component. 'update' merges fields into an existing
component by componentId. 'remove' deletes a component (requires confirm: true).
'layout' replaces the dashboard layout object.
dashboardId (string, required) - 18-character Salesforce dashboard ID, e.g.
'01Z5g000000ABCd'.
componentId (string, optional) - 18-character component ID; required for describe,
update, and remove.
component (unknown, optional) - Component definition for 'add' (full object) or 'update'
(partial merge). Omit null fields entirely — do not pass null values.
layout (object, optional) - For 'layout' operation: full replacement layout object. For
'add' on Lightning grid dashboards: a placement object { colspan, column, row, rowspan }
(integers) that is appended to layout.components.
confirm (boolean, optional) - Required true for 'remove' to confirm permanent deletion.
dryRun (boolean, optional) - When true, return the PATCH request body that would be sent
instead of executing it. Use to diagnose payload issues.

Result
raw component metadata for list/describe or raw Salesforce dashboard save response for
write operations.
dryRun (value) - included in the JSON returned by the tool.
metadata (value) - included in the JSON returned by the tool.
success (value) - included in the JSON returned by the tool.
dashboardId (value) - included in the JSON returned by the tool.
addedComponent (value) - included in the JSON returned by the tool.
componentCount (value) - included in the JSON returned by the tool.
components (value) - included in the JSON returned by the tool.
componentId (value) - included in the JSON returned by the tool.
updatedComponent (value) - included in the JSON returned by the tool.
body (value) - included in the JSON returned by the tool.
warning (value) - included in the JSON returned by the tool.

Required permissions
- "Manage Dashboards" (or "Modify All Data").
- Read on the source report(s).

Idempotency & limits
- add: not idempotent (each call appends a new component).
- update / remove / layout: idempotent on equal input.
- Maximum 25 components per dashboard (DASHBOARD_COMPONENT_LIMIT).

Errors
- DASHBOARD_COMPONENT_LIMIT (add when at 25 components).
- INVALID_REPORT_ID (source report doesn't exist or caller lacks read access).

Example request

manage_dashboard_component({
  "operation": "example",
  "dashboardId": "example"
})
