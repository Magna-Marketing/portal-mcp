Tool: update_report

Description
Update an existing report's metadata. The request body must wrap the fields
to change in a `reportMetadata` key. The Analytics REST API applies partial
update semantics — only fields present in the request body are updated;
fields omitted are preserved as-is.

Salesforce API
Analytics REST API, v66.0. `PATCH /analytics/reports/{reportId}`.

Endpoint
PATCH /services/data/v66.0/analytics/reports/{reportId}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (any subset of reportMetadata fields)
{
  "reportMetadata": {
    "name": "Pipeline This Quarter (v2)",
    "reportFilters": [
      { "column": "AMOUNT", "operator": "greaterOrEqual", "value": "100000" }
    ]
  }
}

Input (parameters)
reportId (string, required) - 18-char Report ID (starts with "00O").
reportMetadata (object, required) - Partial reportMetadata with the fields to change.
  All keys match the create_report schema (all optional inside). Common updates:
  - name, description, folderId (to move the report)
  - detailColumns, aggregates
  - groupingsDown, groupingsAcross
  - reportFilters, reportBooleanFilter
  - standardDateFilter
  - showGrandTotal, showSubtotals, hasDetailRows, hasRecordCount

Result
Raw Analytics REST API response — the complete updated reportMetadata.

Required permissions
- "API Enabled" + "Edit My Reports" (or "Manage All Reports" for others').
- Write access on source and destination folder when moving.

Idempotency & limits
- Idempotent on equal input.

Errors
- INVALID_REPORT_ID
- INSUFFICIENT_FOLDER_ACCESS (when moving to a different folder)

Example request

update_report({
  "reportId": "00OQg0000004aBcDE",
  "reportMetadata": {
    "name": "Pipeline This Quarter (v2)",
    "showGrandTotal": true,
    "reportFilters": [{ "column": "AMOUNT", "operator": "greaterOrEqual", "value": "100000" }]
  }
})
