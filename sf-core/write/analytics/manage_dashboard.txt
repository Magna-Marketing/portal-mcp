Tool: manage_dashboard

Description
Manage Salesforce dashboards. Operations: `list`, `describe`, `read`, `create`,
`update`, `delete`, `refresh`, `refreshStatus`. Returns raw Analytics REST
responses. Components within a dashboard are managed by `manage_dashboard_component`.

Salesforce API
Metadata API (SOAP), v66.0.
Analytics REST API, v66.0.

Endpoint
GET /services/data/v66.0/analytics/dashboards
GET /services/data/v66.0/analytics/dashboards/{dashboardId}/describe
GET /services/data/v66.0/analytics/dashboards/{dashboardId}
GET /services/data/v66.0/analytics/dashboards/{dashboardId}/status
PATCH /services/data/v66.0/analytics/dashboards/{dashboardId}
PUT /services/data/v66.0/analytics/dashboards/{dashboardId}
DELETE /services/data/v66.0/analytics/dashboards/{dashboardId}
POST /services/Soap/m/66.0  (createMetadata)

Headers
Authorization: Bearer <access_token>
Accept: application/json
Content-Type: application/json    (for POST/PATCH)

Body (create example)
{
  "dashboardMetadata": {
    "name": "MTG Pipeline Dashboard",
    "developerName": "MTG_Pipeline_Dashboard",
    "folderId": "00lQg0000008abcAB",
    "description": "Sales pipeline overview"
  }
}

Input (parameters)
operation ("list" | "describe" | "read" | "create" | "update" | "delete" | "refresh" | "refreshStatus", required) -
Dashboard operation; enum value; no default; example: 'refresh'; do not pass
component-specific actions.
dashboardId (string, optional) -
Dashboard ID; Salesforce dashboard ID required for single-dashboard operations; no
default; example: '01Z5g000000ABCd'; do not pass a dashboard name.
dashboardMetadata (unknown, optional).
runningUser (string, optional) -
Running user override; Salesforce User ID for dynamic dashboard reads; omitted uses
dashboard/default behavior; example: '0055g000000ABCd'; do not pass a username.
confirm (boolean, optional) -
Deletion confirmation flag; boolean; defaults to false; example: true; only pass true
when permanent dashboard deletion is intended.

Result
raw Salesforce dashboard metadata or operation status.
 (value) - included in the JSON returned by the tool.
components (value) - included in the JSON returned by the tool.
componentCount (value) - included in the JSON returned by the tool.
warning (value) - included in the JSON returned by the tool.
success (value) - included in the JSON returned by the tool.
id (value) - included in the JSON returned by the tool.
message (value) - included in the JSON returned by the tool.

Required permissions
- "API Enabled" + "Run Reports".
- "Manage Dashboards" for create/update/delete.

Idempotency & limits
- Refresh is rate-limited (~1 per minute per dashboard).
- Dashboard limit: 25 components maximum.

Errors
- INVALID_DASHBOARD_ID, INSUFFICIENT_FOLDER_ACCESS, DASHBOARD_REFRESH_LIMIT.

Example request

manage_dashboard({
  "operation": "refresh"
})
