Tool: create_report

Description
Create a new Salesforce report via the Analytics REST API v66.0. Supply the
report type (use `list_report_types` to discover), the report format
(TABULAR / SUMMARY / MATRIX / JOINED), columns, filters, groupings, and folder
assignment. The new report is saved and ready to run asynchronously with
`manage_report_instance`.

Salesforce API
Analytics REST API, v66.0.

Endpoint
GET /services/data/v66.0/analytics/reports/{reportId}/describe
POST /services/data/v66.0/analytics/{path}
PATCH /services/data/v66.0/analytics/reports/{reportId}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "reportMetadata": {
    "name": "Pipeline This Quarter",
    "developerName": "Pipeline_This_Quarter",
    "reportType": { "type": "Opportunity" },
    "reportFormat": "MATRIX",
    "folderId": "00lQg0000008abcAB",
    "detailColumns": ["NAME", "ACCOUNT.NAME", "AMOUNT", "STAGE_NAME"],
    "aggregates": ["RowCount", "s!AMOUNT"],
    "groupingsAcross": [{ "name": "STAGE_NAME", "sortOrder": "Asc" }],
    "groupingsDown": [{ "name": "OWNER.NAME", "sortOrder": "Asc" }],
    "reportFilters": [
      { "column": "STAGE_NAME", "operator": "notEqual", "value": "Closed Lost" }
    ],
    "standardDateFilter": { "column": "CLOSE_DATE", "durationValue": "THIS_QUARTER" }
  }
}

Input (parameters)
name (string, required) - Report display name; non-empty string; no default; example:
'Pipeline This Quarter'; do not pass a developer/API name here.
reportType (object, required) - Report type object; must include type; no default;
example: { type: 'Opportunity' }; do not pass unrelated reportType fields.
  type (string, required) - Report type API name; string from Salesforce report type
  metadata; no default; example: 'Opportunity'; do not pass the report type label.
reportFormat ("TABULAR" | "SUMMARY" | "MATRIX" | "JOINED", optional) - Report layout
format; enum TABULAR, SUMMARY, MATRIX, or JOINED; Salesforce defaults when omitted;
example: 'SUMMARY'; do not pass lowercase values.
folderId (string, optional) - Destination folder ID; Salesforce folder ID string;
defaults to the user's private reports folder when allowed; example: '00l5g000000ABCd';
do not pass a folder name.
developerName (string, optional) - Report API name; string using Salesforce
developer-name rules; Salesforce derives it from name when omitted; example:
'Pipeline_This_Quarter'; do not include spaces.
description (string, optional) - Report description text; string; omitted means no
description change from API defaults; example: 'Quarterly pipeline by stage'; avoid very
long prose.
detailColumns (string[], optional) - Detail column API names; array of report column
names; omitted lets Salesforce choose defaults; example: ['NAME', 'ACCOUNT.NAME',
'AMOUNT']; do not pass field labels.
aggregates (string[], optional) - Aggregate column names; array using Analytics
aggregate syntax; omitted means no explicit aggregates; example: ['RowCount',
's!AMOUNT']; FORMULA* keys from customSummaryFormula are applied on the follow-up PATCH,
not the initial POST.
groupingsDown (object[], optional) - Row groupings; array for SUMMARY and MATRIX
reports; omitted means no explicit row grouping; example: [{ name: 'OWNER.NAME',
sortOrder: 'Asc' }]; avoid using on TABULAR reports.
  name (string, required) - Grouping column API name; string; no default inside the
  grouping object; example: 'OWNER.NAME'; do not pass a field label.
  sortOrder ("Asc" | "Desc", optional) - Grouping sort direction; enum Asc or Desc;
  Salesforce defaults when omitted; example: 'Asc'; do not pass lowercase values.
  dateGranularity (string, optional) - Date grouping granularity; string accepted by
  Analytics metadata; defaults to Salesforce behavior when omitted; example: 'Month'; do
  not pass it for non-date columns.
groupingsAcross (object[], optional) - Column groupings; array for MATRIX reports;
omitted means no column grouping; example: [{ name: 'STAGE_NAME', sortOrder: 'Asc' }];
do not use for TABULAR or SUMMARY reports.
  name (string, required) - Matrix column grouping API name; string; no default inside
  the grouping object; example: 'STAGE_NAME'; do not pass labels.
  sortOrder ("Asc" | "Desc", optional) - Grouping sort direction; enum Asc or Desc;
  Salesforce defaults when omitted; example: 'Desc'; do not pass lowercase values.
  dateGranularity (string, optional) - Date grouping granularity; string accepted by
  Analytics metadata; defaults to Salesforce behavior when omitted; example: 'Quarter';
  do not use for non-date columns.
reportFilters (object[], optional) - Report filter list; array of filter objects;
omitted means no extra filters; example: [{ column: 'AMOUNT', operator:
'greaterOrEqual', value: '100000' }]; keep boolean logic aligned with item order.
  column (string, required) - Filter column API name; string; no default; example:
  'STAGE_NAME'; do not pass labels.
  operator (string, required) - Analytics filter operator; string accepted by Reports
  API; no default; example: 'greaterOrEqual'; do not pass SOQL operators like '>='.
  value (string, required) - Filter comparison value; string format expected by the
  field type; no default; example: '100000'; do not pass arrays unless the operator
  expects a delimited string.
reportBooleanFilter (string, optional) - Filter boolean expression; string referencing
filter positions; default is Salesforce's AND behavior; example: '(1 OR 2) AND 3'; do
not reference filters that are not present.
standardDateFilter (object, optional) - Standard report date filter; object; omitted
means Salesforce report defaults; example: { column: 'CLOSE_DATE', durationValue:
'THIS_QUARTER' }; do not pass for reports without date support.
  column (string, required) - Standard date column API name; string date field; no
  default; example: 'CLOSE_DATE'; do not pass labels.
  durationValue (string, required) - Date duration alias; string accepted by Reports
  API; no default; example: 'THIS_QUARTER'; use CUSTOM only with startDate/endDate as
  needed.
  startDate (string, optional) - Custom start date; YYYY-MM-DD string; used when
  durationValue is CUSTOM; example: '2026-01-01'; do not pass datetime values.
  endDate (string, optional) - Custom end date; YYYY-MM-DD string; used when
  durationValue is CUSTOM; example: '2026-03-31'; do not pass datetime values.
showGrandTotal (boolean, optional) - Grand total visibility; boolean; Salesforce
defaults by report format when omitted; example: true; do not pass strings.
showSubtotals (boolean, optional) - Subtotal visibility; boolean; Salesforce defaults by
report format when omitted; example: true; do not pass strings.
hasDetailRows (boolean, optional) - Detail-row visibility; boolean; Salesforce defaults
when omitted; example: false; do not enable when report format forbids details.
hasRecordCount (boolean, optional) - Record-count visibility; boolean; Salesforce
defaults when omitted; example: true; do not pass numeric counts.
scope (string, optional) - Report scope value; string accepted by the report type;
Salesforce defaults when omitted; example: 'organization'; do not pass labels.
customSummaryFormula (unknown, optional) - Analytics REST customSummaryFormula map keyed
by FORMULA1/FORMULA2/...; each entry matches documented Custom summary formula fields: "
+ "label, description?, formulaType (number|currency|percent), decimalPlaces?,
downGroup?, downGroupType (all|custom|grand_total), acrossGroup?, acrossGroupType
(all|custom|grand_total), formula. " + "Applied via PATCH after create (POST rejects
CSF); FORMULA* keys are auto-added to aggregates; requires SUMMARY, MATRIX, or JOINED. "
+ "example: { FORMULA1: { label: 'Avg Deal Size', formulaType: 'currency',
decimalPlaces: 2, formula: 'AMOUNT:AVG', downGroupType: 'all', acrossGroupType: 'all' }
}. " + "Do not use UNIQUE or DISTINCT — not supported via API.
checkOnly (boolean, optional) - Validation-only flag; boolean; defaults to false;
example: true; do not expect a saved report when true. CSF PATCH is skipped when
checkOnly is true.

Result
Raw Analytics REST API response — the saved reportMetadata including:
id, name, developerName, reportFormat, folderId, reportType, url,
describeUrl, instancesUrl, and all supplied metadata fields.

Required permissions
- "API Enabled" + "Create and Customize Reports".
- Write access on the destination folder.

Idempotency & limits
- Not idempotent: a second call with the same input creates a second report.
- Folder must allow the running user to write.

Errors
- INVALID_REPORT_TYPE
- INSUFFICIENT_FOLDER_ACCESS
- INVALID_FILTER_VALUE

Example request

create_report({
  "name": "Pipeline This Quarter",
  "reportType": "{ type: 'Opportunity' }"
})
