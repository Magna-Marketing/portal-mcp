Tool: add_lwc_file

Description
Add a new file to an existing LWC bundle. Fails if the file already exists
(use `update_lwc_file` instead). Cannot add a second .js or .js-meta.xml
since the platform allows only one per bundle.

Salesforce API
Tooling API, v66.0. Direct CRUD.

Endpoints
GET  /services/data/v66.0/tooling/query/?q=SELECT Id, FilePath, Format, Source FROM LightningComponentResource WHERE LightningComponentBundleId = '{bundleId}'
POST /services/data/v66.0/tooling/sobjects/LightningComponentResource

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "LightningComponentBundleId": "<bundleId>",
  "FilePath": "lwc/projectCard/projectCard.css",
  "Format": "css",
  "Source": ":host { display: block; padding: 0.5rem; }"
}

Input (parameters)
bundleName (string, required) - DeveloperName of the bundle.
fileName (string, required) - File name including extension.
source (string, required) - File contents.

Result (raw Tooling API response)
filePath (string).
format (string) - Inferred from fileName.
createResult (object) - { id, success, errors }.

Required permissions
- "Customize Application".

Idempotency & limits
- Not idempotent (fails if file already exists).

Errors
- DUPLICATE_VALUE: file already exists in the bundle.
- NOT_FOUND: bundle not found.

Example request

add_lwc_file({
  "bundleName": "projectCard",
  "fileName": "projectCard.css",
  "source": ":host { display: block; padding: 0.5rem; }"
})
