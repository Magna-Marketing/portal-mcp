Tool: clone_lwc_bundle

Description
Clone an existing LWC bundle to a new name. Reads all resources from the
source bundle, optionally rewrites class names and HTML tag references,
then creates the new bundle and its files.

Salesforce API
Tooling API, v66.0. Direct CRUD.
- GET to query source bundle and resources via SOQL.
- POST LightningComponentBundle to create new bundle.
- POST LightningComponentResource per file.

Correction vs. original doc: The original doc referenced MetadataContainer +
ContainerAsyncRequest which is not needed for direct CRUD since v45.0.

Endpoints
GET  /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, Description, ApiVersion, IsExposed FROM LightningComponentBundle WHERE DeveloperName = '{sourceName}'
GET  /services/data/v66.0/tooling/query/?q=SELECT Id, FilePath, Format, Source FROM LightningComponentResource WHERE LightningComponentBundleId = '{bundleId}'
POST /services/data/v66.0/tooling/sobjects/LightningComponentBundle
POST /services/data/v66.0/tooling/sobjects/LightningComponentResource    (per file)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Input (parameters)
sourceName (string, required) - DeveloperName of the source bundle.
newName (string, required) - DeveloperName for the clone. Must follow LWC
  naming rules (lowercase start, alphanumeric + underscores, max 40 chars).
newLabel (string, required) - MasterLabel for the clone.
newDescription (string, optional) - Defaults to the source description.
copyApiVersion (boolean, optional, default true) - Use source ApiVersion.
  When false, defaults to 66.0.
includeFileTypes (string[], optional, default all) - Subset of formats to
  copy: "js" | "html" | "css" | "xml" | "svg" | "json".
rewriteReferences (boolean, optional, default true) - Replaces the JS class
  name and <c-source-name> HTML tag references with the new name.

Result (raw Tooling API responses)
bundle (object) - { id, success, errors } from POST LightningComponentBundle.
resources (object) - Map of fileName → { id, success, errors }.
filesCopied (number) - Count of files copied.

Required permissions
- "Customize Application".

Idempotency & limits
- Not idempotent (fails if newName already exists).
- Source must be unmanaged.

Errors
- NOT_FOUND on sourceName.
- DUPLICATE_VALUE on newName conflict.

Example request

clone_lwc_bundle({
  "sourceName": "projectCard",
  "newName": "projectCardV2",
  "newLabel": "Project Card V2",
  "newDescription": "Cloned for Q3 2026 redesign"
})
