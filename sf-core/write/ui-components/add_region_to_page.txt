Tool: add_region_to_page

Description
Add a new empty region to an existing Lightning Page (FlexiPage). After
creation, populate the region with `add_component_to_region`.

The region's allowed API names depend on the page's template — adding an
unsupported name will be rejected by the platform.

Salesforce API
Metadata API (FlexiPage), v66.0.
Reads via metadata.read(), updates via metadata.update() (SOAP).

Correction vs. original doc: Uses metadata.read() + metadata.update(), not deployRequest.
The appendable field uses the string enum "Appendable" / "NotAppendable" in
the Metadata API (not a boolean).

Input (parameters)
flexiPageName (string, required) - DeveloperName of the FlexiPage.
regionName (string, required) - API name for the new region. Must match the
  template's allowed regions.
type (string, optional, default "Region") - "Region" | "Facet" | "Background".
appendable (boolean, optional, default true) - Serialized as "Appendable" or
  "NotAppendable" in the Metadata API.
position (number|"start"|"end", optional, default "end") - Insertion position
  in the page's region list.

Result
updateResult (object) - Raw Metadata API update response.
region (object) - { name, type, appendable, position }.

Required permissions
- "Customize Application".

Idempotency & limits
- Not idempotent (errors if region name already exists).

Errors
- DUPLICATE_VALUE: region name already exists.
- INVALID_REGION_FOR_TEMPLATE: name not supported by the page template.

Example request

add_region_to_page({
  "flexiPageName": "Project__c_Record_Page",
  "regionName": "right",
  "type": "Region",
  "appendable": true
})
