Tool: remove_component_from_region

Description
Remove a component or field instance from a FlexiPage region by identifier.
Reads the current page, filters out the matching instance, and deploys.

Salesforce API
Metadata API (FlexiPage), v66.0.
Reads via metadata.read(), updates via metadata.update() (SOAP).

Correction vs. original doc: Uses metadata.read() + metadata.update(), not deployRequest.

Input (parameters)
flexiPageName (string, required) - DeveloperName of the FlexiPage.
region (string, required) - Region API name containing the component.
identifier (string, required) - Unique identifier of the component instance
  to remove.

Result
updateResult (object) - Raw Metadata API update response.
removed (object) - { flexiPageName, region, identifier }.

Required permissions
- "Customize Application".

Idempotency & limits
- Not idempotent (errors if identifier not found).

Errors
- NOT_FOUND: flexiPageName, region, or identifier not found.

Example request

remove_component_from_region({
  "flexiPageName": "Project__c_Record_Page",
  "region": "right",
  "identifier": "card_main"
})
