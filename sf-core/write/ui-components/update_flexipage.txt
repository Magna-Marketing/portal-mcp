Tool: update_flexipage

Description
Update metadata on an existing Lightning Page (FlexiPage): label, description,
or template. Reads the current page, applies the changes, and deploys.

For component-level edits use `add_component_to_region`,
`remove_component_from_region`, `update_component_properties`, and
`reorder_region_components`. For adding a single region use `add_region_to_page`.

When `regions` is provided it replaces the entire region list.

Salesforce API
Metadata API (FlexiPage), v66.0.
Reads via metadata.read(), updates via metadata.update() (SOAP).

Correction vs. original doc: Uses SOAP Metadata API (jsforce), not REST deployRequest.

Input (parameters)
fullName (string, required) - DeveloperName of the FlexiPage.
label (string, optional) - New display label.
description (string, optional) - New description.
template (string, optional) - New template name.
regions (array, optional) - Replacement region list:
  name (string), type (string), appendable (boolean).
  Overwrites all existing regions. Omit to keep current regions.

Result (raw Metadata API update response)
fullName (string).
success (boolean).
id (string).
errors (array).

Required permissions
- "Customize Application".

Idempotency & limits
- Idempotent on equal input.

Errors
- NOT_FOUND on fullName.
- INVALID_FIELD on bad template or region type.

Example request (rename + describe)

update_flexipage({
  "fullName": "Project__c_Record_Page",
  "label": "Project Record Page (v2)",
  "description": "Adds the new Status panel"
})
