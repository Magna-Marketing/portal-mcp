Tool: add_component_to_region

Description
Add a Lightning component or field instance to a region of a FlexiPage.
Reads the current page, splices the new instance into the region, and deploys.

Supported componentName values:
- Standard: "lightning:relatedList", "force:highlightsPanel", "force:recordDetailPage"
- Custom LWC/Aura: "c:projectCard" (namespace:componentName format)
- Field instance: "flexipage:fieldInstance" (supply fieldApiName in properties)

Salesforce API
Metadata API (FlexiPage), v66.0.
Reads via metadata.read(), updates via metadata.update() (SOAP).

Correction vs. original doc: The original doc referenced deployRequest. The
correct approach is metadata.read() + metadata.update() with the modified
region itemInstances array.

Input (parameters)
flexiPageName (string, required) - DeveloperName of the FlexiPage.
region (string, required) - Region API name, e.g. "main", "right".
componentName (string, required) - Component or "flexipage:fieldInstance".
identifier (string, optional) - Unique identifier within the region.
  Auto-assigned when omitted.
properties (array, optional) - [{ name, value }] property pairs.
  For flexipage:fieldInstance, include fieldApiName and optionally uiBehavior.
position (number|"start"|"end", optional, default "end") - Insertion position.
visibilityRule (object, optional) - { booleanFilter?, criteria: [{ leftValue, operator, rightValue? }] }.

Result
updateResult (object) - Raw Metadata API update response.
inserted (object) - { region, componentName, identifier, position }.

Required permissions
- "Customize Application".

Idempotency & limits
- Not idempotent (a second call adds a second instance).

Errors
- NOT_FOUND: flexiPageName or region not found.
- INVALID_COMPONENT: componentName not allowed in this region.

Example request

add_component_to_region({
  "flexiPageName": "Project__c_Record_Page",
  "region": "right",
  "componentName": "c:projectCard",
  "identifier": "card_main",
  "properties": [{ "name": "label", "value": "Project Summary" }],
  "position": "start"
})
