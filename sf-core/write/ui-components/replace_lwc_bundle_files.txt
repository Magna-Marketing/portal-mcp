Tool: replace_lwc_bundle_files

Description
Replace, create, or delete files in an existing LWC bundle in a single
operation. Each entry in `files` is POSTed (created) if missing or PATCHed
(updated) if present. Files not listed are left untouched unless
`deleteMissing=true`. Required files (js, xml) are never deleted.

Salesforce API
Tooling API, v66.0. Direct CRUD.

Endpoints
GET   /services/data/v66.0/tooling/query/?q=SELECT Id, FilePath, Format FROM LightningComponentResource WHERE LightningComponentBundleId = '{bundleId}'
POST  /services/data/v66.0/tooling/sobjects/LightningComponentResource       (per new file)
PATCH /services/data/v66.0/tooling/sobjects/LightningComponentResource/{id}  (per existing file)
DELETE /services/data/v66.0/tooling/sobjects/LightningComponentResource/{id} (when deleteMissing=true)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (PATCH existing resource)
{ "Source": "..." }

Body (POST new resource)
{ "LightningComponentBundleId": "<id>", "FilePath": "lwc/name/name.css", "Format": "css", "Source": "..." }

Input (parameters)
bundleName (string, required) - DeveloperName of the bundle.
files (object[], required, min 1) - Each entry:
  fileName (string, required) - File name with extension, e.g. projectCard.css.
  source (string, required) - Full file contents.
  format (string, optional) - Format override. Auto-inferred from fileName.
deleteMissing (boolean, optional, default false) - Delete bundle files not
  listed in the files array. Required files (js, xml) are protected.

Result (raw Tooling API responses)
bundleId (string).
files (object) - Map of fileName → { id, success, errors } or delete result.

Required permissions
- "Customize Application".

Idempotency & limits
- Idempotent when source is identical.
- Each file ≤ 1 MB; bundle total ≤ 5 MB.

Errors
- NOT_FOUND on bundleName.

Example request

replace_lwc_bundle_files({
  "bundleName": "projectCard",
  "files": [
    { "fileName": "projectCard.html", "source": "<template><lightning-card title=\"Project\"></lightning-card></template>" },
    { "fileName": "projectCard.css",  "source": ":host { display: block; }" }
  ]
})
