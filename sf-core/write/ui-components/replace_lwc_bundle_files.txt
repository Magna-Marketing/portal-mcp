Tool: replace_lwc_bundle_files

Description
Replace, create, or delete files in an existing LWC bundle in a single
operation. Each entry in `files` is POSTed (created) if missing or PATCHed
(updated) if present. Files not listed are left untouched unless
`deleteMissing=true`. Required files (js, xml) are never deleted.

Salesforce API
Tooling API, v66.0. Direct CRUD.

Endpoints
GET   /services/data/v66.0/tooling/query/?q=SELECT Id, FilePath, Format FROM LightningComponentResource WHERE LightningComponentBundleId = '{bundleId}'
POST  /services/data/v66.0/tooling/sobjects/LightningComponentResource       (per new file)
PATCH /services/data/v66.0/tooling/sobjects/LightningComponentResource/{id}  (per existing file)
DELETE /services/data/v66.0/tooling/sobjects/LightningComponentResource/{id} (when deleteMissing=true)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (PATCH existing resource)
{ "Source": "..." }

Body (POST new resource)
{ "LightningComponentBundleId": "<id>", "FilePath": "lwc/name/name.css", "Format": "css", "Source": "..." }

Input (parameters)
bundleName (string, required) - Represents the LWC bundle DeveloperName; string existing
in LightningComponentBundle; no default; example: projectCard; do not pass a label,
namespace prefix, file path, or record Id.
files (object[], optional) - Represents files to create or update; non-empty array of
fileName/source entries; no default; example:
[{\"fileName\":\"projectCard.css\",\"source\":\":host{}\"}]; do not pass empty arrays.
  fileName (string, required) - Represents a resource file name inside the bundle;
  string including extension; no default; example: projectCard.html; do not pass a full
  lwc path or duplicate file names.
  source (string, required) - Represents the full resource Source; string content; no
  default; example: <template><p>Hello</p></template>; do not pass base64, a path, or
  partial diffs.
  format ("css" | "html" | "js" | "json" | "svg" | "xml", optional) - Represents an
  optional Salesforce LightningComponentResource Format override; enum css, html, js,
  json, svg, or xml; defaults to inference from fileName; example: html; do not pass
  MIME types or unsupported extensions.
deleteMissing (boolean, optional) - Represents whether to delete existing bundle
resources not listed in files; boolean; defaults to false; example: true; do not use
unless the provided file list is authoritative because non-required files can be
removed.

Result
object keyed by fileName or deleted:fileName with raw Tooling API responses.

Required permissions
- "Customize Application".

Idempotency & limits
- Idempotent when source is identical.
- Each file ≤ 1 MB; bundle total ≤ 5 MB.

Errors
- NOT_FOUND on bundleName.

Example request

replace_lwc_bundle_files({
  "bundleName": "projectCard"
})
