Tool: reorder_region_components

Description
Reorder components within a FlexiPage region. Provide an ordered array of
component identifiers. Components listed in `order` are placed first in the
specified sequence; any components not listed are appended at the end in their
original relative order.

When `strict=true` every component in the region must appear in `order`.

Salesforce API
Metadata API (FlexiPage), v66.0.
Reads via metadata.read(), updates via metadata.update() (SOAP).

Correction vs. original doc: Uses metadata.read() + metadata.update(), not deployRequest.

Input (parameters)
flexiPageName (string, required) - DeveloperName of the FlexiPage.
region (string, required) - Region API name.
order (string[], required, min 1) - Ordered array of component identifiers.
strict (boolean, optional, default false) - When true, all components in the
  region must be present in order. Returns an error if any are missing.

Result
updateResult (object) - Raw Metadata API update response.
finalOrder (string[]) - Component identifiers in their new order.

Required permissions
- "Customize Application".

Idempotency & limits
- Idempotent on equal input.

Errors
- NOT_FOUND: flexiPageName or region not found.
- strict=true and order is not exhaustive.

Example request

reorder_region_components({
  "flexiPageName": "Project__c_Record_Page",
  "region": "right",
  "order": ["card_main", "highlights_panel", "tabs_main"]
})
