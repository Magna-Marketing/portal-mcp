Tool: delete_lwc_file

Description
Delete a single file from an LWC bundle. Refuses to delete required files
(.js and .js-meta.xml). Allowed file types: css, html, svg, json.
Note: deleting html removes the template; the component will throw at runtime.

Returns { alreadyDeleted: true } if the file does not exist (idempotent).

Salesforce API
Tooling API, v66.0. Direct CRUD.

Endpoints
GET    /services/data/v66.0/tooling/query/?q=SELECT Id, FilePath, Format, Source FROM LightningComponentResource WHERE LightningComponentBundleId = '{bundleId}'
DELETE /services/data/v66.0/tooling/sobjects/LightningComponentResource/{id}

Headers
Authorization: Bearer <access_token>

Input (parameters)
bundleName (string, required) - DeveloperName of the bundle.
fileName (string, required) - File name including extension, e.g. projectCard.svg.

Result
raw Tooling API DELETE response, which can be empty for 204 No Content.

Required permissions
- "Customize Application".

Idempotency & limits
- Idempotent: returns alreadyDeleted=true if file not found.

Errors
- NOT_DELETABLE: cannot delete .js or .js-meta.xml files.
- NOT_FOUND: bundle not found.

Example request

delete_lwc_file({ "bundleName": "projectCard", "fileName": "projectCard.svg" })
