Tool: create_lwc_bundle

Description
Create a new Lightning Web Component (LWC) bundle. Supply either a
`template` (quick start) or explicit `files` (full control).

Templates: basic (default), record, list, datatable, form.

Salesforce API
Tooling API, v66.0. Direct CRUD (no MetadataContainer needed).
- POST LightningComponentBundle to create the bundle record.
- POST LightningComponentResource once per file.

Correction vs. original doc: The original doc referenced MetadataContainer +
ContainerAsyncRequest. As of API v45.0+, direct CRUD on
LightningComponentBundle and LightningComponentResource is fully supported
and does not require a MetadataContainer.

Endpoints
POST /services/data/v66.0/tooling/sobjects/LightningComponentBundle
POST /services/data/v66.0/tooling/sobjects/LightningComponentResource

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (bundle)
{
  "DeveloperName": "projectCard",
  "MasterLabel": "Project Card",
  "Description": "...",
  "ApiVersion": 66.0,
  "IsExposed": true
}

Body (per resource file)
{
  "LightningComponentBundleId": "<bundleId>",
  "FilePath": "lwc/projectCard/projectCard.js",
  "Format": "js",
  "Source": "import { LightningElement } from 'lwc'; ..."
}

LightningComponentResource Format values (confirmed from Salesforce docs):
  css | html | js | json | svg | xml
  The meta XML file uses Format: "xml" with FilePath ending in ".js-meta.xml".

Input (parameters)
componentName (string, required) - DeveloperName. Start with lowercase letter,
  alphanumeric + underscores only, max 40 chars.
masterLabel (string, required) - Human-readable label.
description (string, optional) - Max 255 chars.
template (string, optional, default "basic") - "basic" | "record" | "list"
  | "datatable" | "form". Ignored when files are provided.
isExposed (boolean, optional, default true) - Expose in Lightning App Builder.
apiVersion (number, optional, default 66.0) - Bundle API version.
files (object, optional) - Explicit file contents overriding template:
  html (string, optional) - Must start with <template>.
  js (string, optional) - Must export a default LightningElement class.
  css (string, optional).
  xml (string, optional) - *.js-meta.xml content.
  svg (string, optional).

Result (raw Tooling API responses)
bundle (object) - { id, success, errors } from POST LightningComponentBundle.
resources (object) - Map of fileName → { id, success, errors } from each POST.

Required permissions
- "Customize Application".

Idempotency & limits
- Not idempotent (fails if DeveloperName already exists).
- componentName must NOT start with DEPRECATED_.
- Each file ≤ 1 MB.

Errors
- DUPLICATE_VALUE: DeveloperName already used.
- FIELD_INTEGRITY_EXCEPTION: DeveloperName contains invalid characters.

Example request

create_lwc_bundle({
  "componentName": "projectCard",
  "masterLabel": "Project Card",
  "template": "record",
  "isExposed": true
})
