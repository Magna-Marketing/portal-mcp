Tool: create_flexipage

Description
Create a new Lightning Page (FlexiPage). Three supported types:
- RecordPage (requires objectType — the sObject API name).
- AppPage.
- HomePage.

A default template is selected based on the page type unless overridden.
One empty 'main' region (type Region, appendable) is created by default
unless `regions` is specified.

Salesforce API
Metadata API (FlexiPage), v66.0.
Uses the jsforce conn.metadata.create() SOAP-based helper (not REST deployRequest).

Correction vs. original doc: The original doc referenced the REST
`POST /services/data/v66.0/metadata/deployRequest` (zip-based deploy). The
MCP server uses the Metadata SOAP API via jsforce's metadata.create() which
is simpler and produces the same result.

Endpoint (SOAP, via jsforce)
SOAP: MetadataService.createMetadata('FlexiPage', metadata)

Input (parameters)
fullName (string, required) - Represents the FlexiPage metadata fullName and developer
name; string usually using underscores; no default; example: Project__c_Record_Page; do
not pass a label, record Id, or namespace-qualified value unless that is the real
metadata name.
label (string, required) - Represents the page label shown in Setup; string; no default;
example: Project Record Page; do not pass the API name when a user-facing label is
intended.
type ("RecordPage" | "AppPage" | "HomePage", required) - Represents the FlexiPage type;
enum RecordPage, AppPage, or HomePage; no default; example: RecordPage; do not pass
unsupported Metadata API FlexiPageType values here.
objectType (string, optional) - Represents the sObject API name for a RecordPage; string
required when type is RecordPage; default is omitted; example: Project__c; do not pass
labels or record Ids.
description (string, optional) - Represents optional page description text; string;
default is omitted; example: Sales record workspace; do not pass HTML or long
documentation.
template (string, optional) - Represents the FlexiPage template name; string; defaults
by type to flexipage:recordHomeWithHeader, flexipage:defaultHome, or
flexipage:defaultAppHome; example: flexipage:recordHomeWithHeader; do not pass
unsupported template names.
masterLabel (string, optional) - Represents the metadata masterLabel; string; defaults
to label; example: Project Record Page; do not pass a different value unless
intentionally separating labels.
regions (object[], optional) - Represents initial FlexiPage regions; array of region
objects; defaults to one main Region; example:
[{\"name\":\"main\",\"type\":\"Region\"}]; do not pass regions that do not exist in the
chosen template.
  name (string, required) - Represents the FlexiPageRegion name; string unique within
  the page and valid for the selected template; no default inside an entry; example:
  main; do not pass duplicate or template-unsupported region names.
  type ("Region" | "Facet" | "Background", optional) - Represents the FlexiPageRegion
  type; enum Region, Facet, or Background; defaults to Region; example: Region; do not
  pass arbitrary strings.
  appendable (boolean, optional) - Represents whether components can be appended to the
  region; boolean converted to RegionFlagStatus enabled or disabled; omit to leave
  region unlocked by default; example: false; do not pass string flag values.

Result (raw Metadata API create response)
fullName (string).
success (boolean).
id (string).
errors (array).

Required permissions
- "Customize Application".

Idempotency & limits
- Not idempotent (fails on duplicate fullName).

Errors
- DUPLICATE_DEVELOPER_NAME.
- INVALID_TYPE: bad type or objectType combination.

Example request

create_flexipage({
  "fullName": "Project__c_Record_Page",
  "label": "Project Record Page",
  "type": "RecordPage"
})
