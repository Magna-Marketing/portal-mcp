Tool: update_component_properties

Description
Update property values on a component instance within a FlexiPage region.
Three operations:
- set (default): add or overwrite listed properties.
- remove: delete properties by name (provide propertyNames).
- merge: add only properties whose name does not already exist.

Optionally set or clear the component's visibility rule.

Salesforce API
Metadata API (FlexiPage), v66.0.
Reads via metadata.read(), updates via metadata.update() (SOAP).

Correction vs. original doc: Uses metadata.read() + metadata.update(), not deployRequest.
Properties are always strings in FlexiPage metadata (no type coercion needed).

Input (parameters)
flexiPageName (string, required) - DeveloperName of the FlexiPage.
region (string, required) - Region API name.
identifier (string, required) - Component instance identifier.
operation (string, optional, default "set") - "set" | "remove" | "merge".
properties (array, required for set/merge) - [{ name, value }] string pairs.
propertyNames (string[], required for remove) - Names to delete.
visibilityRule (object|"clear", optional) - When set: replaces the rule;
  when "clear": removes the rule entirely.
  Object shape: { booleanFilter?, criteria: [{ leftValue, operator, rightValue? }] }.

Result
updateResult (object) - Raw Metadata API update response.
componentInstance (object) - { identifier, before: { properties, visibilityRule }, after: { properties, visibilityRule } }.

Required permissions
- "Customize Application".

Idempotency & limits
- Idempotent on equal input.

Errors
- NOT_FOUND: flexiPageName, region, or identifier not found.
- Field instances cannot be updated with this tool (use field-specific operations).

Example request (set a property and clear visibility)

update_component_properties({
  "flexiPageName": "Project__c_Record_Page",
  "region": "right",
  "identifier": "card_main",
  "operation": "set",
  "properties": [{ "name": "label", "value": "Project Summary (Q3)" }],
  "visibilityRule": "clear"
})
