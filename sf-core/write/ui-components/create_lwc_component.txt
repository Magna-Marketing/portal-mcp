Tool: create_lwc_component

Description
Create a new LWC component with explicit file contents. Unlike
`create_lwc_bundle` (template-based), this tool requires you to supply the
full JavaScript and XML configuration; HTML, CSS, and SVG are optional.

Salesforce API
Tooling API, v66.0. Direct CRUD.

Endpoints
POST /services/data/v66.0/tooling/sobjects/LightningComponentBundle
POST /services/data/v66.0/tooling/sobjects/LightningComponentResource  (per file)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (bundle)
{
  "DeveloperName": "myCard",
  "MasterLabel": "My Card",
  "Description": "...",
  "ApiVersion": 66.0,
  "IsExposed": false
}

Body (resource)
{
  "LightningComponentBundleId": "<bundleId>",
  "FilePath": "lwc/myCard/myCard.js",
  "Format": "js",
  "Source": "..."
}

Input (parameters)
componentName (string, required) - DeveloperName. Lowercase start,
  alphanumeric + underscores, max 40 chars.
masterLabel (string, required).
description (string, optional).
apiVersion (number, optional, default 66.0).
isExposed (boolean, optional, default false).
files (object, required):
  js (string, required) - JavaScript controller.
  xml (string, required) - Meta XML (*.js-meta.xml content).
  html (string, optional) - HTML template.
  css (string, optional).
  svg (string, optional).

Result (raw Tooling API responses)
bundle (object) - { id, success, errors }.
resources (object) - Map of fileName → { id, success, errors }.

Required permissions
- "Customize Application".

Errors
- DUPLICATE_VALUE: componentName already exists.

Example request

create_lwc_component({
  "componentName": "myCard",
  "masterLabel": "My Card",
  "files": {
    "js": "import { LightningElement, api } from 'lwc';\nexport default class MyCard extends LightningElement { @api recordId; }",
    "xml": "<?xml version=\"1.0\" encoding=\"UTF-8\"?>\n<LightningComponentBundle xmlns=\"http://soap.sforce.com/2006/04/metadata\">\n  <apiVersion>66.0</apiVersion>\n  <isExposed>true</isExposed>\n</LightningComponentBundle>"
  }
})
