Tool: create_lwc_component

Description
Create a new LWC component with explicit file contents. Unlike
`create_lwc_bundle` (template-based), this tool requires you to supply the
full JavaScript and XML configuration; HTML, CSS, and SVG are optional.

Salesforce API
Tooling API, v66.0. Direct CRUD.

Endpoints
POST /services/data/v66.0/tooling/sobjects/LightningComponentBundle
POST /services/data/v66.0/tooling/sobjects/LightningComponentResource  (per file)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (bundle)
{
  "DeveloperName": "myCard",
  "MasterLabel": "My Card",
  "Description": "...",
  "ApiVersion": 66.0,
  "IsExposed": false
}

Body (resource)
{
  "LightningComponentBundleId": "<bundleId>",
  "FilePath": "lwc/myCard/myCard.js",
  "Format": "js",
  "Source": "..."
}

Input (parameters)
componentName (string, required) - Represents the LWC bundle fullName and developer
name; string starting with a lowercase letter, using only letters, numbers, and
underscores, maximum 40 characters; no default; example: myCard; do not pass spaces,
hyphens, namespace prefixes, or names ending in double underscores.
masterLabel (string, required) - Represents the component label shown in Setup and
builders; string up to 255 characters; no default; example: My Card; do not pass the API
name when a user-facing label is intended.
description (string, optional) - Represents the user-facing component description;
string up to 255 characters; default is omitted; example: Displays account health; do
not pass HTML or long documentation.
apiVersion (number, optional) - Represents the LightningComponentBundle metadata
apiVersion; number; defaults to 66.0; example: 66.0; do not pass versions above 66.0.
isExposed (boolean, optional) - Represents whether the component is exposed to builders
and other namespaces; boolean; defaults to false; example: true; do not pass true
without matching targets in the XML file.
files (object, optional) - Represents resource file contents to create; object with
required js and xml strings plus optional html, css, and svg; no default; example:
{\"js\":\"...\",\"xml\":\"...\"}; do not pass empty required files.
  js (string, required) - Represents the JavaScript controller source; string content
  for componentName.js; required; example: import { LightningElement } from 'lwc';
  export default class MyCard extends LightningElement {}; do not pass a file path or
  base64 content.
  xml (string, required) - Represents the component meta XML source; string content for
  componentName.js-meta.xml; required; example: <LightningComponentBundle
  xmlns=\"http://soap.sforce.com/2006/04/metadata\"><apiVersion>66.0</apiVersion></LightningComponentBundle>;
  do not pass JSON or XML for another metadata type.
  html (string, optional) - Represents the HTML template source; string wrapped in a
  root <template>; default is omitted; example: <template><p>Hello</p></template>; do
  not pass multiple root templates.
  css (string, optional) - Represents stylesheet source; string CSS content; default is
  omitted; example: :host { display: block; }; do not pass compiled assets or external
  URLs.
  svg (string, optional) - Represents custom icon SVG source; string SVG content;
  default is omitted; example: <svg viewBox=\"0 0 52 52\"></svg>; do not pass binary
  image data.

Result
object with raw bundleResult and resourceResults Tooling API responses.
bundleResult (value) - included in the JSON returned by the tool.
resourceResults (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Errors
- DUPLICATE_VALUE: componentName already exists.

Example request

create_lwc_component({
  "componentName": "myCard",
  "masterLabel": "My Card"
})
