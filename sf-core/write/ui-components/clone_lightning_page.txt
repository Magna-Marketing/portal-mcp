Tool: clone_lightning_page

Description
Clone an existing Lightning Page (FlexiPage) to a new name and label.
The clone is a faithful copy: same regions, components, properties, and
visibility rules. The clone has no app or profile assignments.

Salesforce API
Metadata API (FlexiPage), v66.0.
Reads via metadata.read(), creates via metadata.create() (SOAP).

Correction vs. original doc: The original doc mentioned Tooling API + deployRequest.
The correct approach is metadata.read() to fetch the source, then metadata.create()
with the modified fullName and masterLabel.

Input (parameters)
sourceName (string, required) - DeveloperName of the source FlexiPage.
newName (string, required) - DeveloperName for the clone. Must be unique.
newLabel (string, required) - Display label for the clone.
newDescription (string, optional) - Description. Defaults to source description.

Result (raw Metadata API create response)
fullName (string).
success (boolean).
id (string).
errors (array).

Required permissions
- "Customize Application".

Idempotency & limits
- Not idempotent (fails on duplicate newName).

Errors
- DUPLICATE_DEVELOPER_NAME.
- NOT_FOUND on sourceName.

Example request

clone_lightning_page({
  "sourceName": "Project__c_Record_Page",
  "newName": "Project__c_Record_Page_Sales",
  "newLabel": "Project Record - Sales"
})
