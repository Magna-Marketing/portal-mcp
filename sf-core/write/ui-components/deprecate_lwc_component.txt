Tool: deprecate_lwc_component

Description
Soft-deprecate an LWC bundle. Prepends `DEPRECATED_` to the DeveloperName,
updates the MasterLabel with a `[DEPRECATED]` prefix, sets IsExposed to false
(so it cannot be added to new pages), and appends a deprecation note to the
description.

Refuses to act on bundles whose DeveloperName already starts with `DEPRECATED_`.

IMPORTANT: Salesforce does NOT automatically update FlexiPage references when
a bundle is renamed via Tooling API. Existing component placements may break.
Use `get_component_dependencies` to audit usages before deprecating.

Salesforce API
Tooling API, v66.0. Direct CRUD.
The DeveloperName is updated via PATCH on the LightningComponentBundle record.

Correction vs. original doc: The original doc referenced the Metadata API
deployRequest. The correct approach is a direct PATCH to the Tooling API,
updating the DeveloperName, MasterLabel, Description, and IsExposed fields.

Endpoints
GET   /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName, MasterLabel, Description, ApiVersion, IsExposed FROM LightningComponentBundle WHERE DeveloperName = '{name}'
PATCH /services/data/v66.0/tooling/sobjects/LightningComponentBundle/{id}
GET   /services/data/v66.0/tooling/query/?q=SELECT Id, DeveloperName FROM FlexiPage WHERE Metadata LIKE '%{name}%' LIMIT 50  (audit query)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (PATCH)
{
  "DeveloperName": "DEPRECATED_projectCard",
  "MasterLabel": "[DEPRECATED] Project Card",
  "Description": "Replaced by projectCardV2 (Q3 2026)",
  "IsExposed": false
}

Input (parameters)
name (string, required) - Existing bundle DeveloperName. Must NOT start
  with `DEPRECATED_`.
deprecationNote (string, optional, default "Deprecated on <today>") -
  Appended to the component description.
disableExposure (boolean, optional, default true) - Sets IsExposed=false.

Result
bundle (object) - { id, oldName, newName, oldLabel, newLabel, isExposed }.
updateResult (object) - Raw PATCH response.
remainingPlacements (string[]) - FlexiPage DeveloperNames that may still
  reference the old component name (best-effort query).
warning (string, optional) - Surfaces when remainingPlacements is non-empty.

Required permissions
- "Customize Application".

Idempotency & limits
- Returns an error if DeveloperName already starts with DEPRECATED_.
- Cannot rename managed bundles.

Errors
- ALREADY_DEPRECATED: component already has DEPRECATED_ prefix.
- NOT_FOUND.
- FIELD_INTEGRITY_EXCEPTION: if rename is blocked by platform.

Example request

deprecate_lwc_component({ "name": "projectCard", "deprecationNote": "Replaced by projectCardV2 (Q3 2026)" })
