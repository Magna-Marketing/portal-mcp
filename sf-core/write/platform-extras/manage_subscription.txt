Tool: manage_subscription

Description
Create / update / delete a Report or Dashboard subscription (scheduled
email delivery).

Salesforce API
Analytics REST API, v66.0.

Endpoint
GET /services/data/v66.0/analytics/notifications
GET /services/data/v66.0/analytics/notifications/{param}
DELETE /services/data/v66.0/analytics/notifications/{param}
POST /services/data/v66.0/analytics/notifications
PATCH /services/data/v66.0/analytics/notifications/{param}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "name": "Weekly Pipeline",
  "source": "lightningReportSubscribe",
  "recordId": "{{recordId}}",
  "schedule": {
    "frequency": "daily",
    "details": {
      "time": 4
    }
  },
  "thresholds": [
    {
      "type": "condition",
      "conditions": [
        {
          "colName": "RowCount",
          "operation": "greaterThan",
          "value": "0"
        }
      ],
      "actions": [
        {
          "type": "sendEmail",
          "configuration": {
            "recipients": [
              {
                "id": "{{id}}",
                "type": "user"
              }
            ]
          }
        }
      ]
    }
  ],
  "active": true
}

Input (parameters)
operation ("create" | "update" | "delete" | "read" | "list", required) - Represents the
Analytics Notifications operation; valid values are create, update, delete, read, and
list; there is no default; example: create; do not pass scheduleFutureRun.
notificationId (string, optional) - Represents the notification/subscription ID;
required for update, delete, and read; no default; example: 0Ni...; do not pass the
report or dashboard ID here.
name (string, optional) - Represents the subscription display name; required for create
unless supplied in notificationOverride; no default; example: Daily Pipeline; do not
pass an empty string.
source (string, optional) - Represents the Analytics notification source; required for
create and list; no default; example: lightningReportSubscribe; do not pass report or
dashboard aliases.
recordId (string, optional) - Represents the report or dashboard record ID being
subscribed to; required for create unless overridden; no default; example: 00O...; do
not pass folder IDs.
schedule (object, optional) - Represents the Analytics notification schedule object;
required for create unless overridden; no default; example:
{\"frequency\":\"daily\",\"details\":{\"time\":9}}; do not pass cron strings.
thresholds (object[], optional) - Represents raw threshold definitions with actions and
conditions; defaults to a generated email threshold when recipients are supplied;
example: [{\"type\":\"always\",\"actions\":[]}]; do not pass UI labels.
conditions (object[], optional) - Represents convenience threshold conditions used with
recipients; defaults to RowCount greaterThan 0; example:
[{\"colName\":\"RowCount\",\"operation\":\"greaterThan\",\"value\":\"0\"}]; do not pass
SOQL.
recipients (object[], optional) - Represents recipients for a generated sendEmail
threshold; defaults to none; example: [{\"id\":\"005...\",\"type\":\"user\"}]; do not
pass email addresses without recipient IDs.
  id (string, required) - Recipient user, group, or role ID.
  type ("user" | "group" | "role", required) - Recipient type.
active (boolean, optional) - Represents whether the notification is active; defaults to
Salesforce behavior when omitted; example: true; do not pass string booleans.
notificationOverride (object, optional) - Represents raw Analytics notification fields
merged last; defaults to none; example: {\"deactivateOnTrigger\":false}; do not pass
fields that conflict unless overriding is intended.

Result
the raw Salesforce Analytics Notifications JSON response.

Required permissions
- "API Enabled" + "Schedule Reports" / "Subscribe to Dashboards".

Idempotency & limits
- update idempotent.

Errors
- INVALID_REPORT_ID / INVALID_DASHBOARD_ID, INSUFFICIENT_FOLDER_ACCESS.

Example request

manage_subscription({
  "operation": "create"
})
