Tool: manage_subscription

Description
Create / update / delete a Report or Dashboard subscription (scheduled
email delivery).

Salesforce API
Analytics REST API, v66.0. `/analytics/notifications`.

Endpoint
POST   /services/data/v66.0/analytics/notifications
PATCH  /services/data/v66.0/analytics/notifications/{id}
DELETE /services/data/v66.0/analytics/notifications/{id}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "name": "Weekly Pipeline",
  "source": "lightningReportSubscribe",
  "recordId": "{{recordId}}",
  "schedule": {
    "frequency": "daily",
    "details": {
      "time": 4
    }
  },
  "thresholds": [
    {
      "type": "condition",
      "conditions": [
        {
          "colName": "RowCount",
          "operation": "greaterThan",
          "value": "0"
        }
      ],
      "actions": [
        {
          "type": "sendEmail",
          "configuration": {
            "recipients": [
              {
                "id": "{{id}}",
                "type": "user"
              }
            ]
          }
        }
      ]
    }
  ],
  "active": true
}

Input (parameters)

name (string, required) - Subscription name.

source (string, required)
- Notification source type.
- Common values:
  - "lightningReportSubscribe"
  - "lightningDashboardSubscribe"

recordId (string, required)
- Report Id or Dashboard Id.

schedule (object, required)
- Notification schedule configuration.

Example:
{
  "frequency": "daily" | "weekly" | "monthly",
  "details": {
    "time": number,
    "daysOfWeek": string[],
    "daysOfMonth": number[]
  }
}

thresholds (array, optional)
- Threshold-based conditions and actions.

Example:
[
  {
    "type": "condition",
    "conditions": [
      {
        "colName": string,
        "operation": "greaterThan" | "lessThan" | "equals",
        "value": string
      }
    ],
    "actions": [
      {
        "type": "sendEmail",
        "configuration": {
          "recipients": [
            {
              "id": string,
              "type": "user" | "group" | "role"
            }
          ]
        }
      }
    ]
  }
]

active (boolean, optional, default true)
- Whether the subscription is enabled.

Result
subscription (object) - { id, name, source, recordId, recipients, schedule, active }.

Required permissions
- "API Enabled" + "Schedule Reports" / "Subscribe to Dashboards".

Idempotency & limits
- update idempotent.

Errors
- INVALID_REPORT_ID / INVALID_DASHBOARD_ID, INSUFFICIENT_FOLDER_ACCESS.

Example request

manage_subscription({
  "operation": "create",
  "name": "Daily Pipeline Email",
  "source": "report",
  "recordId": "00OQg0000004aBcDE",
  "schedule": { "type": "daily", "startTime": "09:00:00" },
  "recipients": [{ "id": "005Qg0000020aBcDE", "type": "user" }]
})
