Tool: manage_duplicate_rule

Description
Create / update / activate / deactivate / delete Duplicate Rules and
their Matching Rules.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (readMetadata MatchingRules)

Headers
Authorization: Bearer <access_token>
Content-Type: multipart/form-data; boundary=...

Body
JSON fields: fullName, masterLabel, description, isActive, actionOnInsert, actionOnUpdate, alertText, securityOption, sortOrder, duplicateRuleFilter, duplicateRuleMatchRules.
JSON fields: matchingRule, objectMapping, sortOrder.
JSON fields: fullName, label, description, ruleStatus, booleanFilter, matchingRuleItems.
JSON fields: fieldName, matchingMethod, blankValueBehavior.

Input (parameters)
operation ("create" | "update" | "upsert" | "activate" | "deactivate" | "delete" | "read", required) -
Operation to perform.
target ("duplicateRule" | "matchingRule", required) -
Whether to manage DuplicateRule metadata or a child rule in a MatchingRules container.
sObject (string, required) -
Object API name, for example Account or Custom_Object__c. Required for matchingRule and
useful for fullName validation.
fullName (string, required) -
Metadata fullName. DuplicateRule usually uses Object.RuleName; MatchingRule accepts
Object.RuleName or RuleName.
masterLabel (string, optional) -
Display label. Required for create/upsert unless supplied through metadataOverride.
label (string, optional) -
MatchingRule label alias for masterLabel.
description (string, optional) -
Optional description.
isActive (boolean, optional) -
DuplicateRule active flag. activate/deactivate override this value.
ruleStatus ("Active" | "Inactive", optional) -
MatchingRule activation status. Defaults to Active. Must be Active for a DuplicateRule
to reference the matching rule. activate/deactivate operations override this value.
actionOnInsert (string, optional) -
DuplicateRule action when a duplicate is found on insert: Allow or Block.
actionOnUpdate (string, optional) -
DuplicateRule action when a duplicate is found on update: Allow or Block.
alertText (string, optional) -
Optional duplicate alert text for users.
securityOption (string, optional) -
DuplicateRule security option, for example EnforceSharingRules or BypassSharingRules.
sortOrder (integer, optional) -
DuplicateRule evaluation sort order.
matchingRule (string, optional) -
MatchingRule reference for DuplicateRule duplicateRuleMatchRules.
objectMapping (object, optional) -
Raw DuplicateRule objectMapping metadata for the matching rule reference.
matchRuleSortOrder (integer, optional) -
Sort order inside duplicateRuleMatchRules. Defaults to 1 when matchingRule is used.
duplicateRuleFilter (object, optional) -
Raw Metadata API duplicateRuleFilter object.
duplicateRuleMatchRules (object[], optional) -
Raw Metadata API duplicateRuleMatchRules array. Overrides matchingRule/objectMapping
convenience fields.
ruleFields (object[], optional) -
MatchingRule field items. Required for matchingRule create unless supplied through
metadataOverride.
  fieldName (string, required) -
  Field API name participating in matching.
  matchingMethod (string, required) -
  Matching method per Salesforce Metadata API: Exact, FirstName, LastName, CompanyName,
  Phone, City, Street, Zip, or Title.
  blankValueBehavior (string, optional) -
  How blanks are handled.
booleanFilter (string, optional) -
Optional MatchingRule boolean filter for matchingRuleItems.
metadataOverride (object, optional) -
Advanced raw Metadata API fields merged into the generated metadata payload. For
target=matchingRule this merges into the individual child rule object only — do NOT pass
container-level fields like matchingRules here. For target=duplicateRule this merges
into the DuplicateRule metadata object.

Result
deploy (object).
rule (object) - Updated identity.

Required permissions
- "Customize Application".

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME, INVALID_FIELD.

Example request

manage_duplicate_rule({
  "operation": "example",
  "target": "example",
  "sObject": "example",
  "fullName": "example"
})
