Tool: manage_knowledge_article

Description
Create / update / publish / archive / delete Knowledge articles.
Articles are versioned: `KnowledgeArticleVersion` rows are created per
draft, and publishing transitions a draft to `Online`.

Salesforce API
REST API (Data), v66.0.

Endpoint
POST /services/data/v66.0/sobjects/{param}
PATCH /services/data/v66.0/sobjects/{param}/{param}
GET /services/data/v66.0/knowledgeManagement/articleVersions/masterVersions/{param}
POST /services/data/v66.0/knowledgeManagement/articleVersions/masterVersions
PATCH /services/data/v66.0/knowledgeManagement/articleVersions/masterVersions/{param}
DELETE /services/data/v66.0/knowledgeManagement/articleVersions/masterVersions/{param}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: articleId.
JSON fields: Title, UrlName, Language, Summary.
JSON fields: Title, UrlName, Summary.
JSON fields: publishStatus, versionNumber, publishScheduleDate.
JSON fields: publishStatus, archiveScheduleDate.

Input (parameters)
operation ("create" | "update" | "publish" | "archive" | "delete" | "newVersion" | "read", required) -
Operation to perform.
articleType (string, optional) -
Article version sObject API name for draft CRUD, for example Knowledge__kav or FAQ__kav.
Defaults to Knowledge__kav.
articleVersionId (string, optional) -
Knowledge article version ID. Required for update, publish, archive, delete, and read.
knowledgeArticleId (string, optional) -
KnowledgeArticleId/articleId. Required for newVersion.
title (string, optional) -
Article title. Mapped to Title for create/update.
urlName (string, optional) -
Article URL name. Mapped to UrlName for create/update.
language (string, optional) -
Article language. Mapped to Language for create.
summary (string, optional) -
Optional Summary field for create/update.
fields (object, optional) -
Additional article version fields, for example Body__c, IsVisibleInPkb, or
validation-specific custom fields.
asMajorVersion (boolean, optional) -
Publish as a major version by sending versionNumber=NextVersion. Applies to publish.
publishScheduleDate (string, optional) -
ISO-8601 date/time for scheduled publication. Applies to publish.
archiveScheduleDate (string, optional) -
ISO-8601 date/time for scheduled archive. Applies to archive.

Result
the raw Salesforce REST response, with empty 204 responses returned as provided by the
client.

Required permissions
- "Manage Articles" + Knowledge enabled on the org.

Idempotency & limits
- publish/archive idempotent.

Errors
- KNOWLEDGE_NOT_ENABLED, INVALID_TYPE.

Example request

manage_knowledge_article({
  "operation": "example"
})
