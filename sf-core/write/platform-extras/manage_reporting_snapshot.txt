Tool: manage_reporting_snapshot

Description
Create / update / delete / schedule a Reporting Snapshot
(`AnalyticSnapshot`). Snapshots take a report's results on a schedule
and write them to a custom object for trending.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (readMetadata AnalyticSnapshot)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: fullName, name, description, groupColumn, runningUser, sourceReport, targetObject, mappings.
JSON fields: sourceField, sourceType, aggregateType, targetField.

Input (parameters)
operation ("create" | "update" | "upsert" | "delete" | "read", required) - Represents
the Metadata API operation; valid values are create, update, upsert, delete, and read;
there is no default; example: upsert; do not pass schedule or unschedule.
fullName (string, required) - Represents the AnalyticSnapshot metadata
fullName/DeveloperName; there is no default; example: Pipeline_Snapshot; do not pass a
record ID.
name (string, optional) - Represents the display name; required for create/upsert unless
metadataOverride supplies it; no default; example: Pipeline Snapshot; do not pass an API
path.
description (string, optional) - Represents the snapshot description; defaults to
omitted; example: Captures weekly pipeline; do not pass HTML-only help.
sourceReport (string, optional) - Represents the source report metadata fullName;
required for create/upsert; no default; example: Public_Reports/Pipeline_Report; do not
pass the 00O report ID.
sourceReportId (string, optional) - Represents a compatibility alias for sourceReport;
no default; example: Public_Reports/Pipeline_Report; do not pass a 00O report ID despite
the name.
targetObject (string, optional) - Represents the target custom object API name; required
for create/upsert; no default; example: Pipeline_Snapshot__c; do not pass a tab label.
runningUser (string, optional) - Represents the username used to run the snapshot;
defaults to Salesforce behavior when omitted; example: analyst@example.com; do not pass
a user ID.
runningUserId (string, optional) - Represents a compatibility alias for runningUser;
default is omitted; example: analyst@example.com; do not pass a 005 user ID for Metadata
API.
groupColumn (string, optional) - Represents the summary report group column; defaults to
omitted; example: CLOSE_DATE; do not pass SOQL expressions.
fieldMappings (object[], optional) - Represents field mappings from report output to
target object fields; required for create/upsert unless metadataOverride supplies
mappings; example: [{\"sourceField\":\"AMOUNT\",\"targetField\":\"Amount__c\"}]; do not
pass target labels.
  sourceField (string, required) - Source report column, summary, or snapshot-provided
  value such as RunningUser or ExecutionTime.
  targetField (string, required) - Target object field API name.
  sourceType (string, optional) - Report job source type where required by the org.
  aggregateType (string, optional) - Aggregate type for summary values when needed.
metadataOverride (object, optional) - Represents raw Metadata API fields merged last;
defaults to none; example: {\"mappings\":[]}; do not pass conflicting fields unless
overriding is intended.

Result
deploy (object|null).
snapshot (object) - { id, name, sourceReportId, targetObject, scheduled (boolean), nextRunDate }.

Required permissions
- "Manage Reporting Snapshots".

Idempotency & limits
- update / schedule idempotent.

Errors
- INVALID_FIELD on bad mappings.

Example request

manage_reporting_snapshot({
  "operation": "upsert",
  "fullName": "Pipeline_Snapshot"
})
