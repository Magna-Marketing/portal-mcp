Tool: update_field_history_tracking

Description
Enable / disable Field History tracking on specific fields of an
sObject. When tracked, edits create rows in `<sObject>History`.
Optional Shield Field Audit Trail retention is controlled separately.

Salesforce API
Metadata REST API, v66.0.

Endpoint
POST /services/data/v66.0/metadata/deployRequest

Headers
Authorization: Bearer <access_token>
Content-Type: multipart/form-data; boundary=...

Body
JSON fields: allowMissingFiles, autoUpdatePackage, checkOnly, ignoreWarnings, performRetrieve, purgeOnDelete, rollbackOnError, runTests, singlePackage, testLevel.

Input (parameters)
sObject (string, required) - Standard or custom object API name, for example Account or
Project__c.
enableObjectHistory (boolean, optional) - Value for CustomObject.enableHistory. Omit to
auto-enable when any field trackHistory is true.
fields (unknown[], required) - Fields whose CustomField.trackHistory value should be
deployed.
metadataOverride (object, optional) - Advanced primitive CustomObject XML elements to
include in the deployment.
checkOnly (boolean, optional) - Validate only without saving metadata. Defaults to
false.
rollbackOnError (boolean, optional) - Roll back all changes if any component fails.
Defaults to true.
ignoreWarnings (boolean, optional) - Continue despite Metadata API warnings. Defaults to
false.
allowMissingFiles (boolean, optional) - Allow package.xml entries missing from the zip.
Defaults to false.
autoUpdatePackage (boolean, optional) - Reserved Salesforce deploy option. Defaults to
false.
performRetrieve (boolean, optional) - Retrieve deployed metadata as part of the
deployment where supported. Defaults to false.
purgeOnDelete (boolean, optional) - Immediately delete destructiveChanges components
where supported. Defaults to false.
runTests (string[], optional) - Apex test class names. Required by Salesforce when
testLevel is RunSpecifiedTests.
testLevel (string, optional) - Salesforce deploy test level. Defaults to platform
behavior if omitted.
waitForCompletion (boolean, optional) - Poll deployRequest status until terminal.
Defaults to true.
includeDetails (boolean, optional) - Include deploy details while polling status.
Defaults to true.
pollIntervalMs (number, optional) - Polling interval in milliseconds when waiting.
Defaults to 5000.
maxWaitMs (number, optional) - Maximum polling time in milliseconds. Defaults to 30
minutes.
includeGeneratedMetadata (boolean, optional) - Include generated package.xml/object XML
in the JSON result for debugging. Defaults to false.

Result
{ deploy, status?, files? } with raw deployRequest and optional polling status
responses.
deploy (value) - included in the JSON returned by the tool.
status (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Idempotency & limits
- Idempotent.
- Each sObject has a max of 20 tracked fields.

Errors
- TRACK_HISTORY_LIMIT_EXCEEDED, INVALID_FIELD.

Example request

update_field_history_tracking({
  "sObject": "example",
  "fields": []
})
