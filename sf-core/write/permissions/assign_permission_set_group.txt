Tool: assign_permission_set_group

Description
Assign a permission set group to users. Mirrors `assign_permission_set`
but writes `PermissionSetAssignment.PermissionSetGroupId` instead of
`PermissionSetId`. Supports optional expiration date.

Salesforce API
REST API (Data), v66.0.

Endpoint
POST /services/data/v66.0/composite/sobjects

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "allOrNone": false,
  "records": [
    { "attributes": { "type": "PermissionSetAssignment" }, "AssigneeId": "005Qg0000020aBcDE", "PermissionSetGroupId": "0PGQg00000004abAB" }
  ]
}

Input (parameters)
groupName (string, optional) - PermissionSetGroup DeveloperName to assign; string;
required when groupId is omitted; example 'Finance_Access_Group'; do not pass
MasterLabel.
groupId (string, optional) - PermissionSetGroup Id to assign; Salesforce Id string;
required when groupName is omitted; example '0PGxx000000001A'; do not pass PermissionSet
Ids.
userIds (string[], optional) - User Ids to assign; array of Salesforce User Id strings;
required when usernames is omitted; example ['005xx0000012345']; do not pass contact
Ids.
usernames (string[], optional) - User.Username values to assign; array of exact
usernames; required when userIds is omitted; example ['admin@example.com']; do not pass
display names.
includeInactiveUsers (boolean, optional) - Whether inactive users can be resolved;
boolean; defaults to false; example false; do not enable unless intentional.
expirationDate (string, optional) - PermissionSetAssignment ExpirationDate; ISO
date-time string; omitted means no expiration; example '2026-12-31T23:59:59.000Z'; do
not pass date-only text.
allOrNone (boolean, optional) - Composite sObject Collections allOrNone flag; boolean;
defaults to false; example true; when true one failed row can roll back the batch.
skipIfAlreadyAssigned (boolean, optional) - Whether existing assignments are queried and
skipped; boolean; defaults to true; example true; do not set false unless duplicate
errors are acceptable.
batchSize (integer, optional) - Composite sObject collection batch size; integer 1-200;
defaults to 200; example 100; do not pass values above the REST API limit.

Result
group (object) - { id, developerName, label, status }.
results (array) - { userId, username, status, assignmentId, error }.
summary (object) - { created, alreadyAssigned, failed, total }.

Required permissions
- "Assign Permission Sets" + "Manage Users".

Idempotency & limits
- Idempotent with `skipIfAlreadyAssigned=true`.
- PSG must be in `Status="Updated"`. The tool surfaces a warning when
  PSG is `Outdated`/`Updating` (assignment still works but new permset
  membership might not have propagated).

Errors
- DUPLICATE_VALUE on existing assignment when skip=false.
- INSUFFICIENT_PERMSET_LICENSE.

Example request

assign_permission_set_group({
  "groupName": "example",
  "groupId": "example",
  "userIds": []
})
