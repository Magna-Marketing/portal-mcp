Tool: create_permission_set_group

Description
Create a new permission set group bundling multiple permission sets.
Optionally attach a "muting" permission set that subtracts perms from
the bundle (advanced; rarely used). After creation, Salesforce kicks
off an asynchronous recalculation; the tool polls until the PSG
`Status="Updated"` (or surfaces "Outdated"/"Failed").

Salesforce API
Metadata API (SOAP), v66.0.
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/
POST /services/Soap/m/66.0  (createMetadata PermissionSetGroup)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: fullName, label, description, permissionSets, mutingPermissionSets, hasActivationRequired.

Input (parameters)
fullName (string, required) - PermissionSetGroup metadata fullName and DeveloperName;
string such as Finance_Access_Group; no default; do not pass MasterLabel or Id.
label (string, required) - Permission set group label; string shown in Setup; no
default; example 'Finance Access Group'; do not pass an API name unless intended.
description (string, optional) - Permission set group description; string; omitted means
no description; example 'Finance role permissions'; do not pass private operational
notes.
permissionSets (string[], required) - Included PermissionSet API names; non-empty string
array; no default; example ['Billing_Read', 'Billing_Edit']; do not pass PermissionSet
Ids.
mutingPermissionSets (string[], optional) - Muting PermissionSet API names; string
array; omitted means no muting set; example ['Billing_Muting']; do not pass regular
members here.
hasActivationRequired (boolean, optional) - Whether session activation is required;
boolean supported in API v53.0+; omitted uses Salesforce default false; example false;
do not enable without activation planning.
waitForRecalc (boolean, optional) - Whether to poll PermissionSetGroup.Status after
create; boolean; defaults to true; example true; do not use when immediate response is
required.
pollIntervalMs (integer, optional) - Recalculation polling interval in milliseconds;
integer 1-10000; defaults to 2000; example 3000; do not pass very low values for large
orgs.
timeoutMs (integer, optional) - Maximum recalculation polling time in milliseconds;
integer 1-120000; defaults to 60000; example 90000; do not pass values above two
minutes.
metadataOverride (unknown, required).
checkOnly (boolean, optional) - Whether to build the payload without calling
createMetadata; boolean; defaults to false; example true; do not use when you expect
Salesforce to create the group.

Result
checkOnly (value) - included in the JSON returned by the tool.
metadata (value) - included in the JSON returned by the tool.
createResponse (value) - included in the JSON returned by the tool.
permissionSetGroupLookup (value) - included in the JSON returned by the tool.
recalcResponses (value) - included in the JSON returned by the tool.

Required permissions
- "Manage Profiles and Permission Sets".

Idempotency & limits
- Create is **not** idempotent (fails on duplicate).
- Recalc usually completes < 5 s; can take longer for very large
  permsets.

Errors
- DUPLICATE_DEVELOPER_NAME.
- INVALID_FIELD on a permset name that doesn't exist.
- PERMISSION_SET_GROUP_RECALC_FAILED with details.

Example request

create_permission_set_group({
  "fullName": "example",
  "label": "example",
  "permissionSets": [],
  "metadataOverride": "example"
})
