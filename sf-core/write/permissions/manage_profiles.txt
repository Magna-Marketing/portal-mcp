Tool: manage_profiles

Description
Manage Profiles via Metadata API. Operations: create (clone-only),
update, clone, compare, delete (custom only), and record-type
visibility management. Salesforce does **not** support creating a
profile from scratch via API — `create` always requires `cloneFrom`.
Bulk operations across many profiles are supported.

Use `extract_permissions_from_profile` to peel permissions off into
permission sets, and `create_differential_permission_set` to capture
deltas between profiles.

Salesforce API
Metadata API (SOAP), v66.0.
REST API (Data), v66.0.

Input (parameters)
operation ("create" | "update" | "clone" | "compare" | "delete" | "manageRecordTypeVisibility", required) -
Profile operation to perform; enum create, update, clone, compare, delete, or
manageRecordTypeVisibility; no default; example 'clone'; do not choose delete unless
removal is intended.
profiles (unknown[], required) -
Profile operation inputs; non-empty array of profile objects; no default; example [{
fullName: 'Custom Sales User', cloneFrom: 'Standard User' }]; compare uses the first
profile only.
compareWith (string, optional) -
Profile metadata fullName to compare against; string profile name; required for compare;
example 'Standard User'; do not pass Profile Id.
checkOnly (boolean, optional) -
Whether to build/read payloads without mutating where supported; boolean; defaults to
false; example true; delete and write operations should use this for previews.

Result
operation (value) - included in the JSON returned by the tool.
responses (value) - included in the JSON returned by the tool.

Required permissions
- "Manage Profiles and Permission Sets" + "Modify All Data".
- "Customize Application" for application/tab visibilities.

Idempotency & limits
- Create/clone is **not** idempotent (fails on duplicate fullName).
- Update is idempotent (re-applies same XML safely).
- Profile XML can exceed 10 MB on long-lived orgs; deploy can be slow.

Errors
- DUPLICATE_DEVELOPER_NAME, INVALID_FIELD, INSUFFICIENT_ACCESS_OR_READONLY.

Example request

manage_profiles({
  "operation": "example",
  "profiles": []
})
