Tool: extract_permissions_from_profile

Description
Extract a chosen subset of permissions from an existing profile into a
brand-new permission set. Useful for incremental profile-to-permset
migrations: pick the slice that's reusable, lift it out, drop it from
the profile (optional), then assign the new permset to users.

Common subsets:
- Object permissions (CRUD on a specific object).
- Field permissions for a category of fields.
- API perms (ApiEnabled, ManageDataIntegrations, ...).
- Custom object access (a single __c object).

Salesforce API
Metadata API (SOAP), v66.0.
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/
POST /services/Soap/m/66.0  (createMetadata PermissionSet)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: field, readable, editable.
JSON fields: fullName, label, description, license, userPermissions, objectPermissions, fieldPermissions, classAccesses, pageAccesses, customMetadataTypeAccesses, customSettingAccesses, customPermissions, externalDataSourceAccesses, flowAccesses, agentAccesses, genComputingSummaryDefAccess, servicePresenceStatusAccesses, tabSettings.

Input (parameters)
sourceProfile (string, required) - Source Profile metadata fullName; string profile
name; no default; example 'Custom Sales User'; do not pass Profile Id.
newPermsetName (string, required) - New PermissionSet metadata fullName; string API
name; no default; example 'Sales_Extracted_Access'; do not reuse an existing name.
newPermsetLabel (string, required) - New PermissionSet label; string up to 80
characters; no default; example 'Sales Extracted Access'; do not pass an API name unless
intended.
newPermsetDescription (string, optional) - New PermissionSet description; string up to
255 characters; omitted means no description; example 'Extracted profile grants'; do not
pass private notes.
license (string, optional) - PermissionSet license metadata value; string license name;
defaults to source profile userLicense when available; example 'Salesforce'; do not pass
LicenseId.
extract (object, optional) - Selected profile grants to extract; object with optional
category arrays; no default; include at least one category; example { systemPermissions:
['ApiEnabled'] }; do not pass full Profile metadata.
  systemPermissions (string[], optional) - Profile userPermissions names to copy when
  enabled; string array; omitted copies none; example ['ApiEnabled']; do not pass
  labels.
  objectPermissions (object[], optional) - Object permissions to copy; array with object
  API name and optional accessTypes; omitted copies none; example { object: 'Account',
  accessTypes: ['read', 'edit'] }; do not pass unsupported access types.
  fieldPermissions (object[], optional) - Field permissions to copy; object is API name
  and fields are unqualified field API names; omitted copies none; example { object:
  'Account', fields: ['Phone'] }; do not pass Object.Field here.
  apexClasses (string[], optional) - Apex class names to copy when enabled; string
  array; omitted copies none; example ['InvoiceController']; do not pass class Ids.
  vfPages (string[], optional) - Visualforce page names to copy when enabled; string
  array; omitted copies none; example ['InvoicePage']; do not pass URLs.
  customMetadataTypes (string[], optional) - Custom metadata type names to copy when
  enabled; string array; omitted copies none; example ['Feature_Flag__mdt']; do not pass
  record names.
  customSettings (string[], optional) - Custom setting names to copy when enabled;
  string array; omitted copies none; example ['App_Config__c']; do not pass setting
  rows.
  customPermissions (string[], optional) - Custom permission names to copy when enabled;
  string array; omitted copies none; example ['Can_Approve']; do not pass labels.
  externalDataSources (string[], optional) - External data source names to copy when
  enabled; string array; omitted copies none; example ['ERP']; do not pass Named
  Credentials.
  flows (string[], optional) - Flow API names to copy when enabled; string array;
  omitted copies none; example ['Submit_Order']; do not pass flow labels.
  agents (string[], optional) - Agentforce agent names to copy when enabled; string
  array; omitted copies none; example ['Sales_Agent']; do not pass bot labels.
  enhancedSummaryConfigs (string[], optional) - Enhanced summary config names to copy
  when enabled; string array; omitted copies none; example ['Sales_Summary']; do not
  pass labels.
  servicePresenceStatuses (string[], optional) - Service Presence Status names to copy
  when enabled; string array; omitted copies none; example ['Available']; do not pass
  translated labels.
  tabs (object[], optional) - Profile tab visibility entries to copy into PermissionSet
  tabSettings; visibility may be Profile or PermissionSet visibility text; omitted
  copies none; example { tab: 'Account', visibility: 'Visible' }; do not pass app names.
removeFromProfile (boolean, optional) - Whether to update the source Profile to remove
selected grants; boolean; defaults to false; example true; do not enable without
reviewing Profile impact.
metadataOverride (unknown, required).
checkOnly (boolean, optional) - Whether to build payloads without createMetadata or
updateMetadata; boolean; defaults to false; example true; do not use when changes must
be applied.

Result
checkOnly (value) - included in the JSON returned by the tool.
profileReadResponse (value) - included in the JSON returned by the tool.
permissionSetMetadata (value) - included in the JSON returned by the tool.
createResponse (value) - included in the JSON returned by the tool.
createdPermissionSetLookup (value) - included in the JSON returned by the tool.
profileUpdateMetadata (value) - included in the JSON returned by the tool.
profileUpdateResponse (value) - included in the JSON returned by the tool.

Required permissions
- "Manage Profiles and Permission Sets".
- "Modify All Data" if removeFromProfile=true.

Idempotency & limits
- New permset creation: not idempotent (fails on duplicate).
- Remove-from-profile: idempotent (no-op when permissions are already
  absent).

Errors
- DUPLICATE_DEVELOPER_NAME on newPermsetName.
- INVALID_FIELD on bad field reference.

Example request

extract_permissions_from_profile({
  "sourceProfile": "example",
  "newPermsetName": "example",
  "newPermsetLabel": "example",
  "metadataOverride": "example"
})
