Tool: assign_permission_set

Description
Assign a permission set to one or more users. Uses the standard
`PermissionSetAssignment` sObject — fast, no metadata deploy. Supports
optional expiration date for time-bound access.

For permission set groups, see `assign_permission_set_group`.
For mass operations using selection criteria (profile, role, dept), see
`bulk_assign_permissions`.

Salesforce API
REST API (Data), v66.0.

Endpoint
POST /services/data/v66.0/composite/sobjects

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (single)
{
  "AssigneeId": "005Qg0000020aBcDE",
  "PermissionSetId": "0PSQg0000004ZyAA",
  "ExpirationDate": "2026-12-31T23:59:59.000Z"
}

Body (bulk via composite/sobjects)
{
  "allOrNone": false,
  "records": [
    { "attributes": { "type": "PermissionSetAssignment" }, "AssigneeId": "005Qg0000020aBcDE", "PermissionSetId": "0PSQg0000004ZyAA" }
  ]
}

Input (parameters)
permissionSetName (string, optional) - PermissionSet Name/API name to assign; string;
required when permissionSetId is omitted; example 'MTG_Project_Manager'; do not pass the
label.
permissionSetId (string, optional) - PermissionSet Id to assign; Salesforce Id string;
required when permissionSetName is omitted; example '0PSxx000000001A'; do not pass
PermissionSetGroup Ids.
userIds (string[], optional) - User Ids to assign; array of Salesforce User Id strings;
required when usernames is omitted; example ['005xx0000012345']; do not pass contact
Ids.
usernames (string[], optional) - User.Username values to assign; array of exact
usernames; required when userIds is omitted; example ['admin@example.com']; do not pass
display names.
includeInactiveUsers (boolean, optional) - Whether inactive users can be resolved;
boolean; defaults to false; example false; do not enable unless assignments to inactive
users are intentional.
expirationDate (string, optional) - PermissionSetAssignment ExpirationDate; ISO
date-time string; omitted means no expiration; example '2026-12-31T23:59:59.000Z'; do
not pass date-only text.
allOrNone (boolean, optional) - Composite sObject Collections allOrNone flag; boolean;
defaults to false; example true; when true one failed row can roll back the batch.
skipIfAlreadyAssigned (boolean, optional) - Whether existing assignments are queried and
skipped; boolean; defaults to true; example true; do not set false unless duplicate
errors are acceptable.
batchSize (integer, optional) - Composite sObject collection batch size; integer 1-200;
defaults to 200; example 100; do not pass values above the REST API limit.

Result
permissionSet (object) - { id, name, label }.
results (array) - One per requested user:
  userId, username, status ("created"|"already_assigned"|"failed"),
  assignmentId (string|null), error (string|null).
summary (object) - { created, alreadyAssigned, failed, total }.

Required permissions
- "Assign Permission Sets" + "Manage Users" (for cross-user assignment).
- "Manage Profiles and Permission Sets" for permsets containing
  Standard Object permissions.

Idempotency & limits
- Idempotent when `skipIfAlreadyAssigned=true`.
- License caps: failures with INSUFFICIENT_PERMSET_LICENSE if the
  permset uses a Permission Set License the org has exhausted.
- Composite: ≤200 per call; tool batches above that.

Errors
- DUPLICATE_VALUE: user already has the permset (when skip=false).
- INSUFFICIENT_PERMSET_LICENSE.
- INVALID_CROSS_REFERENCE_KEY: bad userId or permsetId.

Example request

assign_permission_set({
  "permissionSetName": "example",
  "permissionSetId": "example",
  "userIds": []
})
