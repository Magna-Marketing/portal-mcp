Tool: unassign_permission_set

Description
Remove permission set assignments from one or more users. Targets
`PermissionSetAssignment` rows that match (user, permset). Supports
bulk removal by user list or by selection criteria delegated to
`bulk_remove_permissions` (this tool focuses on a single permset).

Salesforce API
REST API (Data), v66.0.

Endpoint
DELETE /services/data/v66.0/composite/sobjects

Headers
Authorization: Bearer <access_token>

Body
None for the DELETE; ids are query params.

Input (parameters)
permissionSetName (string, optional) - PermissionSet Name/API name to remove; string;
required when permissionSetId is omitted; example 'MTG_Project_Manager'; do not pass
labels.
permissionSetId (string, optional) - PermissionSet Id to remove; Salesforce Id string;
required when permissionSetName is omitted; example '0PSxx000000001A'; do not pass group
Ids.
userIds (string[], optional) - User Ids to remove from; array of Salesforce User Id
strings; required when usernames is omitted; example ['005xx0000012345']; do not pass
contact Ids.
usernames (string[], optional) - User.Username values to remove from; array of exact
usernames; required when userIds is omitted; example ['admin@example.com']; do not pass
display names.
includeInactiveUsers (boolean, optional) - Whether inactive users can be resolved;
boolean; defaults to false; example true; do not enable unless inactive users must be
processed.
allOrNone (boolean, optional) - Composite sObject Collections delete allOrNone flag;
boolean; defaults to false; example true; when true one failed delete can roll back the
batch.
skipIfNotAssigned (boolean, optional) - Whether missing assignments are returned as
notAssigned instead of failing; boolean; defaults to true; example true; do not set
false for broad cleanups.
batchSize (integer, optional) - Composite sObject collection batch size; integer 1-200;
defaults to 200; example 100; do not pass values above the REST API limit.
dryRun (boolean, optional) - Whether to compute deletes without calling DELETE
/composite/sobjects; boolean; defaults to false; example true; do not use when you
expect assignments to be removed.

Result
JSON object with dryRun, permissionSetLookup, userLookup, assignmentLookup, notAssigned,
deleteRequestIds, and deleteResponses.
dryRun (value) - included in the JSON returned by the tool.
permissionSetLookup (value) - included in the JSON returned by the tool.
userLookup (value) - included in the JSON returned by the tool.
assignmentLookup (value) - included in the JSON returned by the tool.
notAssigned (value) - included in the JSON returned by the tool.
deleteRequestIds (value) - included in the JSON returned by the tool.
deleteResponses (value) - included in the JSON returned by the tool.

Required permissions
- "Assign Permission Sets" + "Manage Users".

Idempotency & limits
- Idempotent when `skipIfNotAssigned=true`.

Errors
- ENTITY_IS_DELETED if the assignment was already deleted.
- INVALID_CROSS_REFERENCE_KEY.

Example request

unassign_permission_set({
  "permissionSetName": "example",
  "permissionSetId": "example",
  "userIds": []
})
