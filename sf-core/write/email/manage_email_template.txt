Tool: manage_email_template

Description
Create, update, delete, activate, or deactivate Salesforce EmailTemplate records
via the REST sObjects API v66.0. Supports classic (text/html/custom) and
Visualforce template types. Optionally associates a BrandTemplate (classic
letterhead) or Enhanced Letterhead.

Salesforce API
REST API (Data), v66.0.

Endpoint
GET /services/data/v66.0/query/
POST /services/data/v66.0/sobjects/EmailTemplate
PATCH /services/data/v66.0/sobjects/EmailTemplate/{templateId}
DELETE /services/data/v66.0/sobjects/EmailTemplate/{templateId}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (create example)
{
  "Name": "MTG Project Status",
  "DeveloperName": "MTG_Project_Status_Email",
  "FolderId": "00lQg0000008abcAB",
  "TemplateType": "html",
  "Subject": "Status update: {!Account.Name}",
  "HtmlValue": "<html>...</html>",
  "Body": "Status update for {!Account.Name}.",
  "Encoding": "UTF-8",
  "IsActive": true,
  "BrandTemplateId": "0B0Qg0000008abcAB",
  "EnhancedLetterheadId": null,
  "RelatedEntityType": "Account"
}

Corrections vs. original documentation
- brandTemplateId maps to BrandTemplateId (ID of a BrandTemplate sObject, i.e.,
  a classic letterhead). This field is NOT required; only relevant for html type.
- Added EnhancedLetterheadId (ID of an Enhanced Letterhead for Lightning Experience).
- Added RelatedEntityType (API name of the sObject whose fields supply merge tokens).
- activate/deactivate operations issue a PATCH with { "IsActive": true/false }.
- The POST response body is { "id": "...", "success": true, "errors": [] }.
  PATCH and DELETE return 204 No Content on success (the tool normalizes this).

Input (parameters)
operation ("create" | "update" | "delete" | "activate" | "deactivate", required) -
Template action; enum create, update, delete, activate, or deactivate; required; example
\"update\"; activate/deactivate only patch IsActive.
templateCategory ("classic" | "lightning", optional, default classic) - Email template
category; enum classic or lightning; defaults to classic for backward compatibility.
REQUIRED whenever the user says Lightning, modern email template, Lightning Experience,
or asks for the template to be editable/previewable in Lightning. Use lightning to
create UiType SFX custom templates.
templateId (string, optional) - EmailTemplate Id; Salesforce Id string; required for
update/delete/activate/deactivate; example \"00X...\"; do not pass DeveloperName.
name (string, optional) - Template display name; string; required for create; example
\"Case Update\"; avoid duplicate confusing labels.
developerName (string, optional) - Template DeveloperName; API name string; optional on
create; example \"Case_Update\"; must start with a letter and avoid spaces, trailing
underscores, and double underscores.
folderId (string, optional) - Email template folder Id or private owner User Id;
Salesforce Id string; required for create; example \"00l...\". For Lightning, use a
Folder with Type=EmailTemplate; do not pass an org Id like 00D...
type ("text" | "html" | "custom" | "visualforce", optional) - TemplateType value; enum
text, html, custom, or visualforce; required for Classic create; Lightning always uses
custom and rejects other values.
subject (string, optional) - Subject line; string; optional; example \"Update for
{!Contact.FirstName}\"; omit only when unchanged or not needed.
htmlBody (string, optional) - HTML body mapped to HtmlValue; string; optional; example
\"<p>Hello</p>\"; do not pass base64 or unsafe scripts.
textBody (string, optional) - Plain text body mapped to Body for Classic. For Lightning,
when htmlBody is omitted, this text is escaped and converted into minimal paragraph HTML
so blank-line paragraph breaks are preserved in Lightning rendering; string; optional;
example \"Hello\\n\\nWelcome\".
brandTemplateId (string, optional) - BrandTemplate Id for classic letterhead; Salesforce
Id string; optional; example \"016...\"; only use with compatible html templates.
enhancedLetterheadId (string, optional) - EnhancedLetterhead Id; Salesforce Id string;
optional; example \"0XH...\"; do not pass Letterhead metadata fullName.
encoding (string, optional) - Character encoding; string; defaults by Salesforce when
omitted; example \"UTF-8\"; do not pass invalid encoding names.
description (string, optional) - Template description; string up to Salesforce field
limits; optional; example \"Sent on case updates\"; avoid secrets.
relatedEntityType (string, optional) - Related entity API name for merge fields; sObject
API name string; optional; example \"Contact\"; do not pass labels or Ids.

Result
create:  { "id": "...", "success": true, "errors": [] }
update/activate/deactivate: { "success": true, "id": "..." }  (normalized; API returns 204)
delete:  { "success": true, "id": "..." }                      (normalized; API returns 204)

Required permissions
- "Manage Public Templates" / "Manage Public Documents".

Idempotency
- update, activate, deactivate are idempotent.
- create and delete are not.

Errors
- DUPLICATE_DEVELOPER_NAME
- REQUIRED_FIELD_MISSING
- INVALID_FIELD

Example request

manage_email_template({
  "operation": "example"
})
