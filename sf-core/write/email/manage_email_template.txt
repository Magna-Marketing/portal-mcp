Tool: manage_email_template

Description
Create, update, delete, activate, or deactivate Salesforce EmailTemplate records
via the REST sObjects API v66.0. Supports classic (text/html/custom) and
Visualforce template types. Optionally associates a BrandTemplate (classic
letterhead) or Enhanced Letterhead.

Salesforce API
REST API (sObjects), v66.0.

Endpoints
POST   /services/data/v66.0/sobjects/EmailTemplate           (create)
PATCH  /services/data/v66.0/sobjects/EmailTemplate/{id}      (update, activate, deactivate)
DELETE /services/data/v66.0/sobjects/EmailTemplate/{id}      (delete)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (create example)
{
  "Name": "MTG Project Status",
  "DeveloperName": "MTG_Project_Status_Email",
  "FolderId": "00lQg0000008abcAB",
  "TemplateType": "html",
  "Subject": "Status update: {!Account.Name}",
  "HtmlValue": "<html>...</html>",
  "Body": "Status update for {!Account.Name}.",
  "Encoding": "UTF-8",
  "IsActive": true,
  "BrandTemplateId": "0B0Qg0000008abcAB",
  "EnhancedLetterheadId": null,
  "RelatedEntityType": "Account"
}

Corrections vs. original documentation
- brandTemplateId maps to BrandTemplateId (ID of a BrandTemplate sObject, i.e.,
  a classic letterhead). This field is NOT required; only relevant for html type.
- Added EnhancedLetterheadId (ID of an Enhanced Letterhead for Lightning Experience).
- Added RelatedEntityType (API name of the sObject whose fields supply merge tokens).
- activate/deactivate operations issue a PATCH with { "IsActive": true/false }.
- The POST response body is { "id": "...", "success": true, "errors": [] }.
  PATCH and DELETE return 204 No Content on success (the tool normalizes this).

Input (parameters)
operation (string, required) - "create" | "update" | "delete" | "activate" | "deactivate".
templateId (string, optional) - EmailTemplate record ID. Required for all ops except create.
name (string, required for create) - Display name (EmailTemplate Name field, max 80 chars).
developerName (string, optional) - API unique name (DeveloperName). Auto-generated from
  name on create when omitted.
folderId (string, required for create) - Folder or User ID where the template lives.
type (string, required for create) - "text" | "html" | "custom" | "visualforce".
subject (string, optional) - Subject line. Supports merge fields.
htmlBody (string, optional) - HTML body content (HtmlValue field, max 384 KB).
textBody (string, optional) - Plain text body (Body field, max 384 KB).
brandTemplateId (string, optional) - ID of a BrandTemplate (classic letterhead) for
  html-type templates.
enhancedLetterheadId (string, optional) - ID of an Enhanced Letterhead (Lightning).
encoding (string, optional, default "UTF-8") - Character encoding.
description (string, optional) - Template description (max 4,000 chars).
relatedEntityType (string, optional) - sObject API name for merge-field context,
  e.g. "Account", "Contact", "Opportunity".

Result
create:  { "id": "...", "success": true, "errors": [] }
update/activate/deactivate: { "success": true, "id": "..." }  (normalized; API returns 204)
delete:  { "success": true, "id": "..." }                      (normalized; API returns 204)

Required permissions
- "Manage Public Templates" / "Manage Public Documents".

Idempotency
- update, activate, deactivate are idempotent.
- create and delete are not.

Errors
- DUPLICATE_DEVELOPER_NAME
- REQUIRED_FIELD_MISSING
- INVALID_FIELD

Example request

manage_email_template({
  "operation": "create",
  "name": "MTG Project Status",
  "developerName": "MTG_Project_Status_Email",
  "folderId": "00lQg0000008abcAB",
  "type": "html",
  "subject": "Status update: {!Account.Name}",
  "htmlBody": "<p>Status: <b>{!Account.Status__c}</b></p>",
  "textBody": "Status: {!Account.Status__c}",
  "relatedEntityType": "Account"
})
