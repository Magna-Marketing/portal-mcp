Tool: manage_custom_notification_type

Description
Create, update, or delete Custom Notification Types via the Salesforce Metadata
API v66.0. Custom Notification Types are the channel definitions used by
publish_custom_notification to route notifications to desktop (bell icon) and/or
mobile push.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (deleteMetadata CustomNotificationType)

Input (parameters)
operation (string, required) - "create" | "update" | "delete".
developerName (string, required) - API/developer name (fullName in Metadata API).
masterLabel (string, required for create) - Display label.
customNotifTypeName (string, optional) - Notification type name. Defaults to
  masterLabel on create.
description (string, optional) - Description (max 255 chars).
desktop (boolean, required for create) - Enable desktop channel.
mobile (boolean, required for create) - Enable mobile push channel.

Result
create:  { "create": { "fullName": "...", "success": true } }
update:  { "update": { "fullName": "...", "success": true } }
delete:  { "delete": { "fullName": "...", "success": true } }

Required permissions
- "Customize Application".

Idempotency
- update is idempotent.
- create and delete are not.

Errors
- DUPLICATE_DEVELOPER_NAME
- REQUIRED_FIELD_MISSING

Example request (create)

manage_custom_notification_type({
  "operation": "create",
  "developerName": "MTG_Project_Update",
  "masterLabel": "MTG Project Update",
  "description": "Notifies users of MTG project status changes.",
  "desktop": true,
  "mobile": true
})

Example request (disable mobile)

manage_custom_notification_type({
  "operation": "update",
  "developerName": "MTG_Project_Update",
  "mobile": false
})
