Tool: send_email

Description
Send a single email via the Salesforce emailSimple standard invocable action.
Supports plain-text and rich-text bodies, template-based rendering with merge
fields, activity logging, threading tokens, and file attachments.

Salesforce API
REST API (Data), v66.0.

Endpoint
POST /services/data/v66.0/actions/standard/emailSimple

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "inputs": [{
    "recipientAddresses": "to@example.com,to2@example.com",
    "ccAddresses": "cc@example.com",
    "bccAddresses": "bcc@example.com",
    "recipientId": "003Qg0000020aBcDE",
    "relatedRecordId": "a01Qg0000020aBcDE",
    "emailSubject": "Quarterly Update",
    "emailBody": "<p>Hello</p>",
    "emailTemplateId": "00X4Q00000abcDE",
    "sendRichBody": true,
    "useLineBreaks": false,
    "logEmailOnSend": true,
    "senderType": "CurrentUser",
    "senderAddress": null,
    "attachmentId": "068Qg00000abcDE",
    "addThreadingTokenToBody": false,
    "addThreadingTokenToSubject": false
  }]
}

Corrections vs. original documentation
- emailAddresses / emailAddressesArray → replaced by recipientAddresses,
  ccAddresses, bccAddresses (all string, comma-delimited, available API v65.0+).
- subject → emailSubject.
- htmlBody / textBody → emailBody (plain or HTML depending on sendRichBody).
- saveAsActivity → logEmailOnSend.
- senderType valid values: "CurrentUser" | "DefaultWorkflowUser" |
  "OrgWideEmailAddress" ("DefaultWorkflowUser" was missing in original docs).
- attachments array not supported; use attachmentId (string, comma-delimited,
  API v63.0+) or attachmentIdCollection (API v64.0+) instead.
- whatId is NOT a valid field; use relatedRecordId.
- The action returns NO structured outputs (Salesforce docs say "None").
  The raw response array contains { actionName, errors, isSuccess, outputValues }.

Input (parameters)
recipientAddresses (string, optional) - To recipients; comma-delimited email string;
optional when recipientId is used; example \"jane@example.com,bob@example.com\";
combined recipients must not exceed 150.
ccAddresses (string, optional) - CC recipients; comma-delimited email string; optional;
example \"manager@example.com\"; do not include display-name syntax.
bccAddresses (string, optional) - BCC recipients; comma-delimited email string;
optional; example \"audit@example.com\"; do not use when org compliance disables BCC.
recipientId (string, optional) - Recipient Contact or Lead Id; Salesforce Id string;
required with emailTemplateId; example \"003...\"; do not pass a User Id for template
recipient context.
relatedRecordId (string, optional) - Related record Id for merge fields or activity
logging; Salesforce Id string; optional; example \"500...\"; do not pass person records
here.
emailSubject (string, optional) - Subject text; string; required when no emailTemplateId
is passed; example \"Your case update\"; omit when template supplies the subject.
emailBody (string, optional) - Email body; string plain text or HTML; required without
emailTemplateId; example \"<p>Hello</p>\"; do not pass raw binary or attachment content.
emailTemplateId (string, optional) - EmailTemplate Id; Salesforce Id string; optional;
example \"00X...\"; requires recipientId and uses the single-email limit bucket.
sendRichBody (boolean, optional) - Whether emailBody is treated as HTML; boolean;
defaults to false; example true; do not set true for untrusted HTML.
useLineBreaks (boolean, optional) - Whether rich-text line breaks become <br> tags;
boolean; defaults to false; example true; only applies to rich body sends.
logEmailOnSend (boolean, optional) - Whether to log sent email as activity; boolean;
defaults to false; example true; requires recipientId or relatedRecordId.
senderType ("CurrentUser" | "DefaultWorkflowUser" | "OrgWideEmailAddress", optional) -
Sender type; enum CurrentUser, DefaultWorkflowUser, or OrgWideEmailAddress; defaults to
CurrentUser; example \"OrgWideEmailAddress\"; org-wide requires senderAddress.
senderAddress (string, optional) - Org-wide sender email address; email string; required
when senderType is OrgWideEmailAddress; example \"support@example.com\"; do not pass the
OrgWideEmailAddress Id.
attachmentId (string, optional) - Attachment Ids; comma-delimited Document,
ContentVersion, or Attachment Id string; optional; example \"068...,00P...\"; do not
pass file bytes.
attachmentIdCollection (string, optional) - Attachment Id collection; comma-delimited Id
string; optional; example \"068...,069...\"; avoid passing both attachment fields unless
Salesforce action expects it.
addThreadingTokenToBody (boolean, optional) - Whether to append an Email-to-Case
threading token to body; boolean; optional; example true; only useful with related
case-style records.
addThreadingTokenToSubject (boolean, optional) - Whether to append an Email-to-Case
threading token to subject; boolean; optional; example true; avoid unless reply
threading is needed.

Result
Array: [{ "actionName": "emailSimple", "errors": null, "isSuccess": true, "outputValues": {} }]
The emailSimple action has no defined output values; check isSuccess and errors.

Limits
- Combined recipientAddresses + ccAddresses + bccAddresses + recipientId ≤ 150.
- Using logEmailOnSend or emailTemplateId counts against the single-email daily limit.
- Otherwise counts against the daily workflow email limit.
- Not idempotent.

Required permissions
- "Send Email" (+ read on template folder when using emailTemplateId).

Errors
- INSUFFICIENT_ACCESS_OR_READONLY
- EMAIL_TEMPLATE_NOT_FOUND
- INVALID_EMAIL_ADDRESS
- EMAIL_LIMIT_EXCEEDED

Example request

send_email({
  "recipientAddresses": "example",
  "ccAddresses": "example",
  "bccAddresses": "example"
})
