Tool: manage_custom_tab

Description
Create / update / delete Custom Tabs (sObject tabs, Web tabs, VF tabs,
FlexiPage tabs, Lightning Component tabs).

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (writeMetadata CustomTab)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: fullName, label, description, customObject, url, urlEncodingKey, frameHeight, hasSidebar, page, flexiPage, auraComponent, lwcComponent, motif, icon, scontrol, splashPageLink.

Input (parameters)
operation ("create" | "update" | "upsert" | "delete", required) - Metadata action to
run. Values are create, update, upsert, or delete; no default. Example: upsert. Do not
pass delete unless the tab should be removed.
type (string, optional) - Tab flavor used for validation and field mapping. Values are
sobject, web, visualforce, flexipage, auracomponent, lwc, or scontrol; required for
create and upsert. Example: web. Do not pass more than one content field for a tab.
fullName (string, required) - CustomTab fullName. Use the object API name for sObject
tabs or a developer name with only letters, numbers, and underscores for other tabs;
required. Example: Account or Partner_Portal. Do not include spaces or a trailing
underscore.
label (string, optional) - Displayed tab label. String value; required by this tool for
create/upsert except object tabs derive labels from the object. Example: Partner Portal.
Do not pass an empty string.
description (string, optional) - Optional tab description. Plain string; omitted by
default. Example: Opens the partner portal. Do not pass markup-only content.
sObject (string, optional) - Object API name for sObject tabs. Required when type is
sobject; maps to customObject=true and fullName must match this object. Example:
Project__c. Do not pass for web, page, component, or LWC tabs.
url (string, optional) - External URL for web tabs. Required when type is web; full URL
string. Example: https://example.com. Do not pass with page, flexiPage, auraComponent,
lwcComponent, or scontrol.
urlEncodingKey (string, optional) - Encoding for URL tabs. String encoding name;
defaults in Salesforce to UTF-8 when omitted. Example: UTF-8. Do not pass for non-URL
tabs.
frameHeight (integer, optional) - Frame height for Visualforce, s-control, or URL
content. Integer pixels; omitted by default. Example: 600. Do not pass negative or
decimal values.
hasSidebar (boolean, optional) - Whether the tab shows the Salesforce sidebar. Boolean;
omitted by default. Example: false. Do not pass for tab types where the sidebar is
irrelevant.
page (string, optional) - Visualforce page name. Required when type is visualforce; use
the page developer name. Example: MyPage. Do not pass a namespace separator unless it is
the Metadata API page reference.
flexiPage (string, optional) - Lightning page developer name for FlexiPage tabs.
Required when type is flexipage. Example: My_App_Page. Do not pass a full URL.
lightningComponent (string, optional) - Alias for auraComponent. String component
reference; maps to the Metadata API auraComponent field. Example: c:MyComponent. Prefer
auraComponent for new calls and do not pass with lwcComponent.
auraComponent (string, optional) - Aura component reference. Required when type is
auracomponent unless lightningComponent is supplied. Example: c:MyComponent. Do not pass
with page, flexiPage, lwcComponent, scontrol, or url.
lwcComponent (string, optional) - Lightning Web Component reference for LWC tabs.
Required when type is lwc. Example: c:myComponent. Do not pass with auraComponent or
page.
scontrol (string, optional) - S-control name for legacy s-control tabs. Required when
type is scontrol. Example: MyScontrol. Do not use for new Lightning components.
motif (string, optional) - Standard tab style value. Use Salesforce motif strings such
as Custom70:Handsaw; defaults to Custom14:Hands on create. Example:
Custom74:HotAirBalloon. Do not pass arbitrary icon labels.
icon (string, optional) - Document reference for a custom tab image. String metadata
reference; omitted by default. Example: MyFolder/MyIcon. Do not pass with motif unless
the org accepts both.
splashPageLink (string, optional) - HomePageComponent link shown as a splash page.
String reference; omitted by default. Example: Intro_Link. Do not pass a URL directly.
metadata (unknown, required).

Result
deploy (object).
customTab (object).

Required permissions
- "Customize Application".

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_DEVELOPER_NAME.

Example request

manage_custom_tab({
  "operation": "upsert.",
  "fullName": "Account or Partner_Portal.",
  "metadata": "example"
})
