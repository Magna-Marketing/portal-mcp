Tool: update_mydomain_settings

Description
Update MyDomain configuration: login policy, redirect policy, embedded
login disabled, partial login policy. Domain rename is a heavy operation
(propagates to login URLs) and not exposed by this tool.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (updateMetadata MyDomainSettings)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
N/A.

Input (parameters)
settings (unknown, optional) - Editable MyDomainSettings fields to merge. Object with
v66.0 writable fields; required to contain at least one field. Example:
{\"canOnlyLoginWithMyDomainUrl\":true}. Do not pass read-only fields such as
myDomainName, myDomainSuffix, domainPartition, useEdge, or edgeRoutingMethod.
checkOnly (boolean, optional) - Preview mode. Boolean; defaults to false and skips
updateMetadata when true. Example: true. Do not use when you expect Salesforce to
persist changes.
fullName (string, optional) - Settings component fullName. String; defaults to MyDomain.
Example: MyDomain. Do not pass an org domain name.

Result
JSON containing checkOnly, fullName, raw readResponse, generated metadata, and raw
updateResponse or null.
checkOnly (value) - included in the JSON returned by the tool.
fullName (value) - included in the JSON returned by the tool.
readResponse (value) - included in the JSON returned by the tool.
metadata (value) - included in the JSON returned by the tool.
updateResponse (value) - included in the JSON returned by the tool.

Required permissions
- "Customize Application".

Idempotency & limits
- Idempotent on equal input.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY, INVALID_FIELD.

Example request

update_mydomain_settings({
  "settings": "{\\\"canOnlyLoginWithMyDomainUrl\\\":true}.",
  "checkOnly": "true.",
  "fullName": "MyDomain."
})
