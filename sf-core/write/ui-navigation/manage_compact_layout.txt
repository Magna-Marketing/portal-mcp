Tool: manage_compact_layout

Description
Create / update / delete compact layouts and set per-record-type
primary assignment.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (updateMetadata CustomObject)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: fullName, label, fields.

Input (parameters)
operation ("create" | "update" | "upsert" | "delete" | "setPrimary", required) -
Metadata action to run. Values are create, update, upsert, delete, or setPrimary; no
default. Example: setPrimary. Do not pass delete unless the compact layout should be
removed.
sObject (string, required) - Parent object API name. String required to qualify
CompactLayout names and assignments. Example: Account. Do not pass a label or record ID.
fullName (string, required) - CompactLayout fullName. Pass Object.DeveloperName or
DeveloperName with sObject; required. Example: Account.Mobile_Card. Do not pass spaces.
label (string, optional) - Compact layout label. String; required for create/upsert.
Example: Mobile Card. Do not pass an empty string.
fields (string[], optional) - Fields shown by the compact layout in priority order.
Array of field API names; required for create/upsert. Example: [\"Name\",\"Phone\"]. Do
not pass text area, long text area, rich text area, or multi-select picklist fields.
recordTypeAssignments (unknown[], optional) - Record type assignments for setPrimary.
Array of assignment objects; omitted to set object compactLayoutAssignment. Example:
[{\"recordType\":\"Business\",\"compactLayout\":\"Mobile_Card\"}]. Do not pass for
create/update/delete.
metadata (unknown, required).

Result
JSON from the raw Metadata API operation, or raw CustomObject read/update responses for
setPrimary.

Required permissions
- "Customize Application".

Idempotency & limits
- update idempotent.

Errors
- INVALID_FIELD.

Example request

manage_compact_layout({
  "operation": "setPrimary.",
  "sObject": "Account.",
  "fullName": "Account.Mobile_Card.",
  "metadata": "example"
})
