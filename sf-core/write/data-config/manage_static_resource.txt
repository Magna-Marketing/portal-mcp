Tool: manage_static_resource

Description
Create / update / upsert / delete a Static Resource using the Salesforce Tooling API.
The file body is supplied as a base64-encoded string. For update/upsert/delete the
tool first queries StaticResource by Name to obtain the Id, then performs PATCH/DELETE.

Salesforce API
Tooling API, v66.0.

Endpoint
POST /services/data/v66.0/tooling/sobjects/StaticResource
DELETE /services/data/v66.0/tooling/sobjects/StaticResource

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body (create / update)
{
  "Name": "MyStyles",
  "ContentType": "text/css",
  "CacheControl": "Public",
  "Body": "<base64>",
  "Description": "Optional description",
  "NamespacePrefix": ""
}

Tooling API StaticResource fields
Name             – string, required for create. Unique, alphanumeric + underscores, max 255.
ContentType      – string (MIME type), required for create. E.g. "text/css", "image/png", "application/zip".
CacheControl     – enum "Public" | "Private". Defaults to "Public".
Body             – string (base64-encoded file content). Required for create/update/upsert. Max 5 MB.
Description      – string, optional.
NamespacePrefix  – string, optional. For managed package resources.
BodyLength       – integer, read-only. Returned in lookup/GET responses.

Input (parameters)
operation ("create" | "update" | "upsert" | "delete", required) - Requested
StaticResource operation; enum create, update, upsert, or delete; no default; example:
'upsert'; do not pass read operations here.
name (string, required) - StaticResource Name; string unique in the org or namespace
using letters, numbers, and underscores; required for all operations; example:
'MyStyles'; do not include a file extension or spaces.
contentType (string, optional) - StaticResource ContentType MIME value; string required
for create and for upsert when creating; omitted on update leaves the current content
type unchanged; example: 'text/css'; do not pass an unsupported or informal type like
'css'.
cacheControl ("Public" | "Private", optional) - StaticResource CacheControl value; enum
Public or Private; defaults to Public on create/upsert-create when omitted; example:
'Public'; do not pass lowercase values.
description (string, optional) - StaticResource Description value; string; omitted
leaves the existing description unchanged on update; example: 'Shared app stylesheet';
do not pass binary content here.
base64 (string, optional) - StaticResource Body value; base64-encoded file content
string required for create and upsert-create; omitted on update changes only metadata
fields; example: 'Ym9keSB7fQ=='; do not pass raw file bytes or data: URLs.

Result
Returns a JSON object with:
  operation  – echo of the requested operation.
  object     – "StaticResource".
  lookup     – (update/upsert/delete) the existing record metadata returned by the query.
  create     – (create/upsert-as-create) Tooling API SaveResult: { id, success, errors }.
  update     – (update/upsert-as-update) Tooling API SaveResult.
  delete     – (delete) Tooling API DeleteResult or a not-found message.

Required permissions
- "Customize Application".

Idempotency & limits
- upsert is idempotent on Name.
- Body cap: 5 MB unencoded.

Errors
- DUPLICATE_VALUE if creating with a name that already exists (use upsert instead).
- FILE_TOO_LARGE if body exceeds 5 MB.

Corrections vs original doc
- Operation "upsert" added (missing from original).
- Result shape documents the actual per-operation response keys.

Example request

manage_static_resource({
  "operation": "upsert",
  "name": "MyStyles"
})
