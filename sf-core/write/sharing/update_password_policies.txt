Tool: update_password_policies

Description
Update org-level password policies (length, complexity, expiration,
lockout interval, lockout attempts) and per-profile overrides.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (createMetadata ProfilePasswordPolicy)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: minimumLength, minimumPasswordLength.
JSON fields: fullName, profile, forgotPasswordRedirect, lockoutInterval, maxLoginAttempts, minimumPasswordLength, minimumPasswordLifetime, obscure, passwordComplexity, passwordExpiration, passwordHistory, passwordQuestion.

Input (parameters)
password (unknown, optional) - Represents org-level SecuritySettings.passwordPolicies
fields to merge; object with Metadata API password fields; required when
profileOverrides is omitted; example {\"expiration\":\"NinetyDays\"}; do not pass
removed fields such as enableSetPasswordInApi.
profileOverrides (unknown[], optional) - Represents ProfilePasswordPolicy records to
create or update; array of profile override objects; required when password is omitted;
example [{\"profileName\":\"Standard User\",\"minimumPasswordLength\":12}]; do not pass
profile Ids.
checkOnly (boolean, optional) - Represents whether to build metadata without calling
createMetadata or updateMetadata; boolean; defaults to false; example true; do not use
when policies must be saved.
securitySettingsFullName (string, optional) - Represents the SecuritySettings fullName;
string; defaults to 'Security'; example 'Security'; do not pass a file path.

Result
JSON object with checkOnly, securitySettingsFullName, securitySettings, and
profileOverrides.
checkOnly (value) - included in the JSON returned by the tool.
securitySettingsFullName (value) - included in the JSON returned by the tool.
securitySettings (value) - included in the JSON returned by the tool.
profileOverrides (value) - included in the JSON returned by the tool.

Required permissions
- "Manage Internal Users".

Idempotency & limits
- Idempotent.

Errors
- INVALID_FIELD on bad enum.

Example request

update_password_policies({
  "password": "example",
  "profileOverrides": [],
  "checkOnly": false
})
