Tool: manage_sharing_rule

Description
Create, update, or delete sharing rules (criteria-based or owner-based).
Each rule shares records matching the criteria (or owned by the source)
to a target group/role with a specified access level (Read | Edit |
TransferAccess | All for Account-related rules).

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/data/v66.0/metadata/deployRequest
POST /services/Soap/m/66.0  (readMetadata SharingRules)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: fullName, label, description, accessLevel, sharedTo, sharedFrom, criteriaItems, booleanFilter, includeRecordsOwnedByAll, includeHVUOwnedRecords, accountSettings.

Input (parameters)
operation ("create" | "update" | "upsert" | "delete", required) - Represents the rule
operation; enum create, update, upsert, or delete; no default; example 'upsert'; do not
pass deploy.
sObject (string, required) - Represents the sObject API name that owns the SharingRules
container; standard or custom object name; no default; example 'Account' or
'Project__c'; do not pass a record Id.
ruleType ("criteria" | "owner" | "territory" | "guest", required) - Represents the child
sharing rule collection; enum criteria, owner, territory, or guest; no default; example
'criteria'; do not pass removed pre-v33 metadata type names.
fullName (string, required) - Represents the sharing rule DeveloperName inside the
object container; string without object prefix; no default; example
'Share_With_Project_Managers'; do not pass a label.
label (string, optional) - Represents the sharing rule label; string; required by
Salesforce for create and usually for upsert; example 'Share with Project Managers'; do
not pass the API name here.
description (string, optional) - Represents the admin-facing rule description; string;
omitted by default; example 'Shares western region records'; do not pass HTML-only
content.
accessLevel ("Read" | "Edit" | "All" | "TransferAccess", optional) - Represents the
access level granted by the rule; enum validated by Salesforce per object and rule type;
required for non-delete writes; example 'Read'; do not pass Edit for guest rules.
sharedTo (object, optional) - Represents who receives access; object with Metadata API
shared-to type and name; required for non-delete writes; example
{\"type\":\"group\",\"name\":\"Project_Managers\"}; do not pass Salesforce record Ids.
  type ("allCustomerPortalUsers" | "allInternalUsers" | "allPartnerUsers" |
  "channelProgramGroup" | "channelProgramGroups" | "group" | "groups" | "manager" |
  "managerAndSubordinatesInternal" | "portalRole" | "portalRoleAndSubordinates" |
  "queue" | "role" | "roleAndSubordinates" | "roleAndSubordinatesInternal" | "roles" |
  "territory" | "territoryAndSubordinates", required) - Represents the Metadata API
  shared entity child element; enum value; no default; example 'group'; do not pass
  display-only labels.
  name (string, required) - Represents the shared entity metadata reference; developer
  name or supported metadata value; no default; example 'Project_Managers'; do not pass
  Salesforce record Ids.
sharedFrom (object, optional) - Represents owner or territory source for owner and
territory rules; object with Metadata API shared-from type and name; required for owner
and territory writes; example {\"type\":\"role\",\"name\":\"Sales\"}; do not pass for
criteria rules.
  type ("allCustomerPortalUsers" | "allInternalUsers" | "allPartnerUsers" |
  "channelProgramGroup" | "channelProgramGroups" | "group" | "groups" | "manager" |
  "managerAndSubordinatesInternal" | "portalRole" | "portalRoleAndSubordinates" |
  "queue" | "role" | "roleAndSubordinates" | "roleAndSubordinatesInternal" | "roles" |
  "territory" | "territoryAndSubordinates", required) - Represents the Metadata API
  shared entity child element; enum value; no default; example 'group'; do not pass
  display-only labels.
  name (string, required) - Represents the shared entity metadata reference; developer
  name or supported metadata value; no default; example 'Project_Managers'; do not pass
  Salesforce record Ids.
criteria (unknown[], optional) - Represents criteria items for criteria or guest rules;
array of filter entries; required for criteria and guest writes; example
[{\"field\":\"Region__c\",\"operation\":\"equals\",\"value\":\"West\"}]; do not pass for
pure owner rules.
booleanFilter (string, optional) - Represents advanced criteria logic; string using
1-based item indexes; omitted by default; example '1 AND (2 OR 3)'; do not include
WHERE.
includeRecordsOwnedByAll (boolean, optional) - Represents whether criteria rules include
records owned by users without roles; boolean; omitted by default; example true; do not
pass for unrelated rule types unless Salesforce supports it.
includeHVUOwnedRecords (boolean, optional) - Represents whether guest rules include
high-volume-user owned records; boolean; omitted by default; example true; do not pass
for owner sharing rules.
accountSettings (object, optional) - Represents Account-specific child access settings;
object with case, contact, and opportunity access levels; omitted by default; example
{\"caseAccessLevel\":\"Read\"}; do not pass for non-Account objects.
  caseAccessLevel ("None" | "Read" | "Edit", optional).
  contactAccessLevel ("None" | "Read" | "Edit", optional).
  opportunityAccessLevel ("None" | "Read" | "Edit", optional).
metadataOverride (unknown, required).
checkOnly (boolean, optional) - Represents whether to build metadata without calling
Metadata API; boolean; defaults to false; example true; do not use when the rule must be
saved.

Result
checkOnly (value) - included in the JSON returned by the tool.
readResponse (value) - included in the JSON returned by the tool.
existingRule (value) - included in the JSON returned by the tool.
metadata (value) - included in the JSON returned by the tool.
writeResponse (value) - included in the JSON returned by the tool.

Required permissions
- "Manage Sharing" + "Customize Application".

Idempotency & limits
- update is idempotent.
- New rule triggers a sharing recalc for matching records (async).

Errors
- DUPLICATE_DEVELOPER_NAME, INVALID_FIELD on criteria.

Example request

manage_sharing_rule({
  "operation": "example",
  "sObject": "example",
  "ruleType": "example",
  "fullName": "example",
  "metadataOverride": "example"
})
