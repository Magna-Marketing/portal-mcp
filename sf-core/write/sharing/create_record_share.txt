Tool: create_record_share

Description
Create a manual share row on a record (`<sObject>Share`). This grants
explicit access to a user, group, or role for a single record.

Salesforce API
REST API (Data), v66.0.

Endpoint
POST /services/data/v66.0/composite/sobjects

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: attributes, parentField, UserOrGroupId, accessField, RowCause, OpportunityAccessLevel, CaseAccessLevel, ContactAccessLevel.

Input (parameters)
sObject (string, required) - Represents the parent sObject API name; standard or custom
object name; no default; example 'Account' or 'Project__c'; do not pass the share object
name.
shares (unknown[], required) - Represents share rows to create; non-empty array sent in
batches up to 200; no default; example one row with recordId and username; do not pass
an empty array.
allOrNone (boolean, optional) - Represents the sObject Collections rollback flag;
boolean; defaults to false; example true; do not set true unless one failure should roll
back the whole batch.
batchSize (integer, optional) - Represents records per sObject Collections request;
integer 1-200; defaults to 200; example 100; do not exceed the REST collection limit.
parentIdField (string, optional) - Represents the parent Id field on the share object;
Salesforce field API name; defaults to ParentId for custom objects and <sObject>Id for
standard objects; example 'AccountId'; do not override unless the default is wrong.
accessLevelField (string, optional) - Represents the access level field on the share
object; Salesforce field API name; defaults to AccessLevel for custom objects and
<sObject>AccessLevel for standard objects; example 'AccountAccessLevel'; do not pass
child access fields here.

Result
JSON object with request, lookups, records, and responses arrays containing raw
Salesforce create results.
request (value) - included in the JSON returned by the tool.
lookups (value) - included in the JSON returned by the tool.
records (value) - included in the JSON returned by the tool.
responses (value) - included in the JSON returned by the tool.

Required permissions
- "Modify All" on the parent sObject **or** be the record owner with FullAccess.

Idempotency & limits
- Not idempotent — duplicates with the same UserOrGroupId on the same record return DUPLICATE_VALUE.
- Bulk via composite/sobjects: 200 per call.

Errors
- DUPLICATE_VALUE.
- INSUFFICIENT_ACCESS_OR_READONLY.
- INVALID_ACCESS_LEVEL when "Edit" requested for Read-only sObject.

Example request

create_record_share({
  "sObject": "example",
  "shares": []
})
