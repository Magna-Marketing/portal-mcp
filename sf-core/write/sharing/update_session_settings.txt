Tool: update_session_settings

Description
Update org-level session settings (timeouts, lockouts, HTTPS-required,
session security level) and per-profile overrides. Applies via the
Metadata API.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (createMetadata ProfileSessionSetting)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: fullName, profile, profileName.

Input (parameters)
session (unknown, optional) - Represents org-level SecuritySettings.sessionSettings
fields to merge; object with Metadata API session fields; required when profileOverrides
is omitted; example {\"sessionTimeout\":\"FourHours\"}; do not pass profile-only fields.
profileOverrides (unknown[], optional) - Represents ProfileSessionSetting records to
create or update; array of profile session override objects; required when session is
omitted; example [{\"profileName\":\"Standard User\",\"sessionTimeout\":240}]; do not
pass profile Ids.
checkOnly (boolean, optional) - Represents whether to build metadata without calling
createMetadata or updateMetadata; boolean; defaults to false; example true; do not use
when settings must be saved.
securitySettingsFullName (string, optional) - Represents the SecuritySettings fullName;
string; defaults to 'Security'; example 'Security'; do not pass a file path.

Result
JSON object with checkOnly, securitySettingsFullName, securitySettings, and
profileOverrides.
checkOnly (value) - included in the JSON returned by the tool.
securitySettingsFullName (value) - included in the JSON returned by the tool.
securitySettings (value) - included in the JSON returned by the tool.
profileOverrides (value) - included in the JSON returned by the tool.

Required permissions
- "Manage Internal Users" + "Customize Application".

Idempotency & limits
- Idempotent.

Errors
- INVALID_FIELD on bad enum.

Example request

update_session_settings({
  "session": "example",
  "profileOverrides": [],
  "checkOnly": false
})
