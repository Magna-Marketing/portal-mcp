Tool: share_file

Description
Share a file with one or more users / records / groups by creating
`ContentDocumentLink` rows. Optionally `unshare` (delete the link).

Salesforce API
REST API (Data), v66.0.

Endpoint
POST /services/data/v66.0/sobjects/ContentDocumentLink
DELETE /services/data/v66.0/sobjects/ContentDocumentLink/{id}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "ContentDocumentId": "...", "LinkedEntityId": "...", "ShareType": "V", "Visibility": "AllUsers" }

Input (parameters)
ContentDocumentId (string, required) - ContentDocument Id; Salesforce Id string;
required; example \"069...\"; do not pass ContentVersionId.
operation ("share" | "unshare", required) - Share action; enum share or unshare;
required; example \"share\"; unshare deletes matching links.
links (unknown[], required) - Share target entries; array with at least one object;
required; example [{\"LinkedEntityId\":\"001...\",\"ShareType\":\"V\"}]; do not mix
unrelated files in one call.

Result
raw lookup, create, and delete responses for each requested link.
operation (value) - included in the JSON returned by the tool.
ContentDocumentId (value) - included in the JSON returned by the tool.
responses (value) - included in the JSON returned by the tool.

Required permissions
- File owner or Collaborator access.

Idempotency & limits
- "share" idempotent — duplicates return DUPLICATE_VALUE; tool surfaces as "already_exists".

Errors
- DUPLICATE_VALUE, INVALID_CROSS_REFERENCE_KEY.

Example request

share_file({
  "ContentDocumentId": "example",
  "operation": "example",
  "links": []
})
