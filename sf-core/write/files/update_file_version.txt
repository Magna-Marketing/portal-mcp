Tool: update_file_version

Description
Add a new `ContentVersion` to an existing `ContentDocument` — this is
how Salesforce Files "uploads a new version" of a file. Existing
sharing links continue to point at the latest version automatically.

Salesforce API
REST API (Data), v66.0.

Endpoint
POST /services/data/v66.0/sobjects/ContentVersion       (multipart with `ContentDocumentId` to attach as new version)

Headers
Authorization: Bearer <access_token>
Content-Type: multipart/form-data

Body
multipart/form-data with entity_content (JSON metadata) and VersionData (binary).

Input (parameters)
ContentDocumentId (string, required) - Existing ContentDocument Id; Salesforce Id
string; required; example \"069...\"; do not pass ContentVersionId.
PathOnClient (string, required) - Client file path/name for new version; string with
extension; required; example \"Proposal_v2.pdf\"; do not pass local file paths as data.
VersionData (string, required) - New file contents; base64 string; required; example
\"JVBERi0x...\"; do not pass raw bytes or data URLs.
Title (string, optional) - Version title; string; defaults to PathOnClient; example
\"Proposal v2\"; omit to keep title aligned to filename.
ReasonForChange (string, optional) - Revision reason; string; optional; example
\"Updated pricing\"; do not pass audit-only comments with secrets.
Description (string, optional) - ContentVersion description; string; optional; example
\"Second revision\"; omit when unchanged.
contentType (string, optional) - Multipart MIME type; string; defaults to
application/octet-stream; example \"application/pdf\"; omit when unknown.
OwnerId (string, optional) - Owner User Id; Salesforce Id string; optional; example
\"005...\"; do not pass usernames.
SharingOption ("A" | "R", optional) - Sharing option; enum A allowed or R restricted;
optional; example \"A\"; omit when not changing file sharing behavior.
SharingPrivacy ("N" | "P", optional) - Sharing privacy; enum N or P; optional; example
\"P\"; Salesforce enforces record/file visibility rules.
TagCsv (string, optional) - Content tags; comma-separated string; optional; example
\"contract,renewal\"; do not pass arrays.
IsMajorVersion (boolean, optional) - Major version flag; boolean; optional; example
true; omit for Salesforce default.
RecordTypeId (string, optional) - ContentVersion record type Id; Salesforce Id string;
optional; example \"012...\"; do not pass developer names.

Result
raw ContentVersion create response plus raw lookup query response.
createContentVersion (value) - included in the JSON returned by the tool.
contentVersionLookup (value) - included in the JSON returned by the tool.

Required permissions
- File Collaborator access (share type "C") or owner.

Idempotency & limits
- Not idempotent.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY, FILE_TOO_LARGE.

Example request

update_file_version({
  "ContentDocumentId": "example",
  "PathOnClient": "example",
  "VersionData": "example"
})
