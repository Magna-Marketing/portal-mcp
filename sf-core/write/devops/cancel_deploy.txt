Tool: cancel_deploy

Description
Cancel an in-progress metadata deploy. Status moves to "Canceled" if
caught before tests run, otherwise rollback may be required.

Salesforce API
Metadata REST API, v66.0.

Endpoint
PATCH /services/data/v66.0/metadata/deployRequest/{deployId}

Headers
Authorization: Bearer <access_token>

Body
None.

Input (parameters)
deployId (string, required) - Metadata deployRequest Id; Salesforce Id string; required;
example \"0Af...\"; do not pass a validation Id from another org.
includeDetails (boolean, optional) - Whether the follow-up status includes details;
boolean; defaults to true; example false; ignored when fetchStatus is false.
fetchStatus (boolean, optional) - Whether to read current deploy status after cancel;
boolean; defaults to true; example true; pass false to return only the PATCH response.

Result
raw cancel response, or { cancel, status } when status fetch is enabled.
cancel (value) - included in the JSON returned by the tool.
status (value) - included in the JSON returned by the tool.

Required permissions
- "Modify Metadata Through Metadata API Functions".

Idempotency & limits
- Idempotent (already-canceled job: no-op).

Errors
- DEPLOY_NOT_CANCELABLE: deploy already finished.

Example request

cancel_deploy({
  "deployId": "example"
})
