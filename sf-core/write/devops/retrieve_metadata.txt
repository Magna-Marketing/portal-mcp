Tool: retrieve_metadata

Description
Retrieve a metadata package from the org. Provide either a `package.xml`-
shaped manifest (types + members), an unpackaged single-package manifest,
or one or more managed package names. Returns a downloadable zip
location plus an inline base64 zip on completion.

Salesforce API
Metadata API + Tooling API, v66.0.

Endpoint
POST /services/data/v66.0/metadata/retrieveRequest
GET  /services/data/v66.0/metadata/retrieveResult/{retrieveId}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: apiVersion, singlePackage, unpackaged, packageNames, specificFiles, rootTypesWithDependencies.

Input (parameters)
manifest (object, optional) - Unpackaged manifest shaped like package.xml; object with
types array; required unless packageNames or specificFiles is passed; example
{\"types\":[{\"name\":\"ApexClass\",\"members\":[\"*\"]}]}; do not use unsupported
metadata type names.
  types (unknown[], required) - Package.xml-shaped types and members to retrieve.
packageNames (string[], optional) - Managed package names to retrieve; string array;
optional; example [\"MyPackage\"]; omit for unpackaged-only retrieves.
singlePackage (boolean, optional) - Whether one package is retrieved; boolean; defaults
to true; example true; specificFiles requires true and no packageNames.
specificFiles (string[], optional) - Specific metadata file paths; string array;
optional; example [\"classes/MyClass.cls\"]; do not combine with packageNames.
rootTypesWithDependencies ("Bot"[], optional) - Root metadata types whose dependencies
Salesforce retrieves; enum array; currently only Bot; example [\"Bot\"]; do not pass
arbitrary metadata types.
waitForCompletion (boolean, optional) - Whether to poll until retrieve completes;
boolean; defaults to true; example false; pass false to return async id only.
includeZip (boolean, optional) - Whether final status includes the base64 zip; boolean;
defaults to true; example false; set false for smaller responses.
pollIntervalMs (number, optional) - Polling interval in milliseconds; positive number;
defaults to 5000; example 10000; avoid very low values.
maxWaitMs (number, optional) - Maximum polling duration in milliseconds; positive
number; defaults to 1800000; example 600000; use waitForCompletion false for long
retrieves.

Result
raw retrieve response, or { retrieve, status } when polling is enabled.
retrieve (value) - included in the JSON returned by the tool.
status (value) - included in the JSON returned by the tool.

Required permissions
- "Modify Metadata Through Metadata API Functions".

Idempotency & limits
- Read-only on the source org (no changes), safe to retry.
- Each request consumes deploy quota; large retrieves take several minutes.

Errors
- INVALID_TYPE on bad metadata type, REQUEST_LIMIT_EXCEEDED.

Example request

retrieve_metadata({
  "manifest": {},
  "packageNames": [],
  "singlePackage": false
})
