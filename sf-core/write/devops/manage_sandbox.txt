Tool: manage_sandbox

Description
Create / clone / refresh / delete a sandbox. Long-running operations:
the tool returns immediately with a `SandboxProcessId`; clients poll
status with `view_sandbox`.

Salesforce API
Tooling API, v66.0.

Endpoint
POST /services/data/v66.0/tooling/sobjects/SandboxInfo
DELETE /services/data/v66.0/tooling/sobjects/SandboxInfo
PATCH /services/data/v66.0/tooling/sobjects/SandboxProcess
PATCH /services/data/v66.0/tooling/sobjects/SandboxInfo

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "SandboxName": "DEV1", "LicenseType": "DEVELOPER", "Description": "MTG dev sandbox", "AutoActivate": true, "ApexClassId": null, "TemplateId": null, "SourceId": null, "CopyChatter": false, "HistoryDays": 0 }

Input (parameters)
operation ("create" | "clone" | "refresh" | "activate" | "discard" | "delete", required)
- Sandbox lifecycle action; enum string; required; example \"refresh\"; do not pass
monitor-only actions.
sandboxName (string, optional) - SandboxName value; string; required for create/clone
and used to resolve existing sandboxes; example \"UAT\"; do not include the production
org name prefix.
sandboxInfoId (string, optional) - SandboxInfo Id; Salesforce Id string; preferred for
refresh/activate/discard/delete; example \"0GQ...\"; do not pass SandboxProcess Id.
licenseType (string, optional) - Sandbox license type; enum string; required for
create/clone; example \"PARTIAL\"; must match an available license.
description (string, optional) - Sandbox description; string; optional; example \"UAT
refresh for release 12\"; avoid secrets.
sourceSandboxName (string, optional) - Source sandbox name for clone; string; optional;
example \"QA\"; required for clone unless sourceSandboxInfoId is passed.
sourceSandboxInfoId (string, optional) - Source SandboxInfo Id for clone; Salesforce Id
string; optional; example \"0GQ...\"; do not combine with unrelated source names.
templateId (string, optional) - Sandbox template Id; Salesforce Id string; optional for
partial/full copies; example \"0TT...\"; do not pass template names.
apexClassName (string, optional) - Post-copy Apex class name; string; optional and
resolved to ApexClassId; example \"SandboxPostCopy\"; do not include namespace
separators unless that is the class name.
apexClassId (string, optional) - Post-copy ApexClass Id; Salesforce Id string; optional;
example \"01p...\"; use instead of apexClassName when known.
copyChatter (boolean, optional) - Whether Chatter data is copied when supported;
boolean; defaults to false; example false; ignored for license types that do not support
it.
historyDays (number, optional) - Object history days to copy; number; optional; example
30; Salesforce enforces license/template limits.
autoActivate (boolean, optional) - Whether refresh activates automatically when ready;
boolean; defaults to true; example false; only affects refresh.
waitForCompletion (boolean, optional) - Whether to poll latest SandboxProcess; boolean;
defaults to false; example true; long operations can exceed maxWaitMs.
pollIntervalMs (number, optional) - Polling interval in milliseconds; positive number;
defaults to 15000; example 30000; avoid low values.
maxWaitMs (number, optional) - Maximum polling duration in milliseconds; positive
number; defaults to 3600000; example 7200000; sandbox copies can take much longer.

Result
raw Tooling API write response plus optional SandboxProcess query responses.

Required permissions
- "Manage Sandboxes" + run from production.

Idempotency & limits
- Not idempotent.
- Refresh allowed once per `LicenseType`-specific window (Developer: 1/day; Full: 29 days).

Errors
- SANDBOX_LIMIT_EXCEEDED, SANDBOX_REFRESH_TOO_SOON, INVALID_LICENSE_TYPE.

Example request

manage_sandbox({
  "operation": "example"
})
