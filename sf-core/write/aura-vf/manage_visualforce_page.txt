Tool: manage_visualforce_page

Description
Create / update / delete a Visualforce page (`ApexPage`).

Salesforce API
Tooling API, v66.0.

Endpoint
POST /services/data/v66.0/tooling/sobjects/ApexPage

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: Name, MasterLabel, ApiVersion, Markup, ControllerType, ControllerKey, IsAvailableInTouch, IsConfirmationTokenRequired, Description.

Input (parameters)
operation ("create" | "update" | "upsert" | "delete", required) - Requested ApexPage
operation; enum create, update, upsert, or delete; no default; example: 'upsert'; do not
use update for a page that does not exist.
name (string, required) - ApexPage Name field; string API name unique in the org
namespace; no default; example: 'InvoiceSummary'; do not include .page, namespace
prefixes unless part of the API name, or folder paths.
masterLabel (string, optional) - ApexPage MasterLabel; string setup label required for
create and for upsert when creating; no default; example: 'Invoice Summary'; do not pass
an empty label.
apiVersion (number | string, optional) - ApexPage ApiVersion field; number or numeric
string supported by Tooling API, default 66.0 on create/upsert create; example: 66.0; do
not pass REST path strings like 'v66.0'.
markup (string, optional) - ApexPage Markup field; string containing full Visualforce
page markup; required for create/upsert create; example: '<apex:page>Hi</apex:page>'; do
not pass base64 or metadata XML.
controllerType (string, optional) - ApexPage ControllerType; enum Not Specified,
Standard, StandardSet, or Custom; omitted leaves Salesforce default or existing value;
example: 'Custom'; do not pass Apex class names here.
controllerKey (string, optional) - ApexPage ControllerKey; string sObject API name for
Standard/StandardSet or Apex class name for Custom; omitted leaves it unset or
unchanged; example: 'Account'; do not pass a record Id.
isAvailableInTouch (boolean, optional) - ApexPage IsAvailableInTouch flag; boolean
controlling Salesforce mobile availability for related tabs; omitted leaves default or
existing value; example: true; do not pass string booleans.
isConfirmationTokenRequired (boolean, optional) - ApexPage IsConfirmationTokenRequired
flag; boolean controlling CSRF confirmation token requirement for GET requests; omitted
leaves default or existing value; example: true; do not disable unless the page design
requires it.
description (string, optional) - ApexPage Description; string setup description; omitted
leaves existing value unchanged; example: 'Invoice summary page'; do not pass markup
source here.

Result
JSON containing the raw ApexPage lookup plus the raw create, update, or delete Tooling
API response.

Required permissions
- "Customize Application" / "Author Apex".

Idempotency & limits
- upsert idempotent on `name`.

Errors
- DEPLOY_FAILED on syntax error.

Example request

manage_visualforce_page({
  "operation": "upsert",
  "name": "InvoiceSummary"
})
