Tool: manage_validation_rule

Description
Create, update, or delete validation rules. Each rule has a boolean
formula that, when **true**, blocks the save with the configured error
message and (optionally) attaches the message to a specific field.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (writeMetadata ValidationRule)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "operation": "create",
  "object": "Project__c",
  "fullName": "Status_required_when_active",
  "active": true,
  "errorConditionFormula": "ISBLANK(Status__c) && IsActive__c == true",
  "errorMessage": "Status is required for active projects.",
  "errorDisplayField": "Status__c",
  "description": "Active projects must have a status."
}

Input (parameters)
operation ("create" | "update" | "upsert" | "delete", required) - Requested
ValidationRule operation; enum create, update, upsert, or delete; no default; example:
'upsert'; do not use update for a rule that does not exist.
object (string, required) - ValidationRule parent object; string sObject API name; no
default; example: 'Account'; do not pass labels or record Ids.
fullName (string, required) - ValidationRule fullName; string DeveloperName with
optional ObjectApiName prefix; no default; example: 'Require_Industry'; do not include
file extensions or labels.
active (boolean, optional) - ValidationRule active flag; boolean; defaults to true for
create/upsert; example: false; do not pass string booleans.
errorConditionFormula (string, optional) - ValidationRule errorConditionFormula; string
boolean formula required for create/upsert; no default; example: 'ISBLANK(Industry)'; do
not include a leading '='.
errorMessage (string, optional) - ValidationRule errorMessage; string message shown when
the formula evaluates true, required for create/upsert; no default; example: 'Industry
is required.'; do not pass HTML-only content.
errorDisplayField (string, optional) - ValidationRule errorDisplayField; string field
API name for field-level placement; omitted shows page-level error; example: 'Industry';
do not pass labels or relationship paths.
description (string, optional) - ValidationRule description; string metadata
description; omitted leaves existing value unchanged; example: 'Requires Industry on
business accounts'; do not pass formula text here.
metadata (unknown, required).

Result
deploy (object).
validationRule (object) - Updated identity + active flag.

Required permissions
- "Customize Application".

Idempotency & limits
- upsert / update idempotent on equal input.

Errors
- INVALID_FIELD on bad formula.
- COMPILE_ERROR on syntactically invalid formula.

Example request

manage_validation_rule({
  "operation": "upsert",
  "object": "Account",
  "fullName": "Require_Industry",
  "metadata": "example"
})
