Tool: manage_escalation_rule

Description
Manage Case escalation rules (rule entries with criteria + escalation
actions that fire after a record ages without expected progress).

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (writeMetadata EscalationRules)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: minutesToEscalation, ageOverFromField, assignedTo, assignedToType, assignedToTemplate, notifyTo, notifyToTemplate, notifyCaseOwner.
JSON fields: businessHoursSource, escalationAction.
JSON fields: fullName, active, ruleEntry.

Input (parameters)
operation ("create" | "update" | "upsert" | "activate" | "deactivate" | "delete", required) -
Requested EscalationRule operation; enum create, update, upsert, activate, deactivate,
or delete; no default; example: 'deactivate'; do not use update/activate/deactivate for
a rule that is not already in the Case container.
fullName (string, required) -
EscalationRule fullName within the Case container; string DeveloperName without object
prefix; no default; example: 'Priority_Case_Escalation'; do not pass a label or Id.
label (string, optional) -
Human-readable label context; string not written directly unless supplied through
metadata; omitted has no effect; example: 'Priority Case Escalation'; do not rely on it
as the metadata identity.
active (boolean, optional) -
EscalationRule active flag; boolean; defaults to false when creating unless activate is
used; example: true; do not set conflicting active rules.
ruleEntries (object[], optional) -
EscalationRule ruleEntry values; array of criteria and escalation action objects;
omitted changes rule-level fields only; example:
[{\"criteriaItems\":[{\"field\":\"Case.Priority\",\"operation\":\"equals\",\"value\":\"High\"}],\"escalationActions\":[{\"minutesToEscalation\":60,\"notifyCaseOwner\":true,\"notifyToTemplate\":\"Case_Escalation_Notice\"}]}];
do not pass entries without criteria unless that is intentional.
  criteriaItems (object, required).
  formula (string, optional) -
  RuleEntry formula criteria; string formula evaluated by Salesforce; omitted when using
  criteriaItems; example: 'Priority = \"High\"'; do not include leading '='.
  booleanFilter (string, optional) -
  RuleEntry booleanFilter; string combining criteria item indexes; omitted means
  Salesforce default criteria behavior; example: '1 AND 2'; do not reference indexes
  that are not present.
  businessHoursSource (string, optional) -
  RuleEntry businessHoursSource; Metadata API BusinessHoursSourceType enum value;
  omitted uses default business hours; valid values are object API names such as 'Case'
  or 'Account' that have business hours configured; do not pass 'Default' or a
  BusinessHours record Id.
  escalationActions (object[], optional) -
  Escalation actions for the rule entry; array ordered by minutesToEscalation; omitted
  creates criteria without timed actions; example:
  [{\"minutesToEscalation\":60,\"notifyCaseOwner\":true,\"notifyToTemplate\":\"Case_Escalation_Notice\"}];
  notifyCaseOwner and notifyToTemplate are mutually required — always set both together.
metadata (unknown, required).

Result
JSON containing the raw Metadata API read response and raw create or update response for
the Case container.

Required permissions
- "Customize Application".

Idempotency & limits
- update idempotent.

Errors
- INVALID_FIELD on bad criteria.

Example request

manage_escalation_rule({
  "operation": "deactivate",
  "fullName": "Priority_Case_Escalation",
  "metadata": "example"
})
