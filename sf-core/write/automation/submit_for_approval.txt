Tool: submit_for_approval

Description
Submit a record for approval. Triggers the active approval process for
the sObject if entry criteria match. Returns the new ProcessInstance.

Salesforce API
REST API (Process Approvals), v66.0.

Endpoint
POST /services/data/v66.0/process/approvals/

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: actionType, contextId, comments, nextApproverIds, contextActorId, processDefinitionNameOrId, skipEntryCriteria.

Input (parameters)
records (object[], optional) - Approval submit requests; non-empty array posted in one
Process Approvals call; no default; example:
[{\"recordId\":\"006xx000004TmiQAAS\",\"comments\":\"Please approve\"}]; do not mix
unrelated records if partial failure handling is undesirable.
  recordId (string, required) - Process request contextId; string Salesforce record Id
  to submit; no default; example: '006xx000004TmiQAAS'; do not pass object API names or
  approval workitem Ids.
  comments (string, optional) - Process request comments; string stored in approval
  history; omitted sends no comment; example: 'Submitting for discount approval'; do not
  pass sensitive data not intended for approvers.
  nextApproverIds (string[], optional) - Process request nextApproverIds; array of
  Salesforce User Ids required by some processes; omitted lets Salesforce resolve
  approvers; example: ['005xx000001Sv6dAAC']; do not pass usernames or group Ids.
  submitterId (string, optional) - Process request contextActorId; string User Id
  submitting on behalf of another user; omitted uses the session user; example:
  '005xx000001Sv6dAAC'; do not pass a username.
  processDefinitionNameOrId (string, optional) - Process request
  processDefinitionNameOrId; string approval process developer name or Id; omitted lets
  Salesforce choose an eligible active process; example: 'Discount_Approval'; do not
  pass a process label.
  skipEntryCriteria (boolean, optional) - Process request skipEntryCriteria flag;
  boolean used when processDefinitionNameOrId is supplied; default false; example: true;
  do not pass true without explicitly selecting a process.

Result
JSON containing the raw POST /services/data/v66.0/process/approvals/ response.

Required permissions
- The running user must be a permitted submitter for the process.

Idempotency & limits
- Not idempotent — a record already in pending approval can't be re-submitted (NO_APPLICABLE_PROCESS or ALREADY_IN_PROCESS).

Errors
- NO_APPLICABLE_PROCESS, ALREADY_IN_PROCESS, INSUFFICIENT_ACCESS_OR_READONLY.

Example request

submit_for_approval({
  "records": "[{\\\"recordId\\\":\\\"006xx000004TmiQAAS\\\",\\\"comments\\\":\\\"Please approve\\\"}]"
})
