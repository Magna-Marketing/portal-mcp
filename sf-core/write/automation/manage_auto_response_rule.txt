Tool: manage_auto_response_rule

Description
Manage Lead/Case auto-response rules: rule entries that match incoming
records and send an email template back to the submitter.

Salesforce API
Metadata API (SOAP), v66.0.

Endpoint
POST /services/Soap/m/66.0  (writeMetadata AutoResponseRules)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: senderEmail, senderName, replyTo, template, notifyCcRecipients, sortOrder.
JSON fields: fullName, active, ruleEntry.

Input (parameters)
operation ("create" | "update" | "upsert" | "activate" | "deactivate" | "delete", required) -
Requested AutoResponseRule operation; enum create, update, upsert, activate, deactivate,
or delete; no default; example: 'upsert'; do not use update/activate/deactivate for a
rule that is not already in the container.
sObject ("Lead" | "Case", required) -
AutoResponseRules parent object; enum Lead or Case; no default; example: 'Lead'; do not
pass custom objects or labels.
fullName (string, required) -
AutoResponseRule fullName within the parent container; string DeveloperName without
object prefix; no default; example: 'Web_Lead_Response'; do not pass a label or Id.
label (string, optional) -
Human-readable label context; string not written directly unless supplied through
metadata; omitted has no effect; example: 'Web Lead Response'; do not rely on it as the
metadata identity.
active (boolean, optional) -
AutoResponseRule active flag; boolean; defaults to false when creating unless activate
is used; example: true; do not set conflicting active rules for the same object.
ruleEntries (object[], optional) -
AutoResponseRule ruleEntry values; array of criteria and email response objects; omitted
changes rule-level fields only; example:
[{\"sortOrder\":1,\"template\":\"Lead_Auto_Response\"}]; do not pass entries without
criteria unless that is intentional.
  sortOrder (number, optional) -
  RuleEntry sortOrder; number controlling evaluation order; omitted lets Salesforce
  preserve or infer order; example: 1; do not pass decimals or duplicate orders in the
  same rule.
  criteriaItems (object, required).
  formula (string, optional) -
  RuleEntry formula criteria; string formula evaluated by Salesforce; omitted when using
  criteriaItems; example: 'CONTAINS(Email, \"@example.com\")'; do not include leading
  '='.
  booleanFilter (string, optional) -
  RuleEntry booleanFilter; string combining criteria item indexes; omitted means
  Salesforce default criteria behavior; example: '1 AND 2'; do not reference indexes
  that are not present.
  senderEmail (string, optional) -
  RuleEntry senderEmail; string email address used as sender; omitted uses org defaults;
  example: 'support@example.com'; do not pass display-name formats.
  senderName (string, optional) -
  RuleEntry senderName; string display name for response email; omitted uses Salesforce
  default; example: 'Support Team'; do not pass an email address only unless that is the
  intended name.
  replyTo (string, optional) -
  RuleEntry replyTo; string reply-to email address; omitted uses default routing;
  example: 'support@example.com'; do not pass user Ids.
  template (string, optional) -
  RuleEntry template; string email template fullName; omitted sends no configured
  template; example: 'Lead_Auto_Response'; do not pass template Ids.
  notifyCcRecipients (boolean, optional) -
  RuleEntry notifyCcRecipients flag; boolean; omitted leaves Salesforce default;
  example: false; do not pass string booleans.
metadata (unknown, required).

Result
JSON containing the raw Metadata API read response and raw create or update response for
the container.

Required permissions
- "Customize Application".

Idempotency & limits
- update idempotent.

Errors
- INVALID_FIELD on bad criteria.

Example request

manage_auto_response_rule({
  "operation": "upsert",
  "sObject": "Lead",
  "fullName": "Web_Lead_Response",
  "metadata": "example"
})
