Tool: manage_experience_site

Description
Create or update an Experience Cloud site (Network sObject). For LWR/Aura
Experience sites, content/page editing is via the `ExperienceBundle` Metadata
API; this tool covers the site-level identity, status, login policy, and
member preferences.

NOTE: Delete is NOT supported by the Salesforce REST or Connect API. The
Network sObject only supports describeSObjects(), query(), retrieve(), update().
To deactivate a site, use operation "update" with status "DownForMaintenance".

Salesforce API
Connect REST API, v66.0.
REST API (Data), v66.0.

Endpoint
POST /services/data/v66.0/connect/communities
PATCH /services/data/v66.0/sobjects/Network/{id}
GET /services/data/v66.0/query/

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Create Body
{
  "name": "Customer Hub",
  "urlPathPrefix": "customerhub",
  "templateName": "Customer Service",
  "description": "Self-service portal",
  "templateParams": {}
}

Update Body (Network sObject PATCH — fields that are updatable)
{
  "Status": "Live",
  "Description": "Updated description",
  "OptionsAllowMembersToFlag": true
}

Input (parameters)
operation ("create" | "update", required) - Requested site operation; enum create or
update; no default; example: 'create'; do not pass delete because Network delete is not
supported by REST or Connect API.
siteId (string, optional) - Experience Cloud Network record Id; Salesforce 15- or
18-character Id; required for update when siteName is omitted; example:
'0DBxx000000abcD'; do not pass the site URL or domain.
siteName (string, optional) - Experience Cloud site display name; string Name value;
required for create and used to resolve siteId for update when siteId is omitted;
example: 'Customer Hub'; do not pass the developer name unless it is also the display
name.
urlPathPrefix (string, optional) - Site URL path prefix; string path segment appended
under the Experience Cloud domain; required for create and optional for update; example:
'customers'; do not pass a leading slash, full URL, or spaces.
templateName (string, optional) - Experience Builder template name; string matching an
available /connect/communities/templates entry; required for create; example: 'Customer
Service'; do not guess labels that are not available in the target org.
description (string, optional) - Network Description value; string; omitted leaves the
current description unchanged; example: 'Customer self-service portal'; do not pass HTML
expecting rendering.
templateParams (object, optional) - Template-specific creation parameters; object map of
string keys to string values accepted by the selected template; omitted uses template
defaults; example: { 'CreateStoreDefaults': 'ALL' }; do not pass parameters unsupported
by the selected template.
status ("Live" | "DownForMaintenance" | "UnderConstruction", optional) - Network Status
value; enum Live, DownForMaintenance, or UnderConstruction; omitted leaves status
unchanged; example: 'DownForMaintenance'; do not pass UnderConstruction after the site
has been published.
allowMembersToFlag (boolean, optional) - Network OptionsAllowMembersToFlag flag;
boolean; omitted leaves the current value unchanged; example: true; do not pass for
create because Connect creation ignores it.
directMessagesEnabled (boolean, optional) - Network OptionsDirectMessagesEnabled flag;
boolean; omitted leaves the current value unchanged; example: false; do not pass for
create because Connect creation ignores it.
memberVisibility (boolean, optional) - Network OptionsMemberVisibility flag; boolean
controlling whether members can see other members; omitted leaves the current value
unchanged; example: true; do not pass for create because Connect creation ignores it.
invitationsEnabled (boolean, optional) - Network OptionsInvitationsEnabled flag;
boolean; omitted leaves the current value unchanged; example: true; do not pass for
create because Connect creation ignores it.
selfRegistrationEnabled (boolean, optional) - Network OptionsSelfRegistrationEnabled
flag; boolean; omitted leaves the current value unchanged; example: false; do not pass
for create because Connect creation ignores it.
sendWelcomeEmail (boolean, optional) - Network OptionsSendWelcomeEmail flag; boolean;
omitted leaves the current value unchanged; example: true; do not pass for create
because Connect creation ignores it.
guestChatterEnabled (boolean, optional) - Network OptionsGuestChatterEnabled flag;
boolean; omitted leaves the current value unchanged; example: false; do not enable
unless public Chatter access is intended.
nicknameDisplayEnabled (boolean, optional) - Network OptionsNicknameDisplayEnabled flag;
boolean; omitted leaves the current value unchanged; example: true; do not pass for
create because Connect creation ignores it.
privateMessagesEnabled (boolean, optional) - Network OptionsPrivateMessagesEnabled flag;
boolean; omitted leaves the current value unchanged; example: true; do not pass for
create because Connect creation ignores it.
reputationEnabled (boolean, optional) - Network OptionsReputationEnabled flag; boolean;
omitted leaves the current value unchanged; example: true; do not pass for create
because Connect creation ignores it.
recognitionBadgingEnabled (boolean, optional) - Network OptionsRecognitionBadgingEnabled
flag; boolean; omitted leaves the current value unchanged; example: true; do not pass
for create because Connect creation ignores it.
knowledgeableEnabled (boolean, optional) - Network OptionsKnowledgeableEnabled flag;
boolean; omitted leaves the current value unchanged; example: false; do not pass for
create because Connect creation ignores it.

Result (create)
Raw Community Create response: { id, name, url, loginUrl, siteUrl, status, ... }

Result (update)
Updated Network record: { Id, Name, Description, Status, UrlPathPrefix }
(queried via SOQL after PATCH — PATCH itself returns HTTP 204 No Content)

Required permissions
- "Create and Set Up Experiences".

Idempotency & limits
- Create is not idempotent (duplicate urlPathPrefix raises DUPLICATE_VALUE).
- Update is idempotent.

Errors
- DUPLICATE_VALUE on urlPathPrefix.
- NOT_FOUND if siteId or siteName does not match any Network record.

Corrections from original documentation
- The original doc listed PATCH and DELETE on /connect/communities/{communityId}.
  The Connect REST API's /connect/communities/{communityId} endpoint only supports GET.
- Update is correctly done via PATCH /sobjects/Network/{id} (sObject REST API).
- Delete is not supported at all via any REST or Connect API endpoint for Network.
- "templateOptions" body key does not exist; the correct key is "templateParams".
- Status "DownForMaintenance" is the correct spelling (not camelCase).

Example request

manage_experience_site({
  "operation": "create"
})
