Tool: write_apex_trigger

Description
Create, update, or upsert an Apex trigger using the Tooling API v66.0
container/member/save pattern — identical flow to write_apex but using
ApexTriggerMember instead of ApexClassMember.

Salesforce API
Tooling API, v66.0.

Endpoints
POST /services/data/v66.0/tooling/sobjects/MetadataContainer
POST /services/data/v66.0/tooling/sobjects/ApexTriggerMember
POST /services/data/v66.0/tooling/sobjects/ContainerAsyncRequest
GET  /services/data/v66.0/tooling/sobjects/ContainerAsyncRequest/{id}   (poll)
DELETE /services/data/v66.0/tooling/sobjects/MetadataContainer/{id}     (cleanup)
GET  /services/data/v66.0/tooling/query/?q=...                          (lookup existing trigger)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
ApexTriggerMember (create):  { "MetadataContainerId": "<id>", "FullName": "TriggerName",
                                "TableEnumOrId": "Account", "Body": "trigger ..." }
ApexTriggerMember (update):  { "MetadataContainerId": "<id>", "ContentEntityId": "<triggerId>",
                                "Body": "trigger ..." }
ContainerAsyncRequest:       { "MetadataContainerId": "<id>", "IsCheckOnly": false }

Input (parameters)
operation (string, required) - "create" | "update" | "upsert".
name (string, required) - Trigger API name. Must match the declaration in body.
body (string, required) - Full Apex trigger source.
sObject (string, required for create) - sObject API name the trigger fires on (e.g. "Account",
  "Project__c"). Must match the `trigger X on <sObject>` declaration in body.
  Not required for update/upsert (inferred from existing trigger).
apiVersion (number, optional).
status (string, optional, default "Active") - "Active" | "Inactive".
checkOnly (boolean, optional, default false).

Result
Same shape as write_apex:
{
  "deploy": { "containerId", "state", "done", "errorMessage", "componentSuccesses", "componentFailures" },
  "apexTrigger": { "Id", "Name", "ApiVersion", "Status", "IsValid", "TableEnumOrId", "LastModifiedDate" }
}
apexTrigger is null on checkOnly or failure.

Required permissions
- "Author Apex".
- Production deploys require tests with ≥75% org coverage.

Idempotency & limits
- upsert: idempotent on name.
- A trigger name must be unique per org (not per sObject).

Errors
- DEPLOY_FAILED with line/column on compile error.
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

write_apex_trigger({
  "operation": "upsert",
  "name": "ProjectTrigger",
  "sObject": "Project__c",
  "apiVersion": 62.0,
  "body": "trigger ProjectTrigger on Project__c (before insert, before update) {\n    ProjectTriggerHandler.run();\n}\n"
})
