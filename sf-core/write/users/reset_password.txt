Tool: reset_password

Description
Reset a user's password. Two modes:
1. **Send reset email**: triggers Salesforce to email the user a reset
   link. No password is exposed.
2. **Generate temporary password**: returns a one-time password the
   admin can share (the user is forced to change on next login).

Salesforce API
REST API (Data), v66.0. `/sobjects/User/{id}/password` (POST = generate temp password; DELETE = expire current password).

Endpoint
POST  /services/data/v66.0/sobjects/User/{userId}/password    (sets a new password)
DELETE /services/data/v66.0/sobjects/User/{userId}/password   (expires; user must reset)
POST  /services/data/v66.0/sobjects/User/{userId}/passwordResetEmail   (REST API in Connect)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
For POST password: { "NewPassword": "Temp!1234" }   (or omit to let SF generate)

Input (parameters)
userId (string, optional) - Represents the User Id; Salesforce User Id string; required
when username is omitted; example '005xx0000012345'; do not pass Contact Ids.
username (string, optional) - Represents User.Username for lookup; exact username
string; required when userId is omitted; example 'user@example.com'; do not pass display
names.
mode ("sendResetEmail" | "generateTempPassword" | "setPassword", required) - Represents
the password operation; enum sendResetEmail, generateTempPassword, or setPassword; no
default; example 'sendResetEmail'; do not use setPassword without newPassword.
newPassword (string, optional) - Represents the explicit password for setPassword;
string satisfying org policy; required only for mode=setPassword; example
'Use-a-secure-generated-value'; do not pass when requesting Salesforce-generated reset.
includeInactiveUsers (boolean, optional) - Represents whether inactive users can be
resolved; boolean; defaults to true; example false; do not set false when resetting an
inactive user intentionally.

Result
JSON object with mode, userLookup, passwordRequest, and passwordResponse.
mode (value) - included in the JSON returned by the tool.
userLookup (value) - included in the JSON returned by the tool.
passwordRequest (value) - included in the JSON returned by the tool.
passwordResponse (value) - included in the JSON returned by the tool.

Required permissions
- "Reset User Passwords and Unlock Users" / "Manage Internal Users".

Idempotency & limits
- Not idempotent (each call invalidates any prior session).

Errors
- NOT_FOUND, INSUFFICIENT_ACCESS_OR_READONLY, PASSWORD_LOCKOUT (user already locked).

Example request

reset_password({
  "mode": "example"
})
