Tool: unassign_permission_set_license

Description
Remove a Permission Set License assignment from one or more users. Mirrors
`unassign_permission_set`.

Salesforce API
REST API (Data), v66.0.

Endpoint
DELETE /services/data/v66.0/composite/sobjects

Headers
Authorization: Bearer <access_token>

Body
None.

Input (parameters)
permissionSetLicenseName (string, optional) - Represents PermissionSetLicense
DeveloperName, MasterLabel, or PermissionSetLicenseKey; exact string; required when
permissionSetLicenseId is omitted; example 'SalesConsole'; do not pass PermissionSet
names.
permissionSetLicenseId (string, optional) - Represents PermissionSetLicense Id;
Salesforce Id string; required when permissionSetLicenseName is omitted; example
'0PLxx0000001234'; do not pass PermissionSet Ids.
userIds (string[], optional) - Represents users to unassign by Id; array of Salesforce
User Id strings; required when usernames is omitted; example ['005xx0000012345']; do not
pass Contact Ids.
usernames (string[], optional) - Represents users to unassign by Username; array of
exact usernames; required when userIds is omitted; example ['user@example.com']; do not
pass display names.
includeInactiveUsers (boolean, optional) - Represents whether inactive users can be
resolved; boolean; defaults to true; example false; do not set false when revoking from
inactive users.
allOrNone (boolean, optional) - Represents sObject Collections delete rollback behavior;
boolean; defaults to false; example true; do not set true unless one failure should roll
back a batch.
skipIfNotAssigned (boolean, optional) - Represents whether missing assignments are
returned instead of failing; boolean; defaults to true; example false; do not set false
for broad cleanup.
batchSize (integer, optional) - Represents Ids per sObject Collections delete call;
integer 1-200; defaults to 200; example 100; do not exceed the REST collection limit.
dryRun (boolean, optional) - Represents whether to resolve assignments without DELETE
calls; boolean; defaults to false; example true; do not use when assignments must be
removed.

Result
JSON object with dryRun, permissionSetLicenseLookup, userLookup, assignmentLookup,
notAssigned, deleteRequestIds, and deleteResponses.
dryRun (value) - included in the JSON returned by the tool.
permissionSetLicenseLookup (value) - included in the JSON returned by the tool.
userLookup (value) - included in the JSON returned by the tool.
assignmentLookup (value) - included in the JSON returned by the tool.
notAssigned (value) - included in the JSON returned by the tool.
deleteRequestIds (value) - included in the JSON returned by the tool.
deleteResponses (value) - included in the JSON returned by the tool.

Required permissions
- "Manage Internal Users".

Idempotency & limits
- Idempotent with `skipIfNotAssigned=true`.

Errors
- ENTITY_IS_DELETED, INVALID_CROSS_REFERENCE_KEY.

Example request

unassign_permission_set_license({
  "permissionSetLicenseName": "example",
  "permissionSetLicenseId": "example",
  "userIds": []
})
