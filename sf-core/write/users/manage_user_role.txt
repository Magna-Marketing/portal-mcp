Tool: manage_user_role

Description
Manage `UserRole` records: create, update (rename, change parent,
change opportunity/case/contact access settings), delete (only when no
users assigned), or move within hierarchy.

Salesforce API
REST API (Data), v66.0.

Endpoint
POST /services/data/v66.0/sobjects/UserRole
DELETE /services/data/v66.0/sobjects/UserRole/{Id}
PATCH /services/data/v66.0/sobjects/UserRole/{Id}
GET /services/data/v66.0/query/?q=SELECT None, Read, Edit, create, update, delete, move FROM UserRole
GET /services/data/v66.0/query/?q=SELECT None, Read, Edit, create, update, delete, move FROM User

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: Name, DeveloperName, ParentRoleId, OpportunityAccessForAccountOwner, CaseAccessForAccountOwner, ContactAccessForAccountOwner, MayForecastManagerShare, RollupDescription.

Input (parameters)
operation ("create" | "update" | "delete" | "move", required) - Represents the role
operation; enum create, update, delete, or move; no default; example 'move'; do not pass
assign.
fullName (string, optional) - Represents UserRole DeveloperName or Name for lookup;
exact string; required for non-create when roleId is omitted; example 'Sales_Manager';
do not pass labels from profiles.
roleId (string, optional) - Represents UserRole Id; Salesforce Id string; used before
fullName; example '00Exx0000001234'; do not pass Group Ids.
name (string, optional) - Represents UserRole.Name label; string; required for create
and optional for update; example 'Sales Manager'; do not pass the developer name unless
intended as label.
developerName (string, optional) - Represents UserRole.DeveloperName; API name string;
defaults from fullName or name on create; example 'Sales_Manager'; do not include
spaces.
parentRoleId (string, optional) - Represents parent UserRole Id; Salesforce Id string;
used before parentRoleName; example '00Exx0000009999'; do not pass Group Ids.
parentRoleName (string, optional) - Represents parent UserRole DeveloperName or Name;
exact string; used when parentRoleId is omitted; example 'Sales_VP'; do not pass profile
names.
opportunityAccessForAccountOwner (string, optional) - Represents
UserRole.OpportunityAccessForAccountOwner; enum None, Read, or Edit; omitted leaves
unchanged on update; example 'Read'; do not pass All.
caseAccessForAccountOwner (string, optional) - Represents
UserRole.CaseAccessForAccountOwner; enum None, Read, or Edit; omitted leaves unchanged
on update; example 'Edit'; do not pass All.
contactAccessForAccountOwner (string, optional) - Represents
UserRole.ContactAccessForAccountOwner; enum None, Read, or Edit; omitted leaves
unchanged on update; example 'Read'; do not pass All.
mayForecastManagerShare (boolean, optional) - Represents
UserRole.MayForecastManagerShare; boolean; omitted leaves unchanged; example true; do
not pass forecasting profile settings.
description (string, optional) - Represents role description stored in
RollupDescription; string; omitted leaves unchanged; example 'Western sales managers';
do not pass HTML scripts.
allowDeleteWithUsers (boolean, optional) - Represents whether delete proceeds when
assigned users exist; boolean; defaults to false; example true; do not enable unless
reassignment impact is understood.
checkOnly (boolean, optional) - Represents whether to build payloads without write APIs;
boolean; defaults to false; example true; do not use when changes must be saved.

Result
JSON object with operation, checkOnly, lookup responses, payloads, and raw write
responses.

Required permissions
- "Manage Roles" / "Customize Application".

Idempotency & limits
- Update is idempotent on equal input.
- Delete refuses when users are still assigned to the role.
- Move is idempotent on equal input.

Errors
- DUPLICATE_DEVELOPER_NAME (create), CIRCULAR_DEPENDENCY (move), CANNOT_DELETE_ROLE (users assigned).

Example request

manage_user_role({
  "operation": "example"
})
