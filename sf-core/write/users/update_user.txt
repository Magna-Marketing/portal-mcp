Tool: update_user

Description
Update one or many users. Common operations: deactivate, freeze /
unfreeze, change profile, change role, change manager, change name,
change email, change federation identifier, change timezone/locale.
Bulk-friendly: pass `users[]` for batch updates.

Note: **deactivation** = `IsActive=false` (frees license, removes
session). **Freeze** uses `UserLogin.IsFrozen=true` (keeps license,
blocks login).

Salesforce API
REST API (Data), v66.0.

Endpoint
PATCH /services/data/v66.0/composite/sobjects

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
JSON fields: Username, IsActive, Email, FirstName, LastName, Alias, Department, Title, Phone, MobilePhone, TimeZoneSidKey, LocaleSidKey, LanguageLocaleKey, EmailEncodingKey, FederationIdentifier, Division, EmployeeNumber.
JSON fields: ProfileId, UserRoleId, ManagerId.

Input (parameters)
users (unknown[], required) - Represents users and changes to apply; non-empty array
where each entry has userId or username plus at least one update field; no default;
example [{\"username\":\"user@example.com\",\"isActive\":false}]; do not pass empty
update objects.
includeInactiveUsers (boolean, optional) - Represents whether inactive users can be
resolved; boolean; defaults to true; example false; do not set false when reactivating
users.
allOrNone (boolean, optional) - Represents sObject Collections rollback behavior for
User and UserLogin updates; boolean; defaults to false; example true; do not set true
unless one failure should roll back a batch.
batchSize (integer, optional) - Represents records per sObject Collections update call;
integer 1-200; defaults to 200; example 100; do not exceed the REST collection limit.
dryRun (boolean, optional) - Represents whether to resolve and build payloads without
PATCH calls; boolean; defaults to false; example true; do not use when updates must be
saved.

Result
JSON object with dryRun, lookup responses, resolvedInputs, request records, and raw
update response arrays.
dryRun (value) - included in the JSON returned by the tool.
userLookup (value) - included in the JSON returned by the tool.
userLoginLookup (value) - included in the JSON returned by the tool.
resolvedInputs (value) - included in the JSON returned by the tool.
userUpdateRequestRecords (value) - included in the JSON returned by the tool.
userUpdateResponses (value) - included in the JSON returned by the tool.
userLoginUpdateRequestRecords (value) - included in the JSON returned by the tool.
userLoginUpdateResponses (value) - included in the JSON returned by the tool.

Required permissions
- "Manage Internal Users" + "Manage Profiles and Permission Sets" for profile changes.

Idempotency & limits
- Idempotent on equal input.
- Composite cap: 200 per call; tool batches.

Errors
- INVALID_CROSS_REFERENCE_KEY, DUPLICATE_VALUE, INSUFFICIENT_ACCESS_OR_READONLY.

Example request

update_user({
  "users": []
})
