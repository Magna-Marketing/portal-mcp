Tool: manage_custom_redirect

Description
Create, update, or delete a Custom Redirect. Custom Redirects
attribute clicks to a campaign and translate a vanity URL on a
tracker domain into a destination URL with optional UTM parameters.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST   https://{pi-domain}/api/v5/objects/custom-redirects        (create)
PATCH  https://{pi-domain}/api/v5/objects/custom-redirects/:id    (update)
DELETE https://{pi-domain}/api/v5/objects/custom-redirects/:id    (delete)

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body (create)
{
  "name": "Spring promo",
  "destinationUrl": "https://magnatech.com/spring",
  "campaignId": 1024,
  "trackerDomainId": 7,
  "vanityUrlPath": "r/spring",
  "gaSource": "email",
  "gaMedium": "promo",
  "gaCampaign": "spring-2026"
}

Input (parameters)
operation ("create" | "update" | "delete", required) - "create" creates a new custom redirect; "update" modifies it; "delete" soft-deletes it.
id (number, optional) - Custom redirect id. Required for update and delete.
name (string, optional) - Display name for the redirect. Required for create.
destinationUrl (string, optional) - The URL visitors are redirected to. Required for create.
campaignId (number, optional) - Campaign to attribute clicks to. Required for create.
trackerDomainId (number, optional) - Tracker domain hosting the vanity URL.
vanityUrlPath (string, optional) - Slug appended to the tracker domain (e.g. "r/spring-promo").
folderId (number, optional) - Folder to organize the redirect in.
gaSource (string, optional) - Google Analytics utm_source value.
gaMedium (string, optional) - Google Analytics utm_medium value.
gaTerm (string, optional) - Google Analytics utm_term value.
gaContent (string, optional) - Google Analytics utm_content value.
gaCampaign (string, optional) - Google Analytics utm_campaign value.
bitlyIsPersonalized (boolean, optional) - Use a personalized bit.ly short URL.

Result
Raw Account Engagement response JSON, returned unchanged.
Also included when present: deleted.

Required scopes
- `pardot_api`.

Idempotency & limits
- Soft-delete via `delete`; the row remains queryable with
  `isDeleted=true`.

Errors
- 600 duplicate_vanity (path collision on tracker domain),
  53 tracker_domain_not_validated, 59 not_found.

Example request

manage_custom_redirect({
  "operation": ""
})

Example result

{ }
