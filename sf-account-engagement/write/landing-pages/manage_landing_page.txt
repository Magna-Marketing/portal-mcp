Tool: manage_landing_page

Description
Create a Landing Page. v5 supports `Create` only on landing pages
(no PATCH / DELETE on existing rows). To change content, recreate
the LP and update the redirecting traffic source.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/landing-pages

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: archiveDate, campaignId, content, description, folderId, formId, isDoNotIndex, layoutTemplateId, name, openingGeneralContent, redirectLocation, regionContent, scriptFragment, title, trackerDomainId, vanityUrlPath

Input (parameters)
operation ("create", required) - Only "create" is supported by the v5 API for landing pages.
name (string, required) - Landing page display name. Required.
campaignId (number, required) - Campaign to attribute visits and conversions to. Required.
title (string, optional) - The landing page title shown in the browser tab.
description (string, optional) - The landing page's meta description. Used for SEO.
folderId (number, optional) - Folder to organize the landing page in.
trackerDomainId (number, optional) - Tracker domain for the landing page URL.
layoutTemplateId (number, optional) - Layout template id. Required when using a layout template (with or without regions).
formId (number, optional) - Form id to associate with the landing page.
vanityUrlPath (string, optional) - URL slug appended to the tracker domain (e.g. "spring-2026").
content (string, optional) - HTML content for landing pages using a stock template (Landing Page Builder). Do not
provide layoutTemplateId when using this field.
openingGeneralContent (string, optional) - HTML placed in the %%form-opening-general-content%% tag. Used with layout templates that
do NOT have pardot-region attributes.
regionContent (object, optional) - JSON object overriding region defaults in a layout template that has pardot-region
attributes. Keys are region names; values are objects with region-type fields (e.g.
src/alt/href/content).
scriptFragment (string, optional) - Script specified for a landing page using a stock template. Not queryable.
isDoNotIndex (boolean, optional) - True to add a noindex meta tag and hide the page from search engines.
redirectLocation (string, optional) - URL to redirect prospects to (used when isUseRedirectLocation is true on the record).
archiveDate (string, optional) - Date on which the landing page is archived, in 'yyyy-mm-dd' format.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Not idempotent.

Errors
- 600 duplicate_vanity, 53 tracker_domain_not_validated, 59 not_found.

Example request

manage_landing_page({
  "operation": "",
  "name": "",
  "campaignId": 1
})

Example result

{ }
