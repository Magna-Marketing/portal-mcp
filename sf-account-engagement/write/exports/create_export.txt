Tool: create_export

Description
Start an async export of a filtered set of records from a single
object. Choose one of the canned procedures
(`Prospect.FilterByCreatedAt`, `ListMembership.FilterByUpdatedAt`,
`VisitorActivity.FilterByCreatedAt`, etc.) and pass `arguments` for
the date range.

Poll status with `get_export`; once `status=Complete`, walk
`resultRefs` and download chunks via `download_export_results`.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/exports

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: fields, includeByteOrderMark, maxFileSizeBytes, procedure

Input (parameters)
procedure (string, required) - Export procedure name including object prefix. Examples: "Prospect.FilterByUpdatedAt",
"Prospect.FilterByCreatedAt", "VisitorActivity.FilterByActivityDate". Required.
arguments (object, required) - Procedure-specific filter arguments nested inside the procedure object. Key names depend
on the procedure (e.g. "updatedAfter", "updatedBefore" as ISO-8601 strings). Required.
fields (string[], required) - Array of field names to include in the export output. Required.
maxFileSizeBytes (number, optional) - Maximum size per result chunk file in bytes. Defaults to 250 MB.
includeByteOrderMark (boolean, optional) - When true, includes a UTF-8 BOM at the start of each CSV chunk.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Not idempotent. Up to 5 concurrent exports per BU.
- Result CSV chunks ≈ 250MB each, retained 30 days.

Errors
- 20 invalid_input (procedure not allowed for object), 184
  daily_limit_reached, 53 concurrency_limit (5 concurrent exports
  per BU).

Example request

create_export({
  "procedure": "",
  "arguments": {},
  "fields": []
})
