Tool: merge_tags

Description
Merge one or more source tags into a single target tag. All
`tagged-objects` rows pointing at the source tags are rewritten to
point at the target, and the source tags are deleted. Use this to
clean up duplicate or near-duplicate tag names ("Welcome 2026" vs
"welcome-2026").

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/tags/{mainTagId}/do/merge

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: mergeTagIds

Input (parameters)
mainTagId (number, required) - Tag id of the tag to keep. All tag-object associations from the source tags will be
moved here.
mergeTagIds (number[], required) - Tag ids to merge into the mainTag. These tags will be deleted after the merge.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Not idempotent — merging the same source tags twice is a no-op
  on the second call (already deleted).

Errors
- 53 not_permitted, 59 not_found, 600 self_merge (target id appears
  in sourceTagIds).

Example request

merge_tags({
  "mainTagId": 1,
  "mergeTagIds": []
})

Example result

{ }
