Tool: manage_form_field_options

Description
Manage the picklist values, dependents, and progressive-profiling
config on a Form Field. The v5 API exposes three separate sub-
actions; this tool unifies them under `subOperation`:

- `addValue` — append a picklist value (Dropdown / Radio / Multi /
  Checkbox fields).
- `addDependent` — add a child field that's shown only when this
  field has a specific value.
- `addProgressive` — add a progressive-profiling rule that swaps
  this field for another on subsequent visits.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/form-fields/:id/do/addValue
POST https://{pi-domain}/api/v5/objects/form-fields/:id/do/addDependent
POST https://{pi-domain}/api/v5/objects/form-fields/:id/do/addProgressive

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: replacementProspectApiFieldId, sortOrder

Input (parameters)
id (number, required) - Form field id to operate on. Required.
subOperation ("addValue" | "addDependent" | "addProgressive", required) - "addValue" appends a picklist value; "addDependent" adds a conditional child field;
"addProgressive" adds a progressive-profiling replacement rule.
value (string, optional) - Picklist value text. Required for subOperation="addValue".
isDefault (boolean, optional) - Mark this picklist value as the default selection. Used with addValue. Default false.
sortOrder (number, optional) - Display order for the picklist value or progressive rule. Used with addValue and
addProgressive.
dependentFormFieldId (number, optional) - Form field id to show conditionally. Required for subOperation="addDependent".
triggerValue (string, optional) - The picklist value that triggers showing the dependent field. Required for
subOperation="addDependent".
replacementProspectApiFieldId (string, optional) - Prospect apiFieldId of the field shown on return visits. Required for
subOperation="addProgressive".

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- `addValue` is idempotent on (formFieldId, value).
- `addDependent` / `addProgressive` accumulate — repeated calls
  add duplicate rules.

Errors
- 20 invalid_input, 53 not_permitted, 59 not_found.

Example request

manage_form_field_options({
  "id": 1,
  "subOperation": ""
})

Example result

{ }
