Tool: manage_form

Description
Create or delete a Form. v5 supports `Create` and `Delete` only on
forms (no PATCH); to update, recreate or use the UI. Soft-delete is
the default — `undelete_form` brings the form back within the 90-day
retention window.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST   https://{pi-domain}/api/v5/objects/forms       (operation="create")
DELETE https://{pi-domain}/api/v5/objects/forms/:id   (operation="delete")

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: afterFormContent, beforeFormContent, campaignId, checkboxAlignment, folderId, fontColor, fontFamily, fontSize, isAlwaysDisplay, isCaptchaEnabled, isCookieless, isUseRedirectLocation, labelAlignment, layoutTemplateId, name, radioAlignment, redirectLocation, requiredCharacter, showNotProspect, submitButtonText, tagReplacementLanguage, thankYouCode, thankYouContent, trackerDomainId

Input (parameters)
operation ("create" | "delete", required) - "create" creates a new form; "delete" soft-deletes it (restorable within 90 days via
undelete_form).
id (number, optional) - Form id. Required for delete.
name (string, optional) - Form display name. Required for create.
campaignId (number, optional) - Campaign to attribute form submissions to. Required for create.
folderId (number, optional) - Folder to organize the form in.
trackerDomainId (number, optional) - Tracker domain for the embedded form URL.
layoutTemplateId (number, optional) - Layout template id to wrap the form in branded HTML.
thankYouContent (string, optional) - Inline HTML shown after successful submission.
thankYouCode (string, optional) - Custom JS or pixel-firing code executed on submit.
isUseRedirectLocation (boolean, optional) - Redirect to a URL instead of showing thankYouContent. Default false.
redirectLocation (string, optional) - Redirect URL. Used when isUseRedirectLocation=true.
beforeFormContent (string, optional) - HTML displayed above the form fields.
afterFormContent (string, optional) - HTML displayed below the form fields.
submitButtonText (string, optional) - Label for the submit button. Default "Submit".
isCaptchaEnabled (boolean, optional) - Enable reCAPTCHA on the form. Default true.
isCookieless (boolean, optional) - Disable cookie-based visitor tracking. Default false.
isAlwaysDisplay (boolean, optional) - Show the form to already-identified prospects. Default false.
showNotProspect (boolean, optional) - Show the form to visitors with no prospect record. Default false.
fontFamily (string, optional) - CSS font-family for the form.
fontSize (string, optional) - CSS font-size for the form (e.g. "14px").
fontColor (string, optional) - CSS color for the form text (e.g. "#333333").
labelAlignment ("above" | "left" | "right", optional) - Position of field labels relative to inputs.
radioAlignment (string, optional) - Alignment for radio button groups.
checkboxAlignment (string, optional) - Alignment for checkbox groups.
requiredCharacter (string, optional) - Character appended to required field labels. Default "*".
tagReplacementLanguage (string, optional) - HML rendering language. Default "ENGLISH".

Result
Raw Account Engagement response JSON, returned unchanged.
Also included when present: deleted.

Required scopes
- `pardot_api`.

Idempotency & limits
- Soft delete; restore via `undelete_form` within 90 days.

Errors
- 53 not_permitted, 600 missing_required_field.

Example request

manage_form({
  "operation": ""
})

Example result

{ }
