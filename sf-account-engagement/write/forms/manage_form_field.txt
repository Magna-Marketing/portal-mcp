Tool: manage_form_field

Description
Create a Form Field on an existing Form. v5 supports `Create` only
on form-fields (PATCH / DELETE not exposed); to remove a field,
delete and recreate the parent form, or rebuild the field list
through `reorder_form_fields`.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/form-fields

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: cssClasses, dataFormat, description, errorMessage, formId, isAlwaysDisplay, isDoNotPrefill, isMaintainInitialValue, isRequired, label, prospectApiFieldId, type

Input (parameters)
operation ("create", required) - Only "create" is supported by the v5 API for form fields.
formId (number, required) - Id of the parent form. Required.
prospectApiFieldId (string, required) - Prospect field apiFieldId to map this form field to. Standard fields use the field name
(e.g. "firstName", "email"). Custom fields append __c (e.g. "region__c"). Required.
type ("text" | "textarea" | "email" | "number" | "radio button" | "checkbox" | "dropdown" | "multiselect" | "hidden" | "date" | "crm user", required) - Data type / input type of the form field. Required.
dataFormat ("text" | "email" | "number" | "phone" | "date" | "url", optional) - Validation format to apply to the input. Defaults to "text". Required.
label (string, optional) - Display label shown to form visitors.
description (string, optional) - Internal description for the field (not queryable via API).
errorMessage (string, optional) - Error message shown when the field fails validation or is required but empty.
cssClasses (string, optional) - CSS class names applied to the paragraph element wrapping the form input and label.
isRequired (boolean, optional) - Whether the field is required for form submission. Default false.
isAlwaysDisplay (boolean, optional) - Show the field even to prospects who already have a value. Default false.
isMaintainInitialValue (boolean, optional) - Do not overwrite the prospect field if it already has a value. Default false.
isDoNotPrefill (boolean, optional) - Prevent prospect data from being pre-filled into the field. Default false.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Not idempotent.

Errors
- 53 form_locked, 600 invalid_prospect_field, 59 not_found.

Example request

manage_form_field({
  "operation": "",
  "formId": 1,
  "prospectApiFieldId": "",
  "type": ""
})

Example result

{ }
