Tool: assign_prospect

Description
Assign or unassign a prospect. Send `assignedToUserId` to assign a
user, or `assignedToUserGroupId` to round-robin within a group.
When both are omitted, the prospect is unassigned.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/prospects/{id}/do/assign

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: assignedToUserGroupId, assignedToUserId

Input (parameters)
id (number, required) - Pardot prospect id to assign.
assignedToUserId (number, optional) - Pardot user id to assign the prospect to. If omitted the prospect is unassigned.
assignedToUserGroupId (number, optional) - Pardot user group id. When supplied the prospect is round-robined within the group.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Idempotent: re-assigning to the same target is a no-op.

Errors
- 59 prospect_not_found, 53 user_not_authorized, 4 invalid_user_id.

Example request

assign_prospect({
  "id": 1
})

Example result

{ }
