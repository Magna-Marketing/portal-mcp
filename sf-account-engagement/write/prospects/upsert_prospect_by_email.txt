Tool: upsert_prospect_by_email

Description
Idempotent prospect upsert keyed on email. The recommended write
for inbound integrations: repeat calls with the same email return
the same prospect, preserving id and existing relationships.
Behavior:

- Email match found → update the matched prospect with the supplied
  fields (only fields you pass are changed).
- No match → create a new prospect.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/prospects/do/upsertLatestByEmail

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: address1, address2, annualRevenue, assignedToUserId, campaignId, city, company, country, department, email, employees, fax, firstName, grade, industry, isDoNotCall, isDoNotEmail, isOptedOut, isReviewed, isStarred, jobTitle, lastName, mobilePhone, notes, phone, prospectAccountId, salesforceId, salutation, score, state, website, zip
Custom field values from customFields are copied onto the top level of this body.

Input (parameters)
email (string, required) - Prospect email address (lookup key for upsert).
firstName (string, optional) - Prospect first name.
lastName (string, optional) - Prospect last name.
salutation (string, optional) - Salutation (e.g. "Mr.", "Dr.").
company (string, optional) - Company name.
jobTitle (string, optional) - Job title.
department (string, optional) - Department.
industry (string, optional) - Industry.
phone (string, optional) - Phone number.
mobilePhone (string, optional) - Mobile phone number.
fax (string, optional) - Fax number.
website (string, optional) - Website URL.
address1 (string, optional) - Address line 1.
address2 (string, optional) - Address line 2.
city (string, optional) - City.
state (string, optional) - State or province.
zip (string, optional) - Postal code.
country (string, optional) - Country.
annualRevenue (string|number, optional) - Annual revenue.
employees (string|number, optional) - Number of employees.
notes (string, optional) - Internal notes.
campaignId (number, optional) - Campaign to attribute the prospect to.
assignedToUserId (number, optional) - Pardot user id to assign the prospect to.
prospectAccountId (number, optional) - Prospect account id to link the prospect to.
isDoNotEmail (boolean, optional) - Do not send email to this prospect.
isDoNotCall (boolean, optional) - Do not call this prospect.
isOptedOut (boolean, optional) - Global email opt-out (different from per-list opt-out).
isReviewed (boolean, optional) - Mark the prospect as reviewed.
isStarred (boolean, optional) - Star the prospect for visibility.
score (number, optional) - Prospect score (0–100 typical range, or custom).
grade (string, optional) - Letter grade ("A+" through "F").
salesforceId (string, optional) - Salesforce Lead/Contact id cross-reference.
customFields (object, optional) - Custom field values keyed by apiFieldId (e.g. { "region__c": "EMEA" }).

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Idempotent on `matchEmail`. Repeat calls return the same
  prospect id.
- Subject to BU `apiCallsUsed` quota.

Errors
- 11 invalid_email, 12 multiple_email_matches (if BU has duplicate
  emails — fix by enabling email uniqueness), 184 daily_limit_reached.

Example request

upsert_prospect_by_email({
  "email": ""
})
