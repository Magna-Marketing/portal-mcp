Tool: manage_custom_field

Description
Create, update, or delete a Prospect Custom Field. The `apiFieldId`
is the stable name used in prospect writes; choose a snake-case
identifier ending in `__c` to mirror SFDC custom-field convention.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST   https://{pi-domain}/api/v5/objects/custom-fields                  (operation="create")
PATCH  https://{pi-domain}/api/v5/objects/custom-fields/:id              (operation="update")
DELETE https://{pi-domain}/api/v5/objects/custom-fields/:id              (operation="delete")

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: isRecordMultipleResponses, isRequired, isUseValues, name, salesforceId
PATCH: isRecordMultipleResponses, isRequired, isUseValues, name, salesforceId

Input (parameters)
operation ("create" | "update" | "delete", required) - "create" creates a new custom field; "update" modifies an existing one; "delete"
permanently removes it.
id (number, optional) - Custom field id. Required for update and delete.
name (string, optional) - Display name of the custom field. Required for create.
fieldId (string, optional) - Internal UI-visible id for the field. Required for create. Immutable after creation.
apiFieldId (string, optional) - Read-only. Auto-generated by Pardot from fieldId (e.g. fieldId "region" → apiFieldId
"region__c"). Cannot be set on create or update.
type ("TEXT" | "DROPDOWN" | "RADIO_BUTTON" | "CHECKBOX" | "MULTI_SELECT" | "TEXTAREA" | "DATE" | "NUMBER" | "CRM_USER" | "HIDDEN", optional) - Field type. Required for create.
isRequired (boolean, optional) - Whether the field is required on form submissions. Default false.
isUseValues (boolean, optional) - Whether the field uses a predefined picklist of values (for DROPDOWN, RADIO_BUTTON,
etc.). Default false.
isRecordMultipleResponses (boolean, optional) - Allow recording multiple form responses for this field. Default false.
salesforceId (string, optional) - Salesforce field ID to map this custom field to a SFDC field.

Result
customField (object) - Created/updated row.
deleted (boolean, when operation="delete").

Required scopes
- `pardot_api`.

Idempotency & limits
- Hard delete: deleted custom fields cannot be restored. Existing
  prospect data on the field is preserved as orphaned values.
- 100 custom fields per BU on Pro tier; 200 on Plus / Advanced /
  Premium.

Errors
- 53 not_permitted, 49 readonly_field (api_field_id immutable on
  update), 600 duplicate_api_field_id, 11 limit_reached.

Example request

manage_custom_field({
  "operation": ""
})

Example result
{
  "customField": { "id": 71, "name": "Region", "apiFieldId": "region__c",
    "type": "DROPDOWN", "isUseValues": true }
}
