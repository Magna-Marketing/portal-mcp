Tool: manage_dynamic_content_variation

Description
Create a variation rule on a Dynamic Content block. Variations are
ordered; the first matching rule wins, otherwise `baseContent`
falls through.

v5 supports `Create` only — no PATCH / DELETE on variations. To
remove or reorder, recreate the parent Dynamic Content block.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/dynamic-content-variations

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: content, dynamicContentId, operator, value1, value2

Input (parameters)
operation ("create", required) - Only "create" is supported by the v5 API for dynamic content variations.
dynamicContentId (number, required) - Id of the parent Dynamic Content block. Required.
operator ("is" | "contains" | "between" | "less-than" | "less-than-or-equal" | "greater-than" | "greater-than-or-equal", required) - Comparison operator for the variation rule. Required.
value1 (string, required) - Primary comparison value. Required.
value2 (string, optional) - Secondary value. Required when operator="between".
content (string, required) - HTML content rendered when this variation rule matches. Required.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Not idempotent.

Errors
- 20 invalid_input (operator / comparison mismatch),
  59 not_found (dynamicContentId).

Example request

manage_dynamic_content_variation({
  "operation": "",
  "dynamicContentId": 1,
  "operator": "",
  "value1": "",
  "content": ""
})

Example result

{ }
