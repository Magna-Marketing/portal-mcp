Tool: manage_dynamic_content

Description
Create or "manage" a Dynamic Content block. v5 supports `Create`
only on dynamic content (no PATCH / DELETE on the parent block);
this tool exposes `create` and "soft delete via tag" as the
practical update operations. To replace a block, create a new one
and update the consumers (emails, landing pages) to point at the
new id.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/dynamic-contents

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: baseContent, basedOnProspectApiFieldId, embedCode, folderId, name, trackerDomainId

Input (parameters)
operation ("create", required) - Only "create" is supported by the v5 API for dynamic content blocks.
name (string, required) - Display name for the dynamic content block. Required.
folderId (number, optional) - Folder to organize the block in.
basedOnProspectApiFieldId (string, required).
trackerDomainId (number, optional) - Tracker domain for the embed script.
baseContent (string, required) - Default HTML content shown when no variation rule matches. Required.
embedCode (string, optional) - Override the auto-generated embed <script> tag. Leave blank to use the generated code.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Not idempotent — repeated calls create duplicates.

Errors
- 20 invalid_input, 53 not_permitted.

Example request

manage_dynamic_content({
  "operation": "",
  "name": "",
  "basedOnProspectApiFieldId": "",
  "baseContent": ""
})

Example result

{ }
