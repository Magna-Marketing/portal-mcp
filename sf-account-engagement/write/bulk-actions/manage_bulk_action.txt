Tool: manage_bulk_action

Description
Create or update a Bulk Action on a list of prospect ids. Create
uploads a CSV of ids plus a JSON input part (`object` is Prospect,
and `bulkAction` is delete or permanentdelete). Update changes the
job status. Async — poll `get_bulk_action` until `status` is
terminal.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/bulk-actions
Optional query: fields
PATCH https://{pi-domain}/api/v5/bulk-actions/{id}

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: multipart/form-data (create) or application/json (update)
Accept: application/json

Body
POST multipart parts: file, input
The input part is JSON: object (Prospect), bulkAction, status, and sendSystemEmail when provided.
The file part is a CSV of prospect ids.
PATCH: status

Input (parameters)
operation ("create" | "update", required) - "create" starts a new bulk action job; "update" pauses, resumes, or cancels an existing
job.
id (number, optional) - Bulk action job id. Required when operation is "update".
prospectIds (number[], optional) - Array of prospect IDs to process. Required when operation is "create". Maximum 100,000
IDs per request.
bulkAction ("delete" | "permanentdelete", optional) - "delete" moves prospects to the recycle bin; "permanentdelete" permanently removes them
from the recycle bin. Required when operation is "create".
status ("Ready" | "Paused" | "Cancelled", optional) - Initial status when creating ("Ready" or "Paused"), or target status when updating
("Paused" to pause, "Ready" to resume, "Cancelled" to cancel).
sendSystemEmail (boolean, optional) - When true, sends a notification email to the API user when the job reaches a final
status (Complete, Cancelled, or Failed).
fields (string, optional) - Comma-separated list of fields to return in the response. Defaults to
id,status,bulkAction,object,count,errorCount,createdAt,updatedAt.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Not idempotent — each call queues a new job.
- 50,000 record cap per job; larger sets need multiple bulk actions.
- 1 in-flight bulk action per BU at a time (others queue).

Errors
- 20 invalid_input (bad filter), 53 not_permitted (user lacks
  bulk-action right), 184 daily_limit_reached.

Example request

manage_bulk_action({
  "operation": ""
})

Example result
