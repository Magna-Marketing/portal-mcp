Tool: send_list_email

Description
Fire (or schedule) a List Email blast. v5 exposes only
`Create` on list emails; the actual send still uses the legacy v4
endpoint `/api/email/version/4/do/send`. The MCP server wraps both
the v5 draft and the v4 fire so callers see a single tool.

Use `send_one_to_one_email` for single-recipient transactional sends.

Salesforce API
Account Engagement v4 (legacy XML).

Endpoint
POST https://{pi-domain}/api/email/version/4/do/send/list_email_id/{listEmailId}
Optional query: format

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/x-www-form-urlencoded
Accept: application/json

Body
POST: campaign_id, client_reference, email_template_id, from_email, from_name, from_user_id, prospect_id, send_date

Input (parameters)
listEmailId (number, required) - Id of the list email draft to send. Obtain from create_list_email_draft.
operation ("send" | "test", optional) - "send" sends to the full list; "test" sends to a single prospect for QA.
testProspectId (number, optional) - Prospect id to send the test to. Required when operation="test".
sendDate (string, optional) - ISO-8601 datetime to schedule the send. If omitted, the email is sent immediately.
clientReference (string, optional) - Caller-supplied deduplication key. Repeated calls with the same key within the same hour
are no-ops.
campaignId (number, optional) - Campaign id. Required by v4 send API. Pass the same campaign id used when creating the
draft.
emailTemplateId (number, optional) - Email template id. Required by v4 send API unless providing inline content. Pass the
same id used when creating the draft.
fromUserId (number, optional) - Pardot user id to send from. Alternative to emailTemplateId + from_name/from_email.
fromName (string, optional) - Sender display name. Required when not using emailTemplateId or fromUserId.
fromEmail (string, optional) - Sender email address. Required when not using emailTemplateId or fromUserId.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Idempotent only when `clientReference` matches a prior call within
  the same hour; otherwise repeated calls send the email twice.
- Subject to BU send-rate ceilings.

Errors
- 71 list_email_already_sent (cannot resend a sent list email),
  15 daily_send_limit_reached, 53 not_permitted, 59 not_found.

Example request

send_list_email({
  "listEmailId": 1
})
