Tool: manage_email_template

Description
Create, update, or delete an Email Template. Templates feed
auto-responders, drip campaigns, list emails, and one-to-one sends.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST   https://{pi-domain}/api/v5/objects/email-templates       (create)
PATCH  https://{pi-domain}/api/v5/objects/email-templates/:id   (update)
DELETE https://{pi-domain}/api/v5/objects/email-templates/:id   (delete)

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: campaignId, folderId, htmlMessage, isAutoResponderEmail, isDripEmail, isListEmail, isOneToOneEmail, name, replyToOptions, senderOptions, subject, textMessage, trackerDomainId, type
PATCH: campaignId, folderId, htmlMessage, isAutoResponderEmail, isDripEmail, isListEmail, isOneToOneEmail, name, replyToOptions, senderOptions, subject, textMessage, trackerDomainId, type

Input (parameters)
operation ("create" | "update" | "delete", required) - "create" creates a new email template; "update" modifies it; "delete" permanently
removes it.
id (number, optional) - Email template id. Required for update and delete.
name (string, optional) - Template name. Required for create.
subject (string, optional) - Email subject line. Required for create.
htmlMessage (string, optional) - HTML email body.
textMessage (string, optional) - Plain-text fallback body. Defaults to empty string if omitted.
type ("HtmlAndText" | "HtmlOnly" | "TextOnly", optional) - Template type. Default "HtmlAndText".
isOneToOneEmail (boolean, optional) - Mark template as suitable for one-to-one sends.
isAutoResponderEmail (boolean, optional) - Mark template as an auto-responder template.
isDripEmail (boolean, optional) - Mark template as a drip/engagement studio template.
isListEmail (boolean, optional) - Mark template as a list email template.
campaignId (number, required) - Campaign id to associate with the template. Required.
trackerDomainId (number, required) - Tracker domain id for tracking links. Required.
folderId (number, optional) - Folder to organize the template in.
senderOptions (value[], optional) - Default sender configuration. Must be an array.
replyToOptions (value[], optional) - Default reply-to configuration. Must be an array.

Result
Raw Account Engagement response JSON, returned unchanged.
Also included when present: deleted.

Required scopes
- `pardot_api`.

Idempotency & limits
- Hard delete: deleted templates can't be referenced; existing
  scheduled list emails using the template fail at send.

Errors
- 53 not_permitted, 600 missing_required_field
  (subject / sender required), 59 not_found.

Example request

manage_email_template({
  "operation": "",
  "campaignId": 1,
  "trackerDomainId": 1
})

Example result

{ }
