Tool: send_one_to_one_email

Description
Send a one-to-one email (transactional) from a known Pardot user to
a single prospect. The email content can be inline (`htmlMessage` /
`textMessage` / `subject`) or referenced from an Email Template
(`emailTemplateId`). Requires either `prospectId` or `prospectFid`
(the prospect's external `crmId`). For bulk sends to a list, use
`send_list_email`.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/emails

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: campaignId, emailTemplateId, folderId, htmlMessage, isOperational, name, prospectId, replyToOptions, senderOptions, subject, textMessage, trackerDomainId, userId

Input (parameters)
prospectId (number, required) - Pardot prospect id to send to. Required.
campaignId (number, required) - Campaign to attribute the send to. Required.
emailTemplateId (number, optional) - Email template id. Omit if providing inline name/subject/htmlMessage/textMessage.
userId (number, optional) - Pardot user id that the email is sent "from". Required for one-to-one sends.
name (string, optional) - Internal email name. Required when emailTemplateId is not provided.
subject (string, optional) - Email subject line. Required when emailTemplateId is not provided.
htmlMessage (string, optional) - HTML body. Use HML merge fields like {{Recipient.FirstName}}.
textMessage (string, optional) - Plain-text fallback body.
senderOptions (value[], optional) - Who the email appears to come from. Must be an array.
replyToOptions (value[], optional) - Reply-To address configuration. Must be an array.
trackerDomainId (number, optional) - Tracker domain for tracking links.
folderId (number, optional) - Folder to store the email record in.
isOperational (boolean, optional) - When true, send regardless of global opt-out. Use only for password resets or
transactional alerts.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Not idempotent. There's no `messageKey` equivalent — implement
  caller-side dedupe.
- Subject to BU-level send rate; over-quota sends queue.

Errors
- 14 prospect_opted_out (skipped unless isOperational=true),
  15 daily_send_limit, 30 invalid_template, 59 not_found
  (prospect / template / campaign), 53 user_not_authorized.

Example request

send_one_to_one_email({
  "prospectId": 1,
  "campaignId": 1
})

Example result

{ }
