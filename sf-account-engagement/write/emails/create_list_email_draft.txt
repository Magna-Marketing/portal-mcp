Tool: create_list_email_draft

Description
Create a List Email draft (a one-off blast targeting one or more
lists). v5 only exposes `Create` for list emails (no PATCH /
DELETE). After creation, fire the send via `send_list_email`
(legacy v4 — v5 doesn't yet expose `do/send`).

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/list-emails

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: campaignId, emailTemplateId, folderId, htmlMessage, name, recipientListIds, replyToOptions, scheduledTime, senderOptions, subject, suppressionListIds, textMessage, trackerDomainId

Input (parameters)
name (string, required) - Internal name for the list email draft. Required.
subject (string, optional) - Email subject line. Required when emailTemplateId is not provided.
campaignId (number, required) - Campaign to attribute the send to. Required.
listIds (number[], required) - Array of list ids to send to. At least one required.
suppressionListIds (number[], optional) - Lists whose members are excluded from the send.
emailTemplateId (number, optional) - Email template id to use for content. Omit if providing inline htmlMessage/textMessage.
htmlMessage (string, optional) - Inline HTML body. Used when emailTemplateId is not set.
textMessage (string, optional) - Inline plain-text body. Used when emailTemplateId is not set.
trackerDomainId (number, optional) - Tracker domain for click/open tracking links.
folderId (number, optional) - Folder to store the draft in.
senderOptions (value[], optional) - Who the email appears to come from. Must be an array.
replyToOptions (value[], optional) - Reply-To address configuration. Must be an array.
operationalEmail (boolean, optional) - When true, the email is sent regardless of list-level opt-out status. Use only for
transactional notifications.
scheduledTime (string, optional) - ISO-8601 datetime to schedule the send. If omitted, the draft stays in Draft status
until send_list_email is called.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Not idempotent.

Errors
- 600 missing_required_field, 53 not_permitted, 59 not_found.

Example request

create_list_email_draft({
  "name": "",
  "campaignId": 1,
  "listIds": []
})

Example result
