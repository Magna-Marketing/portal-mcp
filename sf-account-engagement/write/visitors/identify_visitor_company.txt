Tool: identify_visitor_company

Description
Override or set the inferred company on an anonymous Visitor.
By default, Visitors are enriched via reverse-IP firmographics
(Visitor Insight, license-gated). Use this tool to manually attach
or override the company attribution — for example, when an
authoritative source (CRM lookup) identifies the company.

Salesforce API
Account Engagement v5 REST API.

Endpoint
POST https://{pi-domain}/api/v5/objects/visitors/{visitorId}/do/identifyCompany

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Content-Type: application/json
Accept: application/json

Body
POST: companyId, companyName

Input (parameters)
visitorId (number, required) - Pardot visitor id to update.
companyName (string, optional) - Company name to associate with the visitor.
companyId (number, optional) - Pardot Prospect Account id to link the visitor to. Takes precedence over companyName
when both are supplied.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Idempotent on `companyName` — repeat calls with the same payload
  return the same row.

Errors
- 59 not_found, 20 invalid_input.

Example request

identify_visitor_company({
  "visitorId": 1
})

Example result

{ }
