Tool: list_engagement_programs

Description
List Engagement Studio programs (multi-step nurture / onboarding
graphs that act on a target list of prospects). Each program runs
on a schedule (`businessHours`) and exposes its high-level state.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/engagement-studio-programs
Optional query: fields, limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
status ("Draft" | "Running" | "Paused" | "Completed" | "Error", optional) - Filter by program status.
folderId (number, optional) - Filter by folder id.
nameContains (string, optional) - Filter programs whose name contains this string (case-insensitive like match).
campaignId (number, optional) - Filter by campaign id.
recipientListId (number, optional) - Filter by recipient list id.
isDeleted (boolean, optional) - Include deleted programs. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, description, status, recipientListId,
suppressionListIds, businessHoursId, scheduleType, campaignId, folderId, isDeleted,
createdAt, updatedAt, createdById, updatedById, publishedAt, startedAt, completedAt.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_engagement_programs({})
