Tool: list_dynamic_content_variations

Description
List the rule-based variations of a Dynamic Content block. Each
variation defines a comparison (`operator`, `value1`, optional
`value2`) and the HTML snippet to render when the comparison
matches the active prospect.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/dynamic-content-variations
Optional query: fields, limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
dynamicContentId (number, required) - Dynamic Content block id whose variations to list. Required.
fields (string[], optional) - Field projection. Defaults to id, dynamicContentId, comparison, content, operator,
value1, value2.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
variations (value) - included in the JSON returned by the tool.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 59 not_found (when dynamicContentId is invalid).

Example request

list_dynamic_content_variations({
  "dynamicContentId": 1
})

Example result

{
  "variations": null
}
