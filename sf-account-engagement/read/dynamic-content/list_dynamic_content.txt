Tool: list_dynamic_content

Description
List Dynamic Content blocks (personalized content snippets that
swap based on prospect rules / custom fields). Each block exposes
an `embedCode` (HTML script tag) and `embedUrl` for embedding in
emails, landing pages, or external sites.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/dynamic-contents
Optional query: fields, filter[basedOnProspectApiFieldId], filter[basedOn], filter[folderId], filter[isDeleted], filter[name], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
folderId (number, optional) - Filter by folder id.
nameContains (string, optional) - Filter blocks whose name contains this string (case-insensitive like match).
basedOn ("PROSPECT_FIELD" | "TAG" | "GRADE" | "SCORE", optional) - Filter by the criterion the dynamic content is based on.
basedOnProspectApiFieldId (string, optional) - When basedOn=PROSPECT_FIELD, filter by the specific custom field API name (e.g.
"region__c").
isDeleted (boolean, optional) - Include deleted blocks. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, folderId, isDeleted, createdById, updatedById,
createdAt, updatedAt, basedOn, basedOnProspectApiFieldId, trackerDomainId, embedCode,
embedUrl, tagReplacementLanguage.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_dynamic_content({})
