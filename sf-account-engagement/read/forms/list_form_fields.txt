Tool: list_form_fields

Description
List the fields on a Form. Each field maps to a Prospect built-in
field or custom field via `prospectApiFieldId`. Use this to inspect
ordering, required-ness, hidden / read-only flags, and progressive
profiling configuration.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/form-fields
Optional query: fields, formId, limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
formId (number, required) - Form id whose fields to list. Required.
isRequired (boolean, optional) - Filter to required or non-required fields.
type ("Text" | "TextArea" | "Email" | "Number" | "RadioButton" | "Checkbox" | "Dropdown" | "MultiSelect" | "Hidden" | "Date" | "CrmUser", optional) - Filter by field type.
fields (string[], optional) - Field projection. Defaults to id, formId, prospectApiFieldId, type, name, label,
isRequired, isAlwaysDisplay, isMaintainInitialValue, isUseValuesPreFromField, sortOrder,
errorMessage, cssClasses, hasDependents, hasProgressiveProfiling, hasValues, createdAt,
updatedAt.
limit (number, optional) - Page size. Default 200.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
values (value) - included in the JSON returned by the tool.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 59 not_found, 65 invalid_field_projection.

Example request

list_form_fields({
  "formId": 1
})

Example result

{
  "values": null
}
