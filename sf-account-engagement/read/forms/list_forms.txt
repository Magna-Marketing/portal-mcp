Tool: list_forms

Description
List Pardot-hosted Forms. Each form has an embed code, target
campaign, and (optionally) a thank-you content / redirect.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/forms
Optional query: fields, filter[campaignId], filter[folderId], filter[isDeleted], filter[name], filter[trackerDomainId], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
campaignId (number, optional) - Filter by campaign id.
folderId (number, optional) - Filter by folder id.
trackerDomainId (number, optional) - Filter by tracker domain id.
nameContains (string, optional) - Filter forms whose name contains this string (case-insensitive like match).
isDeleted (boolean, optional) - Include deleted forms. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, campaignId, folderId, trackerDomainId,
layoutTemplateId, thankYouContent, thankYouCode, redirectLocation, beforeFormContent,
afterFormContent, salesforceId, isAlwaysDisplay, isCaptchaEnabled, isCookielessTracking,
isUseRedirectLocation, embedCode, createdAt, updatedAt, createdById, updatedById,
isDeleted.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_forms({})
