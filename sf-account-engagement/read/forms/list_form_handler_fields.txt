Tool: list_form_handler_fields

Description
List the inbound-field mapping rows on a Form Handler. Each row
defines a posted-form field name and which prospect field it
populates (`prospectApiFieldId`).

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/form-handler-fields?fields={fields}&filter[formHandlerId]=eq,:id

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
formHandlerId (number, required) - Form Handler id whose fields to list. Required.
isRequired (boolean, optional) - Filter to required or non-required fields.
fields (string[], optional) - Field projection. Defaults to id, formHandlerId, name, prospectApiFieldId, dataFormat,
errorMessage, isMaintainInitialValue, isRequired, sortOrder, createdAt, updatedAt.
limit (number, optional) - Page size. Default 200.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
values (value) - included in the JSON returned by the tool.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 59 not_found.

Example request

list_form_handler_fields({
  "formHandlerId": 1
})

Example result

{
  "values": null
}
