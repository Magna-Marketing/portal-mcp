Tool: list_form_handlers

Description
List Form Handlers (server-side endpoints that accept POSTs from
externally-hosted forms and create / update prospects). Each handler
has a unique `embedUrl` to POST x-www-form-urlencoded data to.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/form-handlers
Optional query: fields, filter[campaignId], filter[folderId], filter[isAlwaysEmail], filter[isCookielessTracking], filter[isDataForwarded], filter[isDeleted], filter[name], filter[trackerDomainId], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
campaignId (number, optional) - Filter by campaign id.
folderId (number, optional) - Filter by folder id.
trackerDomainId (number, optional) - Filter by tracker domain id.
nameContains (string, optional) - Filter form handlers whose name contains this string (case-insensitive like match).
isDataForwarded (boolean, optional) - Filter by data forwarding status.
isCookielessTracking (boolean, optional) - Filter by cookieless tracking status.
isAlwaysEmail (boolean, optional) - Filter by always-email setting.
isDeleted (boolean, optional) - Include deleted form handlers. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, campaignId, folderId, trackerDomainId,
salesforceId, isDataForwarded, isCookielessTracking, isAlwaysEmail, isKioskMode,
errorLocation, successLocation, embedUrl, createdAt, updatedAt, createdById,
updatedById, isDeleted.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_form_handlers({})
