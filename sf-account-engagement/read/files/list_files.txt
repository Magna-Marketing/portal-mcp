Tool: list_files

Description
List Files (uploaded assets — images, PDFs, attachments) in the BU's
file library. Returns each file's `url` (CDN-served), `size`,
`mimeType`, and `folderId`.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/files
Optional query: fields, filter[campaignId], filter[folderId], filter[isDeleted], filter[isTracked], filter[mimeType], filter[name], filter[trackerDomainId], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
folderId (number, optional) - Filter by folder id.
nameContains (string, optional) - Filter files whose name contains this string (case-insensitive like match).
mimeType (string, optional) - Filter by exact MIME type (e.g. "image/png", "application/pdf").
isTracked (boolean, optional) - Filter to files where download clicks are tracked.
campaignId (number, optional) - Filter by campaign id.
trackerDomainId (number, optional) - Filter by tracker domain id.
isDeleted (boolean, optional) - Include deleted files. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, size, mimeType, folderId, trackerDomainId,
campaignId, vanityUrl, vanityUrlPath, trackedUrl, url, bitlyShortUrl,
bitlyIsPersonalized, salesforceId, isTracked, isDeleted, createdAt, updatedAt,
createdById, updatedById.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.
