Tool: list_campaigns

Description
List Account Engagement campaigns (the default attribution / source
of new prospects). When **Connected Campaigns** is enabled in the
SFDC org, each Pardot campaign is bidirectionally linked with a
Salesforce Campaign and `salesforceId` is populated.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/campaigns
Optional query: fields, filter[folderId], filter[isDeleted], filter[name], filter[parentCampaignId], filter[salesforceId], limit, nextPageToken, orderBy

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
nameContains (string, optional) - Filter campaigns whose name contains this string (case-insensitive like match).
folderId (number, optional) - Filter by folder id.
parentCampaignId (number, optional) - Filter to direct children of this parent campaign id.
isDeleted (boolean, optional) - Include deleted campaigns. Default false.
hasSalesforceId (boolean, optional) - When true, returns only campaigns linked to a Salesforce Campaign (Connected Campaigns).
fields (string[], optional) - Field projection. Defaults to id, name, folderId, cost, parentCampaignId, salesforceId,
isDeleted, createdAt, updatedAt, createdById, updatedById.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only. Costs 1 v5 call per page.

Errors
- 65 invalid_field_projection, 184 daily_limit_reached.

Example request

list_campaigns({})
