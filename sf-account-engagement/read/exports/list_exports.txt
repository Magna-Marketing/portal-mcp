Tool: list_exports

Description
List async export jobs. Exports are created by `create_export` and
move through `WAITING -> PROCESSING -> COMPLETE` (or `ERROR`).
Each export targets one object (Prospect, ListMembership, Email,
VisitorActivity, etc.) with a date-range filter.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/exports?fields={fields}&filter[status]=eq,Complete

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
status ("Waiting" | "Processing" | "Complete" | "Error" | "Cancelled", optional) - Filter by export status.
object ("Prospect" | "ListMembership" | "VisitorActivity" | "Email" | "ListEmail" | "Form" | "Folder" | "Tag" | "Visitor" | "Visit" | "VisitorPageView" | "User" | "Opportunity", optional) - Filter by target object type.
createdAfter (string, optional) - ISO-8601 datetime. Filter to exports created after this time.
createdBefore (string, optional) - ISO-8601 datetime. Filter to exports created before this time.
fields (string[], optional) - Field projection. Defaults to id, object, status, createdAt, updatedAt, createdById,
procedure, arguments, errorRef, fileName, counter. Note: fields and resultRefs are only
available via get_export (single-record endpoint).
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_exports({})
