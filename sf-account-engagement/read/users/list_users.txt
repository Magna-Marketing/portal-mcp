Tool: list_users

Description
List Account Engagement Users (the staff with login access to this
BU). Cross-references SFDC User via `salesforceId` once SSO is set up.
Useful for auditing role assignments and finding the right user id
for `assign_prospect`.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/users
Optional query: fields, filter[email], filter[isCrmUser], filter[isDeleted], filter[isVerified], filter[roleName], filter[role], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
role ("Administrator" | "Marketing" | "SalesManager" | "Sales", optional) - Filter by standard role.
roleName (string, optional) - Filter by custom role name (for custom roles not in the standard list).
emailContains (string, optional) - Filter users whose email contains this string (case-insensitive like match).
isVerified (boolean, optional) - Filter by email verification status.
isCrmUser (boolean, optional) - Filter to users that are synced from the connected CRM.
isDeleted (boolean, optional) - Include deleted users. Default false.
fields (string[], optional) - Field projection. Defaults to id, email, firstName, lastName, username, jobTitle, role,
roleName, salesforceId, createdAt, updatedAt, isDeleted, createdById, updatedById,
tagReplacementLanguage.
limit (number, optional) - Page size. Default 200.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_users({})
