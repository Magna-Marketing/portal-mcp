Tool: list_custom_fields

Description
List the BU's prospect custom fields. Each field has a stable
`apiFieldId` that's the API name to use on prospect writes
(`/objects/prospects` POST/PATCH); `fieldId` is the legacy v4 id
(also called the "FID"). Distinct from picklist values — use
`type=DROPDOWN`/`RADIO_BUTTON`/`MULTI_SELECT`/`CHECKBOX` to spot
fields that have a values list.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/custom-fields
Optional query: fields, filter[isAnalyticsSynced], filter[isRequired], filter[name], filter[type], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
type ("TEXT" | "DROPDOWN" | "RADIO_BUTTON" | "CHECKBOX" | "MULTI_SELECT" | "TEXTAREA" | "DATE" | "NUMBER" | "CRM_USER" | "HIDDEN", optional) - Filter by field type.
isRequired (boolean, optional) - Filter to required or non-required fields.
isAnalyticsSynced (boolean, optional) - Filter to fields mirrored to B2B Marketing Analytics.
nameContains (string, optional) - Filter fields whose name contains this string (case-insensitive like match).
fields (string[], optional) - Field projection. Defaults to id, name, fieldId, apiFieldId, type, isRequired,
isUseValues, isRecordMultipleResponses, isAnalyticsSynced, salesforceId, createdAt,
updatedAt, createdById, updatedById.
limit (number, optional) - Page size. Default 200.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_custom_fields({})
