Tool: list_custom_redirects

Description
List Custom Redirects (vanity / trackable links). Each redirect
captures clicks against a campaign and rewrites a tracker-domain URL
to a destination. UTM parameters (`gaSource`, `gaMedium`, etc.) are
appended automatically when set.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/custom-redirects
Optional query: fields, filter[campaignId], filter[folderId], filter[isDeleted], filter[name], filter[trackerDomainId], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
campaignId (number, optional) - Filter by campaign id.
trackerDomainId (number, optional) - Filter by tracker domain id.
folderId (number, optional) - Filter by folder id.
nameContains (string, optional) - Filter redirects whose name contains this string (case-insensitive like match).
isDeleted (boolean, optional) - Include deleted custom redirects. Default false.
fields (string[], optional) - Field projection. Defaults to id, salesforceId, folderId, name, destinationUrl,
campaignId, trackerDomainId, vanityUrlPath, vanityUrl, trackedUrl, url, UTM fields,
bitly fields, createdAt, updatedAt, createdById, updatedById, isDeleted.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_custom_redirects({})
