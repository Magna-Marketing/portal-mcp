Tool: list_lifecycle_history

Description
List Lifecycle History rows (per-prospect funnel transitions). One
row per prospect-stage entry; pair with `list_lifecycle_stages` to
resolve `lifecycleStageId` → stage name. Useful for "how long did
this prospect spend at MQL?" questions.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/lifecycle-histories
Optional query: fields, filter[createdAt], filter[lifecycleStageId], filter[prospectId], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
prospectId (number, optional) - Filter to lifecycle transitions for a specific prospect.
lifecycleStageId (number, optional) - Filter to entries for a specific lifecycle stage.
createdAfter (string, optional) - ISO-8601 datetime. Filter to transitions after this time.
createdBefore (string, optional) - ISO-8601 datetime. Filter to transitions before this time.
fields (string[], optional) - Field projection. Defaults to id, prospectId, lifecycleStageId,
previousLifecycleStageId, secondsElapsedInPreviousStage, createdAt.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_lifecycle_history({})
