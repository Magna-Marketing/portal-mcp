Tool: list_lifecycle_stages

Description
List Lifecycle Stages — the configured funnel steps a prospect can
move through (e.g. Lead → MQL → SQL → Opportunity). Read-only at
this time; stages are configured in Setup.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/lifecycle-stages
Optional query: fields, filter[isLocked], filter[matchType], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
matchType ("all" | "any", optional) - Filter by entry criteria match logic (all = AND, any = OR).
isLocked (boolean, optional) - Filter by locked/unlocked status.
fields (string[], optional) - Field projection. Defaults to id, name, position, matchType, isLocked, isDeleted,
createdAt, updatedAt, createdById, updatedById.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_lifecycle_stages({})

Example result

{ }
