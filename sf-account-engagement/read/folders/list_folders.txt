Tool: list_folders

Description
List folders. Folders are typed-by-object (Email Templates have
their own folder hierarchy distinct from Files), but the v5
`/objects/folders` collection returns all of them; filter by
`parentFolderId` and / or by traversing `path`.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/folders
Optional query: fields, filter[name], filter[parentFolderId], filter[path], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
parentFolderId (number, optional) - Filter to direct children of this parent folder. Use 0 or null for top-level folders.
nameContains (string, optional) - Filter folders whose name contains this string (case-insensitive like match).
pathContains (string, optional) - Filter by path substring (e.g. "/Marketing/Spring").
fields (string[], optional) - Field projection. Defaults to id, name, parentFolderId, path, createdAt, updatedAt,
createdById, updatedById.
limit (number, optional) - Page size. Default 200.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

list_folders({})
