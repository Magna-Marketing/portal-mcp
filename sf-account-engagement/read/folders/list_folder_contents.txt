Tool: list_folder_contents

Description
List the *contents* of a folder regardless of the contained object
type. Returns one row per item with the `objectType` discriminator —
useful when you need a flat "what's in this folder" view across
emails, files, forms, etc.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/folder-contents
Optional query: fields, folderId, limit, nextPageToken, objectName, objectType

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
folderId (number, required) - Folder id whose contents to list. Required.
objectType ("Email" | "EmailTemplate" | "ListEmail" | "Form" | "FormHandler" | "LandingPage" | "LayoutTemplate" | "DynamicContent" | "File" | "Campaign" | "EngagementStudioProgram" | "List" | "Tag" | "CustomField" | "CustomRedirect", optional) - Filter to a specific object type within the folder.
objectName (string, optional) - Filter by exact object name (case-sensitive equality match).
fields (string[], optional) - Field projection. Defaults to id, objectType, objectId, folderId, name, isDeleted,
createdAt, updatedAt.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 59 not_found (folder), 65 invalid_field_projection.

Example request

list_folder_contents({
  "folderId": 1
})

Example result

{ }
