Tool: list_tags

Description
List Tags configured on the BU. Tags are simple labels; the same
tag value can be applied across most object families (Prospects,
Campaigns, Forms, Files, etc.). Use `list_tagged_objects` to see
the things a tag is applied to.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/tags
Optional query: fields, limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
nameContains (string, optional) - Filter tags whose name contains this string (case-insensitive like match).
isDeleted (boolean, optional) - Include deleted tags. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, objectCount, createdAt, updatedAt, createdById,
updatedById, isDeleted.
limit (number, optional) - Page size. Default 200.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
tags (value) - included in the JSON returned by the tool.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_tags({})

Example result

{
  "tags": null
}
