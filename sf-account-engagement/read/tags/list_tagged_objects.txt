Tool: list_tagged_objects

Description
List the join rows between Tags and the objects that carry them
(Prospect, Campaign, Email, Form, etc.). Filter by `tagId` to see
"what's tagged with X" or by `objectId`+`objectType` to see "what
tags does Y carry."

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/tagged-objects
Optional query: fields, filter[objectId], filter[objectType], filter[tagId], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
tagId (number, optional) - Filter to objects tagged with this tag id — answers "what is tagged with X?"
objectId (number, optional) - Filter to tags on a specific object id.
objectType ("Prospect" | "Campaign" | "Email" | "EmailTemplate" | "File" | "Form" | "FormField" | "FormHandler" | "LandingPage" | "LayoutTemplate" | "List" | "Opportunity" | "User" | "CustomField" | "CustomRedirect" | "DynamicContent", optional) - Filter by object type. Combine with objectId to answer "what tags does Y carry?"
fields (string[], optional) - Field projection. Defaults to id, tagId, objectId, objectType, createdAt, createdById.
limit (number, optional) - Page size. Default 200.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_tagged_objects({})
