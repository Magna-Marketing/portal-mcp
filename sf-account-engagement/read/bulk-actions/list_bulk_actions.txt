Tool: list_bulk_actions

Description
List Bulk Action jobs (filtered prospect updates). Used to monitor an
async bulk job: shows the target object, action type, status,
progress percent, error count, and originating user. Pair with
`manage_bulk_action` to start one.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/bulk-actions?fields={fields}&filter[status]={status}&orderBy=createdAt desc

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
status ("Pending" | "Running" | "Complete" | "Error", optional) - Filter by job status.
object (string, optional) - Filter by target object type. Currently only "Prospect" is supported.
bulkAction ("AddTag" | "RemoveTag" | "AddToList" | "RemoveFromList" | "Delete" | "Undelete" | "ChangeAssignment", optional) - Filter by bulk action type.
createdAfter (string, optional) - ISO-8601 datetime. Filter to jobs created after this time.
createdBefore (string, optional) - ISO-8601 datetime. Filter to jobs created before this time.
fields (string[], optional) - Field projection. Defaults to id, object, bulkAction, status, origin, count,
processedCount, errorCount, fileName, createdAt, updatedAt, createdById.
limit (number, optional) - Page size. Default 50, max 1000.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 4 invalid_business_unit_id, 65 invalid_field_projection.

Example request

list_bulk_actions({})
