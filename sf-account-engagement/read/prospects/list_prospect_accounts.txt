Tool: list_prospect_accounts

Description
List Prospect Accounts (the "company" entity that groups prospects).
Cross-references SFDC Account via `salesforceId`. Account-Based
Marketing dashboards are powered by these rows.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/prospect-accounts
Optional query: fields, filter[isDeleted], filter[name], filter[salesforceId], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
salesforceId (string, optional) - Filter by SFDC Account 18-char id.
nameContains (string, optional) - Filter prospect accounts whose name contains this string (case-insensitive like match).
isDeleted (boolean, optional) - Include deleted prospect accounts. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, salesforceId, assignedToUserId, industry,
website, billingAddressOne, billingAddressTwo, billingCity, billingState, billingZip,
billingCountry, createdAt, updatedAt, createdById, updatedById, number, annualRevenue,
employees, ownership, sicCode, tickerSymbol.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_prospect_accounts({})
