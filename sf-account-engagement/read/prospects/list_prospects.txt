Tool: list_prospects

Description
List Prospect records. Supports filtering on built-in fields and
any custom-field `apiFieldId` (use `filter[customFields.region__c]=eq,EMEA`).
Use `fields=` to project relations like `prospectAccount.*` and
`assignedToUser.*`. For server-side scrolling beyond ~100k rows,
prefer an export job (`create_export` with object=Prospect).

Salesforce API
Account Engagement v5 REST API.
Account Engagement v4 API.

Endpoint
GET https://{pi-domain}/api/v5/objects/prospects
Optional query: fields, filter[assignedToGroupId], filter[assignedToUserId], filter[campaignId], filter[createdAt], filter[crmId], filter[customFields.{apiFieldId}], filter[email], filter[isDoNotEmail], filter[isOptedOut], filter[listId], filter[updatedAt], limit, nextPageToken
GET https://{pi-domain}/api/prospect/version/4/do/query
Optional query: assigned_to_user, campaign_id, created_after, email, fields, format, grade_greater_than, limit, list_id, offset, output, salesforce_id, score_greater_than, score_less_than, sort_by, sort_order, updated_after

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
email (string, optional) - Exact email match filter.
emailContains (string, optional) - Case-insensitive like match on email.
crmId (string, optional) - Filter by SFDC Lead/Contact 18-char id.
campaignId (number, optional) - Filter by campaign id.
listId (number, optional) - Filter via list-membership join — returns prospects on this list.
assignedToUserId (number, optional) - Filter by assigned user id.
assignedToGroupId (number, optional) - Filter by assigned group id.
isDoNotEmail (boolean, optional) - Filter by do-not-email flag.
isOptedOut (boolean, optional) - Filter by global opt-out status.
gradeFrom (string, optional) - Minimum letter grade filter (e.g. "B" returns B, A, A+).
scoreMin (number, optional) - Minimum score filter (inclusive).
scoreMax (number, optional) - Maximum score filter (inclusive).
updatedAfter (string, optional) - ISO-8601 datetime. Filter to prospects updated after this time.
createdAfter (string, optional) - ISO-8601 datetime. Filter to prospects created after this time.
customFieldFilters (object, optional) - Custom field filters as key-value pairs where key is "apiFieldId" and value is the
filter expression (e.g. { "region__c": "eq,EMEA" }). These are appended as
filter[customFields.{apiFieldId}] query params.
fields (string[], optional) - Field projection. Defaults to id, email, firstName, lastName, company, jobTitle, score,
grade, salesforceId, campaignId, assignedToUserId, isDoNotEmail, isDoNotCall,
isOptedOut, isReviewed, isStarred, createdAt, updatedAt, lastActivityAt,
prospectAccountId, plus contact fields, notes, source, and customFields.
limit (number, optional) - Page size. Default 50, max 200. For large datasets (>100K rows), prefer create_export.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.
prospects (value) - included in the JSON returned by the tool.
nextPageToken (value) - included in the JSON returned by the tool.
totalResults (value) - included in the JSON returned by the tool.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.
