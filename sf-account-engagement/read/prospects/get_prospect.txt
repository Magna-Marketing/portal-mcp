Tool: get_prospect

Description
Read a single Prospect by id with custom fields, assigned user,
campaign, and prospect account expanded. To resolve by email
instead of id, use `list_prospects?email=...&limit=1` (or
`upsert_prospect_by_email` for write-side semantics).

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/prospects/{id}
Optional query: fields
GET https://{pi-domain}/api/v5/objects/list-memberships
Optional query: fields, filter[prospectId], limit
GET https://{pi-domain}/api/v5/objects/visitor-activities
Optional query: fields, filter[prospectId], limit, orderBy

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
id (number, required).
fields (string[], optional) - Default expands `assignedToUser.*`,
  `prospectAccount.*`, `campaign.*`, `customFields`.
includeListMemberships (boolean, optional, default false) - When
  true, runs `list_list_memberships?prospectId=:id`.
includeRecentActivities (boolean, optional, default false) - When
  true, runs `list_visitor_activities?prospectId=:id&limit=20`.

Result
Raw Account Engagement response JSON, returned unchanged.
Also included when present: listMemberships, recentActivities.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 59 not_found.

Example request

get_prospect({ "id": 7745, "includeListMemberships": true })

Example result

{ }
