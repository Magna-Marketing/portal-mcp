Tool: list_layout_templates

Description
List Layout Templates (the HTML + CSS shells used to wrap forms and
landing pages). Each template defines the page chrome (header,
footer, navigation, fonts).

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/layout-templates
Optional query: fields, filter[folderId], filter[isDeleted], filter[isIncludeDefaultCss], filter[name], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
folderId (number, optional) - Filter by folder id.
nameContains (string, optional) - Filter templates whose name contains this string (case-insensitive like match).
isIncludeDefaultCss (boolean, optional) - Filter by whether the template includes default Pardot CSS.
isDeleted (boolean, optional) - Include deleted templates. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, folderId, isIncludeDefaultCss, createdAt,
updatedAt, createdById, updatedById, isDeleted.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_layout_templates({})
