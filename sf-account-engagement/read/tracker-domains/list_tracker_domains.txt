Tool: list_tracker_domains

Description
List Tracker Domains configured on the BU (vanity domains used to
serve forms, landing pages, custom redirects, and email click links).
The `validationStatus` and `sslStatus` fields surface DNS / cert
health.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/tracker-domains
Optional query: fields, filter[isDeleted], filter[isPrimary], filter[sslStatus], filter[validationStatus], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
isPrimary (boolean, optional) - Filter to the primary (or non-primary) tracker domain.
validationStatus ("validated" | "pending" | "not_validated", optional) - Filter by DNS validation status.
sslStatus ("active" | "pending" | "not_validated", optional) - Filter by SSL certificate status.
isDeleted (boolean, optional) - Include deleted tracker domains. Default false.
fields (string[], optional) - Field projection. Defaults to id, domain, isPrimary, defaultCampaignId,
validationStatus, sslStatus, trackingCode, createdAt, updatedAt, createdById,
updatedById, isDeleted, vanityUrlStatus, sslStatusDetails.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_tracker_domains({})
