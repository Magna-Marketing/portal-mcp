Tool: list_external_activities

Description
List previously-ingested External Activities (events submitted via
`submit_external_activity`). Each row is keyed by
`(extensionSalesforceId, externalId)`; the same key in a fresh ingest
is a no-op.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/external-activities
Optional query: fields, filter[activityDate], filter[extensionSalesforceId], filter[prospectEmail], filter[prospectId], filter[typeName], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
extensionSalesforceId (string, optional) - SFDC id (0Wx...) of the External Activity Type extension.
typeName (string, optional) - Filter by the activity type name (e.g. "Webinar Attended").
prospectId (number, optional) - Filter by prospect id.
prospectEmail (string, optional) - Filter by prospect email address.
activityDateAfter (string, optional) - ISO-8601 datetime. Filter to activities after this date.
activityDateBefore (string, optional) - ISO-8601 datetime. Filter to activities before this date.
fields (string[], optional) - Field projection. Defaults to id, extensionSalesforceId, typeName, prospectId,
externalId, value, activityDate, createdAt, updatedAt, createdById, updatedById.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_external_activities({})
