Tool: get_visitor_activity

Description
Read a single Visitor Activity by id, with the source object (the
email, form, file, etc.) expanded based on `type`.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/visitor-activities/:id?fields={fields}

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
id (number, required).
fields (string[], optional) - Default expands `email.*`, `form.*`,
  `landingPage.*`, `customRedirect.*`, `file.*` (the relevant ones
  per type are populated).

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 59 not_found.

Example request

get_visitor_activity({ "id": 99100 })

Example result

{ }
