Tool: get_visitor

Description
Read a single Visitor by id, with the linked prospect (if
identified) expanded.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/visitors/:id?fields={fields}

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
id (number, required) - Visitor id (internal Pardot id, not visitorId cookie value).
fields (string[], optional) - Field projection. Defaults to id, visitorId, prospectId, firstName, lastName, email,
company, city, state, country, hostName, ipAddress, iprospect, pageViewCount, source,
medium, campaign, referrerType, createdAt, updatedAt, referrer, browser, browserVersion,
platform, screenHeight, screenWidth, with prospect.* expanded.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 59 not_found.

Example request

get_visitor({
  "id": 1
})

Example result

{ }
