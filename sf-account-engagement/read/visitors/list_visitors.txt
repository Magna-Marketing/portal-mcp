Tool: list_visitors

Description
List Visitors (anonymous web visitors not yet identified as a
prospect). Each Visitor has a `piVID` (cookie value), inferred
company / location (Visitor Insight when licensed), and the count of
visits / page views.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/visitors
Optional query: fields, filter[createdAt], filter[createdAt][lte], filter[hostName], filter[ipAddress], filter[prospectId], filter[updatedAt], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
prospectId (number, optional) - Filter to visitors matched to a specific prospect.
isIdentified (boolean, optional) - true to return only visitors matched to a prospect, false to return only anonymous
visitors.
hostNameContains (string, optional) - Case-insensitive like match on hostName.
ipAddress (string, optional) - Exact IP address filter.
createdAfter (string, optional) - ISO-8601 datetime. Return visitors created after this time.
createdBefore (string, optional) - ISO-8601 datetime. Return visitors created before this time.
updatedAfter (string, optional) - ISO-8601 datetime. Return visitors updated after this time.
fields (string[], optional) - Field projection. Defaults to id, visitorId, prospectId, firstName, lastName, email,
company, city, state, country, hostName, ipAddress, pageViewCount, source, medium,
campaign, referrerType, createdAt, updatedAt, browser, platform.
limit (number, optional) - Page size. Default 50, max 200.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

list_visitors({})
