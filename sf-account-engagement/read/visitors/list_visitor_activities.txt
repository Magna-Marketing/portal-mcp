Tool: list_visitor_activities

Description
List Visitor Activity rows — the unified activity feed (form
submission, email click, file download, custom redirect click,
external activity ingest, page view, etc.). The `type` field is
the discriminator.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/visitor-activities
Optional query: fields, filter[activityDate][gte], filter[activityDate][lte], filter[campaignId], filter[isRead], filter[prospectId], filter[type], filter[visitorId], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
visitorId (number, optional) - Filter to activities for a specific visitor.
prospectId (number, optional) - Filter to activities linked to a specific prospect.
type (number, optional) - Filter by activity type: 1=Click, 2=Custom URL, 3=Email, 4=File, 5=Form, 6=Landing Page,
7=Page View, 8=Site Search, 9=Webinar, 10=YouTube, 11=Email View, 12=Social, 13=CRM,
14=Facebook, 15=Custom.
campaignId (number, optional) - Filter to activities associated with this campaign.
activityDateAfter (string, optional) - ISO-8601 datetime. Return activities after this time.
activityDateBefore (string, optional) - ISO-8601 datetime. Return activities before this time.
isRead (boolean, optional) - Filter by read status.
fields (string[], optional) - Field projection. Defaults to id, visitorId, prospectId, type, typeCategory, details,
emailId, campaignId, listEmailId, formId, formHandlerId, landingPageId, fileId,
customRedirectId, activityDate, isRead, campaign, url, device.
limit (number, optional) - Page size. Default 50, max 200.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

list_visitor_activities({})
