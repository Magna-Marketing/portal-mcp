Tool: list_imports

Description
List Prospect import jobs (CSV uploads). An import is a multi-batch
async ingest pipeline. Each row tracks status (`Open`,
`Ready`, `Processing`, `Complete`, `Error`, `Cancelled`), error count,
and the operation (`upsert` vs `create`).

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/imports?fields={fields}&filter[state]=eq,Processing

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
state ("Open" | "Ready" | "Processing" | "Complete" | "Error" | "Cancelled", optional) - Filter by import state.
operation ("Upsert" | "Create", optional) - Filter by import operation.
createdAfter (string, optional) - ISO-8601 datetime. Filter to imports created after this time.
createdBefore (string, optional) - ISO-8601 datetime. Filter to imports created before this time.
fields (string[], optional) - Field projection. Defaults to id, object, operation, state, errorRef, batchProgress,
createdAt, updatedAt, createdById, updatedById, campaignId, restoreDeleted,
isAllowFieldUpdates, visitorId, isAllowUserToManageProspects,
isMatchedOnEmailNotIdsAndCrmId, visibilityListIds, trackerDomainId, visibility.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

list_imports({})
