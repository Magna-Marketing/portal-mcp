Tool: list_email_templates

Description
List Email Templates (the reusable email content used for
auto-responders, drip campaigns, list emails, and one-to-one sends).
Filter by `type` (autoresponder vs drip vs list vs one-to-one) or
folder.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/email-templates
Optional query: fields, filter[campaignId], filter[folderId], filter[isAutoResponderEmail], filter[isDeleted], filter[isDripEmail], filter[isListEmail], filter[isOneToOneEmail], filter[name], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
isOneToOneEmail (boolean, optional) - Filter to one-to-one email templates.
isAutoResponderEmail (boolean, optional) - Filter to auto-responder email templates.
isDripEmail (boolean, optional) - Filter to drip/engagement program email templates.
isListEmail (boolean, optional) - Filter to list email templates.
folderId (number, optional) - Filter by folder id.
campaignId (number, optional) - Filter by campaign id.
nameContains (string, optional) - Filter templates whose name contains this string (case-insensitive like match).
isDeleted (boolean, optional) - Include deleted templates. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, subject, type, isOneToOneEmail,
isAutoResponderEmail, isDripEmail, isListEmail, isDeleted, folderId, campaignId,
trackerDomainId, createdAt, updatedAt, createdById, updatedById, senderOptions.address,
senderOptions.name, replyToOptions.address, tagReplacementLanguage.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_email_templates({})
