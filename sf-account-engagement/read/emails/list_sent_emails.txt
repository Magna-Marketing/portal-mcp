Tool: list_sent_emails

Description
List individual `Email` send rows — one row per delivered (or
failed) email send. This is the most granular send log; for
aggregate stats on a list-email blast, see `get_list_email`.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/emails
Optional query: fields, filter[campaignId], filter[emailTemplateId], filter[listEmailId], filter[prospectId], filter[sentAt], filter[type], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
prospectId (number, optional) - Filter to emails sent to a specific prospect.
listEmailId (number, optional) - Filter to all individual sends for a specific list email blast.
campaignId (number, optional) - Filter by campaign id.
emailTemplateId (number, optional) - Filter by email template id.
type ("ListEmail" | "OneToOneEmail" | "TestEmail" | "AutoresponderEmail" | "DripEmail", optional) - Filter by email send type.
sentAfter (string, optional) - ISO-8601 datetime. Filter to emails sent after this time.
sentBefore (string, optional) - ISO-8601 datetime. Filter to emails sent before this time.
fields (string[], optional) - Field projection. Defaults to id, name, subject, type, userId, campaignId, listId,
clientType, sentAt, prospectId, listEmailId, emailTemplateId, isOperational,
senderOptions.address, senderOptions.name, replyToOptions.address.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_sent_emails({})
