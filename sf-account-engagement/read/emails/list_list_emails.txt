Tool: list_list_emails

Description
List the BU's `ListEmail` records. A List Email is a one-off send to
one or more lists; each row tracks the campaign, sender, send time,
and aggregate counters (`sent`, `deliveries`, `opens`, `clicks`,
`bounces`, `unsubscribes`, `optOuts`, `spamComplaints`).

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/list-emails
Optional query: fields, filter[campaignId], filter[listIds], filter[sentAt], filter[status], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
campaignId (number, optional) - Filter by campaign id.
listIds (number[], optional) - Filter to list emails targeting any of these list ids.
sentAfter (string, optional) - ISO-8601 datetime. Filter to emails sent after this time.
sentBefore (string, optional) - ISO-8601 datetime. Filter to emails sent before this time.
status ("Draft" | "Scheduled" | "Sent" | "Sending" | "Cancelled", optional) - Filter by send status.
fields (string[], optional) - Field projection. Defaults to id, name, subject, sentAt, scheduledTime, status,
campaignId, senderOptions, replyToOptions, trackerDomainId, emailTemplateId,
operationalEmail, createdAt, updatedAt, createdById, updatedById, plus all aggregate
stats.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_list_emails({})
