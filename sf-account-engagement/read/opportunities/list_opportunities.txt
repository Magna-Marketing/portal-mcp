Tool: list_opportunities

Description
List Opportunity records mirrored into Account Engagement from the
connected Salesforce org. Read-only via Account Engagement APIs;
write opportunities in SFDC and let the connector sync them in.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/opportunities
Optional query: fields, filter[campaignId], filter[isDeleted], filter[name], filter[salesforceId], filter[stage], filter[status], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
stage (string, optional) - Filter by stage name (e.g. "Closed Won", "Proposal").
status ("Won" | "Lost" | "Open", optional) - Filter by opportunity status.
campaignId (number, optional) - Filter by campaign id.
salesforceId (string, optional) - Filter by SFDC Opportunity 18-char id.
nameContains (string, optional) - Filter opportunities whose name contains this string (case-insensitive like match).
isDeleted (boolean, optional) - Include deleted opportunities. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, value, probability, stage, status, closedAt,
salesforceId, campaignId, createdAt, updatedAt, createdById, updatedById, isDeleted,
type, prospectIds.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

list_opportunities({})
