Tool: list_list_memberships

Description
List List Membership rows (the join between Prospect and List).
Each row has an `optedOut` flag that is **scoped to that list** —
distinct from a prospect-wide opt-out.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/list-memberships
Optional query: fields, filter[createdAt], filter[listId], filter[optedOut], filter[prospectId], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
listId (number, optional) - Filter to members of a specific list.
prospectId (number, optional) - Filter to all lists a specific prospect belongs to.
optedOut (boolean, optional) - Filter by list-level opt-out status.
createdAfter (string, optional) - ISO-8601 datetime. Filter to memberships created after this time.
fields (string[], optional) - Field projection. Defaults to id, listId, prospectId, optedOut, createdAt, updatedAt,
createdById, updatedById.
limit (number, optional) - Page size. Default 200.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_list_memberships({})
