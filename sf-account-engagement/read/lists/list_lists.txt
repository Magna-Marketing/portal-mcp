Tool: list_lists

Description
List static and dynamic prospect lists. Static lists are populated
by membership writes; dynamic lists evaluate `criteria` on a
schedule (hourly).

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/lists
Optional query: fields, filter[campaignId], filter[folderId], filter[isCrmVisible], filter[isDeleted], filter[isDynamic], filter[isPublic], filter[name], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
isDynamic (boolean, optional) - Filter to dynamic (criteria-based) or static lists.
isPublic (boolean, optional) - Filter to public (self-subscribe enabled) lists.
isCrmVisible (boolean, optional) - Filter to lists visible in the connected CRM.
folderId (number, optional) - Filter by folder id.
campaignId (number, optional) - Filter by campaign id.
nameContains (string, optional) - Filter lists whose name contains this string (case-insensitive like match).
isDeleted (boolean, optional) - Include deleted lists. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, description, isPublic, isDynamic, isCrmVisible,
folderId, campaignId, createdAt, updatedAt, createdById, updatedById, salesforceId,
isDeleted, title.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

list_lists({})
