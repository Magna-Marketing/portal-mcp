Tool: list_landing_pages

Description
List Pardot-hosted Landing Pages. Each LP has a tracker-domain URL,
optional layout template, an inlined Form (`formId`), and the
campaign it attributes traffic to.

Salesforce API
Account Engagement v5 REST API.

Endpoint
GET https://{pi-domain}/api/v5/objects/landing-pages
Optional query: fields, filter[campaignId], filter[folderId], filter[formId], filter[isDeleted], filter[name], filter[trackerDomainId], limit, nextPageToken

Headers
Authorization: Bearer <salesforce-access-token>
Pardot-Business-Unit-Id: <buId>
Accept: application/json

Body
None.

Input (parameters)
campaignId (number, optional) - Filter by campaign id.
formId (number, optional) - Filter by embedded form id.
folderId (number, optional) - Filter by folder id.
trackerDomainId (number, optional) - Filter by tracker domain id.
nameContains (string, optional) - Filter landing pages whose name contains this string (case-insensitive like match).
isDeleted (boolean, optional) - Include deleted landing pages. Default false.
fields (string[], optional) - Field projection. Defaults to id, name, campaignId, folderId, trackerDomainId,
layoutTemplateId, formId, vanityUrl, vanityUrlPath, url, bitly fields, title,
description, isDoNotIndex, isUseRedirectLocation, redirectLocation, salesforceId,
isDeleted, createdAt, updatedAt, createdById, updatedById.
limit (number, optional) - Page size. Default 50.
nextPageToken (string, optional) - Pagination token from a previous response.

Result
Raw Account Engagement response JSON, returned unchanged.

Required scopes
- `pardot_api`.

Idempotency & limits
- Read-only.

Errors
- 65 invalid_field_projection.

Example request

list_landing_pages({})
