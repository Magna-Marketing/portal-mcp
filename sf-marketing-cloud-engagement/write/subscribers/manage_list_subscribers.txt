Tool: manage_list_subscribers

Description
Add subscribers to a list, remove them, or update their list-membership
status. The Subscriber must already exist; this tool wires the
`ListSubscriber` join.

Marketing Cloud API
SOAP API (`Subscriber` Create / Update with `Lists[]`) +
`ListSubscriber` for fine-grained membership.

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP UpdateRequest on Subscriber with Lists[] / SaveOptions.

Input (parameters)
operation ("add" | "remove" | "update_status", required) - add creates membership, remove deletes membership, update_status updates membership
status.
list_id (number, optional) - Numeric Marketing Cloud List ID. Preferred when known.
list_name (string, optional) - Exact List.ListName used to resolve list_id when list_id is not supplied.
customer_key (string, optional) - Exact List.CustomerKey used to resolve list_id when list_id is not supplied.
subscribers (object[], required) - Existing subscribers to add, remove, or update on the list. SOAP writes are capped at
objects per call.
business_unit_id (string, optional) - Business Unit MID used to scope the token and SOAP Client context. Defaults to the
authenticated Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
operation (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
listLookupResponse (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `list_and_subscribers_write`.

Idempotency & limits
- add idempotent with `skipIfAlreadyOnList=true`.
- 200-row batch cap; tool batches.

Errors
- LIST_NOT_FOUND, SUBSCRIBER_NOT_FOUND.

Example request

manage_list_subscribers({
  "operation": "add",
  "subscribers": []
})
