Tool: update_subscriber_status

Description
Update a subscriber's overall status (or unsubscribe them at the
master / list level).

Marketing Cloud API
SOAP API (`Subscriber` Update).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP UpdateRequest on Subscriber.

Input (parameters)
subscribers (object[], required) - Subscribers whose status should be updated. SOAP writes are capped at objects per call.
scope ("Master" | "List", optional) - Default status scope. Master updates All Subscribers; List updates one list membership.
list_id (number, optional) - Default list ID when scope is List. Can be overridden per subscriber.
business_unit_id (string, optional) - Business Unit MID used to scope the token and SOAP Client context. Defaults to the
authenticated Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
operation (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `list_and_subscribers_write`.

Idempotency & limits
- Idempotent on equal status.

Errors
- SUBSCRIBER_NOT_FOUND.

Example request (master unsubscribe)

update_subscriber_status({
  "subscribers": [{ "subscriberKey": "MEM-100023", "status": "Unsubscribed", "reason": "User request" }],
  "scope": "Master"
})
