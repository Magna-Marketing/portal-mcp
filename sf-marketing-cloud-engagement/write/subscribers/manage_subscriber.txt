Tool: manage_subscriber

Description
Create / update / delete a Subscriber directly via the SOAP API. Use
when you need fine-grained control over Subscriber attributes / status
without going through a list (`manage_list_subscribers`) or the
Contact Builder model (`create_or_update_contact`).

Marketing Cloud API
SOAP API (`Subscriber` Create / Update / Delete).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP CreateRequest / UpdateRequest / DeleteRequest on Subscriber with
SaveOptions (`UpdateAdd` for upsert semantics).

Input (parameters)
operation ("create" | "update" | "upsert" | "delete", required) - create=SOAP Create, update=SOAP Update, upsert=SOAP Create with SaveOptions UpdateAdd,
delete=SOAP Delete.
subscribers (object[], required) - Subscribers to manage. SOAP subscriber writes are capped at objects per call.
business_unit_id (string, optional) - Business Unit MID used to scope the token and SOAP Client context. Defaults to the
authenticated Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
operation (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `list_and_subscribers_write`.

Idempotency & limits
- upsert idempotent on subscriberKey.
- 200 per call (SOAP).

Errors
- DUPLICATE_VALUE, SUBSCRIBER_NOT_FOUND.

Example request

manage_subscriber({
  "operation": "create",
  "subscribers": []
})
