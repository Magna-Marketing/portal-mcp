Tool: send_transactional_email

Description
Send a transactional email to one or more recipients via a defined
Transactional Messaging email definition. Modern, idempotent
(via `messageKey`), and supports per-recipient attribute overrides.

Marketing Cloud API
REST API (`/messaging/v1/email/messages/{messageKey}` and bulk variants).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/messaging/v1/email/messages/{message_key}
POST https://{tenant}.rest.marketingcloudapis.com/messaging/v1/email/messages

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
POST: content, definitionKey

Input (parameters)
definition_key (string, required) - Transactional Messaging email send definition key. Salesforce sends the message using
this definition.
recipients (object[], required) - Recipients to send to. Use one recipient with message_key for the single-recipient
endpoint, or multiple recipients for the batch endpoint.
message_key (string, optional) - Required for the single-recipient endpoint. When provided, recipients must contain
exactly one recipient and the tool calls POST /messaging/v1/email/messages/{messageKey}.
content (object, optional) - Optional Salesforce content override object for the send request. Passed as the
top-level content property, for documented channel-specific overrides.
request_body_overrides (object, optional) - Optional advanced Salesforce request body fields to merge into the final request body.
Values here override generated fields.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for this
Transactional Messaging REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `email_send`.

Idempotency & limits
- Idempotent on `messageKey` (duplicates rejected).
- 50 recipients per batch call.

Errors
- DUPLICATE_MESSAGE_KEY, DEFINITION_INACTIVE.

Example request

send_transactional_email({
  "definition_key": "",
  "recipients": []
})
