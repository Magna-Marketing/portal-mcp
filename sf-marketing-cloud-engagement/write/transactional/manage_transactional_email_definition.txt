Tool: manage_transactional_email_definition

Description
Create / update / delete a Transactional Messaging email definition.
This is the modern transactional API; prefer it over Triggered Send
Definitions for new integrations.

Marketing Cloud API
REST API (`/messaging/v1/email/definitions`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/messaging/v1/email/definitions
DELETE https://{tenant}.rest.marketingcloudapis.com/messaging/v1/email/definitions/{definition_key}
PATCH https://{tenant}.rest.marketingcloudapis.com/messaging/v1/email/definitions/{definition_key}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
POST: status
DELETE: status
PATCH: status

Input (parameters)
operation ("create" | "update" | "activate" | "deactivate" | "delete", required) - create calls POST, update calls PATCH, activate/deactivate PATCH only status, and delete
calls DELETE for the send definition.
definition_key (string, required) - Unique Transactional Messaging email send definition key.
name (string, optional) - Unique name for the email send definition. Required by Salesforce when creating a
definition.
description (string, optional) - Optional description for the send definition.
classification (string, optional) - Send classification name, commonly Default Transactional. Salesforce requires a valid
classification for activation.
status ("active" | "inactive" | "Active" | "Inactive", optional) - Optional definition status. create/update sends Active or Inactive when provided.
activate/deactivate set this automatically.
content_customer_key (string, optional) - Content Builder email asset customerKey referenced as content.customerKey. Required by
Salesforce when creating an email definition.
subscriptions (object, optional) - Optional Salesforce subscriptions object. Use list, data_extension, auto_add_subscriber,
and update_subscriber for common fields.
options (object, optional) - Optional Salesforce options object, for example trackLinks or createJourney when
supported in your tenant.
additional_fields (object, optional) - Optional advanced Salesforce definition fields to merge into the request body. Values
here override generated fields.
confirm_deletion (boolean, optional) - Must be true when operation is delete.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for this
Transactional Messaging REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `email_send`.

Idempotency & limits
- update idempotent.
- create not idempotent on duplicate definitionKey.

Errors
- DUPLICATE_VALUE on definitionKey, INVALID_CLASSIFICATION.

Example request

manage_transactional_email_definition({
  "operation": "create",
  "definition_key": ""
})
