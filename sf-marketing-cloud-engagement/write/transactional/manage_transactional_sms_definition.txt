Tool: manage_transactional_sms_definition

Description
Create / update / delete a Transactional Messaging SMS definition.
Mirrors `manage_transactional_email_definition` but for SMS.

Marketing Cloud API
REST API (`/messaging/v1/sms/definitions`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/messaging/v1/sms/definitions
DELETE https://{tenant}.rest.marketingcloudapis.com/messaging/v1/sms/definitions/{definition_key}
PATCH https://{tenant}.rest.marketingcloudapis.com/messaging/v1/sms/definitions/{definition_key}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
POST: status
DELETE: status
PATCH: status

Input (parameters)
operation ("create" | "update" | "activate" | "deactivate" | "delete", required) - create calls POST, update calls PATCH, activate/deactivate PATCH only status, and delete
calls DELETE for the send definition.
definition_key (string, required) - Unique Transactional Messaging SMS send definition key.
name (string, optional) - Unique name for the SMS send definition. Required by Salesforce when creating a
definition.
description (string, optional) - Optional description for the send definition.
status ("active" | "inactive" | "Active" | "Inactive", optional) - Optional definition status. create/update sends Active or Inactive when provided.
activate/deactivate set this automatically.
message_content (string, optional) - SMS message body for the definition, sent as content.message. Required by Salesforce
when creating an SMS definition.
subscriptions (object, optional) - Salesforce subscriptions object. short_code and keyword are required by Salesforce when
creating an SMS definition.
url_shortener_options (object, optional) - Optional Salesforce options.urlShortenerOptions values.
regulatory_authority_template_id (string, optional) - Optional India DLT template ID, sent as options.SmsMessageRegulatoryAuthorityTemplateId.
options (object, optional) - Optional additional Salesforce options fields.
additional_fields (object, optional) - Optional advanced Salesforce definition fields to merge into the request body. Values
here override generated fields.
confirm_deletion (boolean, optional) - Must be true when operation is delete.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for this
Transactional Messaging REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `sms_send`.

Idempotency & limits
- update idempotent.

Errors
- INVALID_SHORTCODE.

Example request

manage_transactional_sms_definition({
  "operation": "create",
  "definition_key": ""
})
