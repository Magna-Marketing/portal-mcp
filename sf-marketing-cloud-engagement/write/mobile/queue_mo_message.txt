Tool: queue_mo_message

Description
Queue an inbound Mobile-Originated (MO) SMS message for processing.
Used to test MO routing or to inject messages received over a non-MC
channel into MobileConnect's keyword-routing engine.

Marketing Cloud API
REST API (`/sms/v1/queueMO`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/sms/v1/queueMO

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "mobileNumber": "+15551234567", "shortCode": "12345", "countryCode": "US", "message": "MTG", "receivedDate": "2026-04-30T15:00:00Z" }

Input (parameters)
mobile_numbers (string[], optional) - Mobile numbers to queue. Provide this or subscribers, not both.
subscribers (string[], optional) - Subscriber keys to queue. Provide this or mobile_numbers, not both.
short_code (string, required) - Short or long code for the MobileConnect opt-in or routing flow.
message_text (string, required) - Inbound MO text to queue, usually the opt-in or opt-out keyword.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile write request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `sms_send`.

Idempotency & limits
- Not idempotent.

Errors
- INVALID_PHONE_NUMBER, INVALID_SHORTCODE.

Example request

queue_mo_message({
  "short_code": "",
  "message_text": ""
})
