Tool: manage_optin_message

Description
Create / update an SMS opt-in (double opt-in) message — the message
sent in response to an MO opt-in keyword to confirm consent.

Marketing Cloud API
REST API (`/sms/v1/message/optin`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/sms/v1/message/optin

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "name": "MTG_Opt_In",
  "message": "Reply YES to confirm your subscription to MTG alerts.",
  "shortCodes": ["12345"],
  "keywordsToTriggerOptIn": ["MTG"],
  "keywordsForConfirmation": ["YES"],
  "confirmationMessage": "Thanks! You're subscribed to MTG alerts."
}

Input (parameters)
operation ("create", optional) - Create an SMS opt-in message. Salesforce public REST references do not document
update/delete routes for this resource.
message_name (string, optional) - Opt-in message name. Sent as messageName. Required unless raw_body is provided.
short_code (string, optional) - Short code for the opt-in message. Sent as shortCode. Required unless raw_body is
provided.
country_code (string, optional) - Two-letter country code. Sent as countryCode. Required unless raw_body is provided.
keyword (string, optional) - Keyword that triggers the opt-in message. Required unless raw_body is provided.
message_opt_in_type ("Single" | "Double" | "DoubleWithAge", optional) - Opt-in flow type sent as messageOptInType.
response_message (string, optional) - Response/confirmation message sent as responseMessage.
allow_single_opt_in (boolean, optional) - Whether to allow single opt-in. Sent as allowSingleOptIn.
duplicate_opt_in_message (string, optional) - Message sent when the contact is already opted in. Sent as duplicateOptInMessage.
optin_error_message (string, optional) - Message sent for opt-in errors. Sent as optinErrorMessage.
raw_body (object, optional) - Advanced raw body for POST /sms/v1/message/optin. If provided, it is sent as-is.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile write request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `sms_send`.

Idempotency & limits
- update idempotent.

Errors
- INVALID_KEYWORD, DUPLICATE_NAME.

Example request

manage_optin_message({})
