Tool: manage_keyword

Description
Create / update / delete a MobileConnect keyword (the SMS keyword that
routes inbound messages to a flow / opt-in process).

Marketing Cloud API
REST API (`/sms/v1/keyword`).

Endpoint
POST   https://{tenant}.rest.marketingcloudapis.com/sms/v1/keyword
PATCH  https://{tenant}.rest.marketingcloudapis.com/sms/v1/keyword/{id}
DELETE https://{tenant}.rest.marketingcloudapis.com/sms/v1/keyword/{id}
DELETE https://{tenant}.rest.marketingcloudapis.com/sms/v1/keyword/{keyword}/{shortCode}/{country}      (delete by keyword text)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "keyword": "MTG", "codeId": 12345, "keywordType": "Information", "restriction": "None" }

Input (parameters)
operation ("create" | "delete", required) - Create or delete a MobileConnect keyword. Salesforce public REST docs expose create and
delete, but not update.
keyword_id (value, optional) - Encoded keyword ID. Required for delete when deleting by ID.
keyword (string, optional) - Keyword text. Required for create and for delete-by-keyword.
short_code (string, optional) - Short code to create/delete the keyword on. Required for create unless long_code is
used, and required for delete-by-keyword.
long_code (string, optional) - Long code to create the keyword on. Use either short_code or long_code for create.
country_code (string, optional) - Two-letter country code for the short or long code. Required for create and
delete-by-keyword.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile write request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `mobile_connect_write`.

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_KEYWORD.

Example request

manage_keyword({
  "operation": "create"
})
