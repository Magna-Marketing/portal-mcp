Tool: send_sms

Description
Send a one-off SMS via MobileConnect (legacy). For modern transactional
flows prefer `send_transactional_sms`.

Marketing Cloud API
REST API (`/sms/v1/messageContact/{messageId}/send`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/sms/v1/messageContact/{messageId}/send

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "mobileNumbers": ["+15551234567"],
  "Subscribe": true,
  "Resubscribe": true,
  "keyword": "MTG"
}

Input (parameters)
message_id (value, required) - Encoded MobileConnect messageContact ID/API key from an active API-triggered outbound
SMS message.
mobile_numbers (string[], optional) - Mobile numbers to send to. Use the phone-number format expected by the message country,
for example 13175551212 for US numbers. Provide this or subscribers, not both.
subscribers (object[], optional) - Subscriber records containing mobile_number and subscriber_key. Provide this or
mobile_numbers, not both.
subscribe (boolean, optional) - When true, Salesforce creates a subscription if one does not exist. keyword is required
when subscribe or resubscribe is true.
resubscribe (boolean, optional) - When true, Salesforce resets an unsubscribed contact subscription. keyword is required
when subscribe or resubscribe is true.
keyword (string, optional) - MobileConnect keyword aligned to the message short code. Required when subscribe or
resubscribe is true.
override (boolean, optional) - When true, Salesforce sends message_text instead of the message definition body.
message_text (string, optional) - Override SMS body. Required by Salesforce when override is true.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile write request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `mobile_connect_send`.

Idempotency & limits
- Not idempotent.
- Subject to short-code throughput.

Errors
- INVALID_PHONE_NUMBER, MESSAGE_NOT_FOUND.

Example request

send_sms({
  "message_id": ""
})
