Tool: manage_mobile_subscriber

Description
Subscribe a phone number to a MobileConnect keyword (opt-in / pending
double-opt-in), update their record, or query subscription status.
For one-call status checks, use `read/mobile/list_sms_subscription_status`.

Marketing Cloud API
REST API.

Endpoint
PATCH https://{tenant}.rest.marketingcloudapis.com/contacts/v1/contacts

Headers
Authorization: Bearer <access_token>
Content-Type: application/json
Accept: application/json

Body
PATCH: messageText, mobileNumbers, shortCode, subscribers

Input (parameters)
operation ("subscribe" | "unsubscribe" | "update" | "check_status", required) - Subscribe/unsubscribe via queueMO, update MobileConnect subscription contact attributes,
or check documented subscription status.
mobile_number (string, optional) - Single mobile number for subscribe, unsubscribe, or update. For subscribe/unsubscribe,
provide mobile_number or contact_key.
mobile_numbers (string[], optional) - Mobile numbers for check_status. Salesforce allows up to 500 values.
subscriber_keys (string[], optional) - Subscriber keys for check_status. Salesforce allows up to 500 values.
contact_key (string, optional) - Contact key for update, or subscriber key for subscribe/unsubscribe when your tenant
uses subscriber-key based queueMO.
keyword (string, optional) - Inbound keyword to queue for subscribe. Also useful as context for update descriptions.
opt_out_keyword (string, optional) - Inbound opt-out keyword to queue for unsubscribe. Defaults to STOP.
short_code (string, optional) - Short or long code for subscribe/unsubscribe queueMO.
keyword_id (value, optional) - Keyword/SubscriptionDefinitionID used when updating MobileConnect Subscriptions through
Contacts.
opt_in_status (number, optional) - MobileConnect Subscriptions Opt In Status value for update, for example 2 for opted in.
opt_out_status (number, optional) - MobileConnect Subscriptions Opt Out Status value for update, for example 1 for opted
out.
contact_payload (object, optional) - Advanced raw Contacts PATCH payload. If provided for update, this payload is sent as-is
to PATCH /contacts/v1/contacts.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile write request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `sms_send` (subscribe) / `sms_read` (status).

Idempotency & limits
- subscribe idempotent for already-active number.

Errors
- INVALID_PHONE_NUMBER.

Example request (status check)

manage_mobile_subscriber({
  "operation": "checkStatus",
  "mobileNumbers": ["+15551234567"],
  "keyword": "MTG",
  "shortCode": "12345"
})
