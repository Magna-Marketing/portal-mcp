Tool: manage_push_location

Description
Create / update / delete a MobilePush location (geofence). Used as a
target for location-triggered push messages.

Marketing Cloud API
REST API (`/push/v1/location/`).

Endpoint
POST   https://{tenant}.rest.marketingcloudapis.com/push/v1/location
PUT    https://{tenant}.rest.marketingcloudapis.com/push/v1/location/{locationId}
DELETE https://{tenant}.rest.marketingcloudapis.com/push/v1/location/{locationId}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "name": "MTG HQ", "description": "MTG corporate HQ geofence", "latitude": 40.7128, "longitude": -74.0060, "radiusInMeters": 500, "address": "...", "city": "New York", "state": "NY", "country": "US", "postalCode": "10005" }

Input (parameters)
operation ("create" | "update" | "delete", required) - Create, update, or delete a MobilePush geofence or beacon location.
location_id (string, optional) - MobilePush location ID. Required for update and delete.
name (string, optional) - Location object name. Required for create.
location (string, optional) - Text defining the location, usually a physical or mailing address.
description (string, optional) - Description or notes for the location.
latitude (number, optional) - Center latitude for a geofence location. Required for geofence create.
longitude (number, optional) - Center longitude for a geofence location. Required for geofence create.
radius (number, optional) - Salesforce radius value for the location circle. Pass the value expected by your
tenant/docs for /push/v1/location.
attributes (object[], optional) - Additional Salesforce location attributes.
location_type (value, optional) - Salesforce locationType. Use 1 for geofence and 3 for beacon. Defaults to Salesforce
behavior when omitted.
proximity_uuid (string, optional) - Beacon UUID. Required by Salesforce when location_type is 3.
major (number, optional) - Beacon major number. Required by Salesforce when location_type is 3.
minor (number, optional) - Beacon minor number. Required by Salesforce when location_type is 3.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile write request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `push_write`.

Idempotency & limits
- update idempotent.

Errors
- INVALID_COORDINATES, 30002 not found.

Example request

manage_push_location({
  "operation": "create"
})
