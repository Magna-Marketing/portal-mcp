Tool: manage_push_app

Description
Create / update / delete a MobilePush application registration.

Marketing Cloud API
REST API (`/push/v1/application/`).

Endpoint
POST   https://{tenant}.rest.marketingcloudapis.com/push/v1/application
PATCH  https://{tenant}.rest.marketingcloudapis.com/push/v1/application/{id}
DELETE https://{tenant}.rest.marketingcloudapis.com/push/v1/application/{id}

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "name": "MTG_iOS", "applicationType": "iOS", "bundleIdentifier": "com.magnatech.mtg", "locationEnabled": true, "analyticsEnabled": true }

Input (parameters)
operation ("update_keys" | "delete_keys" | "delete_key", required) - Manage MobilePush app keys using Salesforce documented app key endpoints. Salesforce
public REST docs do not expose create/update/delete app registration endpoints.
app_id (string, required) - MobilePush app ID.
keys (string[], optional) - Replacement custom key list for update_keys. Salesforce replaces all existing app keys
with this array.
key (string, optional) - Single app key to delete for delete_key.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile write request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `push_write`.

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_BUNDLE_ID.

Example request

manage_push_app({
  "operation": "update_keys",
  "app_id": ""
})
