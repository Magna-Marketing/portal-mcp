Tool: fire_journey_entry_event

Description
Fire a single entry event into a Journey from outside (e.g. a custom
business event). Wraps `/interaction/v1/events` with shape suitable for
one event at a time. Equivalent to a one-row `inject_contacts_into_journey`
but optimized for single-fire latency.

Marketing Cloud API
REST API (`/interaction/v1/events`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/interaction/v1/events

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
POST: ContactKey, Data, EventDefinitionKey

Input (parameters)
event_definition_key (string, required) - EventDefinitionKey for the Journey Builder API entry event. Do not include periods in
this key.
contact_key (string, required) - ContactKey for the subscriber/contact entering the journey.
data (object, optional) - Optional Data object containing event payload fields required by the event definition.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `journeys_execute`.

Idempotency & limits
- Not idempotent.

Errors
- 10000 invalid eventDefinitionKey.

Example request

fire_journey_entry_event({
  "event_definition_key": "",
  "contact_key": ""
})
