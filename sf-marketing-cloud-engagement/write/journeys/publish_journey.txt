Tool: publish_journey

Description
Publish a journey draft (transitions a Draft version to Published, the
status that lets contacts enter).

Marketing Cloud API
REST API (`/interaction/v1/interactions/publishAsync/{id}?versionNumber={v}`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions/publishAsync/{journey_id}
Optional query: versionNumber
POST https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions/publishAsync/key:{journey_key}
Optional query: versionNumber
GET https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions/publishStatus/{statusId}
GET https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions
Optional query: $orderBy, $page, $pageSize, id, key, mostRecentVersionOnly, status

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
None (parameters in URL).

Input (parameters)
journey_id (string, optional) - Journey definition ID. Required when journey_key is omitted.
journey_key (string, optional) - Journey external key. Required when journey_id is omitted.
version_number (number, optional) - Journey version number to publish. Salesforce requires versionNumber; when omitted, the
tool resolves the latest Draft version.
wait_for_completion (boolean, optional) - When false, returns the raw publishAsync response. When true, polls publishStatus and
returns a composite JSON object containing the raw publish response and raw status
responses.
poll_interval_ms (number, optional) - Polling interval used only when wait_for_completion is true.
max_poll_attempts (number, optional) - Maximum publishStatus polls when wait_for_completion is true.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header.

Result
Raw Marketing Cloud response JSON, returned unchanged.
publishResponse (value) - included in the JSON returned by the tool.
statusResponses (value) - included in the JSON returned by the tool.

Required scopes
- `journeys_write`.

Idempotency & limits
- Idempotent on already-published version.

Errors
- VALIDATION_FAILED with errors describing missing trigger / activity.

Example request

publish_journey({})
