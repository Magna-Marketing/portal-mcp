Tool: remove_contact_from_journey

Description
Remove (exit) one or more contacts from one or all journeys they're
currently in. Useful for unsubscribe / preference-center flows or when
a contact's data changes invalidate their journey membership.

Marketing Cloud API
REST API (`/interaction/v1/interactions/contactexit`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions/contactexit

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
POST: ContactKey, DefinitionKey

Input (parameters)
contact_keys (string[], required) - ContactKey values to remove. Salesforce documents a maximum of 50 contacts per
contactexit request.
journey_key (string, required) - Journey DefinitionKey/customer key. Salesforce requires this key for contact exit.
versions (value[], optional) - Optional journey versions to remove the contact from. Omit to remove from all versions
of the journey.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `journeys_execute`.

Idempotency & limits
- Idempotent on already-exited contact (returns success with 0 contacts queued).
- Up to 1000 contacts per call.

Errors
- 10000 invalid contact key, 30002 journey not found.

Example request

remove_contact_from_journey({
  "contact_keys": [],
  "journey_key": ""
})
