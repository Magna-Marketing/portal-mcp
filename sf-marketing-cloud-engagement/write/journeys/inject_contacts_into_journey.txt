Tool: inject_contacts_into_journey

Description
Inject one or more contacts into a journey at the entry event. Wraps
the Journey Audience API (push-style entry). Use for ad-hoc enrollment
outside the journey's normal trigger.

Marketing Cloud API
REST API (`/interaction/v1/events`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/interaction/v1/async/events

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
POST: eventDefinitionKey, members

Input (parameters)
event_definition_key (string, required) - Event definition key for the API entry event or Wait Until API Event. Up to 10 journeys
can use the same event definition key.
contacts (object[], required) - Contacts to enter into the journey. Salesforce accepts up to 100 members per
/interaction/v1/async/events request; the tool batches larger arrays.
batch_size (number, optional) - Contacts per Salesforce async events request. Maximum 100.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header.

Result
Raw Marketing Cloud response JSON, returned unchanged.
batches (value) - included in the JSON returned by the tool.

Required scopes
- `journeys_execute`.

Idempotency & limits
- Marketing Cloud doesn't dedupe by `externalEventId` automatically; inject is not idempotent.
- 1000 events per call.

Errors
- 10000 invalid event definition, JOURNEY_INACTIVE.

Example request

inject_contacts_into_journey({
  "event_definition_key": "",
  "contacts": []
})
