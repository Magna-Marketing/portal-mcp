Tool: manage_email_classic

Description
Create / update / delete a classic Email Studio email (`Email`). For
Content Builder HTML / template assets prefer `manage_asset` with the
`htmlemail` / `templatebasedemail` asset types.

Marketing Cloud API
SOAP API (`Email` Create / Update / Delete).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP CreateRequest / UpdateRequest with Email.

Input (parameters)
operation ("create" | "update" | "delete", required) - SOAP operation for classic Email Studio Email: create, update, or delete.
email_id (number, optional) - Email.ID legacy identifier. Required for update/delete when customer_key is not
supplied.
customer_key (string, optional) - Email.CustomerKey external key. Recommended for create and can identify update/delete.
name (string, optional) - Email.Name. Required for create unless raw_email_xml is supplied.
description (string, optional) - Email.Description.
subject (string, optional) - Email.Subject. Required for create unless raw_email_xml is supplied.
html_body (string, optional) - Email.HTMLBody for classic HTML emails.
text_body (string, optional) - Email.TextBody for text-only or multipart content.
preheader (string, optional) - Email.PreHeader text shown in email clients.
email_type ("Normal" | "Text Only" | "HTML" | "Text", optional) - Salesforce EmailType. Use Normal for HTML emails or Text Only for plain text. HTML maps
to Normal and Text maps to Text Only.
category_id (number, optional) - Email.CategoryID folder identifier.
folder_id (number, optional) - Alias for category_id.
is_html_paste (boolean, optional) - Email.IsHTMLPaste. Defaults to true on create when omitted.
sync_text_with_html (boolean, optional) - Email.SyncTextWithHTML.
character_set (string, optional) - Email.CharacterSet such as utf-8 or iso-8859-1. Defaults to utf-8 on create.
is_active (boolean, optional) - Email.IsActive.
from_name (string, optional) - Email.FromName. Deprecated by Salesforce for send definitions but accepted for legacy
Email object compatibility.
from_address (string, optional) - Email.FromAddress. Deprecated by Salesforce for send definitions but accepted for legacy
Email object compatibility.
raw_email_xml (string, optional) - Exact <Objects xsi:type="Email">...</Objects> XML to send. Use for content areas or
uncommon Salesforce fields not exposed by this schema.
business_unit_id (string, optional) - Business Unit MID used to scope authentication plus SOAP ClientID / REST
Account-Context. Defaults to the authenticated session MID when present.
client_business_unit_id (number, optional) - Optional SOAP object owner/context MID. Defaults to business_unit_id, then the
authenticated session MID. Use when authenticating at parent level but writing into a
child Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
operation (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
clientBusinessUnitId (value) - included in the JSON returned by the tool.
responses (value) - included in the JSON returned by the tool.

Required scopes
- `email_write`.

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_VALUE on customerKey.

Example request

manage_email_classic({
  "operation": "create"
})
