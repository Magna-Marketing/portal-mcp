Tool: send_triggered_email

Description
Fire a triggered email to one or more subscribers via a Triggered Send
Definition. The TSD must be `Active` (start it with
`manage_triggered_send_definition`). The MCP server prefers the modern
REST endpoint `/messaging/v1/messageDefinitionSends/key:{key}/send`
and falls back to SOAP `TriggeredSend.Create` only when the REST path
is unavailable in the tenant's tier.

For status of a previously-fired send, use `get_triggered_send_status`.

Marketing Cloud API
REST API (`/messaging/v1/messageDefinitionSends/key:{key}/send`) +
SOAP fallback (`TriggeredSend.Create`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/messaging/v1/messageDefinitionSends/key:{triggered_send_customer_key}/send
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx
SOAP object: TriggeredSend

Headers
Authorization: Bearer <access_token>
Content-Type: application/json (REST) or text/xml (SOAP)

Body
SOAP request on TriggeredSend.

Input (parameters)
triggered_send_customer_key (string, required) - TriggeredSendDefinition.CustomerKey external key. REST calls
/messaging/v1/messageDefinitionSends/key:{key}/send.
recipients (object[], required) - Recipients to send to. REST sends are one recipient per Salesforce request; this tool
loops over recipients and returns each raw response. SOAP sends can include multiple
subscribers in one Create call.
api_mode ("rest" | "soap", optional) - Use rest for Salesforce REST messageDefinitionSends API or soap for
TriggeredSend.Create. Defaults to rest.
fallback_to_soap (boolean, optional) - When api_mode is rest, retry the whole send using SOAP if the REST request fails.
from_address (string, optional) - REST From.Address or SOAP Owner.FromAddress override. Usually inherited from the
triggered send definition.
from_name (string, optional) - REST From.Name or SOAP Owner.FromName override. Usually inherited from the triggered
send definition.
request_type ("SYNC" | "ASYNC", optional) - REST Options.RequestType. For SOAP, maps to CreateOptions RequestType Synchronous or
Asynchronous.
rest_request_overrides (object, optional) - Advanced REST body fields merged into each generated REST request. Values here override
generated fields.
raw_soap_triggered_send_xml (string, optional) - Exact <Objects xsi:type="TriggeredSend">...</Objects> XML for SOAP mode/fallback. Use
for uncommon Salesforce fields.
business_unit_id (string, optional) - Business Unit MID used to scope authentication plus SOAP ClientID / REST
Account-Context. Defaults to the authenticated session MID when present.
client_business_unit_id (number, optional) - Optional SOAP object owner/context MID. Defaults to business_unit_id, then the
authenticated session MID. Use when authenticating at parent level but writing into a
child Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
mode (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
responses (value) - included in the JSON returned by the tool.

Required scopes
- `email_send`.

Idempotency & limits
- Pass a stable `messageId` for tracking; Marketing Cloud doesn't dedupe automatically.
- Up to 50 recipients per REST batch (1 per `key:.../send` invocation; the MCP server batches).
- Up to 200 per SOAP TriggeredSend.Create.

Errors
- 12014 Triggered Send paused / inactive, 12011 invalid attributes.

Example request

send_triggered_email({
  "triggered_send_customer_key": "",
  "recipients": []
})
