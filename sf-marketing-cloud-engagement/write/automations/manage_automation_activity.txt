Tool: manage_automation_activity

Description
Create / update / delete activity definitions used inside automations:
SQL Query, Filter, Import, Export, Send Email, Verification, Data
Extract, File Transfer, Wait, Refresh, Script.

Marketing Cloud API
REST API (varies by activity type) and SOAP for some.

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/{rest_activity_path}
PATCH https://{tenant}.rest.marketingcloudapis.com/{rest_activity_path}/{activity_id}
PATCH https://{tenant}.rest.marketingcloudapis.com/{rest_activity_path}/{key}
DELETE https://{tenant}.rest.marketingcloudapis.com/{rest_activity_path}/{activity_id}
DELETE https://{tenant}.rest.marketingcloudapis.com/{rest_activity_path}/{key}
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8
Content-Type: application/json
Accept: application/json

Body
Per activity-type schema. The MCP server provides validation helpers.

Input (parameters)
operation ("create" | "update" | "delete" | "validate", required) - create/update/delete sends the activity definition to the Salesforce API. validate
performs local schema/path validation only and does not call Salesforce.
activity_type ("Query" | "Filter" | "FilterDefinition" | "Import" | "SendEmail" | "DataExtract" | "FileTransfer" | "Verification" | "Wait" | "Refresh" | "Script", required) - Automation activity type. Query, Import, SendEmail, Filter/FilterDefinition, and
DataExtract use supported SOAP objects by default. FileTransfer and Script use
Automation Studio REST paths.
activity_id (string, optional) - Activity definition id/ObjectID. Required for update/delete when key is omitted.
key (string, optional) - Activity external key/customer key. Required for create unless supplied in
raw_request/config. Used as CustomerKey for SOAP activity definitions.
name (string, optional) - Activity name. Required for create unless supplied in raw_request/config.
description (string, optional) - Activity description.
category_id (number, optional) - Folder category ID, sent as CategoryID for SOAP objects or categoryId for REST payloads.
config (object, optional) - Activity-specific Salesforce fields. For Query, helpful aliases include queryText,
targetKey, targetUpdateTypeName, targetUpdateType, and targetType. Other keys are sent
through to Salesforce.
raw_request (object, optional) - Exact Salesforce request body for REST activity paths. For SOAP activity types, prefer
config so the tool can build the correct SOAP object.
rest_activity_path (string, optional) - Override REST collection path, for example /automation/v1/fileTransfers. Use this for
Salesforce activity endpoints not represented by activity_type.
soap_object_type (string, optional) - Override SOAP object type, for example QueryDefinition, ImportDefinition,
EmailSendDefinition, FilterDefinition, or ExtractDefinition.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context REST header or
SOAP ClientID context. Defaults to the authenticated Business Unit when the session is
already scoped to one.

Result
valid (value) - included in the JSON returned by the tool.
api (value) - included in the JSON returned by the tool.
restActivityPath (value) - included in the JSON returned by the tool.
soapObjectType (value) - included in the JSON returned by the tool.

Required scopes
- `automations_write`.

Idempotency & limits
- update idempotent.

Errors
- INVALID_ACTIVITY_CONFIG.

Example request (SQL Query activity)

manage_automation_activity({
  "operation": "create",
  "activityType": "Query",
  "name": "Compute_Top_Members",
  "config": {
    "queryText": "SELECT MemberId, Email, TierName FROM Members_DE WHERE LifetimePoints > 50000",
    "targetKey": "Top_Members_DE",
    "targetUpdateTypeName": "Overwrite"
  }
})
