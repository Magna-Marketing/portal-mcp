Tool: manage_automation

Description
Create / update / delete an Automation Studio automation. The
automation includes ordered steps, each with one or more activities.
For activity-level edits use `manage_automation_activity`.

Marketing Cloud API
REST API (`/automation/v1/automations`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/automation/v1/automations
PATCH https://{tenant}.rest.marketingcloudapis.com/automation/v1/automations/{automation_id}
PATCH https://{tenant}.rest.marketingcloudapis.com/automation/v1/automations/key:{automation_key}
DELETE https://{tenant}.rest.marketingcloudapis.com/automation/v1/automations/{automation_id}
DELETE https://{tenant}.rest.marketingcloudapis.com/automation/v1/automations/key:{automation_key}
GET https://{tenant}.rest.marketingcloudapis.com/automation/v1/queries
GET https://{tenant}.rest.marketingcloudapis.com/automation/v1/scripts

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
POST: steps
PATCH: steps
DELETE: steps

Input (parameters)
operation ("create" | "update" | "delete", required) - create=POST /automation/v1/automations, update=PATCH
/automation/v1/automations/{id|key:key}, delete=DELETE
/automation/v1/automations/{id|key:key}.
automation_id (string, optional) - Automation id/ObjectID. Required for update/delete when automation_key is omitted.
automation_key (string, optional) - Automation external key. Used as key:{key} in REST paths. Required for update/delete
when automation_id is omitted.
name (string, optional) - Automation name. Required for create unless raw_request is provided.
key (string, optional) - Automation external key/customer key. Required for create unless raw_request is
provided.
description (string, optional) - Automation description.
category_id (number, optional) - Automation Studio folder categoryId.
type (string, optional) - Automation type when needed by the REST API, commonly scheduled.
start_source (object, optional) - Automation startSource payload, for example { "typeId": 1 } for a scheduled automation.
Sent as startSource.
status (string, optional) - Optional status value to send to Salesforce when supported by the API.
steps (object[], optional) - Ordered Automation Studio steps. Each activity should reference an existing activity
definition by activityObjectId or activityKey and include objectTypeId.
raw_request (object, optional) - Exact Salesforce REST request body. When provided for create/update, this body is sent
as-is except for the Account-Context header.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context REST header or
SOAP ClientID context. Defaults to the authenticated Business Unit when the session is
already scoped to one.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `automations_write`.

Idempotency & limits
- update idempotent.

Errors
- 30002 not found, INVALID_ACTIVITY_TYPE.

Example request

manage_automation({
  "operation": "create"
})
