Tool: delete_contact

Description
Delete a contact (and optionally all linked Subscriber + DataExtension
data) via Marketing Cloud's Contact Delete / Compliance API. Used for
GDPR / CCPA right-to-erasure requests.

Marketing Cloud API
REST API (`/contacts/v1/contacts/actions/delete`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/contacts/v1/addresses/email/search
POST https://{tenant}.rest.marketingcloudapis.com/contacts/v1/contacts/actions/delete
Optional query: type

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
POST: channelAddressList, maximumCount

Input (parameters)
contact_keys (string[], optional) - ContactKey values to delete via type=keys.
contact_ids (value[], optional) - ContactID values to delete via type=ids.
emails (string[], optional) - Email addresses to resolve via POST /contacts/v1/addresses/email/search, then delete by
resolved contactKey.
list_reference (object, optional) - Delete contacts from a list/data extension via type=listReference.
operation_type ("ContactAndAttributes" | "AttributesOnly", optional) - Salesforce DeleteOperationType. For enterprise-level deletes, Salesforce documents
ContactAndAttributes.
delete_list_when_completed (boolean, optional) - For listReference deletes, whether Salesforce should delete the source list when the
operation completes.
delete_list_contents_when_completed (boolean, optional) - For listReference deletes, whether Salesforce should clear the source list contents when
the operation completes.
maximum_email_matches (number, optional) - Maximum contact keys to resolve per email address when emails are supplied.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for this
Contacts REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.
email_search_response (value) - included in the JSON returned by the tool.
delete_response (value) - included in the JSON returned by the tool.
message (value) - included in the JSON returned by the tool.

Required scopes
- `audiences_write`.

Idempotency & limits
- Idempotent on contactKey: deleting an already-deleted contact returns "Complete" with no work.
- The actual data scrubbing is async and can take minutes to hours
  depending on the contact's footprint.

Errors
- 30002 not found, 403 unauthorized (no compliance entitlement).

Example request

delete_contact({})
