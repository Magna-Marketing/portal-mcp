Tool: create_or_update_contact

Description
Create or update one or more Contacts via the Contact Builder REST
API. Used to author / refresh contact records along with their
attribute set values. For the legacy Subscriber model use
`manage_subscriber`; this tool is the modern Contact Builder path.

Marketing Cloud API
REST API (`/contacts/v1/contacts`).

Endpoint
POST  https://{tenant}.rest.marketingcloudapis.com/contacts/v1/contacts        (create)
PATCH https://{tenant}.rest.marketingcloudapis.com/contacts/v1/contacts        (update; bulk)

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "contactKey": "MEM-100023",
  "attributeSets": [{
    "name": "Email Addresses",
    "items": [{
      "values": [
        { "name": "Email Address", "value": "jane.doe@example.com" },
        { "name": "HTML Enabled", "value": "true" }
      ]
    }]
  }]
}

Input (parameters)
operation ("create" | "update" | "upsert", required) - create calls POST /contacts/v1/contacts. update and upsert call PATCH
/contacts/v1/contacts. Salesforce can return operationStatus=FAIL in a 200 response.
contacts (object[], required) - Contacts to create or update. This tool sends one Salesforce Contacts API request per
contact and returns the raw response for each call.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for this
Contacts REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `audiences_write`.

Idempotency & limits
- upsert idempotent on `contactKey`.
- Bulk PATCH up to 100 contacts per call.

Errors
- 30002 not found (update), DUPLICATE_VALUE on contactKey collision (create).

Example request

create_or_update_contact({
  "operation": "create",
  "contacts": []
})
