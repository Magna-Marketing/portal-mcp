Tool: mint_token

Description
Mint a fresh OAuth access token. Useful when impersonating a different
business unit (`accountId`) than the default, or when an explicit
short-lived token is needed for downstream systems.

Marketing Cloud API
OAuth 2.0 (`/v2/token`).

Endpoint
POST https://{tenant}.auth.marketingcloudapis.com/v2/token

Headers
Content-Type: application/json

Body
POST: account_id, code, grant_type, redirect_uri, refresh_token, scope

Input (parameters)
grant_type ("client_credentials" | "authorization_code" | "refresh_token", optional) - OAuth grant for POST /v2/token. Server-to-server Installed Packages use
client_credentials. Web/public app flows can use authorization_code or refresh_token
when the current session was authenticated with matching package credentials.
scopes (string[], optional) - Subset of Installed Package scopes. Sent as a space-separated Salesforce scope string.
An empty array sends scope=""; omit this field to request the package defaults.
scope (string, optional) - Exact Salesforce scope string to send. Use this instead of scopes when you need full
control, including an empty string for no scopes.
code (string, optional) - Authorization code from /v2/authorize. Required when grant_type=authorization_code.
redirect_uri (string, optional) - Redirect URI used for the authorization-code request. Required when
grant_type=authorization_code and must not be URL encoded for /v2/token.
refresh_token (string, optional) - Refresh token returned by a web/public app token exchange. Required when
grant_type=refresh_token.
business_unit_id (string, optional) - Target Business Unit MID. Sent to Salesforce as account_id for /v2/token. Defaults to
the authenticated session MID when the session is already scoped to a BU.
account_id (number, optional) - Alias for business_unit_id using Salesforce OAuth terminology. Do not supply both
account_id and business_unit_id.
use_installed_package_default (boolean, optional) - When true, omit account_id from the /v2/token request so Salesforce mints the token in
the Installed Package default BU context.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- N/A — depends on the underlying Installed Package's grant.

Idempotency & limits
- Repeated calls return new tokens; the previous token remains valid until expiry (≈20 minutes default).
- Tenant-wide token-mint rate limits apply.

Errors
- 400 invalid_scope, 400 invalid_client, 401 unauthorized_client.

Example request

mint_token({})
