Tool: manage_groupconnect_app

Description
Create / update / delete a GroupConnect app registration (LINE channel,
KakaoTalk, etc.).

Marketing Cloud API
REST API (`/legacy/v1/beta/groupconnect/apps`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/ott/v1/registration

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
POST: ottPlatformAttributes, ottPlatformName

Input (parameters)
operation ("upsert" | "create" | "update", optional) - Registration operation. Salesforce exposes POST /ott/v1/registration as an upsert:
registering an existing Messenger Page ID or LINE Channel ID overrides its details. No
official delete endpoint is documented.
raw_request (object, optional) - Exact Salesforce POST /ott/v1/registration request body. If provided, convenience
parameters are ignored.
ott_platform_name ("line" | "messenger", optional) - Salesforce ottPlatformName. Supported values are line and messenger. Required unless
raw_request is provided.
ott_platform_attributes (object, optional) - Salesforce ottPlatformAttributes object. Required unless raw_request is provided.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
GroupConnect REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `messaging_api_app_write`.

Idempotency & limits
- update idempotent.

Errors
- DUPLICATE_VALUE.

Example request

manage_groupconnect_app({})
