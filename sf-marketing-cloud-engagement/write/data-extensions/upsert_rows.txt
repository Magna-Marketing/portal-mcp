Tool: upsert_rows

Description
Insert-or-update rows in a Data Extension keyed on its primary key.
Idempotent on the PK — the recommended write tool for ETL syncs.

Marketing Cloud API
REST API (`/hub/v1/dataevents/key:{key}/rowset`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/hub/v1/dataevents/key:{customerKey}/rowset

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
[
  { "keys": { "MemberId": "MEM-100023" }, "values": { "Email": "jane.doe@new.com", "TierName": "Platinum" } }
]

Input (parameters)
customer_key (string, required) - Data Extension external key.
rows (value[], required) - Rows to upsert. Prefer { keys, values } for synchronous rowset; flat field maps require
key_fields.
key_fields (string[], optional) - Primary-key field names, required when rows are supplied as flat field maps.
async (boolean, optional) - When true, uses PUT /data/v1/async/dataextensions/key:{key}/rows with { items }.
Defaults to true for more than 50 rows.
business_unit_id (string, optional) - Business Unit MID used to scope authentication plus REST Account-Context or SOAP
ClientID. Defaults to the session BU when available.
client_business_unit_id (number, optional) - Optional SOAP object Client.ID owner/context MID. Defaults to business_unit_id/session
MID when numeric. Use this when parent authentication writes into a child BU.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `data_extensions_write`.

Idempotency & limits
- Idempotent on PK.
- DE must have at least one `IsPrimaryKey=true` field.

Errors
- 30002 not found, NO_PRIMARY_KEY (DE has no PK), INVALID_FIELD.

Example request

upsert_rows({
  "customer_key": "",
  "rows": []
})
