Tool: manage_data_extension

Description
Create / update / delete a Data Extension. Schema (fields) is set at
create time; subsequent field adds / drops use this tool with the
field-update operations.

Marketing Cloud API
SOAP API (`DataExtension` Create / Update / Delete) +
`DataExtensionField` for schema.

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP CreateRequest / UpdateRequest / DeleteRequest envelopes.

Input (parameters)
operation ("create" | "update" | "delete" | "addField" | "removeField" | "renameField", required) - create/update/delete DataExtension, addField via DataExtension.Fields, removeField via
DataExtensionField delete, renameField via DataExtensionField update.
customer_key (string, optional) - Data Extension external key. Required for all operations except raw create XML.
name (string, optional) - DataExtension.Name. Required for create unless raw_data_extension_xml is supplied.
description (string, optional) - DataExtension.Description.
category_id (number, optional) - DataExtension.CategoryID folder id. Use list_folders for dataextension folders.
is_sendable (boolean, optional) - DataExtension.IsSendable.
sendable_data_extension_field (string, optional) - Field name in this DE used for sending. Required when creating a sendable DE unless raw
XML is supplied.
sendable_subscriber_field (string, optional) - Subscriber attribute to relate to. Common values: Subscriber Key or Email Address.
is_testable (boolean, optional) - DataExtension.IsTestable. Salesforce requires sendable DEs for testable usage.
fields (object[], optional) - Fields for create or addField.
remove_field_names (string[], optional) - Field names to delete for removeField. When possible, prefer remove_fields with
object_id/customer_key.
remove_fields (object[], optional) - DataExtensionField identifiers to delete. object_id is the safest identifier; name plus
DataExtension.CustomerKey is used as fallback.
rename_fields (object[], optional) - Fields to rename. Salesforce requires the existing DataExtensionField.ObjectID for
reliable updates.
template_object_id (string, optional) - DataExtensionTemplate.ObjectID to create the Data Extension from an existing template
(e.g. the TriggeredSendDataExtension template). Use list_data_extension_templates to
look this up. When set, fields becomes optional since the template supplies its own
column definitions.
template_customer_key (string, optional) - DataExtensionTemplate.CustomerKey to create the Data Extension from an existing
template. Alternative to template_object_id.
data_retention_period_length (number, optional) - DataExtension.DataRetentionPeriodLength. Requires retention permissions.
data_retention_period ("Days" | "Weeks" | "Months" | "Years", optional) - DataExtension.DataRetentionPeriod.
data_retention_period_unit_of_measure (number, optional) - DataExtension.DataRetentionPeriodUnitOfMeasure, if your account uses numeric retention
units.
is_data_retention_enabled (boolean, optional) - DataExtension.RowBasedRetention. true retains the DE and deletes individual rows at
retention expiry.
reset_retention_period_on_import (boolean, optional) - DataExtension.ResetRetentionPeriodOnImport.
delete_at_end_of_retention_period (boolean, optional) - DataExtension.DeleteAtEndOfRetentionPeriod. true deletes the DE at retention expiry.
raw_data_extension_xml (string, optional) - Exact DataExtension or DataExtensionField Objects XML to send inside the SOAP request.
Use for fields not covered by this schema.
confirm_delete (boolean, optional) - Must be true when operation=delete.
business_unit_id (string, optional) - Business Unit MID used to scope authentication plus REST Account-Context or SOAP
ClientID. Defaults to the session BU when available.
client_business_unit_id (number, optional) - Optional SOAP object Client.ID owner/context MID. Defaults to business_unit_id/session
MID when numeric. Use this when parent authentication writes into a child BU.

Result
tool (value) - included in the JSON returned by the tool.
operation (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
clientBusinessUnitId (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `data_extensions_write`.

Idempotency & limits
- update / addField / removeField idempotent.
- Cannot drop a field that participates in a Filter / Query / Send.

Errors
- DUPLICATE_VALUE on customerKey, INVALID_FIELD on bad type/scale combos.

Example request (create)

manage_data_extension({
  "operation": "create",
  "customerKey": "Members_DE",
  "deName": "Members",
  "isSendable": true,
  "sendableDataExtensionField": "Email",
  "sendableSubscriberField": "Subscriber Key",
  "fields": [
    { "name": "MemberId", "fieldType": "Text", "maxLength": 50, "isPrimaryKey": true, "isRequired": true },
    { "name": "Email",    "fieldType": "EmailAddress", "isRequired": true },
    { "name": "TierName", "fieldType": "Text", "maxLength": 50 }
  ]
})
