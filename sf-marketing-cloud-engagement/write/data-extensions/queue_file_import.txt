Tool: queue_file_import

Description
Queue an asynchronous one-time file import into a Data Extension. The
file (CSV / TSV) must already be uploaded to a Marketing Cloud FTP /
file-transfer location. Returns an import operation Id you can poll
with `get_file_import_status`.

For inline row writes use `insert_rows` / `upsert_rows`; for ongoing
scheduled imports configure an Automation with an Import activity
(`manage_automation_activity`).

Marketing Cloud API
REST API (`/data/v1/async/import`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/data/v1/async/import

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "name": "MTG Members Nightly",
  "customerKey": "MTG_Members_Import",
  "destination": { "dataExtensionCustomerKey": "Members_DE" },
  "format": { "fieldMappingType": "InferFromColumnHeadings", "delimiter": "Comma", "qualifier": "DoubleQuote", "dateFormatLocale": "en-US" },
  "source": { "location": { "id": 12345 }, "filename": "members-2026-04-30.csv" },
  "notifications": { "email": "ops@magnatech.com", "format": "Multipart" },
  "options": { "updateType": "AddAndUpdate" }
}

Input (parameters)
name (string, required) - One-time import name.
customer_key (string, optional) - Optional import customerKey/idempotency label supplied to Salesforce.
data_extension_customer_key (string, required) - Target Data Extension external key.
file_location_id (number, optional) - Salesforce file transfer location id for Enhanced FTP/Safehouse sources.
file_name (string, optional) - File name in the selected file transfer location.
delimiter ("Comma" | "Tab" | "Semicolon" | "Pipe" | "Other", optional) - File delimiter.
qualifier ("DoubleQuote" | "SingleQuote" | "None", optional) - Text qualifier.
date_format_locale (string, optional) - Date parsing locale.
field_mapping_type ("InferFromColumnHeadings" | "MapByHeaderMatch" | "MapByOrdinal" | "MapManually", optional) - Salesforce import fieldMappingType.
field_mappings (object[], optional) - Required when field_mapping_type=MapManually.
update_type ("AddOnly" | "UpdateOnly" | "AddAndUpdate" | "Overwrite", optional) - How imported rows affect target rows.
notifications_email (string, optional) - Optional email notification recipient.
has_column_header (boolean, optional) - Whether the file contains column headers.
source (value, optional) - Exact Salesforce source object. Use this for pre-signed cloud locations or advanced
import sources. Overrides file_location_id/file_name.
raw_request (value, optional) - Exact Salesforce /data/v1/async/import request body. Use for fields not covered by this
schema.
business_unit_id (string, optional) - Business Unit MID used to scope authentication plus REST Account-Context or SOAP
ClientID. Defaults to the session BU when available.
client_business_unit_id (number, optional) - Optional SOAP object Client.ID owner/context MID. Defaults to business_unit_id/session
MID when numeric. Use this when parent authentication writes into a child BU.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `data_extensions_write`.

Idempotency & limits
- Not idempotent; each call queues a new import.
- Subject to file-storage quotas and concurrent import caps.

Errors
- 30002 destination not found, INVALID_FILE_LOCATION.

Example request

queue_file_import({
  "name": "",
  "data_extension_customer_key": ""
})
