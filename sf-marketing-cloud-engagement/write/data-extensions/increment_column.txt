Tool: increment_column

Description
Atomically increment (or decrement) a numeric column on a single DE
row, identified by a search key. Used for view counters, click totals,
points balances. Sync or async path.

Marketing Cloud API
REST API
(`/hub/v1/dataevents/key:{key}/rows/{searchKey}:{searchValue}/column/{column}/increment`
sync, or `/hub/v1/dataeventsasync/...` async).

Endpoint
PUT https://{tenant}.rest.marketingcloudapis.com/hub/v1/dataevents/key:{customer_key}/rows/{search_field}:{search_value}/column/{column_name}/increment
Optional query: step

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
None (parameters in URL).

Input (parameters)
customer_key (string, required) - Data Extension external key.
search_field (string, required) - Primary-key/search field used to locate the row.
search_value (value, required) - Value for search_field.
column_name (string, required) - Numeric column to increment.
step (number, optional) - Increment amount. Use a negative number to decrement.
business_unit_id (string, optional) - Business Unit MID used to scope authentication plus REST Account-Context or SOAP
ClientID. Defaults to the session BU when available.
client_business_unit_id (number, optional) - Optional SOAP object Client.ID owner/context MID. Defaults to business_unit_id/session
MID when numeric. Use this when parent authentication writes into a child BU.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `data_extensions_write`.

Idempotency & limits
- Not idempotent — each call applies the step.
- Atomic at the row level (avoids read-modify-write races).

Errors
- 30002 row / DE not found, INVALID_FIELD (column not numeric).

Example request

increment_column({
  "customer_key": "",
  "search_field": "",
  "search_value": "",
  "column_name": ""
})
