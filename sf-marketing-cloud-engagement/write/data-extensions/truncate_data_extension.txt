Tool: truncate_data_extension

Description
Remove all rows from a Data Extension while preserving its schema.
Equivalent to a SQL `TRUNCATE TABLE`.

Marketing Cloud API
SOAP API (`PerformRequest` with `ClearData` action).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP PerformRequest with `Action=ClearData` on the DataExtension.

Input (parameters)
customer_key (string, required) - Data Extension external key.
confirm_truncate (boolean, optional) - Must be true to remove all rows from the Data Extension.
business_unit_id (string, optional) - Business Unit MID used to scope authentication plus REST Account-Context or SOAP
ClientID. Defaults to the session BU when available.
client_business_unit_id (number, optional) - Optional SOAP object Client.ID owner/context MID. Defaults to business_unit_id/session
MID when numeric. Use this when parent authentication writes into a child BU.

Result
tool (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
clientBusinessUnitId (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `data_extensions_write`.

Idempotency & limits
- Truncate is idempotent (a second call truncates an already-empty DE).

Errors
- 30002 not found.

Example request

truncate_data_extension({
  "customer_key": ""
})
