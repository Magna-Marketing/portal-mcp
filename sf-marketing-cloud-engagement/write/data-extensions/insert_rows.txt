Tool: insert_rows

Description
Insert rows into a Data Extension. For DEs with a primary key, prefer
`upsert_rows` for idempotency.

Marketing Cloud API
REST API (`/data/v1/async/dataextensions/key:{key}/rows` for async)
or `/hub/v1/dataevents/key:{key}/rowset` for sync up to 50 rows; SOAP
`DataExtensionObject[ExternalKey]` for >50 rows.

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/data/v1/async/dataextensions/key:{customer_key}/rows
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8
Content-Type: application/json
Accept: application/json

Body
POST: items

Input (parameters)
customer_key (string, required) - Data Extension external key.
rows (object[], required) - Rows to insert as flat field maps. Field names must exactly match the Data Extension
schema.
async (boolean, optional) - When true, uses POST /data/v1/async/dataextensions/key:{key}/rows. Defaults to true for
more than 50 rows, otherwise SOAP Create for synchronous insert-only behavior.
business_unit_id (string, optional) - Business Unit MID used to scope authentication plus REST Account-Context or SOAP
ClientID. Defaults to the session BU when available.
client_business_unit_id (number, optional) - Optional SOAP object Client.ID owner/context MID. Defaults to business_unit_id/session
MID when numeric. Use this when parent authentication writes into a child BU.

Result
Raw Marketing Cloud response JSON, returned unchanged.
tool (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
clientBusinessUnitId (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `data_extensions_write`.

Idempotency & limits
- Inserts are not idempotent; duplicate inserts on a non-PK DE create
  duplicate rows. For idempotency, use `upsert_rows` with a primary key.
- Sync cap: 50 rows per call. Async covers ≥50.

Errors
- 30002 not found, INVALID_FIELD.

Example request

insert_rows({
  "customer_key": "",
  "rows": []
})
