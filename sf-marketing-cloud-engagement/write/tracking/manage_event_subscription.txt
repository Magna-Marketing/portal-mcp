Tool: manage_event_subscription

Description
Manage Event Notification Service (ENS) subscriptions: Marketing Cloud
pushes engagement events (sends, opens, clicks, bounces, unsubscribes,
journey events) to a registered callback URL. The callback (HTTPS
endpoint) is created/maintained by `manage_event_callback`; this tool
manages which event types each callback receives.

Marketing Cloud API
REST API (`/platform/v1/ens-subscriptions`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/platform/v1/ens-subscriptions/{subscription_id}
DELETE https://{tenant}.rest.marketingcloudapis.com/platform/v1/ens-subscriptions
PUT https://{tenant}.rest.marketingcloudapis.com/platform/v1/ens-subscriptions

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "subscriptionId": "...",
  "callbackId": "...",
  "filters": [],
  "subscribedEventCategories": ["TransactionalSendEvents.Email.Sent","EngagementEvents.OpenEvent"],
  "subscriptionName": "MTG-MainSubscription",
  "status": "Active"
}

Input (parameters)
operation ("create" | "update" | "delete" | "activate" | "deactivate" | "pause" | "unpause", required) - create=POST /platform/v1/ens-subscriptions, update=PUT /platform/v1/ens-subscriptions,
delete=DELETE /platform/v1/ens-subscriptions/{subscriptionId}. activate/unpause and
deactivate/pause are update shortcuts that set status to active or paused.
subscription_id (string, optional) - ENS subscriptionId. Required for update, delete, activate, deactivate, pause, and
unpause. Sent as subscriptionId for update operations.
subscription_name (string, optional) - Subscription name. Required for create unless supplied in raw_request. Sent as
subscriptionName.
callback_id (string, optional) - Verified ENS callbackId that receives events. Required for create unless supplied in
raw_request. Sent as callbackId.
event_category_types (string[], optional) - Fully qualified ENS event types, such as TransactionalSendEvents.EmailSent,
EngagementEvents.OpenEvent, EngagementEvents.ClickEvent, EngagementEvents.BounceEvent,
EngagementEvents.UnsubEvent, or JourneyEvents.JourneyComplete. Sent as
eventCategoryTypes.
subscribed_event_categories (string[], optional) - Compatibility alias for older docs. Mapped to Salesforce eventCategoryTypes when
event_category_types is omitted.
filters (string[], optional) - Optional Salesforce ENS filter strings in key=value format, such as
definitionKey=abc123. All filters must evaluate true for an event to be delivered.
status ("active" | "paused" | "Active" | "Paused", optional) - Subscription status for update: active or paused. Salesforce uses paused to pause
delivery.
status_reason (string, optional) - Required by Salesforce when changing status. Sent as statusReason.
raw_request (value, optional) - Exact Salesforce request body. When provided, convenience fields are ignored except
subscription_id for delete endpoint selection.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for this
ENS REST request. Defaults to the authenticated Business Unit when the session is
already scoped to one.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `webhooks_write` (or `event_notifications_write` on newer packages).

Idempotency & limits
- update / activate / deactivate idempotent.

Errors
- 30002 callback not found, 401 unauthorized.

Example request

manage_event_subscription({
  "operation": "create"
})
