Tool: manage_event_callback

Description
Manage Event Notification Service callbacks (the webhook endpoints
ENS pushes events to). Operations: create, update, delete, verify
(POST a one-time challenge to confirm endpoint ownership).

Marketing Cloud API
REST API (`/platform/v1/ens-callbacks` and `/platform/v1/ens-verify`).

Endpoint
PUT https://{tenant}.rest.marketingcloudapis.com/platform/v1/ens-callbacks/{callback_id}
DELETE https://{tenant}.rest.marketingcloudapis.com/platform/v1/ens-verify
POST https://{tenant}.rest.marketingcloudapis.com/platform/v1/ens-callbacks

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
PUT: callbackId, verificationKey
DELETE: callbackId, verificationKey
POST: callbackId, verificationKey

Input (parameters)
operation ("create" | "update" | "delete" | "verify", required) - create=POST /platform/v1/ens-callbacks, update=PUT /platform/v1/ens-callbacks,
delete=DELETE /platform/v1/ens-callbacks/{callbackId}, verify=POST
/platform/v1/ens-verify.
callback_id (string, optional) - ENS callbackId. Required for update, delete, and verify. Sent as callbackId for update
and verify.
callback_name (string, optional) - Callback name. Required for create and update unless supplied in raw_request. Sent as
callbackName.
url (string, optional) - HTTPS callback endpoint. Required for create unless supplied in raw_request. Salesforce
doesn\'t support ports or query strings for ENS callback URLs.
max_batch_size (number, optional) - Maximum events per callback POST. Salesforce defaults to 1000; update requires 100-1000
when supplied. Sent as maxBatchSize.
verification_key (string, optional) - Single-use verificationKey received by the callback endpoint. Required for verify.
raw_request (value, optional) - Exact Salesforce request body. For create, Salesforce documents an array of callback
objects; if omitted, this tool builds that array from callback_name, url, and
max_batch_size.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for this
ENS REST request. Defaults to the authenticated Business Unit when the session is
already scoped to one.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `webhooks_write`.

Idempotency & limits
- update idempotent.
- Marketing Cloud expects the callback URL to respond 200 within 30s during verify.

Errors
- VERIFICATION_FAILED, 30002 not found.

Example request

manage_event_callback({
  "operation": "create"
})
