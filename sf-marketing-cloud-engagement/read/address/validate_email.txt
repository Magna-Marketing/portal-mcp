Tool: validate_email

Description
Validate an email address through Marketing Cloud's Address Validation
API. Returns deliverability score, flagged status (Risky / High Risk /
Invalid), and lightweight syntactic + DNS checks. Use to scrub lists
before sends.

Marketing Cloud API
REST API (`/address/v1/validateEmail`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/address/v1/validateEmail

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "email": "jane.doe@example.com", "validators": ["SyntaxValidator", "MXValidator", "ListDetectiveValidator"] }

Input (parameters)
email (string, required) - Email address to validate.
validators ("SyntaxValidator" | "MXValidator" | "ListDetectiveValidator"[], optional) - Optional validator chain. Defaults to SyntaxValidator, MXValidator, and
ListDetectiveValidator.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `email_send` (or default Installed Package scope).

Idempotency & limits
- Read-only; safe to retry.
- Subject to per-tenant validation rate limits (~10/sec default).

Errors
- 10000 invalid email format.

Example request

validate_email({
  "email": ""
})
