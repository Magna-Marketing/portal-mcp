Tool: list_automations

Description
List Automation Studio automations. Each automation row includes Id,
name, status (Building / Scheduled / Running / Paused / Stopped /
Error), schedule, last run, and step count.

Marketing Cloud API
REST API (`/automation/v1/automations`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/automation/v1/automations?$page=1&$pageSize=50

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
status (value, optional) - Optional automation status filter. Supported values: Building, Scheduled, Running,
Paused, Stopped, Error, Awaiting Trigger.
name_pattern (string, optional) - Optional name search pattern sent as a REST $filter against the automation name.
folder_id (number, optional) - Optional Automation Studio folder/category ID filter.
modified_since (string, optional) - Optional ISO date-time filter for automations modified after this value.
page (number, optional) - REST $page value. Defaults to 1.
page_size (number, optional) - REST $pageSize value. Defaults to 50, maximum 200.
order_by (string, optional) - Optional REST $orderBy value, for example "name" or "modifiedDate desc".
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `automations_read`.

Idempotency & limits
- Read-only.

Errors
- 401 unauthorized.

Example request

list_automations({})
