Tool: list_activity_types

Description
List the catalogue of automation activity types available in the org
(Built-in Salesforce activities + any custom activities registered).
Useful when authoring a new automation programmatically.

Marketing Cloud API
REST API (`/automation/v1/activitytypes`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/automation/v1/activitytypes

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
include_custom (boolean, optional) - Whether to include a note about discovering custom or tenant-specific activity types
from existing automations. Defaults to true.
business_unit_id (string, optional) - Accepted for compatibility with other automation tools. Activity type catalog data is
local and is not scoped by Business Unit.

Result
items (value) - included in the JSON returned by the tool.
totalCount (value) - included in the JSON returned by the tool.
source (value) - included in the JSON returned by the tool.

Required scopes
- `automations_read`.

Idempotency & limits
- Read-only.

Errors
- 401 unauthorized.

Example request

list_activity_types({})
