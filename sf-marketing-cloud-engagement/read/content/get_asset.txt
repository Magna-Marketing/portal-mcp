Tool: get_asset

Description
Get a single Content Builder asset by Id, customerKey, or shared key.
Returns full body (HTML, text, image bytes via separate call), metadata,
and version history.

Marketing Cloud API
REST API (`/asset/v1/content/assets/{id}`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/asset/v1/content/assets/query

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
asset_id (number, optional) - Content Builder asset ID. When provided, the tool calls GET
/asset/v1/content/assets/{id}.
customer_key (string, optional) - Content Builder customerKey. When asset_id is omitted, the tool first queries by
customerKey and then retrieves the matching asset by ID.
fields (string[], optional) - Optional fields used only for the customerKey lookup query. The final asset GET response
is returned without client-side field trimming.
include_lookup_response (boolean, optional) - When resolving by customer_key, include the raw lookup query response next to the raw
asset GET response.
business_unit_id (string, optional) - Business Unit MID used to scope the token and Account-Context header for Content Builder
REST requests.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `email_read` or `documents_and_images_read` depending on assetType.

Idempotency & limits
- Read-only.

Errors
- 30002 not found.

Example request

get_asset({})
