Tool: list_assets

Description
List Content Builder assets — HTML emails, templates, blocks
(text/HTML/free-form), images, documents. Filter by `assetType.id`,
folder, or owner. Use to inventory creative library or pick an asset
for `manage_triggered_send_definition` / `send_email_now`.

Marketing Cloud API
REST API (`/asset/v1/content/assets/query`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/asset/v1/content/assets/query

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "page": { "page": 1, "pageSize": 50 },
  "query": {
    "leftOperand": { "property": "assetType.id", "simpleOperator": "in", "value": [196, 207, 208, 209, 210] },
    "logicalOperator": "AND",
    "rightOperand": { "property": "category.id", "simpleOperator": "equal", "value": 12345 }
  }
}

Input (parameters)
asset_type_ids (number[], optional) - Optional Content Builder assetType.id filters. Examples: 208 htmlemail, 207
templatebasedemail, 197 htmlblock, 28 png.
category_id (number, optional) - Optional Content Builder category/folder ID filter using category.id.
name_pattern (string, optional) - Optional Content Builder asset name pattern. Sent to the advanced query endpoint as a
name like filter.
customer_key (string, optional) - Optional exact customerKey filter.
modified_since (string, optional) - Optional ISO date-time filter for assets modified after this value.
owner_id (number, optional) - Optional owner.id filter.
fields (string[], optional) - Optional response fields list for the advanced query. Omit to request broad useful asset
fields including content, views, category, owner, fileProperties, thumbnail, and
businessUnitAvailability.
sort (object[], optional) - Optional advanced query sort list, for example [{ "property": "modifiedDate",
"direction": "DESC" }].
page (number, optional) - Advanced query page number. Defaults to 1.
page_size (number, optional) - Advanced query page size. Defaults to 50, maximum 200.
business_unit_id (string, optional) - Business Unit MID used to scope the token and Account-Context header for this Content
Builder REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `documents_and_images_read` (images / docs).
- `email_read` (email assets / templates / blocks).

Idempotency & limits
- Read-only.
- Use targeted assetTypeIds in big tenants — full-tenant queries can be slow.

Errors
- 10000 bad request, 30002 not found.

Example request

list_assets({})
