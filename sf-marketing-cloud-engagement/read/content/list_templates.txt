Tool: list_templates

Description
List Content Builder templates (assetType id 207). Convenience wrapper
around `list_assets` filtered to template-specific asset types.

Marketing Cloud API
REST API (`/asset/v1/content/assets/query`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/asset/v1/content/assets/query

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "query": { "property": "assetType.id", "simpleOperator": "in", "value": [4, 5, 6, 207] }, "page": { "page": 1, "pageSize": 50 } }

Input (parameters)
template_type ("any" | "email" | "web" | "default" | "journey_builder" | "json_message", optional) - Template type filter. any includes Salesforce template-family asset types: template,
webtemplate, templatebasedemail, defaulttemplate, jbtemplate, and jsonmessagetemplate.
category_id (number, optional) - Optional Content Builder category/folder ID filter using category.id.
name_pattern (string, optional) - Optional Content Builder template name pattern. Sent to the advanced query endpoint as a
name like filter.
fields (string[], optional) - Optional response fields list for the advanced query. Omit to request broad useful asset
fields including content, views, category, owner, and businessUnitAvailability.
page (number, optional) - Advanced query page number. Defaults to 1.
page_size (number, optional) - Advanced query page size. Defaults to 50, maximum 200.
business_unit_id (string, optional) - Business Unit MID used to scope the token and Account-Context header for this Content
Builder REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `email_read`.

Idempotency & limits
- Read-only.

Errors
- 10000 bad request.

Example request

list_templates({})
