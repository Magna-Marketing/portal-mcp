Tool: list_categories

Description
List folders (`Category` REST API) inside Content Builder. Folders
organize assets, blocks, and templates. For other folder spaces (Email,
DE, Triggered Send, Automation) use `read/folders/list_folders`.

Marketing Cloud API
REST API (`/asset/v1/content/categories`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/asset/v1/content/categories

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
category_id (number, optional) - Optional category ID. When provided, calls GET /asset/v1/content/categories/{id}.
parent_id (number, optional) - Optional Content Builder parent category ID. Salesforce category filtering supports
ParentId.
page (number, optional) - Category page number. Defaults to 1.
page_size (number, optional) - Category page size. Defaults to 100, maximum 200.
order_by (string, optional) - Optional category orderBy expression supported by Salesforce, for example "categoryId
asc" or "name asc".
business_unit_id (string, optional) - Business Unit MID used to scope the token and Account-Context header for this Content
Builder REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `email_read`.

Idempotency & limits
- Read-only.

Errors
- 10000 bad request.

Example request

list_categories({})
