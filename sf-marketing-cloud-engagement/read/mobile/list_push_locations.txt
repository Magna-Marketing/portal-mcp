Tool: list_push_locations

Description
List MobilePush location targets (geofences) registered in the BU.
Each location has a center coordinate, radius, and metadata used to
trigger location-aware push messages.

Marketing Cloud API
REST API (`/push/v1/location/`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/push/v1/location/{location_id}
GET https://{tenant}.rest.marketingcloudapis.com/push/v1/location

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
location_id (string, optional) - Optional MobilePush location ID. When provided, the tool calls GET
/push/v1/location/{locationId} and ignores list filters.
name_pattern (string, optional) - Optional location name pattern, sent as name like {value}.
location_type (value, optional) - Optional Salesforce locationType filter. Use 1 for geofence and 3 for beacon.
raw_filter (string, optional) - Optional raw Salesforce $filter expression. If supplied, it is combined with generated
filters. Salesforce supports name and locationType filters.
order_by (string, optional) - Optional Salesforce $orderBy value, for example "modifiedDate DESC" or "name ASC".
page (number, optional) - Salesforce $page value. Defaults to 1.
page_size (number, optional) - Salesforce $pageSize value. Defaults to 25.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `push_read`.

Idempotency & limits
- Read-only.

Errors
- 401 unauthorized, 30002 not found.

Example request

list_push_locations({})
