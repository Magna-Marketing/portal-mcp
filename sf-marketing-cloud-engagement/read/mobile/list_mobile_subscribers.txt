Tool: list_mobile_subscribers

Description
List MobileConnect subscribers (`Subscription`) — phone number-based
SMS subscribers attached to keywords or lists.

Marketing Cloud API
REST API (`/legacy/v1/beta/mobile/subscription/`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/legacy/v1/beta/mobile/subscription
Optional query: $page, $pageSize, codeId, keywordId, mobileNumber, status

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
mobile_number (string, optional) - Optional mobile number filter for the legacy MobileConnect subscription endpoint.
status ("Active" | "Pending" | "Unsubscribed", optional) - Optional subscription status filter.
keyword_id (number, optional) - Optional MobileConnect keyword ID filter for the legacy endpoint.
code_id (number, optional) - Optional short code/long code ID filter for the legacy endpoint.
page (number, optional) - Legacy endpoint page number. Defaults to 1.
page_size (number, optional) - Legacy endpoint page size. Defaults to 1000.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `mobile_connect_read`.

Idempotency & limits
- Read-only.

Errors
- 401 unauthorized.

Example request

list_mobile_subscribers({})
