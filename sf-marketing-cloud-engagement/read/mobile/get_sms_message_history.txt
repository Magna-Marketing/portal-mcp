Tool: get_sms_message_history

Description
Get SMS delivery history for a single contact + message + token.
Returns send attempts, statuses (Queued / Sent / Delivered / Failed),
timestamps. Pair with `list_sms_subscription_status` for subscription
state.

Marketing Cloud API
REST API (`/sms/v1/messageContact/{messageId}/history/{tokenId}/mobileNumber/{number}`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/sms/v1/messageContact/{message_id}/history/{token_id}/mobileNumber/{mobile_number}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
message_id (string, required) - Message ID/API key provided for the MobileConnect messageContact send definition.
token_id (string, required) - Token ID returned by POST /sms/v1/messageContact/{messageId}/send.
mobile_number (string, required) - Mobile number for the messageContact history lookup. Use the same number format used in
the send request.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `sms_read`.

Idempotency & limits
- Read-only.

Errors
- 30002 not found.

Example request

get_sms_message_history({
  "message_id": "",
  "token_id": "",
  "mobile_number": ""
})
