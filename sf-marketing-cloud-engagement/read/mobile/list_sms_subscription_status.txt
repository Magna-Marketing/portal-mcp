Tool: list_sms_subscription_status

Description
Bulk-check the SMS subscription status for one or more phone numbers
against one or more keywords / short-codes. Returns active / pending /
unsubscribed for each combination.

Marketing Cloud API
REST API (`/sms/v1/contacts/subscriptions`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/sms/v1/contacts/subscriptions

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "mobileNumbers": ["+15551234567"],
  "keywords": [{ "keyword": "MTG", "shortCode": "12345", "countryCode": "US" }]
}

Input (parameters)
mobile_numbers (string[], optional) - Mobile numbers to check. Salesforce sends this as the mobileNumber array and allows up
to 500 values. Use the format expected for the subscriber country, for example
13175551212 for US numbers.
subscriber_keys (string[], optional) - Subscriber keys to check. Salesforce sends this as the subscriberKey array and allows up
to 500 values.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `sms_read`.

Idempotency & limits
- Read-only.

Errors
- INVALID_PHONE_NUMBER.

Example request

list_sms_subscription_status({})
