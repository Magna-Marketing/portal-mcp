Tool: list_push_apps

Description
List MobilePush applications registered to the BU. Each app has
identity, platform (iOS / Android / FireOS), bundle Id, and certificate
expiration.

Marketing Cloud API
REST API (`/push/v1/application/`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/push/v1/application/{app_id}
GET https://{tenant}.rest.marketingcloudapis.com/push/v1/application
GET https://{tenant}.rest.marketingcloudapis.com/push/v1/application/{app_id}/key

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
app_id (string, optional) - Optional MobilePush app ID. When provided, the tool calls GET
/push/v1/application/{appId}; otherwise it lists all apps with GET /push/v1/application.
include_keys (boolean, optional) - When app_id is provided, also call GET /push/v1/application/{appId}/key and return both
raw Salesforce response bodies.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
mobile REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.
application (value) - included in the JSON returned by the tool.
keys (value) - included in the JSON returned by the tool.

Required scopes
- `push_read`.

Idempotency & limits
- Read-only.

Errors
- 401 unauthorized.

Example request

list_push_apps({})
