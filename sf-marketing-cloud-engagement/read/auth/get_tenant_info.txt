Tool: get_tenant_info

Description
Get tenant-wide info: tenant subdomain, edition, time zone, currency,
parent enterprise MID, available REST/SOAP/Auth base URLs, and (for
Enterprise tenants) a business-unit hierarchy summary.

Combines OAuth `/v2/userinfo`, OAuth `/v2/discovery` (canonical base
URL discovery), and a SOAP `Account` retrieve.

Marketing Cloud API
OAuth + SOAP API. Discovery endpoint is the official source for
per-app base URLs:
- `GET /v2/discovery?client_id={clientId}&resource=acct:{userId}`
  returns the REST and SOAP instance URLs the Installed Package can
  call into.

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/platform/v1/tokenContext
GET https://{tenant}.rest.marketingcloudapis.com/platform/v1/endpoints
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx
SOAP object: Account
GET https://{tenant}.auth.marketingcloudapis.com/v2/userinfo
GET https://{tenant}.auth.marketingcloudapis.com/v2/discovery

Headers
Authorization: Bearer <access_token>
Accept: application/json (REST) or text/xml (SOAP)

Body
SOAP request on Account.

Input (parameters)
business_unit_id (string, optional) - Business Unit MID used to request a BU-scoped token and SOAP ClientID context.
include_base_urls (boolean, optional) - Call /platform/v1/endpoints to retrieve tenant endpoint URLs. Defaults to true.
include_account (boolean, optional) - Retrieve the current Account record by MID through SOAP. Defaults to true.
include_business_units (boolean, optional) - Retrieve accessible Account records with QueryAllAccounts=true through SOAP. Defaults to
true.
include_token_context (boolean, optional) - Call /platform/v1/tokenContext to include the raw token context. Defaults to true.
include_discovery (boolean, optional) - Also call the auth-host /v2/discovery endpoint when client_id and a discovery resource
are available. Defaults to false.
discovery_resource (string, optional) - Optional resource query value for /v2/discovery, for example acct:123456. Defaults to
the selected/current MID when available.

Result
userInfo (value) - included in the JSON returned by the tool.
tokenResponse (value) - included in the JSON returned by the tool.

Required scopes
- `accounts_read`.

Idempotency & limits
- Read-only.

Errors
- 401 invalid_token.

Example request

get_tenant_info({})
