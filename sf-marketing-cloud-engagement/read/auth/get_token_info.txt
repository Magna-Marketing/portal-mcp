Tool: get_token_info

Description
Inspect the active access token: tenant subdomain, business-unit (MID)
the token was issued for, granted scopes, expiration, and the Installed
Package client id. Useful for debugging "why is this call returning
401 / 403?".

Marketing Cloud API
REST API.

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/platform/v1/tokenContext
GET https://{tenant}.auth.marketingcloudapis.com/v2/userinfo

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
business_unit_id (string, optional) - Business Unit MID used to request a BU-scoped access token before inspecting token
context.
include_user_info (boolean, optional) - Also call /v2/userinfo and include that raw response. Defaults to false.

Result
Raw Marketing Cloud response JSON, returned unchanged.
tokenContext (value) - included in the JSON returned by the tool.
userInfo (value) - included in the JSON returned by the tool.

Required scopes
- The Installed Package needs at least `offline` scope (issued by default).

Idempotency & limits
- Read-only; safe to retry.

Errors
- 401 invalid_token if the token is expired (the MCP server refreshes
  and retries once).

Example request

get_token_info({})
