Tool: get_user_info

Description
Get the OAuth-mapped user info for the current token (the integration
user the Installed Package authenticates as). Returns identity claims
similar to OpenID Connect.

Marketing Cloud API
REST API.

Endpoint
GET https://{tenant}.auth.marketingcloudapis.com/v2/userinfo

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
business_unit_id (string, optional) - Business Unit MID used to request a BU-scoped access token before calling /v2/userinfo.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- N/A (issued automatically with most package tokens).

Idempotency & limits
- Read-only.

Errors
- 401 invalid_token.

Example request

get_user_info({})
