Tool: list_folders

Description
List folders (`DataFolder` SOAP / `Category` REST) across any object
type (Email, Data Extension, Triggered Send, Automation, Asset, etc.).
Marketing Cloud has separate folder spaces per content type — pass
`contentType` to scope.

Marketing Cloud API
SOAP API (`DataFolder.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP retrieve on DataFolder.

Input (parameters)
content_type (string, required) - Marketing Cloud DataFolder ContentType to retrieve, such as dataextension,
shared_dataextension for Shared Data Extensions, email, triggered_send, automations,
asset, list, queryactivity, filterdefinition, import, or publication.
parent_folder_id (number, optional) - Optional numeric parent DataFolder ID. Sent as a ParentFolder.ID SOAP filter.
name_pattern (string, optional) - Optional SOAP like filter against DataFolder.Name. Use SQL-style wildcards when needed,
for example "Campaign%".
properties (string[], optional) - Optional SOAP DataFolder property projection. Defaults to useful folder metadata, parent
folder fields, and Client.ID.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and SOAP ClientID context.
query_all_accounts (boolean, optional) - Set true to add QueryAllAccounts to the SOAP retrieve when the installed package can
access child Business Units.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
contentType (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- Varies by `contentType`. Most use `email_read` / `data_extensions_read` / `automations_read`.

Idempotency & limits
- Read-only.

Errors
- INVALID_FOLDER_TYPE.

Example request

list_folders({
  "content_type": ""
})
