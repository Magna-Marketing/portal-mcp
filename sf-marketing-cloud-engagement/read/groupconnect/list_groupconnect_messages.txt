Tool: list_groupconnect_messages

Description
List GroupConnect messages sent or scheduled to send.

Marketing Cloud API
REST API (`/legacy/v1/beta/groupconnect/messages`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/ott/v1/send/{message_id}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
message_id (string, required) - Required message identifier to retrieve. Salesforce accepts either the user-defined
messageKey or the ottRequestId returned from POST /ott/v1/send.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
GroupConnect REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `messaging_api_app_read`.

Idempotency & limits
- Read-only.

Errors
- 401 unauthorized.

Example request

list_groupconnect_messages({
  "message_id": ""
})
