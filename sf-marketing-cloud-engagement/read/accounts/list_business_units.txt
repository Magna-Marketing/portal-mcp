Tool: list_business_units

Description
List all business units (child accounts) under the enterprise. Each
entry has its MID, name, account type, and parent. Use to pick a
target MID for tools that accept `accountId`.

Marketing Cloud API
SOAP API (`Account.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP RetrieveRequest on `Account` filtered to `ParentID != 0`.

Input (parameters)
include_inactive (boolean, optional) - Accepted for compatibility. The raw SOAP Account response is returned without
client-side filtering.
include_children (boolean, optional) - Accepted for compatibility with the old business-unit tool. QueryAllAccounts controls
child account retrieval.
name_pattern (string, optional) - Optional SOAP like filter for Account.Name. Omit for the safest full business-unit
discovery call.
business_unit_id (string, optional) - Business Unit MID used for SOAP ClientID context.
query_all_accounts (boolean, optional) - Query all accessible parent and child accounts. Defaults to true.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
business_units (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `accounts_read`.

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS for non-enterprise accounts (returns only the calling MID).

Example request

list_business_units({})
