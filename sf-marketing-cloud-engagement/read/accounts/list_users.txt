Tool: list_users

Description
List Marketing Cloud users (`AccountUser`). Each user has identity, role,
business unit access, last login, locked-out flag.

Marketing Cloud API
SOAP API (`AccountUser.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP RetrieveRequest on `AccountUser`.

Input (parameters)
is_active (boolean, optional) - Filter by AccountUser.ActiveFlag. Defaults to true.
email_pattern (string, optional) - SOAP like filter for AccountUser.Email.
name_pattern (string, optional) - SOAP like filter for AccountUser.Name.
business_unit_id (string, optional) - Business Unit MID used for SOAP ClientID context.
query_all_accounts (boolean, optional) - Query users across parent and child accounts. Defaults to true.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `users_read`.

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_users({})
