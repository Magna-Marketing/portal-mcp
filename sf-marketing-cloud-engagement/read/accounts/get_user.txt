Tool: get_user

Description
Get a single Marketing Cloud user with full role + business unit
assignments.

Marketing Cloud API
SOAP API (`AccountUser.Retrieve` filtered).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP request on AccountUser, Account.

Input (parameters)
user_id (number, optional) - Internal AccountUser ID.
username (string, optional) - AccountUser.UserID username.
email (string, optional) - AccountUser.Email address.
business_unit_id (string, optional) - Business Unit MID used for SOAP ClientID context.
query_all_accounts (boolean, optional) - Query users across parent and child accounts. Defaults to true.
include_default_business_unit (boolean, optional) - Also retrieve the Account record for the user DefaultBusinessUnit when it is present.
Defaults to true.

Result
tool (value) - included in the JSON returned by the tool.
responses (value) - included in the JSON returned by the tool.

Required scopes
- `users_read`.

Idempotency & limits
- Read-only.

Errors
- USER_NOT_FOUND.

Example request

get_user({})
