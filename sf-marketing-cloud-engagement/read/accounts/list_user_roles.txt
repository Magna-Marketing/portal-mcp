Tool: list_user_roles

Description
List Marketing Cloud roles (`Role`) — both standard (Marketing Cloud
Administrator, Content Creator, Channel Manager, etc.) and custom.

Marketing Cloud API
SOAP API (`Role.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP retrieve on Role.

Input (parameters)
custom_only (boolean, optional) - When true, retrieve only non-system/private roles where supported by the SOAP Role
object.
name_pattern (string, optional) - SOAP like filter for Role.Name.
customer_key_pattern (string, optional) - SOAP like filter for Role.CustomerKey, useful for system role keys such as SYS_DEF_*.
business_unit_id (string, optional) - Business Unit MID used for SOAP ClientID context.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `users_read`.

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_user_roles({})
