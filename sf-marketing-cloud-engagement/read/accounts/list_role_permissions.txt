Tool: list_role_permissions

Description
List the granular permissions assigned to a single role
(`RolePermission`).

Marketing Cloud API
SOAP API (`RolePermission.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP retrieve on RolePermission filtered by RoleID.

Input (parameters)
role_id (number, optional) - Role.ID to retrieve.
role_name (string, optional) - Role.Name to retrieve.
role_customer_key (string, optional) - Role.CustomerKey to retrieve.
business_unit_id (string, optional) - Business Unit MID used for SOAP ClientID context.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `users_read`.

Idempotency & limits
- Read-only.

Errors
- ROLE_NOT_FOUND.

Example request

list_role_permissions({})
