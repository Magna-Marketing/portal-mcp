Tool: list_contact_journey_membership

Description
List the journeys (and the activity step they're currently parked at)
that a given contact is enrolled in. Use to answer "what journeys is
this contact in right now?".

Marketing Cloud API
REST API (`/interaction/v1/interactions/contactMembership`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions/contactMembership

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "ContactKeyList": ["MEM-100023"] }

Input (parameters)
contact_keys (string[], required) - Contact keys to check. Salesforce documents a maximum of 50 contact keys per request.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `journeys_read`.

Idempotency & limits
- Read-only.

Errors
- 10000 bad request.

Example request

list_contact_journey_membership({
  "contact_keys": []
})
