Tool: get_contact_exit_status

Description
Check the status of a contact-exit operation queued by
`remove_contact_from_journey`.

Marketing Cloud API
REST API (`/interaction/v1/interactions/contactexit/status`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions/contactexit/status

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
POST: ContactKey, DefinitionKey

Input (parameters)
contact_key (value, required) - ContactKey from the remove-contact request. Salesforce accepts a single contact key or
an array of up to 50 contacts.
definition_key (string, required) - DefinitionKey / journey external key. This is the same for all journey versions.
versions (number[], optional) - Optional journey versions to check. Omit to check the relevant versions Salesforce
returns for the request.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `journeys_read`.

Idempotency & limits
- Read-only.

Errors
- 30002 operation not found.

Example request

get_contact_exit_status({
  "contact_key": "",
  "definition_key": ""
})
