Tool: list_event_definitions

Description
List Journey Builder event definitions: the entry-event schemas
(API events, Data Extension events, Salesforce events, Audience
Builder events) that journeys can listen to. The `eventDefinitionKey`
is what you pass to `inject_contacts_into_journey` /
`fire_journey_entry_event`.

Marketing Cloud API
REST API (`/interaction/v1/eventDefinitions`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/{event_definition_id}
GET https://{tenant}.rest.marketingcloudapis.com/interaction/v1/eventDefinitions/{event_definition_id}
GET https://{tenant}.rest.marketingcloudapis.com/interaction/v1/eventDefinitions/key:{event_definition_key}
GET https://{tenant}.rest.marketingcloudapis.com/interaction/v1/eventDefinitions

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
event_definition_id (string, optional) - Optional event definition ID. When supplied, the tool calls GET
/interaction/v1/eventDefinitions/{id}.
event_definition_key (string, optional) - Optional eventDefinitionKey. When supplied, the tool calls GET
/interaction/v1/eventDefinitions/key:{key}.
name (string, optional) - Optional official Salesforce name query parameter. Salesforce searches the full event
definition name for this value.
page (number, optional) - Salesforce $page value for collection requests. Defaults to 1.
page_size (number, optional) - Salesforce $pageSize value for collection requests. Defaults to 50, maximum 50.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `journeys_read`.

Idempotency & limits
- Read-only.

Errors
- 30002 not found.

Example request

list_event_definitions({})
