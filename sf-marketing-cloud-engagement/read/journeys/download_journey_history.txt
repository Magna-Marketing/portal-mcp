Tool: download_journey_history

Description
Queue a CSV export of a journey's activity history (per-contact, per-
activity events). The export is asynchronous; the response includes a
download Id you can fetch later.

Marketing Cloud API
REST API (`/interaction/v1/interactions/journeyhistory/download`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions/journeyhistory/download?columns=ActivityId,ContactKey,ActivityType,Status,EventDate

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{
  "DefinitionIds": ["abc-journey-id-1"],
  "VersionNumbers": [1, 2],
  "StartDate": "2026-04-01T00:00:00Z",
  "EndDate": "2026-04-30T23:59:59Z",
  "ActivityIds": [],
  "ContactKeys": []
}

Input (parameters)
definition_ids (string[], optional) - Journey definition IDs to include. Salesforce request body field: definitionIds.
definition_instance_ids (string[], optional) - Definition instance IDs to include. Salesforce request body field:
definitionInstanceIds.
activity_ids (string[], optional) - Journey activity IDs to include. Salesforce request body field: activityIds.
activity_types (string[], optional) - Journey activity types to include, for example trigger, emailv2, wait, randomsplit, or
smssync. Salesforce request body field: activityTypes.
contact_keys (string[], optional) - Contact keys to include. Salesforce request body field: contactKeys.
statuses (string[], optional) - Journey history statuses to include, for example complete, failed, waiting, active, or
didnotmeetentrycriteria. Salesforce request body field: statuses.
start (string, optional) - ISO 8601 start timestamp. Salesforce recommends small windows because journey history is
retained for 30 days and downloads cannot be resumed.
end (string, optional) - ISO 8601 end timestamp.
columns ("ActivityId" | "ActivityName" | "ActivityType" | "ClientStatus" | "ContactKey" | "CreatedDate" | "DefinitionId" | "DefinitionInstanceId" | "DefinitionName" | "EndDate" | "EntrySource" | "EpochTimeInMilliseconds" | "EventId" | "EventName" | "Id" | "Message" | "OutcomeActivityId" | "SourceType" | "StartDate" | "Status" | "TransactionTime" | "Result.Messages" | "Result.Outcome" | "Result.Status" | "Result.Tags"[], optional) - Columns query parameter. Salesforce returns only these columns in the downloaded file.
format ("csv" | "tsv", optional) - Output format query parameter. Defaults to csv.
accept_encoding (string, optional) - Optional Accept-Encoding header value such as gzip, deflate, or gzip,deflate.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `journeys_read`.

Idempotency & limits
- Not idempotent — each call queues a new export.
- Large windows can take minutes.

Errors
- 30002 journey not found, INVALID_DATE_RANGE.

Example request

download_journey_history({})
