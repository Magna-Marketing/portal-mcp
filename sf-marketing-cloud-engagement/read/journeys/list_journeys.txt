Tool: list_journeys

Description
List Journey Builder journeys (`/interaction/v1/interactions`). Each
journey row includes Id, name, status (Draft / Published / Stopped /
Paused), version, last published date, and entry mode.

Marketing Cloud API
REST API (`/interaction/v1/interactions`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions
Optional query: $orderBy, $page, $pageSize, definitionType, extras, id, key, mostRecentVersionOnly, nameOrDescription, specificApiVersionNumber, status, tag, versionNumber

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
status (value, optional) - Optional journey status filter. Salesforce supports Deleted, Draft, Paused, Published,
ScheduledToPublish, ScheduledToSend, Sent, Stopped, and Unpublished.
name_or_description (string, optional) - Optional search string sent as the official nameOrDescription query parameter.
Salesforce searches journey names and descriptions.
journey_id (string, optional) - Optional journey ID. When supplied, Salesforce returns all versions of that journey.
journey_key (string, optional) - Optional journey external key filter.
definition_type ("transactional", optional) - Optional definitionType filter. Salesforce currently accepts transactional.
version_number (number, optional) - Optional journey versionNumber filter.
most_recent_version_only (boolean, optional) - Whether Salesforce should return only the most recent version for matching journeys.
Defaults to true.
specific_api_version_number (number, optional) - Optional workflowApiVersion filter. Salesforce defaults this to 1 when omitted.
tag (string, optional) - Optional journey tag filter.
extras (value, optional) - Optional extra data to include: activities, outcome, stats, or all. Avoid all unless
needed because Salesforce documents it as expensive.
page (number, optional) - Salesforce $page value. Defaults to 1.
page_size (number, optional) - Salesforce $pageSize value. Defaults to 50, maximum 50.
order_by (string, optional) - Salesforce $orderBy value. Supported fields include ModifiedDate, Name, and Performance,
with ASC or DESC.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `journeys_read`.

Idempotency & limits
- Read-only.

Errors
- 10000, 401 unauthorized.

Example request

list_journeys({})
