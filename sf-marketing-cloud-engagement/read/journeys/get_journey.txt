Tool: get_journey

Description
Get a journey definition by Id, key, or name + version. Returns the
full canvas: triggers (entry events), activities (email send, SMS,
decision split, wait, custom), connections, and goals.

Marketing Cloud API
REST API (`/interaction/v1/interactions/{id}`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions/{journey_id}
Optional query: extras, versionNumber
GET https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions/key:{journey_key}
Optional query: extras, versionNumber
GET https://{tenant}.rest.marketingcloudapis.com/interaction/v1/eventDefinitions/key:{eventDefinitionKey}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
journey_id (string, optional) - Journey ID for version 1 of the journey. Required when journey_key is omitted.
journey_key (string, optional) - Journey external key. Required when journey_id is omitted. Salesforce expects this as
/interactions/key:{key}.
version_number (number, optional) - Optional journey version number. If omitted, Salesforce returns the latest version.
extras (value, optional) - Optional extra data to include: activities, outcome, stats, or all.
include_audiences (boolean, optional) - When true, this tool also retrieves event definitions referenced by journey triggers and
returns a composite JSON object with raw Salesforce responses.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.
journey (value) - included in the JSON returned by the tool.
eventDefinitions (value) - included in the JSON returned by the tool.

Required scopes
- `journeys_read`.

Idempotency & limits
- Read-only.

Errors
- 30002 not found.

Example request

get_journey({})
