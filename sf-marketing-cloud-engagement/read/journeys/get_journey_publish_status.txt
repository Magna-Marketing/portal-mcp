Tool: get_journey_publish_status

Description
Check the status of a journey-publish operation queued by
`publish_journey`. The publish itself is async; use this to poll
until "Published" or "Failed" with diagnostics.

Marketing Cloud API
REST API (`/interaction/v1/interactions/publishStatus/{statusId}`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/interaction/v1/interactions/publishStatus/{status_id}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
status_id (string, required) - statusId returned by a Journey Builder publishAsync request.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `journeys_read`.

Idempotency & limits
- Read-only.

Errors
- 30002 statusId not found.

Example request

get_journey_publish_status({
  "status_id": ""
})
