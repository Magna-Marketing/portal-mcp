Tool: list_data_extension_fields

Description
List the fields (schema) for a Data Extension. Convenience wrapper for
the schema slice of `get_data_extension`.

Marketing Cloud API
SOAP API (`DataExtensionField.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP request on DataExtension, DataExtensionField.

Input (parameters)
customer_key (string, optional) - DataExtension external key / CustomerKey. Preferred lookup and required for a direct
DataExtensionField retrieve.
de_name (string, optional) - DataExtension name. The tool first retrieves the DataExtension to resolve CustomerKey,
then retrieves fields.
object_id (string, optional) - DataExtension ObjectID. The tool first retrieves the DataExtension to resolve
CustomerKey, then retrieves fields.
properties (string[], optional) - Optional SOAP property projection for DataExtensionField retrieve.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and SOAP ClientID context.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
resolvedCustomerKey (value) - included in the JSON returned by the tool.
lookupResponse (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `data_extensions_read`.

Idempotency & limits
- Read-only.

Errors
- 30002 not found.

Example request

list_data_extension_fields({})
