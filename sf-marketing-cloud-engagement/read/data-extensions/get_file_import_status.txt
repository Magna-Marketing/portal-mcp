Tool: get_file_import_status

Description
Get the status / validation result of a file import queued by
`queue_file_import`. Three views:
- summary: high-level state, processed/failed counts.
- validationsummary: per-validation-rule counts.
- validationresult: detailed per-row validation errors.

Marketing Cloud API
SOAP API.

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx
SOAP object: ImportResultsSummary

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8
Accept: application/json

Body
SOAP request on ImportResultsSummary.

Input (parameters)
task_result_id (value, optional) - TaskResultID returned by starting or queueing an ImportDefinition. Preferred lookup.
operation_id (value, optional) - Alias for task_result_id for compatibility with older docs.
import_definition_customer_key (string, optional) - Optional ImportDefinitionCustomerKey lookup when TaskResultID is unavailable.
properties (string[], optional) - Optional SOAP property projection for ImportResultsSummary retrieve.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and SOAP ClientID context.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `data_extensions_read`.

Idempotency & limits
- Read-only.

Errors
- 30002 operationId not found.

Example request

get_file_import_status({})
