Tool: query_data_extension_rows

Description
Query rows from a Data Extension synchronously. Supports SOAP-style
filters (SimpleFilterPart, ComplexFilterPart) and field projection.
For very large result sets switch to `start_async_retrieve` (write side
since it spawns a job).

Marketing Cloud API
REST API (`/data/v1/customobjectdata/key/{key}/rowset`) for simple
filters, or SOAP `DataExtensionObject[ExternalKey].Retrieve` for
advanced filters.

Endpoint
GET  https://{tenant}.rest.marketingcloudapis.com/data/v1/customobjectdata/key/{customerKey}/rowset
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx     (when filters needed)

Headers
Authorization: Bearer <access_token>
Accept: application/json (REST) or text/xml (SOAP)

Body
SOAP variant: RetrieveRequest with Filter.

Input (parameters)
customer_key (string, required) - DataExtension external key / CustomerKey.
fields (string[], optional) - Optional field projection. Required when api_mode=soap. REST can omit fields to return
all row values.
filter (object, optional) - Optional simple filter object. Converted to REST $filter by default, or SOAP Filter when
api_mode=soap.
raw_filter (string, optional) - Optional raw REST $filter expression, for example "EmailAddress eq
\'person@example.com\'". Used only for REST mode.
soap_filter (value, optional) - Optional advanced SOAP filter tree with {left, operator:"AND"|"OR", right} and simple
operands. Forces SOAP mode.
page (number, optional) - REST $page value. Defaults to 1.
page_size (number, optional) - REST $pageSize value. Defaults to 2500. SOAP retrieve can return up to 2500 rows per
request.
order_by (string, optional) - Optional REST $orderBy expression.
api_mode ("rest" | "soap", optional) - Use REST Data Extension Data API by default. Choose SOAP for advanced SOAP filters or
exact SOAP retrieve behavior.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and REST Account-Context or SOAP ClientID
context.

Result
Raw Marketing Cloud response JSON, returned unchanged.
tool (value) - included in the JSON returned by the tool.
apiMode (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `data_extensions_read`.

Idempotency & limits
- Read-only.
- 100,000 rows per Retrieve (SOAP). For larger, use async.

Errors
- 30002 not found, INVALID_FILTER.

Example request (simple filter)

query_data_extension_rows({
  "customerKey": "Members_DE",
  "fields": ["MemberId","Email","TierName"],
  "filter": { "property": "TierName", "simpleOperator": "equals", "value": "Gold" },
  "top": 1000
})
