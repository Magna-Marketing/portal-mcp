Tool: get_data_extension

Description
Get a single Data Extension by Id, External Key, or name. Returns
identity, schema (fields), retention policy, sendable settings, and row
count.

Marketing Cloud API
SOAP API (`DataExtension.Retrieve` filtered) + `DataExtensionField.Retrieve` for schema.

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP request on DataExtension, DataExtensionField.

Input (parameters)
object_id (string, optional) - DataExtension ObjectID. One of object_id, customer_key, or name is required.
customer_key (string, optional) - DataExtension external key / CustomerKey. One of object_id, customer_key, or name is
required.
name (string, optional) - DataExtension name. Uses a SOAP equals filter. One of object_id, customer_key, or name
is required.
include_fields (boolean, optional) - When true and customer_key is supplied, also retrieves DataExtensionField rows for the
Data Extension.
properties (string[], optional) - Optional SOAP property projection for DataExtension retrieve.
field_properties (string[], optional) - Optional SOAP property projection for DataExtensionField retrieve.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and SOAP ClientID context.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.
fieldsResponse (value) - included in the JSON returned by the tool.

Required scopes
- `data_extensions_read`.

Idempotency & limits
- Read-only.

Errors
- 30002 not found.

Example request

get_data_extension({})
