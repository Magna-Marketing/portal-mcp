Tool: get_async_query_status

Description
Check the status of an asynchronous Data Extension retrieve job
(started by `start_async_retrieve` on the write side). Returns running
state and (when complete) a downloadable result Id.

Marketing Cloud API
REST API (`/data/v1/async/{requestId}/status` and `.../results`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/data/v1/async/{request_id}/status
GET https://{tenant}.rest.marketingcloudapis.com/data/v1/async/{request_id}/results

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
request_id (string, required) - Request ID returned by an asynchronous Data Extension row insert or upsert request.
fetch_results (boolean, optional) - When true, also calls GET /data/v1/async/{requestId}/results and returns that raw
Salesforce response.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and REST Account-Context.

Result
tool (value) - included in the JSON returned by the tool.
status (value) - included in the JSON returned by the tool.
results (value) - included in the JSON returned by the tool.

Required scopes
- `data_extensions_read`.

Idempotency & limits
- Read-only.

Errors
- ASYNC_REQUEST_NOT_FOUND, REQUEST_FAILED.

Example request

get_async_query_status({
  "request_id": ""
})
