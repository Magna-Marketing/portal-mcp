Tool: list_data_extensions

Description
List Data Extensions (`DataExtension`) in the current Business Unit.
Each entry includes identity, External Key (`CustomerKey`), folder,
sendable + testable flags, row count summary.

Marketing Cloud API
SOAP API (`DataExtension.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP RetrieveRequest on `DataExtension`.

Input (parameters)
folder_id (number, optional) - Optional Data Extension folder/category ID. Maps to DataExtension.CategoryID.
name_pattern (string, optional) - Optional SOAP like filter against DataExtension.Name.
customer_key (string, optional) - Optional exact DataExtension CustomerKey filter.
is_sendable (boolean, optional) - Optional exact filter for sendable Data Extensions.
is_testable (boolean, optional) - Optional exact filter for testable Data Extensions.
modified_since (string, optional) - Optional ISO date-time filter for Data Extensions modified after this value.
properties (string[], optional) - Optional SOAP property projection. Defaults to common DataExtension metadata, retention,
sendability, and Client.ID fields.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and SOAP ClientID context.
query_all_accounts (boolean, optional) - Set true to add QueryAllAccounts to the SOAP retrieve when the installed package can
access child Business Units.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `data_extensions_read`.

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_data_extensions({})
