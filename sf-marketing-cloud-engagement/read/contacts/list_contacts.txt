Tool: list_contacts

Description
Search Marketing Cloud Contacts via the Contact Search API. Returns
contacts matching a value across one or more identifiers (Email,
SubscriberKey, MobileNumber, Push Tag, GroupConnect Id, etc.).

Marketing Cloud API
REST API (`/contacts/v1/contacts/search`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/contacts/v1/addresses/search/{attribute_name}
Optional query: $orderBy, $page, $pageSize

Headers
Authorization: Bearer <access_token>
Content-Type: application/json
Accept: application/json

Body
POST: filterConditionOperator, filterConditionValue

Input (parameters)
attribute_name ("ContactKey" | "LastModfiedDate" | "Source" | "Channel" | "Status" | "AudienceID", optional) - Salesforce Contacts API address-search attribute. Valid values: ContactKey,
LastModfiedDate, Source, Channel, Status, AudienceID.
filter_value (string, optional) - Value sent as filterConditionValue. Omit to request all contact addresses for the
selected attribute where the tenant permits unfiltered reads.
filter_operator (string, optional) - Value sent as filterConditionOperator. Salesforce documents Is as the supported
operator.
page (number, optional) - REST $page value. Defaults to 1.
page_size (number, optional) - REST $pageSize value. Defaults to 50. Salesforce examples allow large pages, but very
large pages can time out.
order_by (string, optional) - Optional REST $orderBy value, for example "contactKey asc".
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for
Salesforce Marketing Cloud REST requests.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `audiences_read`.

Idempotency & limits
- Read-only; safe to retry.

Errors
- 10000 (bad request) on invalid searchType.

Example request

list_contacts({})
