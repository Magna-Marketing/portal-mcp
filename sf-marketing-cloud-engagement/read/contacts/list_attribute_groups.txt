Tool: list_attribute_groups

Description
List Contact Builder attribute groups (e.g. "Demographics", "Email
Preferences"). Each group bundles attribute sets that share an entity
type (Person, Behavior, etc.).

Marketing Cloud API
REST API (`/contacts/v1/attributeSetDefinitions/...` and `/contacts/v1/attributeGroups`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/contacts/v1/schemas/{schema_id}/attributeGroups
GET https://{tenant}.rest.marketingcloudapis.com/contacts/v1/schema

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
schema_id (string, optional) - Contact schema ID. When provided, the tool calls GET
/contacts/v1/schemas/{schemaId}/attributeGroups. When omitted, it calls GET
/contacts/v1/schema so you can discover schema IDs first.
attribute_group_id (string, optional) - Optional attribute group ID, key:{key}, or name:{name} under the selected schema.
Requires schema_id.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for
Salesforce Marketing Cloud REST requests.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `audiences_read`.

Idempotency & limits
- Read-only.

Errors
- 10000 bad request.

Example request

list_attribute_groups({})
