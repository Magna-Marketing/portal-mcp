Tool: find_contact_by_email

Description
Look up the Contact Key associated with one or more email addresses
(reverse-lookup). Faster than `list_contacts` when you have email but
need the contactKey.

Marketing Cloud API
REST API (`/contacts/v1/addresses/email/search`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/contacts/v1/addresses/email/search

Headers
Authorization: Bearer <access_token>
Content-Type: application/json

Body
{ "channelAddressList": ["jane.doe@example.com", "john.smith@example.com"], "maximumCount": 100 }

Input (parameters)
emails (string[], required) - Email channel addresses to look up. Salesforce accepts an array of email addresses.
maximum_count (number, optional) - Maximum contact keys to return for each email address. Salesforce defaults to 1.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for
Salesforce Marketing Cloud REST requests.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `audiences_read`.

Idempotency & limits
- Read-only.

Errors
- 10000 bad request.

Example request

find_contact_by_email({
  "emails": []
})
