Tool: get_contact

Description
Get a single contact by ContactKey or ContactID. Returns the contact's
full attribute payload across attribute groups + sets, plus channel
addresses and contact status.

Marketing Cloud API
REST API (`/contacts/v1/contacts/{contactKey}`).

Endpoint
POST https://{tenant}.rest.marketingcloudapis.com/contacts/v1/contacts/search
POST https://{tenant}.rest.marketingcloudapis.com/contacts/v1/addresses/search/ContactKey
Optional query: $page, $pageSize
GET https://{tenant}.rest.marketingcloudapis.com/contacts/v1/contacts/key:{contact_key}/Preferences
GET https://{tenant}.rest.marketingcloudapis.com/contacts/v1/contacts/id:{contact_id}/Preferences

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
POST: conditionSet, request
POST: filterConditionOperator, filterConditionValue

Input (parameters)
contact_key (string, optional) - Contact Key to search for. Provide either contact_key or contact_id.
contact_id (number, optional) - Contact ID to search for. Provide either contact_key or contact_id.
attributes (string[], optional) - Contact Builder attribute keys to request from /contacts/v1/contacts/search, for example
"Contact.Contact Key" or "Email Addresses.Email Address". Defaults to Contact ID and
Contact Key.
include_addresses (boolean, optional) - When contact_key is provided, also call POST /contacts/v1/addresses/search/ContactKey
and return that raw response.
include_preferences (boolean, optional) - Also call the documented contact preferences endpoint by key or ID and return that raw
response.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for
Salesforce Marketing Cloud REST requests.

Result
contactsSearch (value) - included in the JSON returned by the tool.
addressesSearch (value) - included in the JSON returned by the tool.
preferences (value) - included in the JSON returned by the tool.

Required scopes
- `audiences_read`.

Idempotency & limits
- Read-only.

Errors
- 30002 not found.

Example request

get_contact({})
