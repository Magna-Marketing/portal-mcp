Tool: get_contact_delete_request_status

Description
Check the status of contact-delete requests issued via `delete_contact`.
Two views: per-request details (analytics view) and overall summary
(`/summary`).

Marketing Cloud API
REST API (`/contacts/v1/contacts/analytics/deleterequests`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/contacts/v1/contacts/deleteOperations
GET https://{tenant}.rest.marketingcloudapis.com/contacts/v1/contacts/analytics/deleterequests/summary

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
mode ("details" | "summary" | "operations", optional) - details calls the analytics detail endpoint, summary calls the analytics summary
endpoint, and operations calls the deleteOperations endpoint.
start_date_utc (string, optional) - UTC range start for analytics endpoints. Defaults to since_days ago.
end_date_utc (string, optional) - UTC range end for analytics endpoints. Defaults to now.
since_days (number, optional) - Fallback date range length when start_date_utc or end_date_utc is omitted. Defaults to
30.
status_id (value, optional) - Optional analytics status filter. Valid values: 1 Processing, 5 Completed, 7 Invalid.
page (number, optional) - REST $page value for details or operations. Defaults to 1.
page_size (number, optional) - REST $pagesize/$pageSize value. Defaults to 100.
order_by (string, optional) - Optional REST $orderBy value for analytics details. Defaults to operationId desc.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for
Salesforce Marketing Cloud REST requests.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `audiences_read`.

Idempotency & limits
- Read-only.

Errors
- 403 unauthorized (no compliance entitlement).

Example request

get_contact_delete_request_status({})
