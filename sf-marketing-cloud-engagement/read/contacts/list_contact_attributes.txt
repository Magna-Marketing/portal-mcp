Tool: list_contact_attributes

Description
List attribute definitions in Contact Builder (the Contact Model's
schema): name, type, attribute set, attribute group, default value,
data extension binding.

Marketing Cloud API
REST API (`/contacts/v1/attributes`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/contacts/v1/attributeSetDefinitions/{attribute_set_definition_id}
Optional query: $page, $pageSize
GET https://{tenant}.rest.marketingcloudapis.com/contacts/v1/attributeSetDefinitions
Optional query: $page, $pageSize

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
attribute_set_definition_id (string, optional) - Optional attribute set definition ID. When omitted, all attribute set definitions in the
Contact Model are returned.
page (number, optional) - Optional REST $page value if the tenant supports pagination on this endpoint.
page_size (number, optional) - Optional REST $pageSize value if the tenant supports pagination on this endpoint.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for
Salesforce Marketing Cloud REST requests.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `audiences_read`.

Idempotency & limits
- Read-only.

Errors
- 10000 bad request.

Example request

list_contact_attributes({})
