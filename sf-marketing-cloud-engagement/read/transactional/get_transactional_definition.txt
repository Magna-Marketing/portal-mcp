Tool: get_transactional_definition

Description
Get a single Transactional Messaging definition with its full content
reference, classification, sender, and send queue summary.

Marketing Cloud API
REST API (`/messaging/v1/{type}/definitions/{key}`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/messaging/v1/{type}/definitions/{definition_key}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
type ("email" | "sms", required) - Transactional channel. Use email for /messaging/v1/email/definitions/{definitionKey} or
sms for /messaging/v1/sms/definitions/{definitionKey}.
definition_key (string, required) - Unique Transactional Messaging send definition key.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
Transactional Messaging REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `email_send` / `sms_send`.

Idempotency & limits
- Read-only.

Errors
- 30002 not found.

Example request

get_transactional_definition({
  "type": "email",
  "definition_key": ""
})
