Tool: get_transactional_send_status

Description
Get the queue status / per-message send status for a Transactional
Messaging definition. Track individual messages by `messageKey`.

Marketing Cloud API
REST API (`/messaging/v1/{type}/messages/{messageKey}` and `/queueMetrics`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/messaging/v1/{type}/messages/{message_key}
GET https://{tenant}.rest.marketingcloudapis.com/messaging/v1/{type}/definitions/{definition_key}/queue

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
type ("email" | "sms", required) - Transactional channel. Use email or sms.
message_key (string, optional) - Message key for a single recipient send status. Calls GET
/messaging/v1/{email|sms}/messages/{messageKey}.
definition_key (string, optional) - Definition key for aggregate queue metrics. Calls GET
/messaging/v1/{email|sms}/definitions/{definitionKey}/queue.
business_unit_id (string, optional) - Business Unit MID used to scope the access token and Account-Context header for this
Transactional Messaging REST request.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `email_send` / `sms_send`.

Idempotency & limits
- Read-only.

Errors
- 30002 not found.

Example request

get_transactional_send_status({
  "type": "email"
})
