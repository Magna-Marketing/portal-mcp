Tool: get_send_time_optimization

Description
Get Einstein Send Time Optimization (STO) results for a contact / DE
of contacts: the predicted best hour-of-day to send for engagement.

Marketing Cloud API
REST API (`/sts/v1/timezone` and Einstein STO endpoints).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/sts/v1/persona/contact/{contactKey}
GET https://{tenant}.rest.marketingcloudapis.com/sts/v1/persona/de/{deCustomerKey}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
contact_key (string, optional) - Contact/subscriber key for a single Einstein Send Time Optimization persona lookup.
data_extension_customer_key (string, optional) - Data Extension external key for an Einstein Send Time Optimization bulk persona lookup.
channel ("Email" | "Push" | "SMS", optional) - Einstein STO channel hint sent as a query parameter when provided. Supported values:
Email, Push, SMS.
business_unit_id (string, optional) - Business Unit MID used to scope authentication and the Account-Context header for
Salesforce Marketing Cloud REST requests.

Result
Raw Marketing Cloud response JSON, returned unchanged.

Required scopes
- `audiences_read` + Einstein license.

Idempotency & limits
- Read-only.
- Requires Einstein STO entitlement; returns 403 otherwise.

Errors
- 403 unauthorized (no STO entitlement), 30002 not found.

Example request

get_send_time_optimization({})
