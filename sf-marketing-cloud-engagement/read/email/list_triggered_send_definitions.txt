Tool: list_triggered_send_definitions

Description
List `TriggeredSendDefinition` records — the configurations behind
triggered sends (single emails fired from APIs / Journey Builder).
Each definition has its email asset, send classification, status (Active
/ Inactive / Paused), and per-call options.

Marketing Cloud API
SOAP API (`TriggeredSendDefinition.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP retrieve on TriggeredSendDefinition.

Input (parameters)
status (value, optional) - TriggeredSendDefinition status filter. Accepts one or more statuses.
namePattern (string, optional) - SOAP like filter for TriggeredSendDefinition.Name. Include Marketing Cloud wildcards if
needed.
folderId (number, optional) - TriggeredSendDefinition category/folder ID. Sent as CategoryID.
emailId (number, optional) - Filter definitions by associated Email.ID.
emailCustomerKey (string, optional) - Deprecated: TriggeredSendDefinition retrieve does not support Email.CustomerKey filters.
Use emailId instead.
limit (number, optional) - SOAP retrieve batch size. Defaults to 200, maximum 2500.
business_unit_id (string, optional) - Business Unit MID used to scope the Marketing Cloud token and SOAP ClientID context.
Defaults to the authenticated Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
limit (value) - included in the JSON returned by the tool.
filter (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `email_read`.

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_triggered_send_definitions({})
