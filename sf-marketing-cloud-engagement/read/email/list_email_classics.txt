Tool: list_email_classics

Description
List classic Email Studio emails (`Email`). For Content Builder
HTML / template assets use `list_assets` with `assetTypeId=208`
(htmlemail) instead.

Marketing Cloud API
SOAP API (`Email.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP retrieve on Email.

Input (parameters)
folderId (number, optional) - Classic Email Studio folder/category ID. Sent as an Email.CategoryID SOAP filter.
namePattern (string, optional) - SOAP like filter for Email.Name. Include Marketing Cloud wildcards if needed.
modifiedSince (string, optional) - ISO date-time filter for Email.ModifiedDate greater than this value.
emailType ("Standard" | "Triggered" | "Welcome", optional) - Classic Email Studio email type filter. Content Builder emails should be queried with
list_assets.
limit (number, optional) - SOAP retrieve batch size. Defaults to 200, maximum 2500.
business_unit_id (string, optional) - Business Unit MID used to scope the Marketing Cloud token and SOAP ClientID context.
Defaults to the authenticated Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
limit (value) - included in the JSON returned by the tool.
filter (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `email_read`.

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_email_classics({})
