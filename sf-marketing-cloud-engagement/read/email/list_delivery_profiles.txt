Tool: list_delivery_profiles

Description
List `DeliveryProfile` records (delivery settings, Sender
Authentication Package, BCC behavior, dynamic email).

Marketing Cloud API
SOAP API (`DeliveryProfile.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP retrieve on DeliveryProfile.

Input (parameters)
namePattern (string, optional) - SOAP like filter for DeliveryProfile.Name. Include Marketing Cloud wildcards if needed.
limit (number, optional) - SOAP retrieve batch size. Defaults to 200, maximum 2500.
business_unit_id (string, optional) - Business Unit MID used to scope the Marketing Cloud token and SOAP ClientID context.
Defaults to the authenticated Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
namePattern (value) - included in the JSON returned by the tool.
limit (value) - included in the JSON returned by the tool.
supported (value) - included in the JSON returned by the tool.
message (value) - included in the JSON returned by the tool.
alternatives (value) - included in the JSON returned by the tool.

Required scopes
- `email_read`.

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_delivery_profiles({})
