Tool: list_send_classifications

Description
List `SendClassification` records. A Send Classification bundles a
Sender Profile and Delivery Profile and is required on most send
endpoints (Triggered Sends, Automations, Journey email activities).

Marketing Cloud API
SOAP API (`SendClassification.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP retrieve on SendClassification.

Input (parameters)
classificationType (string, optional) - SendClassificationType filter, for example "Default Commercial" or "Default
Transactional".
namePattern (string, optional) - SOAP like filter for SendClassification.Name. Include Marketing Cloud wildcards if
needed.
limit (number, optional) - SOAP retrieve batch size. Defaults to 200, maximum 2500.
business_unit_id (string, optional) - Business Unit MID used to scope the Marketing Cloud token and SOAP ClientID context.
Defaults to the authenticated Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
limit (value) - included in the JSON returned by the tool.
filter (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `email_read`.

Idempotency & limits
- Read-only.

Errors
- INSUFFICIENT_ACCESS_OR_READONLY.

Example request

list_send_classifications({})
