Tool: get_send_status

Description
Get the status of a Send (one queued/in-progress/completed email
batch). Returns identity, status, queued/sent/delivered/opened/clicked
counts, scheduled time.

Marketing Cloud API
SOAP API (`Send.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP retrieve on Send filtered by ID.

Input (parameters)
sendId (number, optional) - Marketing Cloud Send.ID to retrieve.
sendCustomerKey (string, optional) - Marketing Cloud Send.CustomerKey to retrieve.
emailCustomerKey (string, optional) - Unsupported by SOAP Send.Retrieve filters. Use sendId or sendCustomerKey instead.
recentOnly (boolean, optional) - Deprecated. SOAP Send.Retrieve does not support latest-send lookups by emailCustomerKey.
limit (number, optional) - SOAP retrieve batch size. Defaults to 200, maximum 2500.
business_unit_id (string, optional) - Business Unit MID used to scope the Marketing Cloud token and SOAP ClientID context.
Defaults to the authenticated Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
limit (value) - included in the JSON returned by the tool.
filter (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `email_read`.

Idempotency & limits
- Read-only.

Errors
- SEND_NOT_FOUND.

Example request

get_send_status({})
