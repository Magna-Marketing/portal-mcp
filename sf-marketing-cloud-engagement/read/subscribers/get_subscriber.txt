Tool: get_subscriber

Description
Get a single subscriber by SubscriberKey or Email. Returns identity,
overall status, list memberships, attributes, and ACK / unsubscribe
metadata.

Marketing Cloud API
SOAP API (`Subscriber.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP retrieve filtered by SubscriberKey or EmailAddress.

Input (parameters)
subscriber_key (string, optional) - Exact Subscriber.SubscriberKey. One of subscriber_key, email_address, or subscriber_id
is required.
email_address (string, optional) - Exact Subscriber.EmailAddress. One of subscriber_key, email_address, or subscriber_id is
required.
subscriber_id (number, optional) - Numeric SOAP Subscriber.ID. One of subscriber_key, email_address, or subscriber_id is
required.
include_list_memberships (boolean, optional) - When true, requests the Subscriber.Lists property from SOAP.
include_attributes (boolean, optional) - When true, requests the Subscriber.Attributes property from SOAP.
query_all_accounts (boolean, optional) - Sets SOAP QueryAllAccounts=true. Defaults to false so business_unit_id scoping remains
precise.
business_unit_id (string, optional) - Business Unit MID used to scope the token and SOAP ClientID context. Defaults to the
authenticated Business Unit.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
limit (value) - included in the JSON returned by the tool.
filter (value) - included in the JSON returned by the tool.
queryAllAccounts (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `list_and_subscribers_read`.

Idempotency & limits
- Read-only.

Errors
- SUBSCRIBER_NOT_FOUND.

Example request

get_subscriber({})
