Tool: list_event_subscriptions

Description
List Event Notification Service subscriptions. Each subscription binds
a callback (`callbackId`) to one or more event categories
(EngagementEvents, TransactionalSendEvents, JourneyEvents, etc.).

Marketing Cloud API
REST API (`/platform/v1/ens-subscriptions`).

Endpoint
GET https://{tenant}.rest.marketingcloudapis.com/platform/v1/ens-subscriptions/{subscription_id}
GET https://{tenant}.rest.marketingcloudapis.com/platform/v1/ens-subscriptions-by-cb/{callback_id}

Headers
Authorization: Bearer <access_token>
Accept: application/json

Body
None.

Input (parameters)
subscription_id (string, optional) - ENS subscriptionId for GET /platform/v1/ens-subscriptions/{subscriptionId}.
callback_id (string, optional) - ENS callbackId for GET /platform/v1/ens-subscriptions-by-cb/{callbackId}.
business_unit_id (string, optional) - Business Unit MID used to scope authentication plus SOAP ClientID context or REST
Account-Context. Defaults to the authenticated Business Unit.

Result
subscriptions (array) - { subscriptionId, subscriptionName, callbackId, subscribedEventCategories, filters, status ("Active"|"Inactive"), createdDate, lastModifiedDate }.

Required scopes
- `webhooks_read`.

Idempotency & limits
- Read-only.

Errors
- 30002 not found.

Example request

list_event_subscriptions({})
