Tool: list_sends

Description
List recent send-tracking events (`SentEvent`). One row per
subscriber-per-send: when the platform actually queued/sent the email
to the SubscriberKey.

Marketing Cloud API
SOAP API (`SentEvent.Retrieve`).

Endpoint
POST https://{tenant}.soap.marketingcloudapis.com/Service.asmx

Headers
Authorization: Bearer <access_token>
Content-Type: text/xml; charset=utf-8

Body
SOAP retrieve on SentEvent with EventDate filter.

Input (parameters)
since_days (number, optional) - Look back this many days using SentEvent.EventDate. Ignored when start_date or
continue_request_id is provided.
start_date (string, optional) - ISO date/time lower bound for SentEvent.EventDate. Overrides since_days.
end_date (string, optional) - ISO date/time upper bound for SentEvent.EventDate.
send_id (number, optional) - Filter by Salesforce Marketing Cloud SendID / JobID.
subscriber_key (string, optional) - Filter by SubscriberKey.
batch_id (number, optional) - Filter by BatchID for triggered send batches.
limit (number, optional) - SOAP Retrieve batch size. Defaults to 1000, maximum 2500. Salesforce returns at most 2,500
records per request.
continue_request_id (string, optional) - SOAP RequestID from a prior response with MoreDataAvailable. When provided, the tool
calls ContinueRequest and ignores filter fields.
properties (string[], optional) - Optional SOAP property projection. Defaults to verified useful properties for this
tracking event type.
business_unit_id (string, optional) - Business Unit MID used to scope authentication plus SOAP ClientID context or REST
Account-Context. Defaults to the authenticated Business Unit.
query_all_accounts (boolean, optional) - SOAP only. Set true to include QueryAllAccounts when the installed package can retrieve
from accessible child Business Units.

Result
tool (value) - included in the JSON returned by the tool.
objectType (value) - included in the JSON returned by the tool.
businessUnitId (value) - included in the JSON returned by the tool.
limit (value) - included in the JSON returned by the tool.
filter (value) - included in the JSON returned by the tool.
queryAllAccounts (value) - included in the JSON returned by the tool.
continueRequestId (value) - included in the JSON returned by the tool.
response (value) - included in the JSON returned by the tool.

Required scopes
- `tracking_events_read`.

Idempotency & limits
- Read-only.
- Tracking event volume can be large; prefer narrow time windows.

Errors
- 401 unauthorized.

Example request

list_sends({})
